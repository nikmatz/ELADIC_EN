1. What is proved: the statement in the book and in Lean

  • If $0\le f(x)\le g(x)$ for $x\ge a$ and $\int_a^{+\infty}g\,dx$ converges, then $\int_a^{+\infty}f\,dx$ also converges
    theorem comparison (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hg : IntegrableOn g (Set.Ioi a)) : IntegrableOn f (Set.Ioi a)
  • If $\int_a^{+\infty}f\,dx$ diverges, then $\int_a^{+\infty}g\,dx$ also diverges
    theorem comparison_diverges (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hdiv : ¬ IntegrableOn f (Set.Ioi a)) : ¬ IntegrableOn g (Set.Ioi a)
  • Connection with the definition in the book: for integrable $f$, $\int_a^R f\,dx\to\int_a^{+\infty}f\,dx$ as $R\to+\infty$
    theorem limit_of_integrable (f : ℝ → ℝ) (a : ℝ) (hf : IntegrableOn f (Set.Ioi a)) :
    Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 (∫ x in Set.Ioi a, f x))
  • and conversely, for $f\ge 0$: if $\int_a^R f\,dx$ has a limit as $R\to+\infty$, then $f$ is integrable on $(a,+\infty)$
    theorem integrable_of_limit (f : ℝ → ℝ) (a L : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x)
    (hlim : Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 L)) : IntegrableOn f (Set.Ioi a)

In Mathlib, the convergence of the improper integral $\int_a^{+\infty}f\,dx$ is expressed as integrability on $(a,+\infty)$: IntegrableOn f (Set.Ioi a). For nonnegative functions this is exactly convergence in the sense of the book, as the last two theorems show: $\int_a^R f\,dx$ has a limit as $R\to+\infty$ exactly when $f$ is integrable. For simplicity we assume $f$ continuous for $x\ge a$, so that it is integrable on every $[a,R]$; the book requires only this integrability. The set of $x\ge a$ is written Set.Ici a and $(a,+\infty)$ is written Set.Ioi a.

2. Where it is in Mathlib

We used the following theorems:

  • MeasureTheory.Integrable.mono': if $|f|\le g$ and $g$ is integrable, then $f$ is also integrable.
  • ContinuousOn.aestronglyMeasurable: a technical measurability condition, which holds for continuous functions.
  • MeasureTheory.ae_restrict_of_forall_mem: whatever holds at every point of a set also holds “almost everywhere” on it.
  • MeasureTheory.intervalIntegral_tendsto_integral_Ioi: $\int_a^R f\,dx\to\int_a^{+\infty}f\,dx$ for integrable $f$.
  • MeasureTheory.integrableOn_Ioi_of_intervalIntegral_norm_tendsto: if $\int_a^R|f|\,dx$ has a limit, then $f$ is integrable on $(a,+\infty)$.
  • intervalIntegral.integral_congr: functions that are equal on the interval have equal integrals.

-- Chapter 18 · The Comparison Test for Improper Integrals · checked with Lean v4.37.0-rc1 and Mathlib (23/11/2026).

import Mathlib

namespace Ch18.KritirioSygkrisis
open MeasureTheory Filter Topology

-- for nonnegative f, “the integral from a to +∞ converges” is written IntegrableOn f (Set.Ioi a)
theorem comparison (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hg : IntegrableOn g (Set.Ioi a)) : IntegrableOn f (Set.Ioi a) := by
  refine Integrable.mono' hg ((hf.mono Set.Ioi_subset_Ici_self).aestronglyMeasurable measurableSet_Ioi)
    (ae_restrict_of_forall_mem measurableSet_Ioi fun x hx => ?_)
  rw [Real.norm_eq_abs, abs_of_nonneg (hf0 x (Set.Ioi_subset_Ici_self hx))]
  exact hfg x (Set.Ioi_subset_Ici_self hx)

theorem comparison_diverges (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hdiv : ¬ IntegrableOn f (Set.Ioi a)) : ¬ IntegrableOn g (Set.Ioi a) :=
  fun hg => hdiv (comparison f g a hf hf0 hfg hg)

-- connection with the definition in the book (1): then the integral from a to R has a limit as R → +∞
theorem limit_of_integrable (f : ℝ → ℝ) (a : ℝ) (hf : IntegrableOn f (Set.Ioi a)) :
    Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 (∫ x in Set.Ioi a, f x)) :=
  intervalIntegral_tendsto_integral_Ioi a hf tendsto_id

-- connection with the definition in the book (2): for nonnegative f the converse also holds
theorem integrable_of_limit (f : ℝ → ℝ) (a L : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x)
    (hlim : Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 L)) : IntegrableOn f (Set.Ioi a) := by
  refine integrableOn_Ioi_of_intervalIntegral_norm_tendsto L a (fun R => ?_) tendsto_id ?_
  · exact ((hf.mono Set.Icc_subset_Ici_self).integrableOn_Icc).mono_set Set.Ioc_subset_Icc_self
  · refine hlim.congr' ((eventually_ge_atTop a).mono fun R hR => ?_)
    show ∫ x in a..R, f x = ∫ x in a..R, ‖f x‖
    refine intervalIntegral.integral_congr fun x hx => ?_
    rw [Set.uIcc_of_le hR] at hx
    simp only [Real.norm_eq_abs, abs_of_nonneg (hf0 x hx.1)]

end Ch18.KritirioSygkrisis
