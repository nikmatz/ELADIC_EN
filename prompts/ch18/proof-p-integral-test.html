1. What is proved: the statement in the book and in Lean

  • (a) For $a\gt 0$: $\int_a^{+\infty}\dfrac{dx}{x^p}$ converges if and only if $p\gt 1$
    theorem p_test_infinity (a p : ℝ) (ha : 0 < a) :
    IntegrableOn (fun x : ℝ => 1 / x ^ p) (Set.Ioi a) ↔ 1 < p
  • $\int_1^{+\infty}\dfrac{dx}{x^p}$${}=\dfrac{1}{p-1}$ for $p\gt 1$
    theorem p_value_infinity (p : ℝ) (hp : 1 < p) : ∫ x in Set.Ioi 1, 1 / x ^ p = 1 / (p - 1)
  • (b) $\int_0^{1}\dfrac{dx}{x^p}$ converges if and only if $p\lt 1$
    theorem p_test_zero (p : ℝ) : IntegrableOn (fun x : ℝ => 1 / x ^ p) (Set.Ioo 0 1) ↔ p < 1
  • $\int_0^{1}\dfrac{dx}{x^p}$${}=\dfrac{1}{1-p}$ for $p\lt 1$
    theorem p_value_zero (p : ℝ) (hp : p < 1) : ∫ x in (0 : ℝ)..1, 1 / x ^ p = 1 / (1 - p)

The convergence of the improper integral of a positive function is written as integrability: on $(a,+\infty)$ (Set.Ioi a) for the integral of the first kind and on $(0,1)$ (Set.Ioo 0 1) for the integral of the second kind. The power $x^p$ with real exponent is written x ^ p. The proof writes $\dfrac{1}{x^p}=x^{-p}$ for $x\gt 0$ and uses the corresponding Mathlib theorems for $x^{s}$. In both cases the value $p=1$ falls on the side of divergence. The value of the integral of the second kind is written as an integral from $0$ to $1$; the value of the function at the point $0$ does not affect the integral.

2. Where it is in Mathlib

We used the following theorems:

  • integrableOn_Ioi_rpow_iff: $x^{s}$ is integrable on $(a,+\infty)$, $a\gt 0$, exactly when $s\lt -1$.
  • integral_Ioi_rpow_of_lt: the value of $\int_a^{+\infty}x^{s}\,dx$ for $s\lt -1$.
  • intervalIntegral.integrableOn_Ioo_rpow_iff: $x^{s}$ is integrable on $(0,t)$ exactly when $s\gt -1$.
  • integral_rpow: $\int_a^b x^{r}\,dx$${}=\dfrac{b^{r+1}-a^{r+1}}{r+1}$.
  • Real.rpow_neg: $x^{-p}=\dfrac{1}{x^p}$ for $x\ge 0$.
  • MeasureTheory.integrableOn_congr_fun: functions that are equal on a set are integrable there together.
  • MeasureTheory.setIntegral_congr_fun: functions that are equal on a set have equal integrals there.
  • intervalIntegral.integral_congr: functions that are equal on the interval have equal integrals.

import Mathlib

namespace Ch18.KritirioP
open MeasureTheory

-- (a) for a > 0, the integral of 1/x^p from a to +∞ converges exactly when p > 1
theorem p_test_infinity (a p : ℝ) (ha : 0 < a) :
    IntegrableOn (fun x : ℝ => 1 / x ^ p) (Set.Ioi a) ↔ 1 < p := by
  have h : Set.EqOn (fun x : ℝ => 1 / x ^ p) (fun x => x ^ (-p)) (Set.Ioi a) := fun x hx => by
    simp only [Real.rpow_neg (ha.trans (Set.mem_Ioi.mp hx)).le, one_div]
  rw [integrableOn_congr_fun h measurableSet_Ioi, integrableOn_Ioi_rpow_iff ha]
  constructor <;> intro h <;> linarith

theorem p_value_infinity (p : ℝ) (hp : 1 < p) : ∫ x in Set.Ioi 1, 1 / x ^ p = 1 / (p - 1) := by
  have h : Set.EqOn (fun x : ℝ => 1 / x ^ p) (fun x => x ^ (-p)) (Set.Ioi 1) := fun x hx => by
    simp only [Real.rpow_neg (zero_le_one.trans (Set.mem_Ioi.mp hx).le), one_div]
  rw [setIntegral_congr_fun measurableSet_Ioi h, integral_Ioi_rpow_of_lt (a := -p) (by linarith) one_pos,
    Real.one_rpow]
  have h1 : -p + 1 ≠ 0 := ne_of_lt (by linarith)
  have h2 : p - 1 ≠ 0 := ne_of_gt (by linarith)
  field_simp
  ring

-- (b) the integral of 1/x^p from 0 to 1 converges exactly when p < 1
theorem p_test_zero (p : ℝ) : IntegrableOn (fun x : ℝ => 1 / x ^ p) (Set.Ioo 0 1) ↔ p < 1 := by
  have h : Set.EqOn (fun x : ℝ => 1 / x ^ p) (fun x => x ^ (-p)) (Set.Ioo 0 1) := fun x hx => by
    simp only [Real.rpow_neg hx.1.le, one_div]
  rw [integrableOn_congr_fun h measurableSet_Ioo, intervalIntegral.integrableOn_Ioo_rpow_iff one_pos]
  constructor <;> intro h <;> linarith

theorem p_value_zero (p : ℝ) (hp : p < 1) : ∫ x in (0 : ℝ)..1, 1 / x ^ p = 1 / (1 - p) := by
  have h : Set.EqOn (fun x : ℝ => 1 / x ^ p) (fun x => x ^ (-p)) (Set.uIcc 0 1) := fun x hx => by
    rw [Set.uIcc_of_le zero_le_one] at hx
    simp only [Real.rpow_neg hx.1, one_div]
  have h1 : -p + 1 ≠ 0 := ne_of_gt (by linarith)
  rw [intervalIntegral.integral_congr h, integral_rpow (r := -p) (Or.inl (by linarith)), Real.one_rpow,
    Real.zero_rpow h1]
  ring

end Ch18.KritirioP
