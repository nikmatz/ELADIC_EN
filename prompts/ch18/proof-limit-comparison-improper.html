The Limit Comparison Test (improper integrals)

Chapter 18 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $f(x)>0$, $g(x)>0$ for $x\ge a$, integrable on every $[a,R]$, with $\lim_{x\to+\infty}\dfrac{f(x)}{g(x)}=L$ and $0<L<+\infty$. Then $\int_a^{+\infty}f(x)\,dx$ and $\int_a^{+\infty}g(x)\,dx$ converge or diverge together. An analogous test holds for improper integrals of the second kind, with the limit taken at the singular point.

1. What is proved: the statement in the book and in Lean

  • If $g(x)\gt 0$ for $x\ge a$ and $\lim_{x\to+\infty}\dfrac{f(x)}{g(x)}$${}=L$ with $0\lt L\lt+\infty$, then $\int_a^{+\infty}f\,dx$ and $\int_a^{+\infty}g\,dx$ converge or diverge together
    theorem limit_comparison (f g : ℝ → ℝ) (a L : ℝ) (hL : 0 < L)
    (hf : ContinuousOn f (Set.Ici a)) (hg : ContinuousOn g (Set.Ici a))
    (hg0 : ∀ x ∈ Set.Ici a, 0 < g x)
    (hlim : Tendsto (fun x => f x / g x) atTop (𝓝 L)) :
    IntegrableOn f (Set.Ici a) ↔ IntegrableOn g (Set.Ici a)

The convergence of $\int_a^{+\infty}f\,dx$ is written IntegrableOn f (Set.Ici a), as in the comparison test; whether we take $[a,+\infty)$ or $(a,+\infty)$ makes no difference. We assume $f,g$ continuous for $x\ge a$, so that they are integrable on every $[a,R]$. The hypothesis $f\gt 0$ of the book is not needed: from $\dfrac{f}{g}\to L\gt 0$ it follows that $f\gt 0$ for large $x$. The proof shows that, for large $x$, each of the two functions is bounded by a multiple of the other (notation f =O[atTop] g), and applies the comparison. The analogous test for integrals of the second kind is not stated here.

2. Where it is in Mathlib

We used the following theorems:

  • Asymptotics.isBigO_of_div_tendsto_nhds: if $\dfrac{f}{g}\to c$, then $f$ is bounded by a multiple of $g$ for large $x$.
  • Filter.Tendsto.inv₀: if $u\to L\neq 0$, then $\dfrac{1}{u}\to\dfrac{1}{L}$.
  • MeasureTheory.LocallyIntegrableOn.integrableOn_of_isBigO_atTop: comparison at infinity for integrals.
  • ContinuousOn.locallyIntegrableOn: a continuous function is integrable on every closed interval.
  • MeasureTheory.integrableAtFilter_atTop_iff: integrability “at infinity”.

import Mathlib

namespace Ch18.OriakoKritirio
open MeasureTheory Filter Topology Asymptotics

theorem limit_comparison (f g : ℝ → ℝ) (a L : ℝ) (hL : 0 < L)
    (hf : ContinuousOn f (Set.Ici a)) (hg : ContinuousOn g (Set.Ici a))
    (hg0 : ∀ x ∈ Set.Ici a, 0 < g x)
    (hlim : Tendsto (fun x => f x / g x) atTop (𝓝 L)) :
    IntegrableOn f (Set.Ici a) ↔ IntegrableOn g (Set.Ici a) := by
  -- f = O(g) as x → +∞, because f/g → L
  have hfg : f =O[atTop] g := by
    refine isBigO_of_div_tendsto_nhds ?_ L hlim
    filter_upwards [eventually_ge_atTop a] with x hx h0
    exact absurd h0 (hg0 x hx).ne'
  -- g = O(f) as x → +∞, because g/f → 1/L
  have hgf : g =O[atTop] f := by
    have hinv : Tendsto (fun x => g x / f x) atTop (𝓝 L⁻¹) := by
      refine (hlim.inv₀ hL.ne').congr' ?_
      filter_upwards with x
      exact inv_div (f x) (g x)
    refine isBigO_of_div_tendsto_nhds ?_ L⁻¹ hinv
    filter_upwards [hlim.eventually (lt_mem_nhds hL)] with x hx h0
    rw [h0, zero_div] at hx
    exact absurd hx (lt_irrefl 0)
  -- comparison at infinity: the continuous f, g are integrable on every [a, R]
  constructor
  · intro hfi
    exact (hg.locallyIntegrableOn measurableSet_Ici).integrableOn_of_isBigO_atTop hgf
      (integrableAtFilter_atTop_iff.mpr ⟨a, hfi⟩)
  · intro hgi
    exact (hf.locallyIntegrableOn measurableSet_Ici).integrableOn_of_isBigO_atTop hfg
      (integrableAtFilter_atTop_iff.mpr ⟨a, hgi⟩)

end Ch18.OriakoKritirio
