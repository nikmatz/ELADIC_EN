1. What is proved: the statement in the book and in Lean

  • $\int_a^b f=-\int_b^a f$
    theorem reverse_limits (f : ℝ → ℝ) (a b : ℝ) : ∫ x in a..b, f x = -∫ x in b..a, f x
  • $\int_a^a f=0$
    theorem equal_limits (f : ℝ → ℝ) (a : ℝ) : ∫ x in a..a, f x = 0
  • $\int_a^b (Af+Bg)$${}=A\int_a^b f+B\int_a^b g$
    theorem linear_add (f g : ℝ → ℝ) (A B a b : ℝ) (hf : IntervalIntegrable f volume a b)
    (hg : IntervalIntegrable g volume a b) :
    ∫ x in a..b, (A * f x + B * g x) = A * (∫ x in a..b, f x) + B * ∫ x in a..b, g x
  • $\int_a^b (Af-Bg)$${}=A\int_a^b f-B\int_a^b g$
    theorem linear_sub (f g : ℝ → ℝ) (A B a b : ℝ) (hf : IntervalIntegrable f volume a b)
    (hg : IntervalIntegrable g volume a b) :
    ∫ x in a..b, (A * f x - B * g x) = A * (∫ x in a..b, f x) - B * ∫ x in a..b, g x
  • $\int_a^b f=\int_a^c f+\int_c^b f$
    theorem additivity (f : ℝ → ℝ) (a b c : ℝ) (hac : IntervalIntegrable f volume a c)
    (hcb : IntervalIntegrable f volume c b) :
    ∫ x in a..b, f x = (∫ x in a..c, f x) + ∫ x in c..b, f x
  • If $f\ge 0$ on $[a,b]$, then $\int_a^b f\ge 0$
    theorem nonneg_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hf : ∀ x ∈ Set.Icc a b, 0 ≤ f x) :
    0 ≤ ∫ x in a..b, f x
  • If $f\le g$ on $[a,b]$, then $\int_a^b f\le\int_a^b g$
    theorem mono_integral (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hf : IntervalIntegrable f volume a b)
    (hg : IntervalIntegrable g volume a b) (hfg : ∀ x ∈ Set.Icc a b, f x ≤ g x) :
    ∫ x in a..b, f x ≤ ∫ x in a..b, g x

The integral $\int_a^b f(x)\,dx$ is written ∫ x in a..b, f x, and “$f$ is integrable on $[a,b]$” is written IntervalIntegrable f volume a b. Mathlib uses the Lebesgue integral, which is more general than the Riemann integral of the book: every function that is Riemann integrable on $[a,b]$ is also Lebesgue integrable, with the same integral. So the properties also hold for the functions of the book. The convention $\int_a^b f=-\int_b^a f$ is a theorem in Mathlib: the integral is also defined when $a\gt b$, with the opposite sign. Additivity holds for any position of $c$, as long as $f$ is integrable on the two intervals. In the two inequalities we assume $a\le b$. For $\int_a^b f\ge 0$ integrability is not even needed, because in Mathlib the integral of a non-integrable function is defined to be $0$.

2. Where it is in Mathlib

We used the following theorems:

  • intervalIntegral.integral_symm: $\int_b^a f=-\int_a^b f$.
  • intervalIntegral.integral_same: $\int_a^a f=0$.
  • intervalIntegral.integral_add: the integral of a sum.
  • intervalIntegral.integral_sub: the integral of a difference.
  • intervalIntegral.integral_const_mul: $\int_a^b c\,f=c\int_a^b f$.
  • IntervalIntegrable.const_mul: if $f$ is integrable, so is $c\,f$.
  • intervalIntegral.integral_add_adjacent_intervals: $\int_a^c f+\int_c^b f=\int_a^b f$.
  • intervalIntegral.integral_nonneg: if $f\ge 0$, then $\int_a^b f\ge 0$.
  • intervalIntegral.integral_mono_on: if $f\le g$, then $\int_a^b f\le\int_a^b g$.

import Mathlib

namespace Ch14.IdiotitesOloklirwmatos
open MeasureTheory

-- "f is integrable on [a,b]" is written IntervalIntegrable f volume a b

theorem reverse_limits (f : ℝ → ℝ) (a b : ℝ) : ∫ x in a..b, f x = -∫ x in b..a, f x :=
  intervalIntegral.integral_symm b a

theorem equal_limits (f : ℝ → ℝ) (a : ℝ) : ∫ x in a..a, f x = 0 :=
  intervalIntegral.integral_same

theorem linear_add (f g : ℝ → ℝ) (A B a b : ℝ) (hf : IntervalIntegrable f volume a b)
    (hg : IntervalIntegrable g volume a b) :
    ∫ x in a..b, (A * f x + B * g x) = A * (∫ x in a..b, f x) + B * ∫ x in a..b, g x := by
  rw [intervalIntegral.integral_add (hf.const_mul A) (hg.const_mul B),
    intervalIntegral.integral_const_mul, intervalIntegral.integral_const_mul]

theorem linear_sub (f g : ℝ → ℝ) (A B a b : ℝ) (hf : IntervalIntegrable f volume a b)
    (hg : IntervalIntegrable g volume a b) :
    ∫ x in a..b, (A * f x - B * g x) = A * (∫ x in a..b, f x) - B * ∫ x in a..b, g x := by
  rw [intervalIntegral.integral_sub (hf.const_mul A) (hg.const_mul B),
    intervalIntegral.integral_const_mul, intervalIntegral.integral_const_mul]

theorem additivity (f : ℝ → ℝ) (a b c : ℝ) (hac : IntervalIntegrable f volume a c)
    (hcb : IntervalIntegrable f volume c b) :
    ∫ x in a..b, f x = (∫ x in a..c, f x) + ∫ x in c..b, f x :=
  (intervalIntegral.integral_add_adjacent_intervals hac hcb).symm

theorem nonneg_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hf : ∀ x ∈ Set.Icc a b, 0 ≤ f x) :
    0 ≤ ∫ x in a..b, f x :=
  intervalIntegral.integral_nonneg hab hf

theorem mono_integral (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hf : IntervalIntegrable f volume a b)
    (hg : IntervalIntegrable g volume a b) (hfg : ∀ x ∈ Set.Icc a b, f x ≤ g x) :
    ∫ x in a..b, f x ≤ ∫ x in a..b, g x :=
  intervalIntegral.integral_mono_on hab hf hg hfg

end Ch14.IdiotitesOloklirwmatos
