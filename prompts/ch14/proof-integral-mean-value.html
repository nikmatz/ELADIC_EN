The Mean Value Theorem for Integrals

Chapter 14 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementIf $f$ is continuous on $[a,b]$, then there exists $\xi\in[a,b]$ such that $f(\xi)=\dfrac{1}{b-a}\int_a^b f(x)\,dx$. The quantity $\bar{f}=\dfrac{1}{b-a}\int_a^b f(x)\,dx$ is called the mean value of $f$ on $[a,b]$.

1. What is proved: the statement in the book and in Lean

  • If $f$ is continuous on $[a,b]$, with $a\lt b$, there exists $\xi\in[a,b]$ such that $f(\xi)$${}=\dfrac{1}{b-a}\int_a^b f(x)\,dx$
    theorem integral_mean_value (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ x in a..b, f x
  • Application: if moreover $\int_a^b f(x)\,dx=0$, then $f$ has a root in $[a,b]$
    theorem root_of_zero_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) (h0 : ∫ x in a..b, f x = 0) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 0

“There exists $\xi\in[a,b]$” is written ∃ ξ ∈ Set.Icc a b, and the integral $\int_a^b f(x)\,dx$ is written ∫ x in a..b, f x. We assume $a\lt b$, so that the fraction $\dfrac{1}{b-a}$ is defined. The proof follows the book: by the Weierstrass theorem $f$ has a minimum value $m$ and a maximum value $M$; integrating $m\le f(x)\le M$ we find that the mean value $\bar{f}$ lies between $m$ and $M$; and the intermediate value theorem gives $\xi$. Mathlib has a ready-made stronger form (exists_eq_interval_average), with $\xi$ in the open interval $(a,b)$.

2. Step by step: $f(\xi)=\bar{f}$

The idea: the mean value $\bar{f}$ lies between the minimum and the maximum value of $f$, so by the intermediate value theorem it is a value of $f$. We start from the goal:

The goal
f : ℝ → ℝ
a b : ℝ
hab : a < b
hf : ContinuousOn f (Set.Icc a b)
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- Weierstrass: minimum value m = f(x₁) and maximum value M = f(x₂) on [a,b]
obtain ⟨x₁, hx₁, hmin⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab.le) hf

    Weierstrass theorem (IsCompact.exists_isMinOn): $f$ attains a minimum value $m=f(x_1)$ at some $x_1\in[a,b]$. hmin says that $f(x_1)\le f(x)$ for every $x\in[a,b]$.

    What remains to be proved
    x₁ : ℝ
hx₁ : x₁ ∈ Set.Icc a b
hmin : IsMinOn f (Set.Icc a b) x₁
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
  2. obtain ⟨x₂, hx₂, hmax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab.le) hf

    Similarly, $f$ attains a maximum value $M=f(x_2)$ at some $x_2\in[a,b]$.

    What remains to be proved
    x₂ : ℝ
hx₂ : x₂ ∈ Set.Icc a b
hmax : IsMaxOn f (Set.Icc a b) x₂
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
  3. have hint : IntervalIntegrable f volume a b := hf.intervalIntegrable_of_Icc hab.le

    $f$ is continuous on $[a,b]$, hence integrable.

    What remains to be proved
    hint : IntervalIntegrable f volume a b
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
  4. -- m (b - a) ≤ ∫ f: we integrate m ≤ f(x)
have h1 : f x₁ * (b - a) ≤ ∫ x in a..b, f x := by

    Claim h1: $m\,(b-a)\le\int_a^b f(x)\,dx$.

    What remains to be proved
    ⊢ f x₁ * (b - a) ≤ ∫ (x : ℝ) in a..b, f x
  5. have h := intervalIntegral.integral_mono_on hab.le (intervalIntegrable_const (c := f x₁)) hint
  (fun x hx => isMinOn_iff.mp hmin x hx)

    Monotonicity of the integral (intervalIntegral.integral_mono_on): we integrate $m\le f(x)$ over $[a,b]$.

    What remains to be proved
    h : ∫ (u : ℝ) in a..b, f x₁ ≤ ∫ (u : ℝ) in a..b, f u
⊢ f x₁ * (b - a) ≤ ∫ (x : ℝ) in a..b, f x
  6. rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h

    The integral of the constant $m$ is $(b-a)\,m$.

    What remains to be proved
    h : f x₁ * (b - a) ≤ ∫ (u : ℝ) in a..b, f u
⊢ f x₁ * (b - a) ≤ ∫ (x : ℝ) in a..b, f x
  7. exact h

    This is exactly the claim h1.

    ✓ This part is complete.
  8. -- ∫ f ≤ M (b - a): we integrate f(x) ≤ M
have h2 : ∫ x in a..b, f x ≤ f x₂ * (b - a) := by
  have h := intervalIntegral.integral_mono_on hab.le hint (intervalIntegrable_const (c := f x₂))
    (fun x hx => isMaxOn_iff.mp hmax x hx)
  rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h
  exact h

    In the same way, integrating $f(x)\le M$, we get the claim h2: $\int_a^b f(x)\,dx\le M\,(b-a)$.

    ✓ This part is complete.
  9. -- divide by b - a > 0: m ≤ mean value ≤ M
have hba : 0 < b - a := sub_pos.mpr hab

    We have $b-a\gt 0$, because $a\lt b$.

    What remains to be proved

hab : a < b
hf : ContinuousOn f (Set.Icc a b)

  rw [one_div_mul_eq_div, le_div_iff₀ hba]
  exact h1

    Claim h3: $m\le\bar{f}$. We write $\dfrac{1}{b-a}\int_a^b f$${}=\dfrac{\int_a^b f}{b-a}$ and multiply by $b-a\gt 0$ (le_div_iff₀); the result is exactly h1.

    ✓ This part is complete.
  11. have h4 : 1 / (b - a) * ∫ x in a..b, f x ≤ f x₂ := by
  rw [one_div_mul_eq_div, div_le_iff₀ hba]
  exact h2

    Similarly, the claim h4: $\bar{f}\le M$, from h2.

    ✓ This part is complete.

have hsub : Set.uIcc x₁ x₂ ⊆ Set.Icc a b := Set.uIcc_subset_Icc hx₁ hx₂

    The interval with endpoints $x_1$ and $x_2$ is contained in $[a,b]$. It is written Set.uIcc x₁ x₂, because we do not know whether $x_1\lt x_2$ or $x_2\lt x_1$.

h2 : ∫ (x : ℝ) in a..b, f x ≤ f x₂ * (b - a)
hba : 0 < b - a

⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x

    Intermediate value theorem (intermediate_value_uIcc): since $f(x_1)\le\bar{f}\le f(x_2)$, there exists $\xi$ between $x_1$ and $x_2$ with $f(\xi)=\bar{f}$.

hfξ : f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x

    $\xi$ belongs to $[a,b]$, by hsub.

4. In Mathlib

We used the following theorems:

  • IsCompact.exists_isMinOn: the Weierstrass theorem for the minimum value.
  • IsCompact.exists_isMaxOn: the Weierstrass theorem for the maximum value.
  • ContinuousOn.intervalIntegrable_of_Icc: a function continuous on $[a,b]$ is integrable.
  • intervalIntegral.integral_mono_on: the monotonicity of the integral.
  • intervalIntegral.integral_const: $\int_a^b c\,dx=(b-a)\,c$.
  • le_div_iff₀: for $c\gt 0$: $a\le\dfrac{b}{c}$ exactly when $a\,c\le b$.
  • div_le_iff₀: for $c\gt 0$: $\dfrac{a}{c}\le b$ exactly when $a\le b\,c$.
  • intermediate_value_uIcc: the intermediate value theorem.

theorem integral_mean_value (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ x in a..b, f x := by
  -- Weierstrass: minimum value m = f(x₁) and maximum value M = f(x₂) on [a,b]
  obtain ⟨x₁, hx₁, hmin⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab.le) hf
  obtain ⟨x₂, hx₂, hmax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab.le) hf
  have hint : IntervalIntegrable f volume a b := hf.intervalIntegrable_of_Icc hab.le
  -- m (b - a) ≤ ∫ f: we integrate m ≤ f(x)
  have h1 : f x₁ * (b - a) ≤ ∫ x in a..b, f x := by
    have h := intervalIntegral.integral_mono_on hab.le (intervalIntegrable_const (c := f x₁)) hint
      (fun x hx => isMinOn_iff.mp hmin x hx)
    rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h
    exact h
  -- ∫ f ≤ M (b - a): we integrate f(x) ≤ M
  have h2 : ∫ x in a..b, f x ≤ f x₂ * (b - a) := by
    have h := intervalIntegral.integral_mono_on hab.le hint (intervalIntegrable_const (c := f x₂))
      (fun x hx => isMaxOn_iff.mp hmax x hx)
    rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h
    exact h
  -- divide by b - a > 0: m ≤ mean value ≤ M
  have hba : 0 < b - a := sub_pos.mpr hab
  have h3 : f x₁ ≤ 1 / (b - a) * ∫ x in a..b, f x := by
    rw [one_div_mul_eq_div, le_div_iff₀ hba]
    exact h1
  have h4 : 1 / (b - a) * ∫ x in a..b, f x ≤ f x₂ := by
    rw [one_div_mul_eq_div, div_le_iff₀ hba]
    exact h2
  -- intermediate value theorem on the interval with endpoints x₁ and x₂
  have hsub : Set.uIcc x₁ x₂ ⊆ Set.Icc a b := Set.uIcc_subset_Icc hx₁ hx₂
  obtain ⟨ξ, hξ, hfξ⟩ := intermediate_value_uIcc (hf.mono hsub) (Set.mem_uIcc_of_le h3 h4)
  exact ⟨ξ, hsub hξ, hfξ⟩

theorem root_of_zero_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) (h0 : ∫ x in a..b, f x = 0) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 0 := by
  obtain ⟨ξ, hξ, hfξ⟩ := integral_mean_value f a b hab hf
  rw [h0, mul_zero] at hfξ
  exact ⟨ξ, hξ, hfξ⟩
