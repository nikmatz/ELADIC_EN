Geometric Series — Convergence and Sum

Chapter 19 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementThe geometric series $\sum_{n=0}^{\infty} a\,r^n$ (with $a\ne 0$) has partial sums $S_N=a\,\dfrac{1-r^{\,N+1}}{1-r}$ (for $r\ne 1$). It converges if and only if $|r|\lt 1$, with sum $\sum_{n=0}^{\infty} a\,r^n=\dfrac{a}{1-r}$; for $|r|\ge 1$ it diverges. In particular, for $a=1,\ r=\tfrac12$: $S_N=2\bigl(1-\tfrac{1}{2^{\,N+1}}\bigr)\to 2$.

1. What is proved: the statement in the book and in Lean

  • Partial sums: $\sum_{n=0}^{N}a\,r^n$${}=a\,\dfrac{1-r^{N+1}}{1-r}$ for $r\neq 1$
    theorem partial_sum (a r : ℝ) (hr : r ≠ 1) (N : ℕ) :
    ∑ n ∈ Finset.range (N + 1), a * r ^ n = a * (1 - r ^ (N + 1)) / (1 - r)
  • For $|r|\lt 1$: $\sum_{n=0}^{\infty}a\,r^n$${}=\dfrac{a}{1-r}$
    theorem geometric_sum (a r : ℝ) (hr : |r| < 1) :
    Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) atTop (𝓝 (a / (1 - r)))
  • For $|r|\ge 1$ and $a\neq 0$ the series diverges
    theorem geometric_diverges (a r : ℝ) (ha : a ≠ 0) (hr : 1 ≤ |r|) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a * r ^ n) atTop (𝓝 S)
  • Example: $\sum_{n=0}^{\infty}\left(\tfrac12\right)^n$${}=2$
    theorem half_series :
    Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), (1 / 2 : ℝ) ^ n) atTop (𝓝 2)

The partial sum $S_N=\sum_{n=0}^{N}a\,r^n$ is written ∑ n ∈ Finset.range (N + 1), a * r ^ n: Finset.range (N + 1) is the set $\{0,1,\dots,N\}$. The convergence of the series to $\dfrac{a}{1-r}$ is written as a limit of the partial sums, as in the book, and divergence as “the partial sums have no limit”. Together the two theorems give the “if and only if” of the book. For divergence the proof uses the necessary condition: if the series converged, we would have $a\,r^n\to 0$, whereas $|a\,r^n|\ge|a|\gt 0$.

2. Step by step: $\sum_{n=0}^{\infty}a\,r^n$${}=\dfrac{a}{1-r}$ for $|r|\lt 1$

The idea: we write the partial sums by their closed formula and take the limit. We start from the goal:

The goal
a r : ℝ
hr : |r| < 1
⊢ Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) atTop (𝓝 (a / (1 - r)))

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hr1 : r ≠ 1 := by
  intro h
  rw [h, abs_one] at hr
  exact lt_irrefl 1 hr

    From $|r|\lt 1$ it follows that $r\neq 1$, so the formula for the partial sums applies.

    What remains to be proved
    hr1 : r ≠ 1
⊢ Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) atTop (𝓝 (a / (1 - r)))
  2. have h1 : (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) =
    fun N => a * (1 - r ^ (N + 1)) / (1 - r) := by
  funext N
  exact partial_sum a r hr1 N

    The partial sums are given by the closed formula $S_N=a\,\dfrac{1-r^{N+1}}{1-r}$ (theorem partial_sum).

    What remains to be proved
    h1 : (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) = fun N => a * (1 - r ^ (N + 1)) / (1 - r)
⊢ Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) atTop (𝓝 (a / (1 - r)))
  3. rw [h1]

    We replace the partial sums with the closed formula; the goal is now the limit of a simple sequence.

    What remains to be proved
    ⊢ Tendsto (fun N => a * (1 - r ^ (N + 1)) / (1 - r)) atTop (𝓝 (a / (1 - r)))
  4. have h2 : Tendsto (fun N : ℕ => r ^ (N + 1)) atTop (𝓝 0) :=
  (tendsto_pow_atTop_nhds_zero_of_abs_lt_one hr).comp (tendsto_add_atTop_nat 1)

    Since $|r|\lt 1$, we have $r^{N+1}\to 0$.

    What remains to be proved
    h2 : Tendsto (fun N => r ^ (N + 1)) atTop (𝓝 0)
⊢ Tendsto (fun N => a * (1 - r ^ (N + 1)) / (1 - r)) atTop (𝓝 (a / (1 - r)))
  5. have h3 : Tendsto (fun N : ℕ => a * (1 - r ^ (N + 1)) / (1 - r)) atTop
    (𝓝 (a * (1 - 0) / (1 - r))) :=
  ((tendsto_const_nhds.sub h2).const_mul a).div_const (1 - r)

    By the limit laws: $a\,\dfrac{1-r^{N+1}}{1-r}\to a\,\dfrac{1-0}{1-r}$.

    What remains to be proved
    h3 : Tendsto (fun N => a * (1 - r ^ (N + 1)) / (1 - r)) atTop (𝓝 (a * (1 - 0) / (1 - r)))
⊢ Tendsto (fun N => a * (1 - r ^ (N + 1)) / (1 - r)) atTop (𝓝 (a / (1 - r)))
  6. rw [sub_zero, mul_one] at h3

    We simplify: $a\,(1-0)=a$. Now h3 is exactly the goal.

    What remains to be proved
    h3 : Tendsto (fun N => a * (1 - r ^ (N + 1)) / (1 - r)) atTop (𝓝 (a / (1 - r)))
⊢ Tendsto (fun N => a * (1 - r ^ (N + 1)) / (1 - r)) atTop (𝓝 (a / (1 - r)))

Solution
theorem half_series :
    Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), (1 / 2 : ℝ) ^ n) atTop (𝓝 2) := by
  have h := geometric_sum 1 (1 / 2) (by rw [abs_of_pos (by norm_num)]; norm_num)
  simp only [one_mul] at h
  rwa [show (1 : ℝ) / (1 - 1 / 2) = 2 by norm_num] at h

4. In Mathlib

We used the following theorems:

  • geom_sum_eq: $\sum_{n=0}^{N-1}r^n$${}=\dfrac{r^N-1}{r-1}$ for $r\neq 1$.
  • tendsto_pow_atTop_nhds_zero_of_abs_lt_one: $r^n\to 0$ for $|r|\lt 1$.
  • Filter.Tendsto.const_mul: if $u_n\to u$, then $a\,u_n\to a\,u$.
  • Filter.Tendsto.div_const: if $u_n\to u$, then $\dfrac{u_n}{c}\to\dfrac{u}{c}$.
  • one_le_pow₀: $|r|^n\ge 1$ for $|r|\ge 1$.

import Mathlib

namespace Ch19.GewmetrikiSeira
open Filter Topology

-- partial sums: a + a r + … + a r^N = a (1 - r^(N+1))/(1 - r)
theorem partial_sum (a r : ℝ) (hr : r ≠ 1) (N : ℕ) :
    ∑ n ∈ Finset.range (N + 1), a * r ^ n = a * (1 - r ^ (N + 1)) / (1 - r) := by
  rw [← Finset.mul_sum, geom_sum_eq hr (N + 1)]
  have h1 : r - 1 ≠ 0 := sub_ne_zero.mpr hr
  have h2 : 1 - r ≠ 0 := sub_ne_zero.mpr (Ne.symm hr)
  field_simp
  ring

-- for |r| < 1 the partial sums tend to a/(1 - r)
theorem geometric_sum (a r : ℝ) (hr : |r| < 1) :
    Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) atTop (𝓝 (a / (1 - r))) := by
  have hr1 : r ≠ 1 := by
    intro h
    rw [h, abs_one] at hr
    exact lt_irrefl 1 hr
  have h1 : (fun N => ∑ n ∈ Finset.range (N + 1), a * r ^ n) =
      fun N => a * (1 - r ^ (N + 1)) / (1 - r) := by
    funext N
    exact partial_sum a r hr1 N
  rw [h1]
  have h2 : Tendsto (fun N : ℕ => r ^ (N + 1)) atTop (𝓝 0) :=
    (tendsto_pow_atTop_nhds_zero_of_abs_lt_one hr).comp (tendsto_add_atTop_nat 1)
  have h3 : Tendsto (fun N : ℕ => a * (1 - r ^ (N + 1)) / (1 - r)) atTop
      (𝓝 (a * (1 - 0) / (1 - r))) :=
    ((tendsto_const_nhds.sub h2).const_mul a).div_const (1 - r)
  rw [sub_zero, mul_one] at h3
  exact h3

-- for |r| ≥ 1 (and a ≠ 0) the series diverges
theorem geometric_diverges (a r : ℝ) (ha : a ≠ 0) (hr : 1 ≤ |r|) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a * r ^ n) atTop (𝓝 S) := by
  rintro ⟨S, hS⟩
  -- the terms would tend to 0
  have h0 : Tendsto (fun n => a * r ^ n) atTop (𝓝 0) := by
    have h1 := (hS.comp (tendsto_add_atTop_nat 1)).sub hS
    simp only [Function.comp_def, Finset.sum_range_succ, add_sub_cancel_left, sub_self] at h1
    exact h1
  -- but |a rⁿ| ≥ |a| > 0
  have h2 : ∀ n : ℕ, |a| ≤ |a * r ^ n| := fun n => by
    rw [abs_mul, abs_pow]
    exact le_mul_of_one_le_right (abs_nonneg a) (one_le_pow₀ hr)
  have h3 := h0.abs.eventually (gt_mem_nhds (show |(0 : ℝ)| < |a| by
    rw [abs_zero]
    exact abs_pos.mpr ha))
  obtain ⟨n, hn⟩ := h3.exists
  exact absurd (h2 n) (not_le.mpr hn)

theorem half_series :
    Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), (1 / 2 : ℝ) ^ n) atTop (𝓝 2) := by
  have h := geometric_sum 1 (1 / 2) (by rw [abs_of_pos (by norm_num)]; norm_num)
  simp only [one_mul] at h
  rwa [show (1 : ℝ) / (1 - 1 / 2) = 2 by norm_num] at h

end Ch19.GewmetrikiSeira
