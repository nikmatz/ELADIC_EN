1. What is proved: the statement in the book and in Lean

  • $(a_n)$ converges if and only if for every $\varepsilon\gt 0$ there exists $N$ such that $|a_m-a_n|\lt\varepsilon$ for all $m,n\ge N$
    theorem cauchy_criterion (a : ℕ → ℝ) :
    (∃ L, Tendsto a atTop (𝓝 L)) ↔
      ∀ ε > 0, ∃ N, ∀ m ≥ N, ∀ n ≥ N, |a m - a n| < ε

Mathlib defines a Cauchy sequence, CauchySeq a, in general metric spaces; the proof first checks that for real numbers it means exactly the condition of the book, with distance $|a_m-a_n|$. That every convergent sequence is Cauchy holds in every metric space. The converse is the completeness of $\mathbb{R}$; in Mathlib the real numbers are constructed from Cauchy sequences of rationals, and completeness is a proved property of them.

2. Where it is in Mathlib

We used the following theorems:

  • Metric.cauchySeq_iff: a Cauchy sequence in a metric space, in terms of $\varepsilon$ and $N$.
  • Real.dist_eq: the distance in $\mathbb{R}$ is $|x-y|$.
  • Filter.Tendsto.cauchySeq: every convergent sequence is Cauchy.
  • cauchySeq_tendsto_of_complete: in a complete space every Cauchy sequence converges.

namespace Ch19.KritirioCauchy
open Filter Topology

theorem cauchy_criterion (a : ℕ → ℝ) :
    (∃ L, Tendsto a atTop (𝓝 L)) ↔
      ∀ ε > 0, ∃ N, ∀ m ≥ N, ∀ n ≥ N, |a m - a n| < ε := by
  have h : CauchySeq a ↔ ∀ ε > 0, ∃ N, ∀ m ≥ N, ∀ n ≥ N, |a m - a n| < ε := by
    simp only [Metric.cauchySeq_iff, Real.dist_eq]
  rw [← h]
  exact ⟨fun ⟨L, hL⟩ => hL.cauchySeq, cauchySeq_tendsto_of_complete⟩

end Ch19.KritirioCauchy
