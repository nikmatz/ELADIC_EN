1. What is proved: the statement in the book and in Lean

  • If $b_n\gt 0$ and $\dfrac{a_n}{b_n}\to L$ with $L\gt 0$, then $\sum a_n$ converges if and only if $\sum b_n$ converges
    theorem limit_comparison (a b : ℕ → ℝ) (L : ℝ) (hL : 0 < L) (hb : ∀ n, 0 < b n)
    (hlim : Tendsto (fun n => a n / b n) atTop (𝓝 L)) : Summable a ↔ Summable b

Convergence is written Summable; for series with positive terms this is exactly convergence in the sense of the book. The limit $L$ is a real number, so automatically $L\lt\infty$. The hypothesis $a_n\gt 0$ is not needed: from $\dfrac{a_n}{b_n}\to L\gt 0$ it follows that $a_n\gt 0$ for large $n$. The proof shows that, for large $n$, each of the two sequences is bounded by a multiple of the other (notation a =O[atTop] b), as in the analogous test for improper integrals in Chapter 18.

2. Where it is in Mathlib

We used the following theorems:

  • Asymptotics.isBigO_of_div_tendsto_nhds: if $\dfrac{a_n}{b_n}\to c$, then $a$ is bounded by a multiple of $b$ for large $n$.
  • Filter.Tendsto.inv₀: if $u_n\to L\neq 0$, then $\dfrac{1}{u_n}\to\dfrac{1}{L}$.
  • summable_of_isBigO_nat': if $a$ is bounded by a multiple of $b$ for large $n$ and $\sum b_n$ converges, then $\sum a_n$ also converges.

import Mathlib

namespace Ch19.OriakoKritirio
open Filter Topology Asymptotics

theorem limit_comparison (a b : ℕ → ℝ) (L : ℝ) (hL : 0 < L) (hb : ∀ n, 0 < b n)
    (hlim : Tendsto (fun n => a n / b n) atTop (𝓝 L)) : Summable a ↔ Summable b := by
  -- a = O(b), because a/b → L
  have hab : a =O[atTop] b :=
    isBigO_of_div_tendsto_nhds (Eventually.of_forall fun n h0 => absurd h0 (hb n).ne') L hlim
  -- b = O(a), because b/a → 1/L
  have hba : b =O[atTop] a := by
    have hinv : Tendsto (fun n => b n / a n) atTop (𝓝 L⁻¹) := by
      refine (hlim.inv₀ hL.ne').congr' ?_
      filter_upwards with n
      exact inv_div (a n) (b n)
    refine isBigO_of_div_tendsto_nhds ?_ L⁻¹ hinv
    filter_upwards [hlim.eventually (lt_mem_nhds hL)] with n hn h0
    rw [h0, zero_div] at hn
    exact absurd hn (lt_irrefl 0)
  exact ⟨fun ha => summable_of_isBigO_nat' ha hba, fun hb' => summable_of_isBigO_nat' hb' hab⟩

end Ch19.OriakoKritirio
