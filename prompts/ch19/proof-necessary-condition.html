1. What is proved: the statement in the book and in Lean

  • If $\sum a_n$ converges, then $a_n\to 0$
    theorem necessary (a : ℕ → ℝ) (S : ℝ)
    (h : Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)) :
    Tendsto a atTop (𝓝 0)
  • The converse does not hold: $\dfrac{1}{n}\to 0$, but the partial sums of the harmonic series tend to $+\infty$
    theorem harmonic :
    Tendsto (fun n : ℕ => 1 / ((n : ℝ) + 1)) atTop (𝓝 0) ∧
      Tendsto (fun N => ∑ n ∈ Finset.range N, 1 / ((n : ℝ) + 1)) atTop atTop
  • If $a_n\to 0$ does not hold, the series diverges
    theorem diverges_of_not_tendsto (a : ℕ → ℝ) (h : ¬ Tendsto a atTop (𝓝 0)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)

The convergence of the series is written as in the book, through the partial sums: Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S), where $S_N=a_0+\dots+a_{N-1}$. The indexing starts at $0$; for the harmonic series we write the terms as $\dfrac{1}{n+1}$ with $n\ge 0$, which are the $1,\tfrac12,\tfrac13,\dots$ of the book.

2. Step by step: $\sum a_n$ converges $\Rightarrow$ $a_n\to 0$

The idea, as in the book: $a_N=S_{N+1}-S_N\to S-S=0$. We start from the goal:

The goal
a : ℕ → ℝ
S : ℝ
h : Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)
⊢ Tendsto a atTop (𝓝 0)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- the sequence S_{N+1} also tends to S
have h1 : Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a n) atTop (𝓝 S) :=
  h.comp (tendsto_add_atTop_nat 1)

    Since $S_N\to S$, the shifted sequence $S_{N+1}$ also tends to $S$.

    What remains to be proved
    h1 : Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a n) atTop (𝓝 S)
⊢ Tendsto a atTop (𝓝 0)
  2. -- a_N = S_{N+1} - S_N
have h2 : (fun N => ∑ n ∈ Finset.range (N + 1), a n - ∑ n ∈ Finset.range N, a n) = a := by
  funext N
  rw [Finset.sum_range_succ]

    To compare the two partial sums, we write $S_{N+1}=S_N+a_N$; the goal becomes $S_N+a_N-S_N=a_N$.

    What remains to be proved
    N : ℕ
⊢ ∑ x ∈ Finset.range N, a x + a N - ∑ n ∈ Finset.range N, a n = a N
  3. ring

    ring confirms it. Thus $S_{N+1}-S_N=a_N$ for every $N$.

    What remains to be proved
    h2 : (fun N => ∑ n ∈ Finset.range (N + 1), a n - ∑ n ∈ Finset.range N, a n) = a
⊢ Tendsto a atTop (𝓝 0)
  4. -- hence a_N → S - S = 0
have h3 := h1.sub h

    By the limit laws, $S_{N+1}-S_N\to S-S$.

    What remains to be proved
    h3 : Tendsto (fun x => ∑ n ∈ Finset.range (x + 1), a n - ∑ n ∈ Finset.range x, a n) atTop (𝓝 (S - S))
⊢ Tendsto a atTop (𝓝 0)
  5. rw [h2, sub_self] at h3

    We substitute $S_{N+1}-S_N=a_N$ and $S-S=0$: h3 says that $a_n\to 0$, which is the goal.

    What remains to be proved
    h3 : Tendsto a atTop (𝓝 0)
⊢ Tendsto a atTop (𝓝 0)

4. In Mathlib

We used the following theorems:

  • Filter.tendsto_add_atTop_nat: $N+1\to+\infty$ as $N\to+\infty$.
  • Filter.Tendsto.comp: composition of limits; here it gives $S_{N+1}\to S$.
  • Finset.sum_range_succ: $S_{N+1}=S_N+a_N$.
  • Filter.Tendsto.sub: the limit of a difference.
  • tendsto_one_div_add_atTop_nhds_zero_nat: $\dfrac{1}{n+1}\to 0$.
  • Real.tendsto_sum_range_one_div_nat_succ_atTop: the partial sums of the harmonic series tend to $+\infty$.

import Mathlib

namespace Ch19.AnagkaiaSynthiki
open Filter Topology

-- if the partial sums S_N converge, then a n → 0
theorem necessary (a : ℕ → ℝ) (S : ℝ)
    (h : Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)) :
    Tendsto a atTop (𝓝 0) := by
  -- the sequence S_{N+1} also tends to S
  have h1 : Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a n) atTop (𝓝 S) :=
    h.comp (tendsto_add_atTop_nat 1)
  -- a_N = S_{N+1} - S_N
  have h2 : (fun N => ∑ n ∈ Finset.range (N + 1), a n - ∑ n ∈ Finset.range N, a n) = a := by
    funext N
    rw [Finset.sum_range_succ]
    ring
  -- hence a_N → S - S = 0
  have h3 := h1.sub h
  rw [h2, sub_self] at h3
  exact h3

-- the converse does not hold: 1/(n+1) → 0, but the harmonic series diverges
theorem harmonic :
    Tendsto (fun n : ℕ => 1 / ((n : ℝ) + 1)) atTop (𝓝 0) ∧
      Tendsto (fun N => ∑ n ∈ Finset.range N, 1 / ((n : ℝ) + 1)) atTop atTop :=
  ⟨tendsto_one_div_add_atTop_nhds_zero_nat, Real.tendsto_sum_range_one_div_nat_succ_atTop⟩

theorem diverges_of_not_tendsto (a : ℕ → ℝ) (h : ¬ Tendsto a atTop (𝓝 0)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S) := by
  rintro ⟨S, hS⟩
  exact h (necessary a S hS)

end Ch19.AnagkaiaSynthiki
