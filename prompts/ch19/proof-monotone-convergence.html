Monotone Convergence Theorem

Chapter 19 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementIf $(a_n)$ is increasing and bounded above, or decreasing and bounded below, then it converges. Increasing and bounded above by $M$: $\lim a_n=\sup\{a_n\}\le M$; decreasing and bounded below by $m$: $\lim a_n=\inf\{a_n\}\ge m$.

1. What is proved: the statement in the book and in Lean

  • If $(a_n)$ is increasing and $a_n\le M$, then $a_n\to\sup\{a_n\}$ and $\sup\{a_n\}\le M$
    theorem monotone_convergence (a : ℕ → ℝ) (M : ℝ) (hmono : Monotone a) (hM : ∀ n, a n ≤ M) :
    Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ (⨆ n, a n) ≤ M
  • If $(a_n)$ is decreasing and $a_n\ge m$, then $a_n\to\inf\{a_n\}$ and $\inf\{a_n\}\ge m$
    theorem antitone_convergence (a : ℕ → ℝ) (m : ℝ) (hanti : Antitone a) (hm : ∀ n, m ≤ a n) :
    Tendsto a atTop (𝓝 (⨅ n, a n)) ∧ m ≤ ⨅ n, a n

$\sup\{a_n\}$ is written ⨆ n, a n and $\inf\{a_n\}$ is written ⨅ n, a n. An increasing sequence is written Monotone a and a decreasing one Antitone a. Mathlib defines $\sup$ for every set of real numbers, but its properties hold when the set is bounded above (BddAbove), which is why the proof first shows the bound. Convergence to the $\sup$ is proved with the $\varepsilon$-$N$ definition, as in the book.

2. Step by step: Increasing and bounded above $\Rightarrow$ $a_n\to\sup\{a_n\}$

The idea, as in the book: $\sup\{a_n\}$ is the least upper bound, so from some $N$ onward the terms come as close to the $\sup$ as we wish. We start from the goal:

The goal
a : ℕ → ℝ
M : ℝ
hmono : Monotone a
hM : ∀ (n : ℕ), a n ≤ M
⊢ Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ ⨆ n, a n ≤ M

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- the set of terms is bounded above
have hbdd : BddAbove (Set.range a) := ⟨M, by
  rintro _ ⟨n, rfl⟩
  exact hM n⟩

    The set of terms $\{a_n\}$ is bounded above by $M$, so the properties of $\sup\{a_n\}$, written ⨆ n, a n, apply.

    What remains to be proved
    hbdd : BddAbove (Set.range a)
⊢ Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ ⨆ n, a n ≤ M
  2. refine ⟨?_, ciSup_le hM⟩

    The second part, $\sup\{a_n\}\le M$, holds because $M$ is an upper bound (ciSup_le). The limit remains.

    What remains to be proved
    ⊢ Tendsto a atTop (𝓝 (⨆ n, a n))
  3. rw [Metric.tendsto_atTop]

    We write the limit by its definition: for every $\varepsilon\gt 0$ there exists $N$ such that the distance of $a_n$ from the $\sup$ is less than $\varepsilon$ for $n\ge N$. The distance dist x y is $|x-y|$.

    What remains to be proved
    ⊢ ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (a n) (⨆ n, a n) < ε
  4. intro ε hε
-- sup - ε is not an upper bound: there exists N with a N > sup - ε
obtain ⟨N, hN⟩ := exists_lt_of_lt_ciSup (show (⨆ n, a n) - ε < ⨆ n, a n by linarith)

    We take $\varepsilon\gt 0$. $\sup-\varepsilon$ is not an upper bound, because it is smaller than the least upper bound; hence there is a term $a_N\gt\sup-\varepsilon$.

    What remains to be proved
    ε : ℝ
hε : ε > 0
N : ℕ
hN : (⨆ n, a n) - ε < a N
⊢ ∃ N, ∀ n ≥ N, dist (a n) (⨆ n, a n) < ε
  5. refine ⟨N, fun n hn => ?_⟩

    This $N$ is the one we want. We take $n\ge N$.

    What remains to be proved
    n : ℕ
hn : n ≥ N
⊢ dist (a n) (⨆ n, a n) < ε
  6. -- for n ≥ N: sup - ε < a N ≤ a n ≤ sup
have h1 : a N ≤ a n := hmono hn
have h2 : a n ≤ ⨆ n, a n := le_ciSup hbdd n

    The sequence is increasing, so $a_N\le a_n$, and every term is at most the $\sup$.

    What remains to be proved
    h1 : a N ≤ a n
h2 : a n ≤ ⨆ n, a n
⊢ dist (a n) (⨆ n, a n) < ε
  7. rw [Real.dist_eq, abs_lt]

    The inequality $|a_n-\sup|\lt\varepsilon$ is written as $-\varepsilon\lt a_n-\sup$ and $a_n-\sup\lt\varepsilon$; both follow linearly from the previous inequalities (linarith).

    What remains to be proved
    ⊢ -ε < a n - ⨆ n, a n ∧ a n - ⨆ n, a n < ε

4. In Mathlib

We used the following theorems:

  • ciSup_le: if $a_n\le M$ for every $n$, then $\sup\{a_n\}\le M$.
  • le_ciSup: in a set that is bounded above, every term is at most $\sup\{a_n\}$.
  • exists_lt_of_lt_ciSup: if $x\lt\sup\{a_n\}$, there is a term $a_N\gt x$.
  • Metric.tendsto_atTop: the $\varepsilon$-$N$ definition of the limit.
  • tendsto_atTop_ciInf: a decreasing sequence that is bounded below converges to $\inf\{a_n\}$.
  • le_ciInf: if $a_n\ge m$ for every $n$, then $\inf\{a_n\}\ge m$.

import Mathlib

namespace Ch19.MonotoniSygklisi
open Filter Topology

-- increasing and bounded above by M: it converges to the sup, and sup ≤ M
theorem monotone_convergence (a : ℕ → ℝ) (M : ℝ) (hmono : Monotone a) (hM : ∀ n, a n ≤ M) :
    Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ (⨆ n, a n) ≤ M := by
  -- the set of terms is bounded above
  have hbdd : BddAbove (Set.range a) := ⟨M, by
    rintro _ ⟨n, rfl⟩
    exact hM n⟩
  refine ⟨?_, ciSup_le hM⟩
  rw [Metric.tendsto_atTop]
  intro ε hε
  -- sup - ε is not an upper bound: there exists N with a N > sup - ε
  obtain ⟨N, hN⟩ := exists_lt_of_lt_ciSup (show (⨆ n, a n) - ε < ⨆ n, a n by linarith)
  refine ⟨N, fun n hn => ?_⟩
  -- for n ≥ N: sup - ε < a N ≤ a n ≤ sup
  have h1 : a N ≤ a n := hmono hn
  have h2 : a n ≤ ⨆ n, a n := le_ciSup hbdd n
  rw [Real.dist_eq, abs_lt]
  constructor <;> linarith

theorem antitone_convergence (a : ℕ → ℝ) (m : ℝ) (hanti : Antitone a) (hm : ∀ n, m ≤ a n) :
    Tendsto a atTop (𝓝 (⨅ n, a n)) ∧ m ≤ ⨅ n, a n :=
  ⟨tendsto_atTop_ciInf hanti ⟨m, by
    rintro _ ⟨n, rfl⟩
    exact hm n⟩, le_ciInf hm⟩

end Ch19.MonotoniSygklisi
