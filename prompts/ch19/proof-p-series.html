1. What is proved: the statement in the book and in Lean

  • $\sum\dfrac{1}{n^p}$ converges if and only if $p\gt 1$
    theorem p_series (p : ℝ) : Summable (fun n : ℕ => 1 / (n : ℝ) ^ p) ↔ 1 < p
  • $p=1$: the partial sums of the harmonic series tend to $+\infty$
    theorem harmonic_diverges :
    Tendsto (fun N => ∑ n ∈ Finset.range N, 1 / ((n : ℝ) + 1)) atTop atTop
  • $p=2$: $\sum_{n=1}^{\infty}\dfrac{1}{n^2}$${}=\dfrac{\pi^2}{6}$
    theorem basel : HasSum (fun n : ℕ => 1 / (n : ℝ) ^ 2) (Real.pi ^ 2 / 6)
  • $p=\tfrac12$: the series diverges
    theorem half_diverges : ¬ Summable (fun n : ℕ => 1 / (n : ℝ) ^ (1 / 2 : ℝ))

The series is written with indexing from $0$, and the term for $n=0$ is $\dfrac{1}{0^p}$: a number that does not affect convergence, and for $p=2$ it equals $0$, since in Mathlib $\dfrac{1}{0}=0$. Convergence is written Summable, which for series with nonnegative terms is convergence in the sense of the book. The power $n^p$ with a real exponent is written (n : ℝ) ^ p. For the harmonic series, divergence is stated in a stronger form: the partial sums $1+\tfrac12+\cdots+\tfrac1N$ tend to $+\infty$. The sum $\dfrac{\pi^2}{6}$ (the Basel problem) is written with HasSum: the series converges and has this sum.

2. Where it is in Mathlib

We used the following theorems:

  • Real.summable_one_div_nat_rpow: $\sum\dfrac{1}{n^p}$ converges exactly when $p\gt 1$.
  • Real.tendsto_sum_range_one_div_nat_succ_atTop: the partial sums of the harmonic series tend to $+\infty$.
  • hasSum_zeta_two: $\sum\dfrac{1}{n^2}$${}=\dfrac{\pi^2}{6}$.

import Mathlib

namespace Ch19.PSeira
open Filter Topology

-- the term for n = 0 is 1/0^p, a number that does not affect convergence
theorem p_series (p : ℝ) : Summable (fun n : ℕ => 1 / (n : ℝ) ^ p) ↔ 1 < p :=
  Real.summable_one_div_nat_rpow

theorem harmonic_diverges :
    Tendsto (fun N => ∑ n ∈ Finset.range N, 1 / ((n : ℝ) + 1)) atTop atTop :=
  Real.tendsto_sum_range_one_div_nat_succ_atTop

theorem basel : HasSum (fun n : ℕ => 1 / (n : ℝ) ^ 2) (Real.pi ^ 2 / 6) :=
  hasSum_zeta_two

theorem half_diverges : ¬ Summable (fun n : ℕ => 1 / (n : ℝ) ^ (1 / 2 : ℝ)) := by
  rw [Real.summable_one_div_nat_rpow]
  norm_num

end Ch19.PSeira
