Ratio Test (d'Alembert)

Proof with the help of a Large Language Model (AI)

StatementLet $\sum a_n$ be a series with $a_n\neq 0$ and let $L=\lim_{n\to\infty}\left|\dfrac{a_{n+1}}{a_n}\right|$ (provided the limit exists). If $L<1$, the series converges absolutely; if $L>1$ (or $L=+\infty$), it diverges; if $L=1$, the test is inconclusive. (With $\limsup$ in place of the limit, only the condition $\limsup<1$ guarantees convergence; from $\limsup>1$ divergence does NOT follow.)
