Properties of Limits of Sequences

Chapter 19 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementIf $\lim a_n=A$ and $\lim b_n=B$: $\lim(a_n\pm b_n)=A\pm B$; $\lim(a_n b_n)=AB$; $\lim\dfrac{a_n}{b_n}=\dfrac{A}{B}$ ($B\ne 0$); $\lim|a_n|=|A|$; $\lim a_n^p=A^p$ for $p\in\mathbb{R}$ (for non-integer $p$ one needs $a_n\gt 0$ and $A\gt 0$, and for $p\lt 0$ one needs $A\ne 0$). Squeeze: if $a_n\le c_n\le b_n$ and $\lim a_n=\lim b_n=L$, then $\lim c_n=L$.

    (hb : Tendsto b atTop (𝓝 L)) (hac : ∀ n, a n ≤ c n) (hcb : ∀ n, c n ≤ b n) :
    Tendsto c atTop (𝓝 L)

$\lim a_n=A$ is written Tendsto a atTop (𝓝 A): $a_n$ tends to $A$ as $n\to+\infty$. The limit of the sum is proved with $\varepsilon$-$N$, as in the book; the other properties follow from the corresponding Mathlib theorems. For powers we distinguish three cases: a natural exponent, with no restriction; an integer exponent, with $A\neq 0$, so that $A^k$ is defined for $k\lt 0$; and a real exponent, with $A\gt 0$. In the last case the hypothesis $a_n\gt 0$ is not needed: from $a_n\to A\gt 0$ it follows that $a_n\gt 0$ for large $n$.

2. Step by step: $\lim(a_n+b_n)=A+B$

The idea, as in the book: we take $\tfrac{\varepsilon}{2}$ for each sequence and use the triangle inequality. We start from the goal:

The goal
a b : ℕ → ℝ
A B : ℝ
ha : Tendsto a atTop (𝓝 A)
hb : Tendsto b atTop (𝓝 B)
⊢ Tendsto (fun n => a n + b n) atTop (𝓝 (A + B))

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [Metric.tendsto_atTop] at ha hb ⊢

    We write all three limits with the $\varepsilon$-$N$ definition. The distance dist x y is $|x-y|$.

    What remains to be proved
    ha : ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (a n) A < ε
hb : ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (b n) B < ε
⊢ ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (a n + b n) (A + B) < ε
  2. intro ε hε

    We take $\varepsilon\gt 0$.

    What remains to be proved
    ε : ℝ
hε : ε > 0
⊢ ∃ N, ∀ n ≥ N, dist (a n + b n) (A + B) < ε
  3. -- N₁ for ε/2 in a and N₂ for ε/2 in b
obtain ⟨N₁, hN₁⟩ := ha (ε / 2) (by linarith)
obtain ⟨N₂, hN₂⟩ := hb (ε / 2) (by linarith)

    We apply the definition with $\tfrac{\varepsilon}{2}$: for $n\ge N_1$ we have $|a_n-A|\lt\tfrac{\varepsilon}{2}$, and for $n\ge N_2$ we have $|b_n-B|\lt\tfrac{\varepsilon}{2}$.

    What remains to be proved
    N₁ : ℕ
hN₁ : ∀ n ≥ N₁, dist (a n) A < ε / 2
N₂ : ℕ
hN₂ : ∀ n ≥ N₂, dist (b n) B < ε / 2
⊢ ∃ N, ∀ n ≥ N, dist (a n + b n) (A + B) < ε
  4. refine ⟨max N₁ N₂, fun n hn => ?_⟩

    We choose $N=\max(N_1,N_2)$ and take $n\ge N$.

    What remains to be proved
    n : ℕ
hn : n ≥ max N₁ N₂
⊢ dist (a n + b n) (A + B) < ε
  5. have h1 := hN₁ n (le_of_max_le_left hn)
have h2 := hN₂ n (le_of_max_le_right hn)

    Since $n\ge N_1$ and $n\ge N_2$, both inequalities hold.

    What remains to be proved
    h1 : dist (a n) A < ε / 2
h2 : dist (b n) B < ε / 2
⊢ dist (a n + b n) (A + B) < ε
  6. rw [Real.dist_eq] at h1 h2 ⊢

    We write the distances as absolute values. The triangle inequality completes the proof: $|a_n+b_n-(A+B)|\le|a_n-A|$${}+|b_n-B|\lt\tfrac{\varepsilon}{2}$${}+\tfrac{\varepsilon}{2}$${}=\varepsilon$.

    What remains to be proved
    h1 : |a n - A| < ε / 2
h2 : |b n - B| < ε / 2
⊢ |a n + b n - (A + B)| < ε

Solution
theorem diff_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n - b n) atTop (𝓝 (A - B)) := by
  have h := sum_rule a (fun n => -b n) A (-B) ha hb.neg
  simp only [← sub_eq_add_neg] at h
  exact h

4. In Mathlib

We used the following theorems:

  • Metric.tendsto_atTop: the $\varepsilon$-$N$ definition of the limit.
  • abs_add_le: the triangle inequality $|x+y|\le|x|+|y|$.
  • le_of_max_le_left: if $\max(N_1,N_2)\le n$, then $N_1\le n$.
  • Filter.Tendsto.neg: if $b_n\to B$, then $-b_n\to -B$.
  • Filter.Tendsto.mul: the limit of a product.
  • Filter.Tendsto.div: the limit of a quotient, when the limit of the denominator is not $0$.
  • Filter.Tendsto.abs: the limit of the absolute value.
  • Filter.Tendsto.pow: the limit of a power with a natural exponent.
  • Filter.Tendsto.zpow₀: the limit of a power with an integer exponent.
  • Filter.Tendsto.rpow_const: the limit of a power with a real exponent.
  • tendsto_of_tendsto_of_tendsto_of_le_of_le: the squeeze theorem.

import Mathlib

namespace Ch19.IdiotitesOriwn
open Filter Topology

-- limit of a sum, with ε-N
theorem sum_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n + b n) atTop (𝓝 (A + B)) := by
  rw [Metric.tendsto_atTop] at ha hb ⊢
  intro ε hε
  -- N₁ for ε/2 in a and N₂ for ε/2 in b
  obtain ⟨N₁, hN₁⟩ := ha (ε / 2) (by linarith)
  obtain ⟨N₂, hN₂⟩ := hb (ε / 2) (by linarith)
  refine ⟨max N₁ N₂, fun n hn => ?_⟩
  have h1 := hN₁ n (le_of_max_le_left hn)
  have h2 := hN₂ n (le_of_max_le_right hn)
  rw [Real.dist_eq] at h1 h2 ⊢
  -- triangle inequality
  calc |a n + b n - (A + B)| = |(a n - A) + (b n - B)| := by congr 1; ring
    _ ≤ |a n - A| + |b n - B| := abs_add_le _ _
    _ < ε / 2 + ε / 2 := by linarith
    _ = ε := by ring

theorem diff_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n - b n) atTop (𝓝 (A - B)) := by
  have h := sum_rule a (fun n => -b n) A (-B) ha hb.neg
  simp only [← sub_eq_add_neg] at h
  exact h

theorem mul_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n * b n) atTop (𝓝 (A * B)) :=
  ha.mul hb

theorem div_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) (hB : B ≠ 0) :
    Tendsto (fun n => a n / b n) atTop (𝓝 (A / B)) :=
  ha.div hb hB

theorem abs_rule (a : ℕ → ℝ) (A : ℝ) (ha : Tendsto a atTop (𝓝 A)) :
    Tendsto (fun n => |a n|) atTop (𝓝 |A|) :=
  ha.abs

theorem npow_rule (a : ℕ → ℝ) (A : ℝ) (k : ℕ) (ha : Tendsto a atTop (𝓝 A)) :
    Tendsto (fun n => a n ^ k) atTop (𝓝 (A ^ k)) :=
  ha.pow k

theorem zpow_rule (a : ℕ → ℝ) (A : ℝ) (k : ℤ) (ha : Tendsto a atTop (𝓝 A)) (hA : A ≠ 0) :
    Tendsto (fun n => a n ^ k) atTop (𝓝 (A ^ k)) :=
  ha.zpow₀ k (Or.inl hA)

theorem pow_rule (a : ℕ → ℝ) (A p : ℝ) (ha : Tendsto a atTop (𝓝 A)) (hA : 0 < A) :
    Tendsto (fun n => a n ^ p) atTop (𝓝 (A ^ p)) :=
  ha.rpow_const (Or.inl hA.ne')

theorem squeeze (a b c : ℕ → ℝ) (L : ℝ) (ha : Tendsto a atTop (𝓝 L))
    (hb : Tendsto b atTop (𝓝 L)) (hac : ∀ n, a n ≤ c n) (hcb : ∀ n, c n ≤ b n) :
    Tendsto c atTop (𝓝 L) :=
  tendsto_of_tendsto_of_tendsto_of_le_of_le ha hb hac hcb
