1. What is proved: the statement in the book and in Lean

  • If $0\le a_n\le b_n$ for every $n$ and $\sum b_n$ converges, then $\sum a_n$ also converges
    theorem comparison (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hb : Summable b) : Summable a
  • The same, when $0\le a_n\le b_n$ holds only for $n\ge N$
    theorem comparison_from (a b : ℕ → ℝ) (N : ℕ) (ha : ∀ n ≥ N, 0 ≤ a n)
    (hab : ∀ n ≥ N, a n ≤ b n) (hb : Summable b) : Summable a
  • If $\sum a_n$ diverges, then $\sum b_n$ also diverges
    theorem comparison_diverges (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hdiv : ¬ Summable a) : ¬ Summable b

The convergence of a series is written Summable. For real numbers this Mathlib notion means absolute convergence, but for series with nonnegative terms, as here, it is exactly convergence in the sense of the book; divergence is written ¬ Summable. The sum of the series $\sum_{n=0}^{\infty}b_n$ is written ∑' n, b n, and the indexing of the terms starts at $0$. The version with $n\ge N$ reduces to the first one via the “tails” $a_{n+N}$ and $b_{n+N}$: a series converges exactly when its tail converges.

2. Step by step: $0\le a_n\le b_n$ and $\sum b_n$ converges $\Rightarrow$ $\sum a_n$ converges

The idea: the partial sums of $\sum a_n$ increase and are bounded by the sum of $\sum b_n$. We start from the goal:

The goal
a b : ℕ → ℝ
ha : ∀ (n : ℕ), 0 ≤ a n
hab : ∀ (n : ℕ), a n ≤ b n
hb : Summable b
⊢ Summable a

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- the partial sums of a are bounded by the sum of b
have hbound : ∀ N, ∑ n ∈ Finset.range N, a n ≤ ∑' n, b n := by
  intro N

    We first show that every partial sum of $a$ is at most $\sum_{n=0}^{\infty}b_n$. We take an arbitrary $N$.

    What remains to be proved
    N : ℕ
⊢ ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
  2. -- term by term: a n ≤ b n
have h1 : ∑ n ∈ Finset.range N, a n ≤ ∑ n ∈ Finset.range N, b n :=
  Finset.sum_le_sum fun n _ => hab n

    Term by term $a_n\le b_n$, so $a_0+\dots+a_{N-1}\le b_0+\dots+b_{N-1}$.

    What remains to be proved
    h1 : ∑ n ∈ Finset.range N, a n ≤ ∑ n ∈ Finset.range N, b n
⊢ ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
  3. -- every partial sum of b is ≤ the sum of the series, because b n ≥ 0
have h2 : ∑ n ∈ Finset.range N, b n ≤ ∑' n, b n :=
  hb.sum_le_tsum (Finset.range N) fun n _ => (ha n).trans (hab n)

    The terms of $b$ are nonnegative, since $b_n\ge a_n\ge 0$; hence every partial sum of $b$ is at most the sum of the whole series.

    What remains to be proved
    h2 : ∑ n ∈ Finset.range N, b n ≤ ∑' (n : ℕ), b n
⊢ ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
  4. exact h1.trans h2

    The two inequalities give the bound hbound for every $N$. A series with nonnegative terms and bounded partial sums converges, because the partial sums form an increasing sequence that is bounded above; this completes the proof.

    What remains to be proved
    hbound : ∀ (N : ℕ), ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
⊢ Summable a

Hint

By contradiction: if $\sum b_n$ converged, the test would give that $\sum a_n$ converges as well. exact fun hb => hdiv (comparison a b ha hab hb).

Solution
theorem comparison_diverges (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hdiv : ¬ Summable a) : ¬ Summable b :=
  fun hb => hdiv (comparison a b ha hab hb)

4. In Mathlib

We used the following theorems:

  • Finset.sum_le_sum: if $f(i)\le g(i)$ for every $i$, then $\sum f(i)\le\sum g(i)$ for a finite sum.
  • Summable.sum_le_tsum: for a series with nonnegative terms, every partial sum is at most the sum of the series.
  • summable_of_sum_range_le: nonnegative terms and bounded partial sums: the series converges.
  • summable_nat_add_iff: a series converges exactly when its tail $\sum a_{n+N}$ converges.

import Mathlib

namespace Ch19.KritirioSygkrisis

theorem comparison (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hb : Summable b) : Summable a := by
  -- the partial sums of a are bounded by the sum of b
  have hbound : ∀ N, ∑ n ∈ Finset.range N, a n ≤ ∑' n, b n := by
    intro N
    -- term by term: a n ≤ b n
    have h1 : ∑ n ∈ Finset.range N, a n ≤ ∑ n ∈ Finset.range N, b n :=
      Finset.sum_le_sum fun n _ => hab n
    -- every partial sum of b is ≤ the sum of the series, because b n ≥ 0
    have h2 : ∑ n ∈ Finset.range N, b n ≤ ∑' n, b n :=
      hb.sum_le_tsum (Finset.range N) fun n _ => (ha n).trans (hab n)
    exact h1.trans h2
  -- nonnegative terms with bounded partial sums: the series converges
  exact summable_of_sum_range_le ha hbound

-- the same, when 0 ≤ a n ≤ b n holds only for n ≥ N
theorem comparison_from (a b : ℕ → ℝ) (N : ℕ) (ha : ∀ n ≥ N, 0 ≤ a n)
    (hab : ∀ n ≥ N, a n ≤ b n) (hb : Summable b) : Summable a := by
  -- we apply the test to the tails a (n + N) and b (n + N)
  have h := comparison (fun n => a (n + N)) (fun n => b (n + N))
    (fun n => ha (n + N) (Nat.le_add_left N n)) (fun n => hab (n + N) (Nat.le_add_left N n))
    ((summable_nat_add_iff N).mpr hb)
  exact (summable_nat_add_iff N).mp h

theorem comparison_diverges (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hdiv : ¬ Summable a) : ¬ Summable b :=
  fun hb => hdiv (comparison a b ha hab hb)

end Ch19.KritirioSygkrisis
