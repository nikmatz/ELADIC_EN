1. What is proved: the statement in the book and in Lean

  • If $\sqrt[n]{|a_n|}\le q$ for large $n$, with $q\lt 1$ (that is, $\limsup\sqrt[n]{|a_n|}\lt 1$), then $\sum a_n$ converges absolutely
    theorem root_test (a : ℕ → ℝ) (q : ℝ) (hq : q < 1)
    (h : ∀ᶠ n in atTop, |a n| ^ ((n : ℝ)⁻¹) ≤ q) : Summable a
  • In particular, if $\sqrt[n]{|a_n|}\to L$ with $L\lt 1$, the series converges absolutely
    theorem root_test_limit (a : ℕ → ℝ) (L : ℝ) (hL : L < 1)
    (h : Tendsto (fun n => |a n| ^ ((n : ℝ)⁻¹)) atTop (𝓝 L)) : Summable a
  • If $\sqrt[n]{|a_n|}\gt 1$ for infinitely many $n$, which holds when $\limsup\sqrt[n]{|a_n|}\gt 1$, the series diverges
    theorem root_test_diverges (a : ℕ → ℝ) (h : ∃ᶠ n in atTop, 1 < |a n| ^ ((n : ℝ)⁻¹)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)

The root $\sqrt[n]{|a_n|}$ is written as a power with exponent $\tfrac1n$: |a n| ^ ((n : ℝ)⁻¹). Instead of $\limsup$ we use its elementary meaning: $\limsup\sqrt[n]{|a_n|}\lt 1$ means that there exists $q\lt 1$ with $\sqrt[n]{|a_n|}\le q$ for large $n$ (∀ᶠ n in atTop), and $\limsup\sqrt[n]{|a_n|}\gt 1$ implies that $\sqrt[n]{|a_n|}\gt 1$ for infinitely many $n$ (∃ᶠ n in atTop). Absolute convergence is written Summable a. For divergence, $|a_n|\gt 1$ holds for infinitely many $n$, so $a_n\to 0$ does not hold and the necessary condition fails. The case $L=1$, where the test is inconclusive, is not stated.

2. Step by step: $\sqrt[n]{|a_n|}\le q\lt 1$ $\Rightarrow$ $\sum a_n$ converges absolutely

The idea: for large $n$ we have $|a_n|\le q^n$, and we compare with the geometric series. We start from the goal:

The goal
a : ℕ → ℝ
q : ℝ
hq : q < 1
h : ∀ᶠ (n : ℕ) in atTop, |a n| ^ (↑n)⁻¹ ≤ q
⊢ Summable a

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- for large n: |a n| ≤ qⁿ
have h1 : ∀ᶠ n in atTop, |a n| ≤ q ^ n := by
  filter_upwards [h, eventually_ge_atTop 1] with n hn hn1

    We first show that $|a_n|\le q^n$ for large $n$. We take $n\ge 1$ with $\sqrt[n]{|a_n|}\le q$.

    What remains to be proved
    n : ℕ
hn : |a n| ^ (↑n)⁻¹ ≤ q
hn1 : 1 ≤ n
⊢ |a n| ≤ q ^ n
  2. have hn0 : n ≠ 0 := by omega

    For $n\ge 1$ we have $n\neq 0$, which is needed for the identity $\left(\sqrt[n]{x}\right)^n=x$.

    What remains to be proved
    hn0 : n ≠ 0
⊢ |a n| ≤ q ^ n
  3. calc |a n| = (|a n| ^ ((n : ℝ)⁻¹)) ^ n := (Real.rpow_inv_natCast_pow (abs_nonneg _) hn0).symm
  _ ≤ q ^ n := pow_le_pow_left₀ (Real.rpow_nonneg (abs_nonneg _) _) hn n

    We raise to the power $n$: $|a_n|$${}=\left(\sqrt[n]{|a_n|}\right)^n\le q^n$. Thus we have h1: $|a_n|\le q^n$ for large $n$.

    What remains to be proved
    h1 : ∀ᶠ (n : ℕ) in atTop, |a n| ≤ q ^ n
⊢ Summable a
  4. -- q is nonnegative
have hq0 : 0 ≤ q := by
  obtain ⟨n, hn⟩ := h.exists
  exact (Real.rpow_nonneg (abs_nonneg _) _).trans hn

    $q$ is nonnegative, because it is greater than or equal to a root, and roots are $\ge 0$.

    What remains to be proved
    hq0 : 0 ≤ q
⊢ Summable a
  5. -- the geometric series Σ qⁿ converges, because 0 ≤ q < 1
have hgeom : Summable (fun n => q ^ n) := summable_geometric_of_lt_one hq0 hq

    Since $0\le q\lt 1$, the geometric series $\sum q^n$ converges. The comparison $|a_n|\le q^n$ for large $n$ gives that $\sum a_n$ converges absolutely, and this completes the proof.

    What remains to be proved
    hgeom : Summable fun n => q ^ n
⊢ Summable a

4. In Mathlib

We used the following theorems:

  • Real.rpow_inv_natCast_pow: $\left(\sqrt[n]{x}\right)^n=x$ for $x\ge 0$ and $n\neq 0$.
  • pow_le_pow_left₀: if $0\le x\le y$, then $x^n\le y^n$.
  • summable_geometric_of_lt_one: $\sum q^n$ converges for $0\le q\lt 1$.
  • Summable.of_norm_bounded_eventually_nat: if $|a_n|\le b_n$ for large $n$ and $\sum b_n$ converges, then $\sum a_n$ converges absolutely.
  • Real.rpow_le_one: $x^t\le 1$ for $0\le x\le 1$ and $t\ge 0$.

import Mathlib

namespace Ch19.KritirioRizas
open Filter Topology

-- for large n, ⁿ√|a n| is ≤ q, with q < 1 (this is what limsup ⁿ√|a n| < 1 means)
theorem root_test (a : ℕ → ℝ) (q : ℝ) (hq : q < 1)
    (h : ∀ᶠ n in atTop, |a n| ^ ((n : ℝ)⁻¹) ≤ q) : Summable a := by
  -- for large n: |a n| ≤ qⁿ
  have h1 : ∀ᶠ n in atTop, |a n| ≤ q ^ n := by
    filter_upwards [h, eventually_ge_atTop 1] with n hn hn1
    have hn0 : n ≠ 0 := by omega
    calc |a n| = (|a n| ^ ((n : ℝ)⁻¹)) ^ n := (Real.rpow_inv_natCast_pow (abs_nonneg _) hn0).symm
      _ ≤ q ^ n := pow_le_pow_left₀ (Real.rpow_nonneg (abs_nonneg _) _) hn n
  -- q is nonnegative
  have hq0 : 0 ≤ q := by
    obtain ⟨n, hn⟩ := h.exists
    exact (Real.rpow_nonneg (abs_nonneg _) _).trans hn
  -- the geometric series Σ qⁿ converges, because 0 ≤ q < 1
  have hgeom : Summable (fun n => q ^ n) := summable_geometric_of_lt_one hq0 hq
  -- comparison with the geometric series
  exact hgeom.of_norm_bounded_eventually_nat (by simpa [Real.norm_eq_abs] using h1)

theorem root_test_limit (a : ℕ → ℝ) (L : ℝ) (hL : L < 1)
    (h : Tendsto (fun n => |a n| ^ ((n : ℝ)⁻¹)) atTop (𝓝 L)) : Summable a :=
  root_test a ((L + 1) / 2) (by linarith) (h.eventually (ge_mem_nhds (by linarith)))

-- if frequently ⁿ√|a n| > 1 (limsup > 1), the partial sums do not converge
theorem root_test_diverges (a : ℕ → ℝ) (h : ∃ᶠ n in atTop, 1 < |a n| ^ ((n : ℝ)⁻¹)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S) := by
  rintro ⟨S, hS⟩
  have h0 : Tendsto a atTop (𝓝 0) := by
    have h1 := (hS.comp (tendsto_add_atTop_nat 1)).sub hS
    simp only [Function.comp_def, Finset.sum_range_succ, add_sub_cancel_left, sub_self] at h1
    exact h1
  have h2 : ∀ᶠ n in atTop, |a n| < 1 := by
    have h3 := h0.abs.eventually (gt_mem_nhds (show |(0 : ℝ)| < 1 by norm_num))
    exact h3
  obtain ⟨n, hn1, hn2⟩ := (h.and_eventually h2).exists
  have h4 := Real.rpow_le_one (abs_nonneg (a n)) hn2.le (inv_nonneg.mpr (Nat.cast_nonneg n))
  linarith

end Ch19.KritirioRizas
