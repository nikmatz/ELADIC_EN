1. What is proved: the statement in the book and in Lean

  • If $f$ is differentiable and $f(x)\neq 0$ on $I$, then $\bigl(\ln|f(x)|\bigr)'$${}=\dfrac{f'(x)}{f(x)}$, that is, $\int\dfrac{f'(x)}{f(x)}\,dx$${}=\ln|f(x)|+C$
    theorem log_rule (f f' : ℝ → ℝ) (I : Set ℝ) (hf : ∀ x ∈ I, HasDerivAt f (f' x) x)
    (hne : ∀ x ∈ I, f x ≠ 0) :
    ∀ x ∈ I, HasDerivAt (fun x => Real.log |f x|) (f' x / f x) x
  • Example: $\bigl(\ln|\cos x|\bigr)'$${}=\dfrac{-\sin x}{\cos x}$, so $\int\tan x\,dx=-\ln|\cos x|+C$
    theorem tan_rule (x : ℝ) (hx : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |Real.cos x|) (-Real.sin x / Real.cos x) x

The formula $\int\dfrac{f'(x)}{f(x)}\,dx$${}=\ln|f(x)|+C$ is written as “$\ln|f(x)|$ has derivative $\dfrac{f'(x)}{f(x)}$ at every point of $I$”. In Mathlib the logarithm Real.log is defined for every real number, with $\ln t=\ln|t|$ when $t\lt 0$ (and $\ln 0=0$). That is why the absolute value disappears at once (Real.log_abs), and the formula $(\ln t)'=\dfrac{1}{t}$ holds for every $t\neq 0$. In the book the same result is obtained by examining the cases $f\gt 0$ and $f\lt 0$ separately.

2. Step by step: $\bigl(\ln|f|\bigr)'=\dfrac{f'}{f}$

The idea: in Lean $\ln|t|=\ln t$, so what remains is the chain rule for $\ln f(x)$. We start from the goal:

The goal
f f' : ℝ → ℝ
I : Set ℝ
hf : ∀ x ∈ I, HasDerivAt f (f' x) x
hne : ∀ x ∈ I, f x ≠ 0
⊢ ∀ x ∈ I, HasDerivAt (fun x => Real.log |f x|) (f' x / f x) x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro x hx

    We take an arbitrary $x\in I$.

    What remains to be proved
    x : ℝ
hx : x ∈ I
⊢ HasDerivAt (fun x => Real.log |f x|) (f' x / f x) x
  2. have habs : (fun x => Real.log |f x|) = fun x => Real.log (f x) := by

    Claim habs: in Lean, $\ln|t|=\ln t$ for every $t$.

    What remains to be proved
    ⊢ (fun x => Real.log |f x|) = fun x => Real.log (f x)
  3. funext y
exact Real.log_abs (f y)

    This is the theorem Real.log_abs: the Mathlib logarithm is also defined for negative numbers, as $\ln|t|$.

    ✓ This part is complete.
  4. rw [habs]

    So it suffices to find the derivative of $\ln f(x)$.

    What remains to be proved
    f f' : ℝ → ℝ
I : Set ℝ
hf : ∀ x ∈ I, HasDerivAt f (f' x) x
hne : ∀ x ∈ I, f x ≠ 0
x : ℝ
hx : x ∈ I
habs : (fun x => Real.log |f x|) = fun x => Real.log (f x)
⊢ HasDerivAt (fun x => Real.log (f x)) (f' x / f x) x
  5. have hlog : HasDerivAt Real.log (f x)⁻¹ (f x) := Real.hasDerivAt_log (hne x hx)

    The derivative of the logarithm at the point $f(x)\neq 0$ is $\dfrac{1}{f(x)}$.

    What remains to be proved
    hlog : HasDerivAt Real.log (f x)⁻¹ (f x)
⊢ HasDerivAt (fun x => Real.log (f x)) (f' x / f x) x
  6. have hfx := hf x hx

    $f$ has derivative $f'(x)$ at $x$.

    What remains to be proved
    hfx : HasDerivAt f (f' x) x
⊢ HasDerivAt (fun x => Real.log (f x)) (f' x / f x) x
  7. have h := hlog.comp x hfx

    Chain rule: $\ln f(x)$ has derivative $\dfrac{1}{f(x)}\cdot f'(x)$.

    What remains to be proved
    h : HasDerivAt (Real.log ∘ f) ((f x)⁻¹ * f' x) x
⊢ HasDerivAt (fun x => Real.log (f x)) (f' x / f x) x
  8. rw [div_eq_mul_inv, mul_comm]

    We write $\dfrac{f'(x)}{f(x)}$ as $\dfrac{1}{f(x)}\cdot f'(x)$.

    What remains to be proved
    ⊢ HasDerivAt (fun x => Real.log (f x)) ((f x)⁻¹ * f' x) x
  9. exact h

    This is exactly h.

    ✓ No goals: the proof is complete.

theorem tan_rule (x : ℝ) (hx : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |Real.cos x|) (-Real.sin x / Real.cos x) x := by

4. In Mathlib

We used the following theorems:

  • Real.log_abs: in Mathlib, $\ln|t|=\ln t$.
  • Real.hasDerivAt_log: the derivative of the logarithm, for $t\neq 0$.
  • HasDerivAt.comp: the chain rule.
  • div_eq_mul_inv: $\dfrac{a}{b}=a\cdot\dfrac{1}{b}$.
  • Real.hasDerivAt_cos: the derivative of $\cos x$.

theorem log_rule (f f' : ℝ → ℝ) (I : Set ℝ) (hf : ∀ x ∈ I, HasDerivAt f (f' x) x)
    (hne : ∀ x ∈ I, f x ≠ 0) :
    ∀ x ∈ I, HasDerivAt (fun x => Real.log |f x|) (f' x / f x) x := by
  intro x hx
  have habs : (fun x => Real.log |f x|) = fun x => Real.log (f x) := by
    funext y
    exact Real.log_abs (f y)
  rw [habs]
  have hlog : HasDerivAt Real.log (f x)⁻¹ (f x) := Real.hasDerivAt_log (hne x hx)
  have hfx := hf x hx
  have h := hlog.comp x hfx
  rw [div_eq_mul_inv, mul_comm]
  exact h

theorem tan_rule (x : ℝ) (hx : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |Real.cos x|) (-Real.sin x / Real.cos x) x := by
  exact log_rule Real.cos (fun x => -Real.sin x) {y | Real.cos y ≠ 0}
    (fun y _ => Real.hasDerivAt_cos y) (fun y hy => hy) x hx

end Ch13.LogarithmikosKanonas
