1. What is proved: the statement in the book and in Lean

  • If $F'=f$ and $a\neq 0$, then $\left(\dfrac{1}{a}F(ax+b)\right)'$${}=f(ax+b)$, that is, $\int f(ax+b)\,dx$${}=\dfrac{1}{a}F(ax+b)+C$
    theorem linear_substitution (F f : ℝ → ℝ) (a b : ℝ) (ha : a ≠ 0)
    (hF : ∀ u, HasDerivAt F (f u) u) :
    ∀ x, HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x
  • Example: $\int e^{ax+b}\,dx$${}=\dfrac{1}{a}e^{ax+b}+C$
    theorem exp_linear (a b : ℝ) (ha : a ≠ 0) :
    ∀ x, HasDerivAt (fun x => 1 / a * Real.exp (a * x + b)) (Real.exp (a * x + b)) x

The indefinite integral $\int f(x)\,dx=F(x)+C$ means that $F$ is an antiderivative of $f$, that is, $F$ has derivative $f$: this is written HasDerivAt F (f x) x. Here we assume that this holds at every point (∀ u, HasDerivAt F (f u) u). The proof is the chain rule: the derivative of $F(ax+b)$ is $f(ax+b)\cdot a$, and the factor $\dfrac{1}{a}$ cancels the $a$. The composition $x\mapsto F(ax+b)$ is written F ∘ fun x => a * x + b. The rule holds only for a first-degree inner argument: for any other $u(x)$ the chain rule gives the factor $u'(x)$, which is not constant.

2. Step by step: $\int f(ax+b)\,dx$

The idea: we differentiate $\dfrac{1}{a}F(ax+b)$ with the chain rule and find $f(ax+b)$. We start from the goal:

The goal
F f : ℝ → ℝ
a b : ℝ
ha : a ≠ 0
hF : ∀ (u : ℝ), HasDerivAt F (f u) u
⊢ ∀ (x : ℝ), HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro x

    We take an arbitrary $x$.

    What remains to be proved
    x : ℝ
⊢ HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x
  2. have h1 : HasDerivAt (fun x => a * x + b) a x := by

    Claim h1: $u=ax+b$ has derivative $a$.

    What remains to be proved
    ⊢ HasDerivAt (fun x => a * x + b) a x
  3. simpa using ((hasDerivAt_id x).const_mul a).add_const b

    This follows from the rules for $a\cdot x$ and for adding a constant; simpa does the simplifications.

    ✓ This part is complete.
  4. have hFx := hF (a * x + b)

    $F$ has derivative $f(ax+b)$ at the point $u=ax+b$.

    What remains to be proved
    F f : ℝ → ℝ
a b : ℝ
ha : a ≠ 0
hF : ∀ (u : ℝ), HasDerivAt F (f u) u
x : ℝ
h1 : HasDerivAt (fun x => a * x + b) a x
hFx : HasDerivAt F (f (a * x + b)) (a * x + b)
⊢ HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x
  5. have h2 := hFx.comp x h1

    Chain rule: $x\mapsto F(ax+b)$ has derivative $f(ax+b)\cdot a$.

    What remains to be proved
    h2 : HasDerivAt (F ∘ fun x => a * x + b) (f (a * x + b) * a) x
⊢ HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x
  6. have h3 : HasDerivAt (fun x => 1 / a * F (a * x + b)) (1 / a * (f (a * x + b) * a)) x :=
  h2.const_mul (1 / a)

    We multiply by the constant $\dfrac{1}{a}$: $\dfrac{1}{a}F(ax+b)$ has derivative $\dfrac{1}{a}\,f(ax+b)\,a$.

    What remains to be proved
    h3 : HasDerivAt (fun x => 1 / a * F (a * x + b)) (1 / a * (f (a * x + b) * a)) x
⊢ HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x
  7. convert h3 using 1

    The function is already the right one; it remains to show that the two derivatives are equal.

    What remains to be proved
    ⊢ f (a * x + b) = 1 / a * (f (a * x + b) * a)
  8. field_simp

    $\dfrac{1}{a}\,f(ax+b)\,a=f(ax+b)$, since $a\neq 0$. The simplification is done by field_simp.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • HasDerivAt.comp: the chain rule.
  • HasDerivAt.const_mul: the rule for $c\,f(x)$.
  • HasDerivAt.add_const: $f(x)+c$ has the same derivative as $f$.
  • hasDerivAt_id: the derivative of $x\mapsto x$ is $1$.
  • Real.hasDerivAt_exp: the derivative of $e^x$.

theorem linear_substitution (F f : ℝ → ℝ) (a b : ℝ) (ha : a ≠ 0)
    (hF : ∀ u, HasDerivAt F (f u) u) :
    ∀ x, HasDerivAt (fun x => 1 / a * F (a * x + b)) (f (a * x + b)) x := by
  intro x
  have h1 : HasDerivAt (fun x => a * x + b) a x := by
    simpa using ((hasDerivAt_id x).const_mul a).add_const b
  have hFx := hF (a * x + b)
  have h2 := hFx.comp x h1
  have h3 : HasDerivAt (fun x => 1 / a * F (a * x + b)) (1 / a * (f (a * x + b) * a)) x :=
    h2.const_mul (1 / a)
  convert h3 using 1
  field_simp

theorem exp_linear (a b : ℝ) (ha : a ≠ 0) :
    ∀ x, HasDerivAt (fun x => 1 / a * Real.exp (a * x + b)) (Real.exp (a * x + b)) x := by
  exact linear_substitution Real.exp Real.exp a b ha Real.hasDerivAt_exp

end Ch13.GrammikiAntikatastasi
