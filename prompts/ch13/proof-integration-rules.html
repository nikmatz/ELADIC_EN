Basic Rules of Integration

Chapter 13 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $f,g$ be functions having an antiderivative on an interval $I$ (for example, continuous ones) and let $\lambda,\mu\in\mathbb{R}$ be constants. Then the indefinite integral is linear: $\int\bigl(\lambda f(x)+\mu g(x)\bigr)\,dx=\lambda\int f(x)\,dx+\mu\int g(x)\,dx$. In particular, $\int \lambda f\,dx=\lambda\int f\,dx$ and $\int (f\pm g)\,dx=\int f\,dx\pm\int g\,dx$.

The indefinite integral $\int f(x)\,dx=F(x)+C$ means that $F$ is an antiderivative of $f$, that is, $F$ has derivative $f$: this is written HasDerivAt F (f x) x. On the set $I$ it is written ∀ x ∈ I, HasDerivAt F (f x) x. Thus the equality $\int(c_1f+c_2g)\,dx$${}=c_1\int f\,dx+c_2\int g\,dx$ says that $c_1F+c_2G$ is an antiderivative of $c_1f+c_2g$; the constant $C$ absorbs the constants of the two integrals. The book's constants $\lambda,\mu$ are written c₁ and c₂, because λ is a reserved word in Lean.

2. Step by step: linearity

The idea: the differentiation rules for a constant multiple and for a sum, read in reverse. We start from the goal:

The goal
F G f g : ℝ → ℝ
c₁ c₂ : ℝ
I : Set ℝ
hF : ∀ x ∈ I, HasDerivAt F (f x) x
hG : ∀ x ∈ I, HasDerivAt G (g x) x
⊢ ∀ x ∈ I, HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro x hx

    We take an arbitrary $x\in I$.

    What remains to be proved
    x : ℝ
hx : x ∈ I
⊢ HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x
  2. have h1 : HasDerivAt (fun x => c₁ * F x) (c₁ * f x) x := (hF x hx).const_mul c₁

    Constant multiple rule: $c_1F$ has derivative $c_1f$.

    What remains to be proved
    h1 : HasDerivAt (fun x => c₁ * F x) (c₁ * f x) x
⊢ HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x
  3. have h2 : HasDerivAt (fun x => c₂ * G x) (c₂ * g x) x := (hG x hx).const_mul c₂

    Similarly, $c_2G$ has derivative $c_2g$.

    What remains to be proved
    h2 : HasDerivAt (fun x => c₂ * G x) (c₂ * g x) x
⊢ HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x
  4. exact h1.add h2

    Sum rule: $c_1F+c_2G$ has derivative $c_1f+c_2g$.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch13.KanonesOloklirwsis

-- ∫ (c₁ f + c₂ g) dx = c₁ ∫ f dx + c₂ ∫ g dx, written with antiderivatives
theorem linearity (F G f g : ℝ → ℝ) (c₁ c₂ : ℝ) (I : Set ℝ)
    (hF : ∀ x ∈ I, HasDerivAt F (f x) x) (hG : ∀ x ∈ I, HasDerivAt G (g x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x := by
  intro x hx
  have h1 : HasDerivAt (fun x => c₁ * F x) (c₁ * f x) x := (hF x hx).const_mul c₁
  have h2 : HasDerivAt (fun x => c₂ * G x) (c₂ * g x) x := (hG x hx).const_mul c₂
  exact h1.add h2

theorem const_mul_rule (F f : ℝ → ℝ) (c : ℝ) (I : Set ℝ) (hF : ∀ x ∈ I, HasDerivAt F (f x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => c * F x) (c * f x) x :=
  fun x hx => (hF x hx).const_mul c

theorem add_rule (F G f g : ℝ → ℝ) (I : Set ℝ)
    (hF : ∀ x ∈ I, HasDerivAt F (f x) x) (hG : ∀ x ∈ I, HasDerivAt G (g x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => F x + G x) (f x + g x) x :=
  fun x hx => (hF x hx).add (hG x hx)

theorem sub_rule (F G f g : ℝ → ℝ) (I : Set ℝ)
    (hF : ∀ x ∈ I, HasDerivAt F (f x) x) (hG : ∀ x ∈ I, HasDerivAt G (g x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => F x - G x) (f x - g x) x := by
  intro x hx
  exact (hF x hx).sub (hG x hx)

end Ch13.KanonesOloklirwsis
