Basic Rules of Integration

Proof with the help of a Large Language Model (AI)

StatementLet $f,g$ be functions having an antiderivative on an interval $I$ (for example, continuous ones) and let $\lambda,\mu\in\mathbb{R}$ be constants. Then the indefinite integral is linear: $\int\bigl(\lambda f(x)+\mu g(x)\bigr)\,dx=\lambda\int f(x)\,dx+\mu\int g(x)\,dx$. In particular, $\int \lambda f\,dx=\lambda\int f\,dx$ and $\int (f\pm g)\,dx=\int f\,dx\pm\int g\,dx$.
