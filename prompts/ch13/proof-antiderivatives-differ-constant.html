Antiderivatives Differ by a Constant

StatementIf $F$ and $G$ are antiderivatives of the same function $f$ on an interval $I$, that is, $F′(x)=G′(x)=f(x)$ for every $x\in I$, then there exists a constant $C\in\mathbb{R}$ such that $G(x)=F(x)+C$ for every $x\in I$.

1. What is proved: the statement in the book and in Lean

  • If $F'=G'=f$ on $(a,b)$, there exists a constant $C$ such that $G(x)=F(x)+C$ for every $x\in(a,b)$
    theorem antiderivatives_differ_const (F G f : ℝ → ℝ) (a b : ℝ)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x) :
    ∃ C, ∀ x ∈ Set.Ioo a b, G x = F x + C
  • Application: if moreover $G(x_0)=F(x_0)$ at one point, then $G=F$ on all of $(a,b)$
    theorem same_value_same_function (F G f : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x)
    (h0 : G x₀ = F x₀) : ∀ x ∈ Set.Ioo a b, G x = F x

“$F$ is an antiderivative of $f$ on the interval” is written ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x: at every point of $(a,b)$, $F$ has derivative $f(x)$. As the interval $I$ we take an open interval $(a,b)$. The proof uses the mean value theorem (exists_hasDerivAt_eq_slope): $H=G-F$ has derivative $0$, so it takes the same value at all points of the interval. The hypothesis that $I$ is an interval is needed, because on two disjoint intervals the constants may differ.

2. Step by step: $G=F+C$

The idea: $H=G-F$ has derivative $0$, so by the mean value theorem it is constant; the constant is its value at the midpoint of the interval. We start from the goal:

⊢ ∃ C, ∀ x ∈ Set.Ioo a b, G x = F x + C

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

4. In Mathlib

We used the following theorems:

  • exists_hasDerivAt_eq_slope: the mean value theorem.
  • HasDerivAt.sub: the difference rule.
  • HasDerivAt.continuousAt: a differentiable function is continuous.
  • div_eq_zero_iff: $\dfrac{a}{b}=0$ exactly when $a=0$ or $b=0$.
  • lt_trichotomy: for two numbers, $x\lt y$, $x=y$, or $x\gt y$.

theorem antiderivatives_differ_const (F G f : ℝ → ℝ) (a b : ℝ)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x) :
    ∃ C, ∀ x ∈ Set.Ioo a b, G x = F x + C := by
  -- the difference H = G - F has derivative 0
  have hH : ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => G x - F x) 0 x := by
    intro x hx
    have h := (hG x hx).sub (hF x hx)
    rw [sub_self] at h
    exact h
  -- mean value theorem: H takes the same value at any two points
  have hconst : ∀ x ∈ Set.Ioo a b, ∀ y ∈ Set.Ioo a b, x < y → G y - F y = G x - F x := by
    intro x hx y hy hxy
    have hcont : ContinuousOn (fun x => G x - F x) (Set.Icc x y) := fun z hz =>
      (hH z ⟨hx.1.trans_le hz.1, hz.2.trans_lt hy.2⟩).continuousAt.continuousWithinAt
    obtain ⟨c, -, hc⟩ := exists_hasDerivAt_eq_slope (fun x => G x - F x) (fun _ => 0) hxy hcont
      (fun z hz => hH z ⟨hx.1.trans hz.1, hz.2.trans hy.2⟩)
    have h : (G y - F y - (G x - F x)) / (y - x) = 0 := hc.symm
    rw [div_eq_zero_iff, sub_eq_zero] at h
    exact h.resolve_right (sub_ne_zero.mpr hxy.ne')
  by_cases hab : a < b
  · have hm : (a + b) / 2 ∈ Set.Ioo a b := ⟨by linarith, by linarith⟩
    refine ⟨G ((a + b) / 2) - F ((a + b) / 2), fun x hx => ?_⟩
    rcases lt_trichotomy x ((a + b) / 2) with h | h | h
    · have := hconst x hx _ hm h
      linarith
    · rw [h]
      ring
    · have := hconst _ hm x hx h
      linarith
  · exact ⟨0, fun x hx => absurd (hx.1.trans hx.2) hab⟩

theorem same_value_same_function (F G f : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x)
    (h0 : G x₀ = F x₀) : ∀ x ∈ Set.Ioo a b, G x = F x := by
  obtain ⟨C, hC⟩ := antiderivatives_differ_const F G f a b hF hG
  have hC0 : C = 0 := by
    have h := hC x₀ hx₀
    linarith
  intro x hx
  rw [hC x hx, hC0, add_zero]
