1. What is proved: the statement in the book and in Lean

  • Law of Cosines: $c^2=a^2+b^2-2ab\cos C$
    theorem cosines (A B C : EuclideanSpace ℝ (Fin 2)) :
    dist A B ^ 2 = dist B C ^ 2 + dist C A ^ 2
      - 2 * dist B C * dist C A * Real.cos (∠ A C B)
  • Law of Sines: $\dfrac{a}{\sin A}$${}=\dfrac{b}{\sin B}$
    theorem sines (A B C : EuclideanSpace ℝ (Fin 2)) :
    dist B C * Real.sin (∠ A B C) = dist C A * Real.sin (∠ B A C)

The triangle is given by its vertices A B C in the plane. The sides are distances: $a=$ dist B C, $b=$ dist C A, $c=$ dist A B. The angle $C$ is ∠ A C B (vertex at $C$), $A$ is ∠ B A C and $B$ is ∠ A B C. We write the Law of Sines without division, $a\sin B=b\sin A$, which says the same thing without having to check that the sines are nonzero. The equality with $\dfrac{c}{\sin C}$ follows in the same way.

2. Where it is in Mathlib

Both laws are in Mathlib, for triangles in any Euclidean space:

  • EuclideanGeometry.law_cos: the Law of Cosines.
  • EuclideanGeometry.law_sin: the Law of Sines, in product form.

import Mathlib

namespace Ch0.NomoiTrig
open EuclideanGeometry

theorem cosines (A B C : EuclideanSpace ℝ (Fin 2)) :
    dist A B ^ 2 = dist B C ^ 2 + dist C A ^ 2
      - 2 * dist B C * dist C A * Real.cos (∠ A C B) := by
  have h := law_cos A C B
  rw [dist_comm A C] at h
  linear_combination h

theorem sines (A B C : EuclideanSpace ℝ (Fin 2)) :
    dist B C * Real.sin (∠ A B C) = dist C A * Real.sin (∠ B A C) := by
  have h := law_sin A B C
  rw [angle_comm C A B] at h
  linear_combination h

end Ch0.NomoiTrig
