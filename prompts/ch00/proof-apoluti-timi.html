Properties of the Absolute Value

Chapter 0 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementProperties of the absolute value: $|a|\ge 0$ with $|a|=0\Leftrightarrow a=0$; $|ab|=|a|\,|b|$ and $\left|\dfrac{a}{b}\right|=\dfrac{|a|}{|b|}$ ($b\ne 0$); $|a|\lt b\Leftrightarrow -b\lt a\lt b$ (for $b\gt 0$); the triangle inequality $|a+b|\le|a|+|b|$ and the reverse triangle inequality $\bigl||a|-|b|\bigr|\le|a-b|$; geometrically, $|a-b|$ is the distance between $a$ and $b$.

  • $|a|\ge 0$
    theorem nonneg (a : ℝ) : |a| ≥ 0
  • $|a|=0\Leftrightarrow a=0$
    theorem eq_zero_iff (a : ℝ) : |a| = 0 ↔ a = 0
  • $|ab|=|a|\,|b|$
    theorem abs_product (a b : ℝ) : |a * b| = |a| * |b|
  • $\left|\dfrac{a}{b}\right|$${}=\dfrac{|a|}{|b|}$
    theorem abs_quotient (a b : ℝ) : |a / b| = |a| / |b|
  • $|a|\lt b\Leftrightarrow -b\lt a\lt b$
    theorem lt_iff (a b : ℝ) : |a| < b ↔ -b < a ∧ a < b
  • Triangle inequality: $|a+b|\le|a|+|b|$
    theorem triangle (a b : ℝ) : |a + b| ≤ |a| + |b|
  • Reverse triangle inequality: $\bigl||a|-|b|\bigr|\le|a-b|$

  • $|a-b|$ is the distance between $a,b$

The symbol ↔ means “if and only if”, and ∧ means “and”. Two small differences from the book: in Lean $\frac{a}{0}=0$, so the formula for $\left|\frac{a}{b}\right|$ holds even without the hypothesis $b\neq 0$; and the equivalence for $|a|\lt b$ does not need $b\gt 0$ (if $b\le 0$, both sides are false). Here dist a b is the distance as defined in Mathlib.

2. Step by step: the triangle inequality

In the book: $-|a|\le a\le|a|$ and $-|b|\le b\le|b|$; adding, $-(|a|+|b|)\le a+b\le|a|+|b|$, that is, $|a+b|\le|a|+|b|$. In Lean:

The goal
a b : ℝ
⊢ |a + b| ≤ |a| + |b|

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have ha₁ : -|a| ≤ a := neg_abs_le a
have ha₂ : a ≤ |a| := le_abs_self a
have hb₁ : -|b| ≤ b := neg_abs_le b
have hb₂ : b ≤ |b| := le_abs_self b

    We write down the four known inequalities: neg_abs_le is $-|x|\le x$ and le_abs_self is $x\le|x|$.

    What remains to be proved
    ha₁ : -|a| ≤ a
ha₂ : a ≤ |a|
hb₁ : -|b| ≤ b
hb₂ : b ≤ |b|
⊢ |a + b| ≤ |a| + |b|
  2. rw [abs_le]

    The theorem abs_le says that $|x|\le y$ if and only if $-y\le x\le y$. The goal becomes two inequalities.

    What remains to be proved
    ⊢ -(|a| + |b|) ≤ a + b ∧ a + b ≤ |a| + |b|
  3. constructor

    We split the two inequalities into two goals.

    What remains to be proved (2 goals)part left
    ⊢ -(|a| + |b|) ≤ a + b
    part right
    ⊢ a + b ≤ |a| + |b|
  4. · linarith

    The first, $-(|a|+|b|)\le a+b$, follows by adding $-|a|\le a$ and $-|b|\le b$. The addition is found by linarith.

    ✓ This part is complete.
  5. · linarith

    The second, $a+b\le|a|+|b|$, follows by adding $a\le|a|$ and $b\le|b|$.

    ✓ No goals: the proof is complete.

3. Try it yourself: the reverse triangle inequality

Hint

Write $a=(a-b)+b$ and apply triangle: you get $|a|\le|a-b|+|b|$. Do the same with $b=(b-a)+a$, where $|b-a|=|a-b|$ (abs_sub_comm). Then rw [abs_le], constructor and linarith.

Solution
theorem reverse_triangle (a b : ℝ) : |(|a| - |b|)| ≤ |a - b| := by
  have h₁ : |a| ≤ |a - b| + |b| := by
    calc |a| = |a - b + b| := by rw [sub_add_cancel]
      _ ≤ |a - b| + |b| := triangle (a - b) b
  have h₂ : |b| ≤ |a - b| + |a| := by
    calc |b| = |b - a + a| := by rw [sub_add_cancel]
      _ ≤ |b - a| + |a| := triangle (b - a) a
      _ = |a - b| + |a| := by rw [abs_sub_comm]
  rw [abs_le]
  constructor
  · linarith
  · linarith

  have hb₁ : -|b| ≤ b := neg_abs_le b
  have hb₂ : b ≤ |b| := le_abs_self b
