We write each formula for sine and cosine together; for the tangent, the formulas follow by division, since $\tan\omega$${}=\dfrac{\sin\omega}{\cos\omega}$.

1. What is proved: the statement in the book and in Lean

  • Angle $-\omega$: $\sin(-\omega)=-\sin\omega$, $\cos(-\omega)=\cos\omega$
    theorem neg_angle (ω : ℝ) : sin (-ω) = -sin ω ∧ cos (-ω) = cos ω
  • Angle $\frac{\pi}{2}-\omega$: sine $\cos\omega$, cosine $\sin\omega$
    theorem pi_div_two_sub (ω : ℝ) : sin (π / 2 - ω) = cos ω ∧ cos (π / 2 - ω) = sin ω
  • Angle $\frac{\pi}{2}+\omega$: sine $\cos\omega$, cosine $-\sin\omega$
    theorem pi_div_two_add (ω : ℝ) : sin (π / 2 + ω) = cos ω ∧ cos (π / 2 + ω) = -sin ω
  • Angle $\pi-\omega$: sine $\sin\omega$, cosine $-\cos\omega$
    theorem pi_sub (ω : ℝ) : sin (π - ω) = sin ω ∧ cos (π - ω) = -cos ω
  • Angle $\pi+\omega$: sine $-\sin\omega$, cosine $-\cos\omega$
    theorem pi_add (ω : ℝ) : sin (π + ω) = -sin ω ∧ cos (π + ω) = -cos ω
  • Angle $\frac{3\pi}{2}-\omega$: sine $-\cos\omega$, cosine $-\sin\omega$
    theorem three_pi_div_two_sub (ω : ℝ) :
    sin (3 * π / 2 - ω) = -cos ω ∧ cos (3 * π / 2 - ω) = -sin ω
  • Angle $\frac{3\pi}{2}+\omega$: sine $-\cos\omega$, cosine $\sin\omega$
    theorem three_pi_div_two_add (ω : ℝ) :
    sin (3 * π / 2 + ω) = -cos ω ∧ cos (3 * π / 2 + ω) = sin ω
  • Angle $2\pi-\omega$: sine $-\sin\omega$, cosine $\cos\omega$
    theorem two_pi_sub (ω : ℝ) : sin (2 * π - ω) = -sin ω ∧ cos (2 * π - ω) = cos ω

The symbol ∧ means “and”: each theorem states two things, one for the sine and one for the cosine. The formulas are proved for every real $\omega$, not only for an acute angle. In Mathlib the trigonometric functions are defined by power series, not via the unit circle; the familiar values, such as $\sin\pi=0$ and $\cos\pi=-1$, are theorems of the library.

2. Step by step: the formula for the angle $\pi-\omega$

In the book, the reduction formulas follow from the sum and difference formulas, e.g. $\sin(\pi-\omega)$${}=\sin\pi\cos\omega-\cos\pi\sin\omega$${}=0-(-1)\sin\omega$${}=\sin\omega$. Lean does exactly this:

The goal
ω : ℝ
⊢ sin (π - ω) = sin ω ∧ cos (π - ω) = -cos ω

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. constructor

    The goal is two equalities joined by “and”. The tactic constructor splits it into two goals, which are proved separately.

    What remains to be proved (2 goals)part left
    ⊢ sin (π - ω) = sin ω
    part right
    ⊢ cos (π - ω) = -cos ω
  2. · rw [sin_sub, sin_pi, cos_pi]

    First part. The difference formula sin_sub: $\sin(x-y)$${}=\sin x\cos y-\cos x\sin y$. Then we substitute the values $\sin\pi=0$ (sin_pi) and $\cos\pi=-1$ (cos_pi).

    What remains to be proved
    ⊢ 0 * cos ω - -1 * sin ω = sin ω
  3. ring

    The computation $0\cdot\cos\omega-(-1)\sin\omega$${}=\sin\omega$ is done with ring.

    ✓ This part is complete.
  4. · rw [cos_sub, sin_pi, cos_pi]

    Second part, with the formula cos_sub: $\cos(x-y)$${}=\cos x\cos y+\sin x\sin y$, and the same values.

    What remains to be proved
    ω : ℝ
⊢ -1 * cos ω + 0 * sin ω = -cos ω
  5. ring

    Again a computation: $-1\cdot\cos\omega+0\cdot\sin\omega$${}=-\cos\omega$.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch0.Anagogikoi
open Real

theorem neg_angle (ω : ℝ) : sin (-ω) = -sin ω ∧ cos (-ω) = cos ω :=
  ⟨sin_neg ω, cos_neg ω⟩

theorem pi_div_two_sub (ω : ℝ) : sin (π / 2 - ω) = cos ω ∧ cos (π / 2 - ω) = sin ω :=
  ⟨sin_pi_div_two_sub ω, cos_pi_div_two_sub ω⟩

theorem pi_div_two_add (ω : ℝ) : sin (π / 2 + ω) = cos ω ∧ cos (π / 2 + ω) = -sin ω := by
  rw [add_comm]
  exact ⟨sin_add_pi_div_two ω, cos_add_pi_div_two ω⟩

theorem pi_sub (ω : ℝ) : sin (π - ω) = sin ω ∧ cos (π - ω) = -cos ω := by
  constructor
  · rw [sin_sub, sin_pi, cos_pi]
    ring
  · rw [cos_sub, sin_pi, cos_pi]
    ring

theorem pi_add (ω : ℝ) : sin (π + ω) = -sin ω ∧ cos (π + ω) = -cos ω := by
  constructor
  · rw [sin_add, sin_pi, cos_pi]
    ring
  · rw [cos_add, sin_pi, cos_pi]
    ring

theorem three_pi_div_two_sub (ω : ℝ) :
    sin (3 * π / 2 - ω) = -cos ω ∧ cos (3 * π / 2 - ω) = -sin ω := by
  have h : 3 * π / 2 - ω = (π / 2 - ω) + π := by ring
  rw [h, sin_add_pi, cos_add_pi, sin_pi_div_two_sub, cos_pi_div_two_sub]
  exact ⟨rfl, rfl⟩

theorem three_pi_div_two_add (ω : ℝ) :
    sin (3 * π / 2 + ω) = -cos ω ∧ cos (3 * π / 2 + ω) = sin ω := by
  have h : 3 * π / 2 + ω = (ω + π / 2) + π := by ring
  rw [h, sin_add_pi, cos_add_pi, sin_add_pi_div_two, cos_add_pi_div_two, neg_neg]
  exact ⟨rfl, rfl⟩

theorem two_pi_sub (ω : ℝ) : sin (2 * π - ω) = -sin ω ∧ cos (2 * π - ω) = cos ω :=
  ⟨sin_two_pi_sub ω, cos_two_pi_sub ω⟩

end Ch0.Anagogikoi
