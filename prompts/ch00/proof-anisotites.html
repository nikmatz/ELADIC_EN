1. What is proved: the statement in the book and in Lean

  • If $a\lt b$, then $a+c\lt b+c$
    theorem add_c (a b c : ℝ) (h : a < b) : a + c < b + c
  • If $a\lt b$ and $c\gt 0$, then $ac\lt bc$
    theorem mul_c_pos (a b c : ℝ) (h : a < b) (hc : 0 < c) : a * c < b * c
  • If $a\lt b$ and $c\lt 0$, then $ac\gt bc$
    theorem mul_c_neg (a b c : ℝ) (h : a < b) (hc : c < 0) : a * c > b * c
  • Transitivity: if $a\lt b$ and $b\lt c$, then $a\lt c$
    theorem transitivity (a b c : ℝ) (h₁ : a < b) (h₂ : b < c) : a < c
  • If $0\lt a\lt b$, then $\dfrac{1}{a}\gt\dfrac{1}{b}$
    theorem inverse (a b : ℝ) (ha : 0 < a) (hab : a < b) : 1 / a > 1 / b

Every hypothesis has a name: e.g. (h : a < b) means “we know that $a\lt b$, and we call this fact h”. The first four properties are ready-made theorems of Mathlib (add_lt_add_left, mul_lt_mul_of_pos_right, mul_lt_mul_of_neg_right, lt_trans); the last one we prove step by step.

2. Step by step: if $0\lt a\lt b$, then $\frac{1}{a}\gt\frac{1}{b}$

In the book: $\dfrac{1}{a}-\dfrac{1}{b}$${}=\dfrac{b-a}{ab}\gt 0$, since $b-a\gt 0$ and $ab\gt 0$. In Lean:

The goal
a b : ℝ
ha : 0 < a
hab : a < b
⊢ 1 / a > 1 / b

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hb : 0 < b := lt_trans ha hab

    First we note that $b\gt 0$ as well, by transitivity ($0\lt a$ and $a\lt b$). The tactic have adds a new fact to what we know.

    What remains to be proved
    hb : 0 < b
⊢ 1 / a > 1 / b
  2. have key : 1 / a - 1 / b = (b - a) / (a * b) := by
  rw [div_sub_div _ _ ha.ne' hb.ne']
  ring

    The identity $\dfrac{1}{a}-\dfrac{1}{b}$${}=\dfrac{b-a}{ab}$: div_sub_div brings the fractions to a common denominator (this requires $a\neq 0$ and $b\neq 0$), and ring carries out the operations in the numerator.

    What remains to be proved
    key : 1 / a - 1 / b = (b - a) / (a * b)
⊢ 1 / a > 1 / b
  3. have pos : 0 < (b - a) / (a * b) := div_pos (sub_pos.mpr hab) (mul_pos ha hb)

    The fraction $\dfrac{b-a}{ab}$ is positive: a positive numerator (sub_pos: $b-a\gt 0$ since $a\lt b$) divided by a positive denominator (mul_pos: $ab\gt 0$).

    What remains to be proved
    pos : 0 < (b - a) / (a * b)
⊢ 1 / a > 1 / b
  4. linarith

    From $\frac1a-\frac1b=\frac{b-a}{ab}$ and $\frac{b-a}{ab}\gt 0$ we get $\frac1a\gt\frac1b$. This is a linear combination of what we know, and it is found by the tactic linarith.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch0.Anisotites

theorem add_c (a b c : ℝ) (h : a < b) : a + c < b + c :=
  add_lt_add_left h c

theorem mul_c_pos (a b c : ℝ) (h : a < b) (hc : 0 < c) : a * c < b * c :=
  mul_lt_mul_of_pos_right h hc

theorem mul_c_neg (a b c : ℝ) (h : a < b) (hc : c < 0) : a * c > b * c :=
  mul_lt_mul_of_neg_right h hc

theorem transitivity (a b c : ℝ) (h₁ : a < b) (h₂ : b < c) : a < c :=
  lt_trans h₁ h₂

theorem inverse (a b : ℝ) (ha : 0 < a) (hab : a < b) : 1 / a > 1 / b := by
  have hb : 0 < b := lt_trans ha hab
  have key : 1 / a - 1 / b = (b - a) / (a * b) := by
    rw [div_sub_div _ _ ha.ne' hb.ne']
    ring
  have pos : 0 < (b - a) / (a * b) := div_pos (sub_pos.mpr hab) (mul_pos ha hb)
  linarith

end Ch0.Anisotites
