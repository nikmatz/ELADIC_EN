Parallel and Perpendicular Lines

StatementFor two nonvertical lines with slopes $m_1,m_2$ and $y$-intercepts $b_1,b_2$: they are parallel and distinct $\Leftrightarrow m_1=m_2$ and $b_1\ne b_2$ (if $m_1=m_2$ and $b_1=b_2$ they coincide); they are perpendicular $\Leftrightarrow m_1 m_2=-1$.

The lines are $y=m_1x+b_1$ and $y=m_2x+b_2$. “Parallel and distinct” means that they have no common point: there is no $x$ with $m_1x+b_1=m_2x+b_2$.

1. What is proved: the statement in the book and in Lean

  • Parallel and distinct $\Leftrightarrow m_1=m_2$ and $b_1\neq b_2$
    theorem parallel_iff (m₁ m₂ b₁ b₂ : ℝ) :
    (¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂) ↔ m₁ = m₂ ∧ b₁ ≠ b₂
  • If $m_1=m_2$ and $b_1=b_2$, they coincide
    theorem coincide (m b : ℝ) : ∀ x : ℝ, m * x + b = m * x + b
  • Perpendicular $\Leftrightarrow m_1m_2=-1$
    theorem perpendicular_iff (m₁ m₂ : ℝ) : (1 : ℝ) * 1 + m₁ * m₂ = 0 ↔ m₁ * m₂ = -1

The expression ¬ ∃ x means “there is no $x$”. For perpendicularity: the lines have direction vectors $(1,m_1)$ and $(1,m_2)$, and they are perpendicular when their dot product $1\cdot 1+m_1m_2$ is $0$. The proof of the first theorem uses two auxiliary results: no_common_point and common_point.

2. Step by step: if $m_1\neq m_2$, the lines intersect

If $m_1\neq m_2$, the equation $m_1x+b_1=m_2x+b_2$ can be solved: $x=\dfrac{b_2-b_1}{m_1-m_2}$. So the lines have a common point and are not parallel. In Lean:

The goal
m₁ m₂ b₁ b₂ : ℝ
hm : m₁ ≠ m₂
⊢ ∃ x, m₁ * x + b₁ = m₂ * x + b₂

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hne : m₁ - m₂ ≠ 0 := sub_ne_zero.mpr hm

    Since $m_1\neq m_2$, we have $m_1-m_2\neq 0$ (sub_ne_zero); we will divide by it.

    What remains to be proved
    hne : m₁ - m₂ ≠ 0
⊢ ∃ x, m₁ * x + b₁ = m₂ * x + b₂
  2. refine ⟨(b₂ - b₁) / (m₁ - m₂), ?_⟩

    We provide $x=\dfrac{b_2-b_1}{m_1-m_2}$. It remains to check that it satisfies the equation.

    What remains to be proved
    ⊢ m₁ * ((b₂ - b₁) / (m₁ - m₂)) + b₁ = m₂ * ((b₂ - b₁) / (m₁ - m₂)) + b₂
  3. have key : (m₁ - m₂) * ((b₂ - b₁) / (m₁ - m₂)) = b₂ - b₁ := by
  rw [← mul_div_assoc, mul_div_cancel_left₀ _ hne]

    The key: $(m_1-m_2)\cdot\dfrac{b_2-b_1}{m_1-m_2}$${}=b_2-b_1$, because the denominator is not $0$ (mul_div_cancel_left₀).

    What remains to be proved
    key : (m₁ - m₂) * ((b₂ - b₁) / (m₁ - m₂)) = b₂ - b₁
⊢ m₁ * ((b₂ - b₁) / (m₁ - m₂)) + b₁ = m₂ * ((b₂ - b₁) / (m₁ - m₂)) + b₂
  4. linear_combination key

    The equation we want differs from key only by a rearrangement of terms: $m_1x+b_1-(m_2x+b_2)$${}=(m_1-m_2)x-(b_2-b_1)$. The tactic linear_combination key checks this.

    ✓ No goals: the proof is complete.

Hint

Start with rintro ⟨x, hx⟩: assume that there is a common point $x$ and reach a contradiction. With rw [hm] at hx substitute $m_1=m_2$ into the equation; then linarith gives $b_1=b_2$, which contradicts hb: exact hb (by linarith).

Solution
theorem no_common_point (m₁ m₂ b₁ b₂ : ℝ) (hm : m₁ = m₂) (hb : b₁ ≠ b₂) :
    ¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂ := by
  rintro ⟨x, hx⟩
  rw [hm] at hx
  exact hb (by linarith)

namespace Ch0.Eutheies

theorem no_common_point (m₁ m₂ b₁ b₂ : ℝ) (hm : m₁ = m₂) (hb : b₁ ≠ b₂) :
    ¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂ := by
  rintro ⟨x, hx⟩
  rw [hm] at hx
  exact hb (by linarith)

theorem common_point (m₁ m₂ b₁ b₂ : ℝ) (hm : m₁ ≠ m₂) :
    ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂ := by
  have hne : m₁ - m₂ ≠ 0 := sub_ne_zero.mpr hm
  refine ⟨(b₂ - b₁) / (m₁ - m₂), ?_⟩
  have key : (m₁ - m₂) * ((b₂ - b₁) / (m₁ - m₂)) = b₂ - b₁ := by
    rw [← mul_div_assoc, mul_div_cancel_left₀ _ hne]
  linear_combination key

theorem parallel_iff (m₁ m₂ b₁ b₂ : ℝ) :
    (¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂) ↔ m₁ = m₂ ∧ b₁ ≠ b₂ := by
  constructor
  · intro h
    by_cases hm : m₁ = m₂
    · refine ⟨hm, ?_⟩
      intro hb
      apply h
      exact ⟨0, by rw [hm, hb]⟩
    · exact absurd (common_point m₁ m₂ b₁ b₂ hm) h
  · rintro ⟨hm, hb⟩
    exact no_common_point m₁ m₂ b₁ b₂ hm hb

theorem coincide (m b : ℝ) : ∀ x : ℝ, m * x + b = m * x + b := fun _ => rfl

theorem perpendicular_iff (m₁ m₂ : ℝ) : (1 : ℝ) * 1 + m₁ * m₂ = 0 ↔ m₁ * m₂ = -1 := by
  constructor
  · intro h
    linarith
  · intro h
    linarith

end Ch0.Eutheies
