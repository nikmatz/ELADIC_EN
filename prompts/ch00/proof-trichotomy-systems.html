Lean is a language in which a proof is written so rigorously that a computer checks every step. If a step does not follow from the previous ones, the check fails. A linear system is written $A\vec x=\vec b$, where $A$ is an $m\times n$ matrix. Its solution set is {x | A *ᵥ x = b}.

1. What is proved: the statement in the book and in Lean

  • Every linear system has no solution, a unique solution, or infinitely many solutions
    theorem trichotomy (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    {x | A *ᵥ x = b} = ∅ ∨ (∃ x, {x | A *ᵥ x = b} = {x}) ∨ {x | A *ᵥ x = b}.Infinite
  • Exactly one of the three: the cases are mutually exclusive
    theorem exclusive (S : Set (Fin n → ℝ)) :
    ¬ (S = ∅ ∧ ∃ x, S = {x}) ∧ ¬ (S = ∅ ∧ S.Infinite) ∧ ¬ ((∃ x, S = {x}) ∧ S.Infinite)
  • The key step: if $\vec x,\vec y$ are solutions, then every $\vec x+t(\vec y-\vec x)$ is also a solution
    theorem line_of_solutions (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) (t : ℝ) : A *ᵥ (x + t • (y - x)) = b

A *ᵥ x is the product of the matrix $A$ with the vector $\vec x$. ∅ is the empty set, {x} is a set with a single element, and .Infinite means “infinite”. The geometric picture for two equations in two unknowns (lines that meet, are parallel, or coincide) is not formalized here.

2. Step by step: if $\vec x,\vec y$ are solutions, then so is $\vec x+t(\vec y-\vec x)$

This is the key: if the system has two different solutions, it has a whole line of solutions, hence infinitely many. In the book: $A(\vec x+t(\vec y-\vec x))$${}=A\vec x+t(A\vec y-A\vec x)$${}=\vec b+t(\vec b-\vec b)$${}=\vec b$. In Lean:

The goal
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
x y : Fin n → ℝ
hx : A *ᵥ x = b
hy : A *ᵥ y = b
t : ℝ
⊢ A *ᵥ (x + t • (y - x)) = b

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [mulVec_add]

    $A(\vec u+\vec v)=A\vec u+A\vec v$.

    What remains to be proved
    ⊢ A *ᵥ x + A *ᵥ t • (y - x) = b
  2. rw [mulVec_smul]

    $A(t\vec v)=t\,A\vec v$.

    What remains to be proved
    ⊢ A *ᵥ x + t • A *ᵥ (y - x) = b
  3. rw [difference A b x y hx hy]

    By the auxiliary theorem difference: $A(\vec y-\vec x)=\vec 0$, since $A\vec y=A\vec x=\vec b$.

    What remains to be proved
    ⊢ A *ᵥ x + t • 0 = b
  4. rw [smul_zero, add_zero, hx]

    $t\cdot\vec 0=\vec 0$, $A\vec x+\vec 0=A\vec x$ and $A\vec x=\vec b$.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch0.Trichotomia
open Matrix

variable {m n : ℕ}

theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (y - x) = 0 := by
  rw [mulVec_sub, hx, hy, sub_self]

theorem line_of_solutions (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) (t : ℝ) : A *ᵥ (x + t • (y - x)) = b := by
  rw [mulVec_add]
  rw [mulVec_smul]
  rw [difference A b x y hx hy]
  rw [smul_zero, add_zero, hx]

theorem trichotomy (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    {x | A *ᵥ x = b} = ∅ ∨ (∃ x, {x | A *ᵥ x = b} = {x}) ∨ {x | A *ᵥ x = b}.Infinite := by
  by_cases h0 : {x | A *ᵥ x = b}.Nonempty
  · right
    obtain ⟨x, hx⟩ := h0
    by_cases h1 : ∀ y, A *ᵥ y = b → y = x
    · left
      refine ⟨x, ?_⟩
      ext y
      constructor
      · intro hy
        exact h1 y hy
      · intro hy
        rw [Set.mem_singleton_iff] at hy
        rw [hy]
        exact hx
    · right
      push Not at h1
      obtain ⟨y, hy, hne⟩ := h1
      have hd : y - x ≠ 0 := sub_ne_zero.mpr hne
      apply Set.infinite_of_injective_forall_mem (f := fun t : ℝ => x + t • (y - x))
      · intro s t hst
        dsimp only at hst
        have h' : s • (y - x) = t • (y - x) := add_left_cancel hst
        exact smul_left_injective ℝ hd h'
      · intro t
        exact line_of_solutions A b x y hx hy t
  · left
    exact Set.not_nonempty_iff_eq_empty.mp h0

theorem exclusive (S : Set (Fin n → ℝ)) :
    ¬ (S = ∅ ∧ ∃ x, S = {x}) ∧ ¬ (S = ∅ ∧ S.Infinite) ∧ ¬ ((∃ x, S = {x}) ∧ S.Infinite) := by
  refine ⟨?_, ?_, ?_⟩
  · rintro ⟨h₁, x, h₂⟩
    rw [h₁] at h₂
    exact (Set.singleton_nonempty x).ne_empty h₂.symm
  · rintro ⟨h₁, h₂⟩
    rw [h₁] at h₂
    exact h₂ Set.finite_empty
  · rintro ⟨⟨x, h₁⟩, h₂⟩
    rw [h₁] at h₂
    exact h₂ (Set.finite_singleton x)

end Ch0.Trichotomia
