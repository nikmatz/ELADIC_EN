In Lean, a vector of $\mathbb{R}^n$ is written as a function Fin n → ℝ (coordinate $i$, for $i=0,\dots,n-1$), and the dot product $\vec u\cdot\vec v=\sum_i u_iv_i$ is written u ⬝ᵥ v.

1. What is proved: the statement in the book and in Lean

  • $\vec{u}\cdot\vec{v}$${}=\vec{v}\cdot\vec{u}$
    theorem comm (u v : Fin n → ℝ) : u ⬝ᵥ v = v ⬝ᵥ u
  • $\vec{u}\cdot(\vec{v}+\vec{w})$${}=\vec{u}\cdot\vec{v}+\vec{u}\cdot\vec{w}$
    theorem add_right (u v w : Fin n → ℝ) : u ⬝ᵥ (v + w) = u ⬝ᵥ v + u ⬝ᵥ w
  • $(\lambda\vec{u})\cdot\vec{v}$${}=\lambda(\vec{u}\cdot\vec{v})$
    theorem smul_left (c : ℝ) (u v : Fin n → ℝ) : (c • u) ⬝ᵥ v = c * (u ⬝ᵥ v)
  • $\vec{u}\cdot\vec{u}\ge 0$
    theorem self_nonneg (u : Fin n → ℝ) : 0 ≤ u ⬝ᵥ u
  • $\vec{u}\cdot\vec{u}=0$ only when $\vec{u}=\vec{0}$
    theorem self_eq_zero (u : Fin n → ℝ) : u ⬝ᵥ u = 0 ↔ u = 0
  • $\vec{u}\cdot\vec{u}=\|\vec{u}\|^2$
    theorem self_eq_norm_sq (u : EuclideanSpace ℝ (Fin n)) : ⟪u, u⟫_ℝ = ‖u‖ ^ 2
  • $\vec{u}\cdot\vec{v}$${}=\|\vec{u}\|\,\|\vec{v}\|\cos\theta$
    theorem geometric (u v : EuclideanSpace ℝ (Fin n)) :
    ⟪u, v⟫_ℝ = ‖u‖ * ‖v‖ * Real.cos (InnerProductGeometry.angle u v)

The symbol • is multiplication by a scalar (here $\lambda$ is called c). For the length and the angle we use EuclideanSpace ℝ (Fin n), that is, $\mathbb{R}^n$ with the Euclidean norm; there the dot product is written ⟪u, v⟫_ℝ and it is the same sum $\sum_i u_iv_i$. In Mathlib the angle $\theta$ is defined from the dot product (via $\arccos$), just as in the book, so the geometric formula is almost the definition.

2. Step by step: the commutative property

In the book: $\vec u\cdot\vec v$${}=\sum_i u_iv_i$${}=\sum_i v_iu_i$${}=\vec v\cdot\vec u$, since multiplication of real numbers is commutative. In Lean:

The goal
n : ℕ
u v : Fin n → ℝ
⊢ u ⬝ᵥ v = v ⬝ᵥ u

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. unfold dotProduct

    We unfold the definition: the dot product is the sum $\sum_i u_iv_i$.

    What remains to be proved
    ⊢ ∑ i, u i * v i = ∑ i, v i * u i
  2. apply Finset.sum_congr rfl

    Two sums over the same indices are equal if their terms are equal one by one (Finset.sum_congr).

    What remains to be proved
    ⊢ ∀ x ∈ Finset.univ, u x * v x = v x * u x
  3. intro i _

    We take an arbitrary index $i$.

    What remains to be proved
    i : Fin n
a✝ : i ∈ Finset.univ
⊢ u i * v i = v i * u i
  4. exact mul_comm (u i) (v i)

    For this index, $u_iv_i=v_iu_i$ is the commutative property of multiplication (mul_comm).

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch0.EsotGinomeno
open scoped InnerProductSpace

variable {n : ℕ}

theorem comm (u v : Fin n → ℝ) : u ⬝ᵥ v = v ⬝ᵥ u := by
  unfold dotProduct
  apply Finset.sum_congr rfl
  intro i _
  exact mul_comm (u i) (v i)

theorem add_right (u v w : Fin n → ℝ) : u ⬝ᵥ (v + w) = u ⬝ᵥ v + u ⬝ᵥ w := by
  simp only [dotProduct, Pi.add_apply, mul_add, Finset.sum_add_distrib]

theorem smul_left (c : ℝ) (u v : Fin n → ℝ) : (c • u) ⬝ᵥ v = c * (u ⬝ᵥ v) := by
  simp only [dotProduct, Pi.smul_apply, smul_eq_mul, Finset.mul_sum, mul_assoc]

theorem self_nonneg (u : Fin n → ℝ) : 0 ≤ u ⬝ᵥ u := by
  unfold dotProduct
  exact Finset.sum_nonneg (fun i _ => mul_self_nonneg (u i))

theorem self_eq_zero (u : Fin n → ℝ) : u ⬝ᵥ u = 0 ↔ u = 0 := dotProduct_self_eq_zero

theorem self_eq_norm_sq (u : EuclideanSpace ℝ (Fin n)) : ⟪u, u⟫_ℝ = ‖u‖ ^ 2 :=
  real_inner_self_eq_norm_sq u

theorem geometric (u v : EuclideanSpace ℝ (Fin n)) :
    ⟪u, v⟫_ℝ = ‖u‖ * ‖v‖ * Real.cos (InnerProductGeometry.angle u v) := by
  rw [← InnerProductGeometry.cos_angle_mul_norm_mul_norm u v]
  ring

end Ch0.EsotGinomeno
