Factor Theorem

Chapter 0 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFactor Theorem: for a polynomial $P$ of degree $n\ge 1$, $r$ is a root ($P(r)=0$) $\Leftrightarrow$ $(x-r)$ divides $P(x)$, that is, $P(x)=(x-r)Q(x)$ with $Q$ of degree $n-1$.

1. What is proved: the statement in the book and in Lean

  • Division by $x-r$, with remainder $P(r)$: $P(x)=(x-r)Q(x)+P(r)$
    theorem division (P : ℝ[X]) (r : ℝ) :
    P = (X - C r) * (P /ₘ (X - C r)) + C (P.eval r)
  • $P(r)=0\Leftrightarrow$ $x-r$ divides $P(x)$
    theorem factor (P : ℝ[X]) (r : ℝ) : P.eval r = 0 ↔ (X - C r) ∣ P
  • The quotient $Q$ has degree $n-1$
    theorem quotient_degree (P : ℝ[X]) (r : ℝ) :
    (P /ₘ (X - C r)).natDegree = P.natDegree - 1

Here ℝ[X] denotes the polynomials with real coefficients, and X their variable. The expression C r is the constant polynomial $r$, P.eval r (or eval r P) is the value $P(r)$, ∣ means “divides”, and P /ₘ (X - C r) is the quotient of the division by $x-r$. Finally, natDegree is the degree. The first theorem is the division identity that the book uses.

2. Step by step: $P(r)$${}=0\Leftrightarrow (x-r)\mid P(x)$

In the book: from the identity $P(x)=(x-r)Q(x)+P(r)$. If $P(r)=0$, then $P(x)=(x-r)Q(x)$. Conversely, if $P(x)=(x-r)Q(x)$, then $P(r)=0\cdot Q(r)=0$. In Lean:

⊢ eval r P = 0 ↔ X - C r ∣ P

Hint

The theorem natDegree_divByMonic says that the degree of the quotient is the difference of the degrees, when the divisor has leading coefficient $1$, like $x-r$ (monic_X_sub_C r). Then natDegree_X_sub_C: $x-r$ has degree $1$.

Solution
theorem quotient_degree (P : ℝ[X]) (r : ℝ) :
    (P /ₘ (X - C r)).natDegree = P.natDegree - 1 := by
  rw [natDegree_divByMonic P (monic_X_sub_C r), natDegree_X_sub_C]

import Mathlib

namespace Ch0.Paragontas
open Polynomial

theorem division (P : ℝ[X]) (r : ℝ) :
    P = (X - C r) * (P /ₘ (X - C r)) + C (P.eval r) := by
  have h := modByMonic_add_div P (X - C r)
  rw [modByMonic_X_sub_C_eq_C_eval] at h
  rw [add_comm]
  exact h.symm

theorem factor (P : ℝ[X]) (r : ℝ) : P.eval r = 0 ↔ (X - C r) ∣ P := by
  constructor
  · intro h
    rw [division P r, h, C_0, add_zero]
    exact dvd_mul_right (X - C r) _
  · intro h
    obtain ⟨Q, hQ⟩ := h
    rw [hQ, eval_mul, eval_sub, eval_X, eval_C, sub_self, zero_mul]

theorem quotient_degree (P : ℝ[X]) (r : ℝ) :
    (P /ₘ (X - C r)).natDegree = P.natDegree - 1 := by
  rw [natDegree_divByMonic P (monic_X_sub_C r), natDegree_X_sub_C]

end Ch0.Paragontas
