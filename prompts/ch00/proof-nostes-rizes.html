nth Roots of a Complex Number

1. What is proved: the statement in the book and in Lean

  • Every $z_k$${}=\rho^{1/n}e^{i(\varphi+2k\pi)/n}$ is an $n$th root of $w=\rho e^{i\varphi}$
    theorem z_pow (ρ φ : ℝ) (hρ : 0 < ρ) (n k : ℕ) (hn : n ≠ 0) :
    z ρ φ n k ^ n = ρ * exp (φ * I)
  • The roots $z_0,\dots,z_{n-1}$ are distinct
    theorem z_injective (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) {j k : ℕ}
    (hj : j < n) (hk : k < n) (h : z ρ φ n j = z ρ φ n k) : j = k
  • Every $n$th root of $w$ is some $z_k$ with $k\lt n$
    theorem all_roots (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) (x : ℂ)
    (hx : x ^ n = ρ * exp (φ * I)) : ∃ k < n, x = z ρ φ n k
  • A nonzero complex number has exactly $n$ distinct $n$th roots
    theorem exactly_n (n : ℕ) (hn : n ≠ 0) (w : ℂ) (hw : w ≠ 0) :
    (Polynomial.nthRoots n w).Nodup ∧ Multiset.card (Polynomial.nthRoots n w) = n

The hypothesis hρ : 0 < ρ says that the modulus is positive ($w\neq 0$), and hn : n ≠ 0 says that $n\ge 1$. The expression ρ ^ (↑n)⁻¹ is $\rho^{1/n}$. In the last theorem, nthRoots n w are the roots of the polynomial $x^n-w$, with multiplicities; Nodup says that none of them is repeated, and card that there are $n$ of them. The geometric picture (vertices of a regular $n$-gon) is not formalized here.

2. Step by step: every $z_k$ is a root: $z_k^{\,n}=\rho e^{i\varphi}$

In the book: $z_k^{\,n}$${}=\left(\rho^{1/n}\right)^n e^{i(\varphi+2k\pi)}$${}=\rho\,e^{i\varphi}\,e^{2k\pi i}$${}=\rho\,e^{i\varphi}$, since $e^{2k\pi i}=1$. In Lean:

The goal
ρ φ : ℝ
hρ : 0 < ρ
n k : ℕ
hn : n ≠ 0
⊢ z ρ φ n k ^ n = ↑ρ * cexp (↑φ * I)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hn' : (n : ℂ) ≠ 0 := Nat.cast_ne_zero.mpr hn

    We note that $n\neq 0$ also as a complex number; we will divide by it.

    What remains to be proved
    hn' : ↑n ≠ 0
⊢ z ρ φ n k ^ n = ↑ρ * cexp (↑φ * I)
  2. unfold z

    We unfold the definition of $z_k$.

    What remains to be proved
    ⊢ (↑(ρ ^ (↑n)⁻¹) * cexp ((↑φ + 2 * ↑k * ↑π) / ↑n * I)) ^ n = ↑ρ * cexp (↑φ * I)
  3. rw [mul_pow, ← ofReal_pow, Real.rpow_inv_natCast_pow hρ.le hn]

    $(ab)^n=a^nb^n$, and $\left(\rho^{1/n}\right)^n=\rho$ for $\rho\ge 0$ (Real.rpow_inv_natCast_pow).

    What remains to be proved
    ⊢ ↑ρ * cexp ((↑φ + 2 * ↑k * ↑π) / ↑n * I) ^ n = ↑ρ * cexp (↑φ * I)
  4. rw [← exp_natCast_mul]

    $\left(e^x\right)^n=e^{nx}$.

    What remains to be proved
    ⊢ ↑ρ * cexp (↑n * ((↑φ + 2 * ↑k * ↑π) / ↑n * I)) = ↑ρ * cexp (↑φ * I)
  5. have h : (n : ℂ) * ((φ + 2 * k * π) / n * I) = φ * I + k * (2 * π * I) := by
  calc (n : ℂ) * ((φ + 2 * k * π) / n * I) = (n / n) * ((φ + 2 * k * π) * I) := by ring
    _ = φ * I + k * (2 * π * I) := by rw [div_self hn', one_mul]; ring

    The exponent: $n\cdot\dfrac{\varphi+2k\pi}{n}\,i$${}=\varphi i+k\cdot 2\pi i$. We compute it with two equalities (calc), where $n/n=1$ since $n\neq 0$.

    What remains to be proved
    h : ↑n * ((↑φ + 2 * ↑k * ↑π) / ↑n * I) = ↑φ * I + ↑k * (2 * ↑π * I)
⊢ ↑ρ * cexp (↑n * ((↑φ + 2 * ↑k * ↑π) / ↑n * I)) = ↑ρ * cexp (↑φ * I)
  6. rw [h, exp_add, exp_nat_mul_two_pi_mul_I, mul_one]

    $e^{\varphi i+k\cdot 2\pi i}$${}=e^{\varphi i}\,e^{2k\pi i}$${}=e^{\varphi i}\cdot 1$, since $e^{2k\pi i}=1$ (exp_nat_mul_two_pi_mul_I).

    ✓ No goals: the proof is complete.

3. In Mathlib

For the distinctness and completeness of the roots we used the primitive roots of unity in Mathlib: $z_k=z_0\cdot\zeta^k$ with $\zeta=e^{2\pi i/n}$ (theorem z_eq).

  • Complex.isPrimitiveRoot_exp: $e^{2\pi i/n}$ is a primitive $n$th root of unity.
  • IsPrimitiveRoot.nthRoots_eq: the solutions of $x^n=w$ are $\zeta^k\alpha$, $k=0,\dots,n-1$.
  • IsPrimitiveRoot.nthRoots_nodup: they are distinct.
  • IsPrimitiveRoot.card_nthRoots: there are exactly $n$ of them.

-- Chapter 0 · nth Roots of a Complex Number · checked with Lean v4.37.0-rc1 and Mathlib (22/11/2026).

import Mathlib

namespace Ch0.NostesRizes
open Complex
open scoped Real

/-- The root with index k: ρ^(1/n) · e^(i(φ + 2kπ)/n). -/
noncomputable def z (ρ φ : ℝ) (n k : ℕ) : ℂ :=
  ((ρ ^ ((n : ℝ)⁻¹) : ℝ) : ℂ) * exp ((φ + 2 * k * π) / n * I)

theorem z_pow (ρ φ : ℝ) (hρ : 0 < ρ) (n k : ℕ) (hn : n ≠ 0) :
    z ρ φ n k ^ n = ρ * exp (φ * I) := by
  have hn' : (n : ℂ) ≠ 0 := Nat.cast_ne_zero.mpr hn
  unfold z
  rw [mul_pow, ← ofReal_pow, Real.rpow_inv_natCast_pow hρ.le hn]
  rw [← exp_natCast_mul]
  have h : (n : ℂ) * ((φ + 2 * k * π) / n * I) = φ * I + k * (2 * π * I) := by
    calc (n : ℂ) * ((φ + 2 * k * π) / n * I) = (n / n) * ((φ + 2 * k * π) * I) := by ring
      _ = φ * I + k * (2 * π * I) := by rw [div_self hn', one_mul]; ring
  rw [h, exp_add, exp_nat_mul_two_pi_mul_I, mul_one]

theorem z_eq (ρ φ : ℝ) (n k : ℕ) :
    z ρ φ n k = z ρ φ n 0 * exp (2 * π * I / n) ^ k := by
  unfold z
  rw [← exp_natCast_mul, mul_assoc (((ρ ^ ((n : ℝ)⁻¹) : ℝ) : ℂ)), ← exp_add]
  congr 2
  push_cast
  ring

theorem z_injective (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) {j k : ℕ}
    (hj : j < n) (hk : k < n) (h : z ρ φ n j = z ρ φ n k) : j = k := by
  have h0 : z ρ φ n 0 ≠ 0 := by
    unfold z
    apply mul_ne_zero
    · exact_mod_cast (Real.rpow_pos_of_pos hρ _).ne'
    · exact exp_ne_zero _
  rw [z_eq ρ φ n j, z_eq ρ φ n k] at h
  have h' := mul_left_cancel₀ h0 h
  exact (isPrimitiveRoot_exp n hn).pow_inj hj hk h'

theorem exactly_n (n : ℕ) (hn : n ≠ 0) (w : ℂ) (hw : w ≠ 0) :
    (Polynomial.nthRoots n w).Nodup ∧ Multiset.card (Polynomial.nthRoots n w) = n := by
  have hζ := isPrimitiveRoot_exp n hn
  refine ⟨hζ.nthRoots_nodup hw, ?_⟩
  have hex : ∃ α, α ^ n = w := IsAlgClosed.exists_pow_nat_eq w (Nat.pos_of_ne_zero hn)
  rw [hζ.card_nthRoots]
  simp [hex]

theorem all_roots (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) (x : ℂ)
    (hx : x ^ n = ρ * exp (φ * I)) : ∃ k < n, x = z ρ φ n k := by
  have hζ := isPrimitiveRoot_exp n hn
  have hmem : x ∈ Polynomial.nthRoots n ((ρ : ℂ) * exp (φ * I)) :=
    (Polynomial.mem_nthRoots (Nat.pos_of_ne_zero hn)).mpr hx
  rw [hζ.nthRoots_eq (z_pow ρ φ hρ n 0 hn)] at hmem
  obtain ⟨k, hk, hkx⟩ := Multiset.mem_map.mp hmem
  refine ⟨k, Multiset.mem_range.mp hk, ?_⟩
  rw [← hkx, z_eq ρ φ n k, mul_comm]

end Ch0.NostesRizes
