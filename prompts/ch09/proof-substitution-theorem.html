1. What is proved: the statement in the book and in Lean

  • If $\lim_{x\to x_0}g(x)=\ell$ and $f$ is continuous at $\ell$, then $\lim_{x\to x_0}f(g(x))=f(\ell)$
    theorem lim_comp (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : HasLim g x₀ ℓ) (hf : ContAt f ℓ) :
    HasLim (f ∘ g) x₀ (f ℓ)
  • The same theorem with Mathlib's limit and continuity
    theorem lim_comp_mathlib (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : Tendsto g (𝓝[≠] x₀) (𝓝 ℓ))
    (hf : ContinuousAt f ℓ) : Tendsto (f ∘ g) (𝓝[≠] x₀) (𝓝 (f ℓ))

The limit is written as HasLim g x₀ ℓ, with the book's $\varepsilon$-$\delta$ definition, and the continuity of $f$ at $\ell$ as ContAt f ℓ: for every $\varepsilon\gt 0$ there exists $\eta\gt 0$ such that $|u-\ell|\lt\eta\Rightarrow|f(u)-f(\ell)|\lt\varepsilon$. The composition $x\mapsto f(g(x))$ is written f ∘ g. In the Mathlib statement, continuity is ContinuousAt f ℓ.

2. Step by step: $\lim f(g(x))=f(\ell)$

The idea: the continuity of $f$ gives an $\eta$ for $\varepsilon$, and the limit of $g$ gives a $\delta$ for this $\eta$. We start from the goal:

The goal
f g : ℝ → ℝ
x₀ ℓ : ℝ
hg : HasLim g x₀ ℓ
hf : ContAt f ℓ
⊢ HasLim (f ∘ g) x₀ (f ℓ)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro ε hε

    We take an arbitrary $\varepsilon\gt 0$.

    What remains to be proved
    ε : ℝ
hε : ε > 0
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  2. obtain ⟨η, hη, h₁⟩ := hf ε hε

    From the continuity of $f$ at $\ell$: there exists $\eta\gt 0$ such that $|u-\ell|\lt\eta\Rightarrow|f(u)-f(\ell)|\lt\varepsilon$.

    What remains to be proved
    η : ℝ
hη : η > 0
h₁ : ∀ (u : ℝ), |u - ℓ| < η → |f u - f ℓ| < ε
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  3. obtain ⟨δ, hδ, h₂⟩ := hg η hη

    From the limit of $g$, with $\eta$ in place of $\varepsilon$: there exists $\delta\gt 0$ such that $|g(x)-\ell|\lt\eta$ whenever $0\lt|x-x_0|\lt\delta$.

    What remains to be proved
    δ : ℝ
hδ : δ > 0
h₂ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |g x - ℓ| < η
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  4. refine ⟨δ, hδ, ?_⟩

    We choose this $\delta$.

    What remains to be proved
    ⊢ ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  5. intro x hx hxδ

    We take $x$ with $0\lt|x-x_0|\lt\delta$.

    What remains to be proved
    x : ℝ
hx : 0 < |x - x₀|
hxδ : |x - x₀| < δ
⊢ |(f ∘ g) x - f ℓ| < ε
  6. have hgx : |g x - ℓ| < η := h₂ x hx hxδ

    Then $|g(x)-\ell|\lt\eta$.

    What remains to be proved
    hgx : |g x - ℓ| < η
⊢ |(f ∘ g) x - f ℓ| < ε
  7. exact h₁ (g x) hgx

    We apply the continuity of $f$ with $u=g(x)$ and get $|f(g(x))-f(\ell)|\lt\varepsilon$. Here (f ∘ g) x is $f(g(x))$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • ContinuousAt.tendsto: continuity at $\ell$ means that $f(u)\to f(\ell)$ as $u\to\ell$.
  • Filter.Tendsto.comp: the limit of a composition.

import Mathlib

namespace Ch9.Antikatastasi
open Filter Topology

-- the book's definition: lim_{x→x₀} f(x) = L
def HasLim (f : ℝ → ℝ) (x₀ L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε

-- continuity of f at ℓ, also with ε and δ
def ContAt (f : ℝ → ℝ) (ℓ : ℝ) : Prop :=
  ∀ ε > 0, ∃ η > 0, ∀ u, |u - ℓ| < η → |f u - f ℓ| < ε

theorem lim_comp (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : HasLim g x₀ ℓ) (hf : ContAt f ℓ) :
    HasLim (f ∘ g) x₀ (f ℓ) := by
  intro ε hε
  obtain ⟨η, hη, h₁⟩ := hf ε hε
  obtain ⟨δ, hδ, h₂⟩ := hg η hη
  refine ⟨δ, hδ, ?_⟩
  intro x hx hxδ
  have hgx : |g x - ℓ| < η := h₂ x hx hxδ
  exact h₁ (g x) hgx

theorem cont_id (ℓ : ℝ) : ContAt (fun u => u) ℓ := by
  intro ε hε
  refine ⟨ε, hε, ?_⟩
  intro u hu
  exact hu

theorem lim_comp_mathlib (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : Tendsto g (𝓝[≠] x₀) (𝓝 ℓ))
    (hf : ContinuousAt f ℓ) : Tendsto (f ∘ g) (𝓝[≠] x₀) (𝓝 (f ℓ)) :=
  hf.tendsto.comp hg

end Ch9.Antikatastasi
