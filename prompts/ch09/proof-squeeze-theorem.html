1. What is proved: the statement in the book and in Lean

  • If $h\le f\le g$ near $x_0$ and $\lim h=\lim g=L$, then $\lim f=L$
    theorem squeeze (f g h : ℝ → ℝ) (x₀ L δ₀ : ℝ) (hδ₀ : 0 < δ₀)
    (hle : ∀ x, 0 < |x - x₀| → |x - x₀| < δ₀ → h x ≤ f x ∧ f x ≤ g x)
    (hh : HasLim h x₀ L) (hg : HasLim g x₀ L) : HasLim f x₀ L
  • The same theorem with Mathlib's limit
    theorem squeeze_mathlib (f g h : ℝ → ℝ) (x₀ L : ℝ) (hh : Tendsto h (𝓝[≠] x₀) (𝓝 L))
    (hg : Tendsto g (𝓝[≠] x₀) (𝓝 L)) (hhf : ∀ᶠ x in 𝓝[≠] x₀, h x ≤ f x)
    (hfg : ∀ᶠ x in 𝓝[≠] x₀, f x ≤ g x) : Tendsto f (𝓝[≠] x₀) (𝓝 L)
  • Application: if $|f(x)-L|\le|x-x_0|$ for every $x$, then $\lim f=L$
    theorem lim_of_bound (f : ℝ → ℝ) (x₀ L : ℝ) (hb : ∀ x, |f x - L| ≤ |x - x₀|) :
    HasLim f x₀ L

The book's definition is written as HasLim f x₀ L: for every $\varepsilon\gt 0$ there exists $\delta\gt 0$ such that $|f(x)-L|\lt\varepsilon$ for every $x$ with $0\lt|x-x_0|\lt\delta$. The “neighborhood of $x_0$, possibly except at $x_0$” consists of the $x$ with $0\lt|x-x_0|\lt\delta_0$ (hypothesis hle). In the Mathlib statement, “near $x_0$, with $x\neq x_0$” is written ∀ᶠ x in 𝓝[≠] x₀.

2. Step by step: the squeeze theorem

The idea: for $x$ close enough to $x_0$ we have $L-\varepsilon\lt h(x)\le f(x)\le g(x)\lt L+\varepsilon$. We start from the goal:

The goal
f g h : ℝ → ℝ
x₀ L δ₀ : ℝ
hδ₀ : 0 < δ₀
hle : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₀ → h x ≤ f x ∧ f x ≤ g x
hh : HasLim h x₀ L
hg : HasLim g x₀ L
⊢ HasLim f x₀ L

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro ε hε

    We take an arbitrary $\varepsilon\gt 0$.

    What remains to be proved
    ε : ℝ
hε : ε > 0
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε
  2. obtain ⟨δ₁, hδ₁, h₁⟩ := hh ε hε

    From the limit of $h$ we get $\delta_1\gt 0$ with $|h(x)-L|\lt\varepsilon$ whenever $0\lt|x-x_0|\lt\delta_1$.

    What remains to be proved
    δ₁ : ℝ
hδ₁ : δ₁ > 0
h₁ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₁ → |h x - L| < ε
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε
  3. obtain ⟨δ₂, hδ₂, h₂⟩ := hg ε hε

    From the limit of $g$ we get $\delta_2\gt 0$ with $|g(x)-L|\lt\varepsilon$ whenever $0\lt|x-x_0|\lt\delta_2$.

    What remains to be proved
    δ₂ : ℝ
hδ₂ : δ₂ > 0
h₂ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₂ → |g x - L| < ε
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε
  4. refine ⟨min δ₀ (min δ₁ δ₂), lt_min hδ₀ (lt_min hδ₁ hδ₂), ?_⟩

    We choose $\delta$${}=\min(\delta_0,\delta_1,\delta_2)$, which is positive.

    What remains to be proved
    ⊢ ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < min δ₀ (min δ₁ δ₂) → |f x - L| < ε
  5. intro x hx hxδ

    We take $x$ with $0\lt|x-x_0|\lt\delta$.

    What remains to be proved
    x : ℝ
hx : 0 < |x - x₀|
hxδ : |x - x₀| < min δ₀ (min δ₁ δ₂)
⊢ |f x - L| < ε
  6. have hx₀ : |x - x₀| < δ₀ := lt_of_lt_of_le hxδ (min_le_left _ _)
have hx₁ : |x - x₀| < δ₁ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_left _ _))
have hx₂ : |x - x₀| < δ₂ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_right _ _))

    Since $\delta$ is the smallest of the three, we have $|x-x_0|\lt\delta_0$, $|x-x_0|\lt\delta_1$ and $|x-x_0|\lt\delta_2$.

    What remains to be proved
    hx₀ : |x - x₀| < δ₀
hx₁ : |x - x₀| < δ₁
hx₂ : |x - x₀| < δ₂
⊢ |f x - L| < ε
  7. obtain ⟨hhf, hfg⟩ := hle x hx hx₀

    From hypothesis hle: $h(x)\le f(x)$ and $f(x)\le g(x)$.

    What remains to be proved
    hhf : h x ≤ f x
hfg : f x ≤ g x
⊢ |f x - L| < ε
  8. have ha := h₁ x hx hx₁
have hb := h₂ x hx hx₂

    From the limits: $|h(x)-L|\lt\varepsilon$ and $|g(x)-L|\lt\varepsilon$.

    What remains to be proved
    ha : |h x - L| < ε
hb : |g x - L| < ε
⊢ |f x - L| < ε
  9. rw [abs_sub_lt_iff] at ha hb ⊢

    We write each absolute value as two inequalities: $|a-b|\lt\varepsilon$ means $a-b\lt\varepsilon$ and $b-a\lt\varepsilon$.

    What remains to be proved
    ha : h x - L < ε ∧ L - h x < ε
hb : g x - L < ε ∧ L - g x < ε
⊢ f x - L < ε ∧ L - f x < ε
  10. constructor

    Two goals: $f(x)-L\lt\varepsilon$ and $L-f(x)\lt\varepsilon$.

    What remains to be proved (2 goals)part left
    ⊢ f x - L < ε
    part right
    ⊢ L - f x < ε
  11. · linarith [hb.1]

    $f(x)-L\le g(x)-L\lt\varepsilon$.

    ✓ This part is complete.
  12. · linarith [ha.2]

    $L-f(x)\le L-h(x)\lt\varepsilon$.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch9.Parembolh
open Filter Topology

-- the book's definition: lim_{x→x₀} f(x) = L
def HasLim (f : ℝ → ℝ) (x₀ L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε

theorem squeeze (f g h : ℝ → ℝ) (x₀ L δ₀ : ℝ) (hδ₀ : 0 < δ₀)
    (hle : ∀ x, 0 < |x - x₀| → |x - x₀| < δ₀ → h x ≤ f x ∧ f x ≤ g x)
    (hh : HasLim h x₀ L) (hg : HasLim g x₀ L) : HasLim f x₀ L := by
  intro ε hε
  obtain ⟨δ₁, hδ₁, h₁⟩ := hh ε hε
  obtain ⟨δ₂, hδ₂, h₂⟩ := hg ε hε
  refine ⟨min δ₀ (min δ₁ δ₂), lt_min hδ₀ (lt_min hδ₁ hδ₂), ?_⟩
  intro x hx hxδ
  have hx₀ : |x - x₀| < δ₀ := lt_of_lt_of_le hxδ (min_le_left _ _)
  have hx₁ : |x - x₀| < δ₁ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_left _ _))
  have hx₂ : |x - x₀| < δ₂ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_right _ _))
  obtain ⟨hhf, hfg⟩ := hle x hx hx₀
  have ha := h₁ x hx hx₁
  have hb := h₂ x hx hx₂
  rw [abs_sub_lt_iff] at ha hb ⊢
  constructor
  · linarith [hb.1]
  · linarith [ha.2]

theorem lim_of_bound (f : ℝ → ℝ) (x₀ L : ℝ) (hb : ∀ x, |f x - L| ≤ |x - x₀|) :
    HasLim f x₀ L := by
  intro ε hε
  refine ⟨ε, hε, ?_⟩
  intro x _ hxδ
  exact lt_of_le_of_lt (hb x) hxδ

theorem squeeze_mathlib (f g h : ℝ → ℝ) (x₀ L : ℝ) (hh : Tendsto h (𝓝[≠] x₀) (𝓝 L))
    (hg : Tendsto g (𝓝[≠] x₀) (𝓝 L)) (hhf : ∀ᶠ x in 𝓝[≠] x₀, h x ≤ f x)
    (hfg : ∀ᶠ x in 𝓝[≠] x₀, f x ≤ g x) : Tendsto f (𝓝[≠] x₀) (𝓝 L) :=
  tendsto_of_tendsto_of_tendsto_of_le_of_le' hh hg hhf hfg

end Ch9.Parembolh
