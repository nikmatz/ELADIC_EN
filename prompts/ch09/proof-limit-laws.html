1. What is proved: the statement in the book and in Lean

  • $\lim(f+g)=L+M$, with the book’s $\varepsilon$-$\delta$ definition
    theorem lim_add (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f + g) x₀ (L + M)
  • $\lim(f-g)=L-M$
    theorem lim_sub (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f - g) x₀ (L - M)
  • $\lim(fg)=LM$
    theorem lim_mul (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f * g) x₀ (L * M)
  • $\lim\dfrac{f}{g}=\dfrac{L}{M}$, when $M\ne 0$
    theorem lim_div (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M)
    (hM : M ≠ 0) : HasLim (f / g) x₀ (L / M)
  • $\lim f^n=L^n$
    theorem lim_pow (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (f ^ n) x₀ (L ^ n)
  • $\lim\sqrt{f}=\sqrt{L}$
    theorem lim_sqrt (f : ℝ → ℝ) (x₀ L : ℝ) (hf : HasLim f x₀ L) :
    HasLim (fun x => √(f x)) x₀ (√L)
  • $\lim f^{1/n}=L^{1/n}$, that is, $\lim\sqrt[n]{f}=\sqrt[n]{L}$ when the values are $\ge 0$
    theorem lim_root (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (fun x => f x ^ ((1 : ℝ) / n)) x₀ (L ^ ((1 : ℝ) / n))
  • The book’s $\varepsilon$-$\delta$ definition agrees with the Mathlib limit
    theorem hasLim_iff (f : ℝ → ℝ) (x₀ L : ℝ) : HasLim f x₀ L ↔ Tendsto f (𝓝[≠] x₀) (𝓝 L)

The book’s definition is written as HasLim f x₀ L: for every $\varepsilon\gt 0$ there exists $\delta\gt 0$ such that for every $x$ with $0\lt|x-x_0|\lt\delta$ we have $|f(x)-L|\lt\varepsilon$. The sum $f+g$ is the function $x\mapsto f(x)+g(x)$. The sum law is proved directly from the definition. For the others, we first show that the book’s definition agrees with the Mathlib limit, Tendsto f (𝓝[≠] x₀) (𝓝 L), where 𝓝[≠] x₀ means “$x\to x_0$ with $x\neq x_0$”. In this way we use Mathlib’s ready-made theorems. In Lean the square root is defined for every real number, with $\sqrt{t}=0$ when $t\lt 0$, and the power $t^{1/n}$ coincides with the $n$-th root when $t\ge 0$. So, when $f\ge 0$ near $x_0$ and $L\ge 0$ (the book’s conditions for even $n$), the last two laws say exactly what the book says. The case of odd $n$ with negative values is not covered here, because for $t\lt 0$ Lean’s power $t^{1/n}$ is not the real root $\sqrt[n]{t}$.

2. Step by step: $\lim(f+g)=L+M$

The idea: we make $|f(x)-L|$ and $|g(x)-M|$ each smaller than $\varepsilon/2$ and use the triangle inequality. We start from the goal:

The goal
f g : ℝ → ℝ
x₀ L M : ℝ
hf : HasLim f x₀ L
hg : HasLim g x₀ M
⊢ HasLim (f + g) x₀ (L + M)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro ε hε

    We take an arbitrary $\varepsilon\gt 0$. The definition unfolds: we must find a suitable $\delta$.

    What remains to be proved
    ε : ℝ
hε : ε > 0
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f + g) x - (L + M)| < ε
  2. obtain ⟨δ₁, hδ₁, h₁⟩ := hf (ε / 2) (by linarith)

    From the limit of $f$, with $\varepsilon/2$ in place of $\varepsilon$, we get $\delta_1\gt 0$. The by linarith shows that $\varepsilon/2\gt 0$.

    What remains to be proved
    δ₁ : ℝ
hδ₁ : δ₁ > 0
h₁ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₁ → |f x - L| < ε / 2
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f + g) x - (L + M)| < ε
  3. obtain ⟨δ₂, hδ₂, h₂⟩ := hg (ε / 2) (by linarith)

    Similarly, from the limit of $g$ we get $\delta_2\gt 0$.

    What remains to be proved
    δ₂ : ℝ
hδ₂ : δ₂ > 0
h₂ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₂ → |g x - M| < ε / 2
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f + g) x - (L + M)| < ε
  4. refine ⟨min δ₁ δ₂, lt_min hδ₁ hδ₂, ?_⟩

    We choose $\delta=\min(\delta_1,\delta_2)$, which is positive.

    What remains to be proved
    ⊢ ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < min δ₁ δ₂ → |(f + g) x - (L + M)| < ε
  5. intro x hx hxδ

    We take $x$ with $0\lt|x-x_0|\lt\delta$.

    What remains to be proved
    x : ℝ
hx : 0 < |x - x₀|
hxδ : |x - x₀| < min δ₁ δ₂
⊢ |(f + g) x - (L + M)| < ε
  6. have hfx := h₁ x hx (lt_of_lt_of_le hxδ (min_le_left δ₁ δ₂))

    Since $\delta\le\delta_1$, we have $|f(x)-L|\lt\varepsilon/2$.

    What remains to be proved
    hfx : |f x - L| < ε / 2
⊢ |(f + g) x - (L + M)| < ε
  7. have hgx := h₂ x hx (lt_of_lt_of_le hxδ (min_le_right δ₁ δ₂))

    Since $\delta\le\delta_2$, we have $|g(x)-M|\lt\varepsilon/2$.

    What remains to be proved
    hgx : |g x - M| < ε / 2
⊢ |(f + g) x - (L + M)| < ε
  8. rw [Pi.add_apply]

    The value of $f+g$ at $x$ is $f(x)+g(x)$.

    What remains to be proved
    ⊢ |f x + g x - (L + M)| < ε
  9. calc |f x + g x - (L + M)| = |(f x - L) + (g x - M)| := by congr 1; ring
  _ ≤ |f x - L| + |g x - M| := abs_add_le _ _
  _ < ε / 2 + ε / 2 := add_lt_add hfx hgx
  _ = ε := by ring

    The chain: $|f(x)+g(x)-(L+M)|$${}=|(f(x)-L)+(g(x)-M)|$, which by the triangle inequality is $\le|f(x)-L|+|g(x)-M|$, and this is $\lt\varepsilon/2+\varepsilon/2$${}=\varepsilon$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • abs_add_le: the triangle inequality $|a+b|\le|a|+|b|$.
  • Metric.tendsto_nhdsWithin_nhds: the Mathlib limit written with $\varepsilon$ and $\delta$.
  • Filter.Tendsto.sub: the limit of a difference.
  • Filter.Tendsto.mul: the limit of a product.
  • Filter.Tendsto.div: the limit of a quotient.
  • Filter.Tendsto.pow: the limit of a power.
  • Filter.Tendsto.sqrt: the limit of a square root.
  • Filter.Tendsto.rpow_const: the limit of $f^{p}$ for a constant exponent $p\ge 0$.

import Mathlib

namespace Ch9.NomoiOrion
open Filter Topology

-- the book’s definition: lim_{x→x₀} f(x) = L
def HasLim (f : ℝ → ℝ) (x₀ L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε

theorem lim_add (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f + g) x₀ (L + M) := by
  intro ε hε
  obtain ⟨δ₁, hδ₁, h₁⟩ := hf (ε / 2) (by linarith)
  obtain ⟨δ₂, hδ₂, h₂⟩ := hg (ε / 2) (by linarith)
  refine ⟨min δ₁ δ₂, lt_min hδ₁ hδ₂, ?_⟩
  intro x hx hxδ
  have hfx := h₁ x hx (lt_of_lt_of_le hxδ (min_le_left δ₁ δ₂))
  have hgx := h₂ x hx (lt_of_lt_of_le hxδ (min_le_right δ₁ δ₂))
  rw [Pi.add_apply]
  calc |f x + g x - (L + M)| = |(f x - L) + (g x - M)| := by congr 1; ring
    _ ≤ |f x - L| + |g x - M| := abs_add_le _ _
    _ < ε / 2 + ε / 2 := add_lt_add hfx hgx
    _ = ε := by ring

theorem lim_const (c x₀ : ℝ) : HasLim (fun _ => c) x₀ c := by
  intro ε hε
  refine ⟨1, one_pos, ?_⟩
  intro x _ _
  simpa using hε

-- the book’s definition agrees with the Mathlib limit
theorem hasLim_iff (f : ℝ → ℝ) (x₀ L : ℝ) : HasLim f x₀ L ↔ Tendsto f (𝓝[≠] x₀) (𝓝 L) := by
  rw [Metric.tendsto_nhdsWithin_nhds]
  constructor
  · intro h ε hε
    obtain ⟨δ, hδ, hx⟩ := h ε hε
    refine ⟨δ, hδ, ?_⟩
    intro x hx1 hx2
    rw [Real.dist_eq] at hx2 ⊢
    exact hx x (abs_pos.mpr (sub_ne_zero.mpr (Set.mem_compl_singleton_iff.mp hx1))) hx2
  · intro h ε hε
    obtain ⟨δ, hδ, hx⟩ := h ε hε
    refine ⟨δ, hδ, ?_⟩
    intro x hx1 hx2
    have hne : x ≠ x₀ := sub_ne_zero.mp (abs_pos.mp hx1)
    have h2 := hx (Set.mem_compl_singleton_iff.mpr hne) (by rw [Real.dist_eq]; exact hx2)
    rwa [Real.dist_eq] at h2

theorem lim_sub (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f - g) x₀ (L - M) := by
  rw [hasLim_iff] at hf hg ⊢
  exact hf.sub hg

theorem lim_mul (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f * g) x₀ (L * M) := by
  rw [hasLim_iff] at hf hg ⊢
  exact hf.mul hg

theorem lim_div (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M)
    (hM : M ≠ 0) : HasLim (f / g) x₀ (L / M) := by
  rw [hasLim_iff] at hf hg ⊢
  exact hf.div hg hM

theorem lim_pow (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (f ^ n) x₀ (L ^ n) := by
  rw [hasLim_iff] at hf ⊢
  exact hf.pow n

theorem lim_sqrt (f : ℝ → ℝ) (x₀ L : ℝ) (hf : HasLim f x₀ L) :
    HasLim (fun x => √(f x)) x₀ (√L) := by
  rw [hasLim_iff] at hf ⊢
  exact hf.sqrt

theorem lim_root (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (fun x => f x ^ ((1 : ℝ) / n)) x₀ (L ^ ((1 : ℝ) / n)) := by
  rw [hasLim_iff] at hf ⊢
  exact hf.rpow_const (Or.inr (by positivity))
