1. What is proved: the statement in the book and in Lean

  • If $f$ is continuous on $[a,b]$, there exist $x_{\min},x_{\max}\in[a,b]$ with $f(x_{\min})\le f(x)\le f(x_{\max})$ for every $x\in[a,b]$
    theorem extreme_values (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ xmin ∈ Set.Icc a b, ∃ xmax ∈ Set.Icc a b,
      ∀ x ∈ Set.Icc a b, f xmin ≤ f x ∧ f x ≤ f xmax

Continuity on $[a,b]$ is written ContinuousOn f (Set.Icc a b). Mathlib proves the theorem in general: a continuous function on a compact, nonempty set attains a maximum and a minimum value. The interval $[a,b]$ is compact (isCompact_Icc) and, when $a\le b$, nonempty. IsMinOn f s xmin means that $f$ attains at $x_{\min}$ its minimum value on $s$.

2. Where it is in Mathlib

We used the following theorems:

  • IsCompact.exists_isMinOn: a continuous function on a compact, nonempty set attains a minimum value.
  • IsCompact.exists_isMaxOn: the same for the maximum value.
  • isCompact_Icc: $[a,b]$ is compact.
  • Set.nonempty_Icc: $[a,b]$ is nonempty exactly when $a\le b$.

import Mathlib

namespace Ch9.Weierstrass

theorem extreme_values (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ xmin ∈ Set.Icc a b, ∃ xmax ∈ Set.Icc a b,
      ∀ x ∈ Set.Icc a b, f xmin ≤ f x ∧ f x ≤ f xmax := by
  obtain ⟨xmin, hmin, hmin'⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab) hf
  obtain ⟨xmax, hmax, hmax'⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab) hf
  exact ⟨xmin, hmin, xmax, hmax, fun x hx => ⟨isMinOn_iff.mp hmin' x hx, isMaxOn_iff.mp hmax' x hx⟩⟩

end Ch9.Weierstrass
