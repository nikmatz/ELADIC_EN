1. What is proved: the statement in the book and in Lean

  • $W^{\perp}=\{v:\langle w,v\rangle=0$ for every $w\in W\}$, and it is a subspace

  • $\dim W+\dim W^{\perp}=n$

    finrank ℝ W + finrank ℝ Wᗮ = n

$\mathbb{R}^n$ is EuclideanSpace ℝ (Fin n), and $W^{\perp}$ is written Wᗮ. In Mathlib, $W^{\perp}$ is defined directly as a subspace (Submodule), so the fact that it is a subspace is part of the definition. The theorem mem_iff shows which elements it contains. The intersection is written ⊓, $\{0\}$ is ⊥, and IsCompl W Wᗮ means $\mathbb{R}^n=W\oplus W^{\perp}$.

2. Where it is in Mathlib

We used the following theorems:

  • Submodule.orthogonal: the definition of $W^{\perp}$ as a subspace.
  • Submodule.inf_orthogonal_eq_bot: $W\cap W^{\perp}=\{0\}$.
  • Submodule.isCompl_orthogonal: $W\oplus W^{\perp}$ is the whole space.
  • Submodule.finrank_add_finrank_orthogonal: $\dim W+\dim W^{\perp}=\dim V$.
  • Submodule.orthogonal_orthogonal: $(W^{\perp})^{\perp}=W$.

import Mathlib

namespace Ch1.OrthogonioSymplirwma
open scoped InnerProductSpace
open Module Submodule

variable {n : ℕ}

theorem mem_iff (W : Submodule ℝ (EuclideanSpace ℝ (Fin n))) (v : EuclideanSpace ℝ (Fin n)) :
    v ∈ Wᗮ ↔ ∀ w ∈ W, ⟪w, v⟫_ℝ = 0 :=
  mem_orthogonal W v

theorem inter_zero (W : Submodule ℝ (EuclideanSpace ℝ (Fin n))) : W ⊓ Wᗮ = ⊥ :=
  inf_orthogonal_eq_bot W

theorem direct_sum (W : Submodule ℝ (EuclideanSpace ℝ (Fin n))) : IsCompl W Wᗮ :=
  isCompl_orthogonal W

theorem dim_sum (W : Submodule ℝ (EuclideanSpace ℝ (Fin n))) :
    finrank ℝ W + finrank ℝ Wᗮ = n := by
  rw [finrank_add_finrank_orthogonal, finrank_euclideanSpace_fin]

theorem double_perp (W : Submodule ℝ (EuclideanSpace ℝ (Fin n))) : Wᗮᗮ = W :=
  orthogonal_orthogonal W

end Ch1.OrthogonioSymplirwma
