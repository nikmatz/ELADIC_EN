1. What is proved: the statement in the book and in Lean

  • $u,v$ are linearly dependent $\Leftrightarrow$ one of them is a scalar multiple of the other
    theorem dependent_iff (u v : V) :
    ¬ LinearIndependent ℝ ![u, v] ↔ (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u)
  • Linearly dependent $\Rightarrow$ $u=cv$ or $v=cu$ for some $c$
    theorem multiple_of_dependent (u v : V) (h : ¬ LinearIndependent ℝ ![u, v]) :
    (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u)
  • If $u=cv$, then $u,v$ are linearly dependent
    theorem dependent_of_multiple (u v : V) (c : ℝ) (h : u = c • v) :
    ¬ LinearIndependent ℝ ![u, v]

![u, v] is the family of the two vectors, and LinearIndependent ℝ ![u, v] means that they are linearly independent. With ¬ in front, it means that they are linearly dependent. c • v is $cv$. The phrase “one is a multiple of the other” is written “$u=cv$ for some $c$ or $v=cu$ for some $c$”. Both cases are needed: if $u\neq 0$ and $v=0$, then $v=0\cdot u$, while $u$ is not a multiple of $v$.

2. Step by step: if $u,v$ are linearly dependent, one is a multiple of the other

This is the substantial direction. The idea: there are $s,t$, not both zero, with $su+tv=0$. We solve for the vector whose coefficient is nonzero. We start from the goal:

The goal
V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
u v : V
h : ¬LinearIndependent ℝ ![u, v]
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [LinearIndependent.pair_iff] at h

    We unfold the definition: $u,v$ are linearly independent when $su+tv=0$ implies $s=t=0$ (theorem LinearIndependent.pair_iff). The hypothesis h says that this does not hold.

    What remains to be proved
    h : ¬∀ (s t : ℝ), s • u + t • v = 0 → s = 0 ∧ t = 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  2. push Not at h

    We push the negation inward: there are $s,t$ with $su+tv=0$ that are not both zero. Lean writes this as “if $s=0$, then $t\neq 0$”.

    What remains to be proved
    h : ∃ s t, s • u + t • v = 0 ∧ (s = 0 → t ≠ 0)
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  3. obtain ⟨s, t, hst, hne⟩ := h

    We take these $s,t$ together with their two properties, hst and hne.

    What remains to be proved
    s t : ℝ
hst : s • u + t • v = 0
hne : s = 0 → t ≠ 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  4. by_cases hs : s = 0

    Two cases: $s=0$ (case pos) or $s\neq 0$ (case neg).

    What remains to be proved (2 goals)part pos
    hs : s = 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
    part neg
    hs : ¬s = 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  5. · right
  refine ⟨0, ?_⟩

    If $s=0$, we will show that $v$ is a multiple of $u$, in fact $v=0\cdot u$. We choose the second part of the “or” with right, and the number $c=0$.

    What remains to be proved
    ⊢ v = 0 • u
  6. rw [hs, zero_smul, zero_add] at hst

    With $s=0$, the relation $su+tv=0$ becomes $tv=0$.

    What remains to be proved
    hst : t • v = 0
⊢ v = 0 • u
  7. rw [zero_smul]
exact (smul_eq_zero.mp hst).resolve_left (hne hs)

    Since $t\neq 0$ (by hne), $tv=0$ gives $v=0$, that is, $v=0\cdot u$. The first case is done.

    ✓ This part is complete.
  8. · left
  refine ⟨-t / s, ?_⟩

    If $s\neq 0$, we solve for $u$ and will show that $u=-\frac{t}{s}\,v$. We choose the first part of the “or” with left.

    What remains to be proved
    V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
u v : V
s t : ℝ
hst : s • u + t • v = 0
hne : s = 0 → t ≠ 0
hs : ¬s = 0
⊢ u = (-t / s) • v
  9. have e : s • u = -(t • v) := eq_neg_of_add_eq_zero_left hst

    From $su+tv=0$ we get $su=-tv$.

    What remains to be proved
    e : s • u = -(t • v)
⊢ u = (-t / s) • v
  10. calc u = s⁻¹ • (s • u) := by rw [smul_smul, inv_mul_cancel₀ hs, one_smul]
  _ = s⁻¹ • -(t • v) := by rw [e]
  _ = (-t / s) • v := by rw [smul_neg, smul_smul, ← neg_smul]; congr 1; ring

    We multiply by $\frac{1}{s}$: $u$${}=\frac{1}{s}(su)$${}=\frac{1}{s}(-tv)$${}=-\frac{t}{s}\,v$. calc writes exactly this chain of equalities, and Lean checks each link separately.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch1.KritirioDuo

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem dependent_of_multiple (u v : V) (c : ℝ) (h : u = c • v) :
    ¬ LinearIndependent ℝ ![u, v] := by
  rw [LinearIndependent.pair_iff]
  intro hli
  have h1 := hli 1 (-c) (by rw [h]; module)
  norm_num at h1

theorem dependent_of_multiple' (u v : V) (c : ℝ) (h : v = c • u) :
    ¬ LinearIndependent ℝ ![u, v] := by
  rw [LinearIndependent.pair_iff]
  intro hli
  have h1 := hli (-c) 1 (by rw [h]; module)
  norm_num at h1

theorem multiple_of_dependent (u v : V) (h : ¬ LinearIndependent ℝ ![u, v]) :
    (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u) := by
  rw [LinearIndependent.pair_iff] at h
  push Not at h
  obtain ⟨s, t, hst, hne⟩ := h
  by_cases hs : s = 0
  · right
    refine ⟨0, ?_⟩
    rw [hs, zero_smul, zero_add] at hst
    rw [zero_smul]
    exact (smul_eq_zero.mp hst).resolve_left (hne hs)
  · left
    refine ⟨-t / s, ?_⟩
    have e : s • u = -(t • v) := eq_neg_of_add_eq_zero_left hst
    calc u = s⁻¹ • (s • u) := by rw [smul_smul, inv_mul_cancel₀ hs, one_smul]
      _ = s⁻¹ • -(t • v) := by rw [e]
      _ = (-t / s) • v := by rw [smul_neg, smul_smul, ← neg_smul]; congr 1; ring

theorem dependent_iff (u v : V) :
    ¬ LinearIndependent ℝ ![u, v] ↔ (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u) := by
  constructor
  · exact multiple_of_dependent u v
  · rintro (⟨c, hc⟩ | ⟨c, hc⟩)
    · exact dependent_of_multiple u v c hc
    · exact dependent_of_multiple' u v c hc

end Ch1.KritirioDuo
