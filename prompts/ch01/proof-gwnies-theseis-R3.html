1. What is proved: the statement in the book and in Lean

  • Two planes: $\cos\theta$${}=\dfrac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{\|\mathbf{n}_1\|\,\|\mathbf{n}_2\|}$, where the fraction lies in $[0,1]$
    theorem plane_angle (n₁ n₂ : EuclideanSpace ℝ (Fin 3)) (h₁ : n₁ ≠ 0) (h₂ : n₂ ≠ 0) :
    0 ≤ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ∧ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ≤ 1
  • Line and plane: $\sin\varphi$${}=\dfrac{|\mathbf{d}\cdot\mathbf{n}|}{\|\mathbf{d}\|\,\|\mathbf{n}\|}$, where the fraction lies in $[0,1]$
    theorem line_plane_angle (d n : EuclideanSpace ℝ (Fin 3)) (hd : d ≠ 0) (hn : n ≠ 0) :
    0 ≤ |⟪d, n⟫_ℝ| / (‖d‖ * ‖n‖) ∧ |⟪d, n⟫_ℝ| / (‖d‖ * ‖n‖) ≤ 1
  • Two lines are coplanar $\Leftrightarrow(\mathbf{p}_2-\mathbf{p}_1)\cdot(\mathbf{d}_1\times\mathbf{d}_2)$${}=0$, that is, when $\mathbf{p}_2-\mathbf{p}_1,\mathbf{d}_1,\mathbf{d}_2$ are linearly dependent
    theorem coplanar_iff (p₁ p₂ d₁ d₂ : Fin 3 → ℝ) :
    (p₂ - p₁) ⬝ᵥ (d₁ ⨯₃ d₂) = 0 ↔ ¬ LinearIndependent ℝ ![p₂ - p₁, d₁, d₂]

The angles are defined by the formulas. What needs proof is that the fraction really lies in $[0,1]$, so that there is an angle with this cosine or sine. EuclideanSpace ℝ (Fin 3) is $\mathbb{R}^3$ with the usual inner product ⟪n₁, n₂⟫_ℝ. For the lines, Lean checks the algebraic part: the scalar triple product equals the determinant whose rows are the three vectors, and the determinant vanishes exactly when the rows are linearly dependent. Three linearly dependent vectors lie in a plane, and hence so do the two lines.

2. Step by step: the formula for the angle between two planes gives a value in $[0,1]$

For the angle $\theta$ with $\cos\theta$${}=\frac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{\|\mathbf{n}_1\|\,\|\mathbf{n}_2\|}$ to be defined, the fraction must lie between $0$ and $1$. This is what we prove here. We start from the goal:

The goal
n₁ n₂ : EuclideanSpace ℝ (Fin 3)
h₁ : n₁ ≠ 0
h₂ : n₂ ≠ 0
⊢ 0 ≤ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ∧ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ≤ 1

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hpos : 0 < ‖n₁‖ * ‖n₂‖ := mul_pos (norm_pos_iff.mpr h₁) (norm_pos_iff.mpr h₂)

    $\mathbf{n}_1,\mathbf{n}_2$ are nonzero, so they have positive length and the denominator is positive: $\|\mathbf{n}_1\|\,\|\mathbf{n}_2\|\gt 0$.

    What remains to be proved
    hpos : 0 < ‖n₁‖ * ‖n₂‖
⊢ 0 ≤ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ∧ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ≤ 1
  2. constructor

    The goal is two inequalities together (∧ means “and”). constructor splits it into two goals, left and right.

    What remains to be proved (2 goals)part left
    ⊢ 0 ≤ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖)
    part right
    ⊢ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ≤ 1
  3. · exact div_nonneg (abs_nonneg _) hpos.le

    First goal: the fraction is $\ge 0$, because the numerator is an absolute value and the denominator is positive (theorem div_nonneg).

    ✓ This part is complete.
  4. · rw [div_le_one hpos]

    Second goal: for a positive denominator, $\frac{a}{b}\le 1\Leftrightarrow a\le b$ (theorem div_le_one). What remains is $|\mathbf{n}_1\cdot\mathbf{n}_2|\le\|\mathbf{n}_1\|\,\|\mathbf{n}_2\|$.

    What remains to be proved
    n₁ n₂ : EuclideanSpace ℝ (Fin 3)
h₁ : n₁ ≠ 0
h₂ : n₂ ≠ 0
hpos : 0 < ‖n₁‖ * ‖n₂‖
⊢ |⟪n₁, n₂⟫_ℝ| ≤ ‖n₁‖ * ‖n₂‖
  5. exact abs_real_inner_le_norm n₁ n₂

    This is exactly the Cauchy–Schwarz inequality (theorem abs_real_inner_le_norm).

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • abs_real_inner_le_norm: the Cauchy–Schwarz inequality.
  • triple_product_eq_det: the scalar triple product as a determinant.
  • Matrix.linearIndependent_row_iff: the rows are linearly independent exactly when the matrix is nonsingular.
  • Matrix.nonsingular_iff_det_ne_zero: a matrix is nonsingular $\Leftrightarrow$ its determinant is $\neq 0$.

theorem plane_angle (n₁ n₂ : EuclideanSpace ℝ (Fin 3)) (h₁ : n₁ ≠ 0) (h₂ : n₂ ≠ 0) :
    0 ≤ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ∧ |⟪n₁, n₂⟫_ℝ| / (‖n₁‖ * ‖n₂‖) ≤ 1 := by

  constructor
  · exact div_nonneg (abs_nonneg _) hpos.le
  · rw [div_le_one hpos]
    exact abs_real_inner_le_norm n₁ n₂

theorem line_plane_angle (d n : EuclideanSpace ℝ (Fin 3)) (hd : d ≠ 0) (hn : n ≠ 0) :
    0 ≤ |⟪d, n⟫_ℝ| / (‖d‖ * ‖n‖) ∧ |⟪d, n⟫_ℝ| / (‖d‖ * ‖n‖) ≤ 1 := by
  have hpos : 0 < ‖d‖ * ‖n‖ := mul_pos (norm_pos_iff.mpr hd) (norm_pos_iff.mpr hn)
  constructor
  · exact div_nonneg (abs_nonneg _) hpos.le
  · rw [div_le_one hpos]
    exact abs_real_inner_le_norm d n

theorem independent_iff_det (a b c : Fin 3 → ℝ) :
    LinearIndependent ℝ ![a, b, c] ↔ Matrix.det ![a, b, c] ≠ 0 :=
  (Matrix.linearIndependent_row_iff (A := Matrix.of ![a, b, c])).trans
    Matrix.nonsingular_iff_det_ne_zero

theorem coplanar_iff (p₁ p₂ d₁ d₂ : Fin 3 → ℝ) :
    (p₂ - p₁) ⬝ᵥ (d₁ ⨯₃ d₂) = 0 ↔ ¬ LinearIndependent ℝ ![p₂ - p₁, d₁, d₂] := by
  rw [triple_product_eq_det, independent_iff_det, not_not]

end Ch1.GwniesR3
