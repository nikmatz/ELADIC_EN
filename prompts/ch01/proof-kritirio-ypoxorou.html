1. What is proved: the statement in the book and in Lean

  • A nonempty $W\subseteq V$ is a subspace $\Leftrightarrow$ for all $u,v\in W$ and $\lambda,\mu\in\mathbb{R}$ we have $\lambda u+\mu v\in W$
    theorem criterion (W : Set V) :
    (∃ S : Submodule ℝ V, (S : Set V) = W) ↔
      W.Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W
  • If $W$ is nonempty and closed, then $\mathbf{0}\in W$
    theorem zero_mem_of_closed (W : Set V) (hne : W.Nonempty)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) : (0 : V) ∈ W
  • If $W$ is closed, then $u+v\in W$ for $u,v\in W$
    theorem add_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) {u v : V} (hu : u ∈ W) (hv : v ∈ W) :
    u + v ∈ W
  • If $W$ is closed, then $cu\in W$ for $u\in W$
    theorem smul_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) (c : ℝ) {u : V} (hu : u ∈ W) :
    c • u ∈ W
  • Every subspace is nonempty and closed
    theorem closed (W : Submodule ℝ V) :
    (W : Set V).Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W

A subspace in Mathlib is a Submodule ℝ V: a set together with proofs that it contains $\mathbf{0}$ and is closed under addition and scalar multiplication. The statement ∃ S : Submodule ℝ V, (S : Set V) = W says that $W$ is a subspace. The definition ofClosed in the code builds the subspace from the three lemmas. W.Nonempty means that $W$ is nonempty. In Lean this condition goes on the right-hand side of the equivalence, because a subspace is always nonempty.

2. Step by step: a nonempty closed set contains $\mathbf{0}$

For $W$ to be a subspace, three things are needed: $\mathbf{0}\in W$, closure under addition, and closure under scalar multiplication. The first is the most interesting, because it is the only place where we need $W$ to be nonempty. We start from the goal:

The goal
V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
W : Set V
hne : W.Nonempty
h : ∀ u ∈ W, ∀ v ∈ W, ∀ (a b : ℝ), a • u + b • v ∈ W
⊢ 0 ∈ W

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. obtain ⟨w, hw⟩ := hne

    $W$ is nonempty, so we take an element of it, $w\in W$.

    What remains to be proved
    w : V
hw : w ∈ W
⊢ 0 ∈ W
  2. have h0 := h w hw w hw 0 0

    We apply the hypothesis with $u=v=w$ and $\lambda=\mu=0$: $0w+0w\in W$.

    What remains to be proved
    h0 : 0 • w + 0 • w ∈ W
⊢ 0 ∈ W
  3. rw [zero_smul, zero_add] at h0

    We carry out the operations: $0w=\mathbf{0}$ and $\mathbf{0}+\mathbf{0}=\mathbf{0}$.

    What remains to be proved
    h0 : 0 ∈ W
⊢ 0 ∈ W
  4. exact h0

    This is exactly what we wanted.

import Mathlib

namespace Ch1.KritirioYpoxorou

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem zero_mem_of_closed (W : Set V) (hne : W.Nonempty)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) : (0 : V) ∈ W := by
  obtain ⟨w, hw⟩ := hne
  have h0 := h w hw w hw 0 0
  rw [zero_smul, zero_add] at h0
  exact h0

theorem add_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) {u v : V} (hu : u ∈ W) (hv : v ∈ W) :
    u + v ∈ W := by
  have h1 := h u hu v hv 1 1
  rw [one_smul, one_smul] at h1
  exact h1

theorem smul_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) (c : ℝ) {u : V} (hu : u ∈ W) :
    c • u ∈ W := by
  have h2 := h u hu u hu c 0
  rw [zero_smul, add_zero] at h2
  exact h2

/-- The subspace whose elements are exactly the elements of W. -/
def ofClosed (W : Set V) (hne : W.Nonempty)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) : Submodule ℝ V where
  carrier := W
  zero_mem' := zero_mem_of_closed W hne h
  add_mem' := add_mem_of_closed W h
  smul_mem' := smul_mem_of_closed W h

theorem closed (W : Submodule ℝ V) :
    (W : Set V).Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W := by
  refine ⟨⟨0, W.zero_mem⟩, ?_⟩
  intro u hu v hv a b
  exact W.add_mem (W.smul_mem a hu) (W.smul_mem b hv)

theorem criterion (W : Set V) :
    (∃ S : Submodule ℝ V, (S : Set V) = W) ↔
      W.Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W := by
  constructor
  · rintro ⟨S, rfl⟩
    exact closed S
  · rintro ⟨hne, h⟩
    exact ⟨ofClosed W hne h, rfl⟩

end Ch1.KritirioYpoxorou
