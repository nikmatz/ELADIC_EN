$\mathbb{R}^3$ is Fin 3 → ℝ, and a subspace is a Submodule ℝ (Fin 3 → ℝ). The dimension is written finrank ℝ W. $\{\mathbf{0}\}$ is ⊥ and the whole space is ⊤. The line $\{tv:t\in\mathbb{R}\}$ is span ℝ {v}, which Lean displays as ℝ ∙ v, and the plane spanned by two independent vectors $u,v$ is span ℝ (Set.range ![u, v]). Conversely, each of these is a subspace, because in Lean it is a Submodule by definition.

2. Step by step: every subspace of $\mathbb{R}^3$ is one of the four types

The idea: the dimension of a subspace of $\mathbb{R}^3$ is $0$, $1$, $2$ or $3$, and each dimension gives one type. The lemmas for each dimension appear earlier in the code. We start from the goal:

The goal
W : Submodule ℝ (Fin 3 → ℝ)
⊢ W = ⊥ ∨ (∃ v, v ≠ 0 ∧ W = ℝ ∙ v) ∨ (∃ u v, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v])) ∨ W = ⊤

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

4. In Mathlib

We used the following theorems:

  • Submodule.finrank_eq_zero: dimension $0$ exactly for $\{\mathbf{0}\}$.
  • Submodule.eq_top_of_finrank_eq: a subspace with the dimension of the space is the whole space.
  • finrank_eq_one_iff': a space of dimension $1$ is spanned by a nonzero vector.
  • Module.finBasisOfFinrankEq: a basis with as many vectors as the dimension.
  • finrank_span_eq_card: the dimension of the space spanned by independent vectors equals their number.

import Mathlib

namespace Ch1.YpoxoroiR3
open Module Submodule

theorem dim_le_three (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W ≤ 3 := by
  have h := W.finrank_le
  rw [Module.finrank_fin_fun] at h
  exact h

theorem dim_zero_iff (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W = 0 ↔ W = ⊥ :=
  Submodule.finrank_eq_zero

theorem dim_three_iff (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W = 3 ↔ W = ⊤ := by
  constructor
  · intro h
    apply eq_top_of_finrank_eq
    rw [h, Module.finrank_fin_fun]
  · rintro rfl
    rw [finrank_top, Module.finrank_fin_fun]

theorem dim_one_iff (W : Submodule ℝ (Fin 3 → ℝ)) :
    finrank ℝ W = 1 ↔ ∃ v ≠ 0, W = span ℝ {v} := by
  constructor
  · intro h
    obtain ⟨v, hv, hall⟩ := finrank_eq_one_iff'.mp h
    refine ⟨v, fun h0 => hv (Subtype.ext h0), ?_⟩
    apply le_antisymm
    · intro x hx
      obtain ⟨c, hc⟩ := hall ⟨x, hx⟩
      rw [mem_span_singleton]
      exact ⟨c, congrArg Subtype.val hc⟩
    · rw [span_le, Set.singleton_subset_iff]
      exact v.2
  · rintro ⟨v, hv, rfl⟩
    exact finrank_span_singleton hv

theorem dim_two_iff (W : Submodule ℝ (Fin 3 → ℝ)) :
    finrank ℝ W = 2 ↔
      ∃ u v : Fin 3 → ℝ, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v]) := by
  constructor
  · intro h
    let b := Module.finBasisOfFinrankEq ℝ W h
    have hf : (W.subtype ∘ b) = ![(b 0 : Fin 3 → ℝ), (b 1 : Fin 3 → ℝ)] := by
      funext i
      fin_cases i <;> rfl
    refine ⟨b 0, b 1, ?_, ?_⟩
    · rw [← hf]
      exact b.linearIndependent.map' W.subtype (ker_subtype W)
    · rw [← hf, Set.range_comp, ← map_span, b.span_eq, Submodule.map_top, Submodule.range_subtype]
  · rintro ⟨u, v, h, rfl⟩
    rw [finrank_span_eq_card h, Fintype.card_fin]

theorem classification (W : Submodule ℝ (Fin 3 → ℝ)) :
    W = ⊥ ∨ (∃ v ≠ 0, W = span ℝ {v}) ∨
      (∃ u v : Fin 3 → ℝ, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v])) ∨
        W = ⊤ := by
  obtain h0 | h1 | h2 | h3 :
      finrank ℝ W = 0 ∨ finrank ℝ W = 1 ∨ finrank ℝ W = 2 ∨ finrank ℝ W = 3 := by
    have h := dim_le_three W
    omega
  · exact Or.inl ((dim_zero_iff W).mp h0)
  · exact Or.inr (Or.inl ((dim_one_iff W).mp h1))
  · exact Or.inr (Or.inr (Or.inl ((dim_two_iff W).mp h2)))
  · exact Or.inr (Or.inr (Or.inr ((dim_three_iff W).mp h3)))

end Ch1.YpoxoroiR3
