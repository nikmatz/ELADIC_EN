How to read them: • is scalar multiplication, ∀ means “for every”, ∨ means “or”, and (h : …) is a hypothesis named h. λ is a reserved word in Lean, so we call the scalar κ. Lean checks the proof; whether its statement says the same thing as the book is for the reader to judge, which is why we put them side by side.

The eight axioms, as we wrote them in Lean
add_comm$u+v=v+u$
add_assoc$(u+v)+w=u+(v+w)$
add_zero$u+0=u$
add_neg$u+(-u)=0$

add_smul$(\kappa+\mu)u=\kappa u+\mu u$

For all $u,v,w\in V$ and $\kappa,\mu\in\mathbb{R}$. In the code, the definition is the structure VectorSpace:

class VectorSpace (V : Type) extends Add V, Zero V, Neg V, SMul ℝ V where
  /-- u + v = v + u -/
  add_comm : ∀ u v : V, u + v = v + u
  /-- (u + v) + w = u + (v + w) -/
  add_assoc : ∀ u v w : V, u + v + w = u + (v + w)
  /-- u + 0 = u -/
  add_zero : ∀ u : V, u + 0 = u
  /-- u + (−u) = 0 -/
  add_neg : ∀ u : V, u + -u = 0
  /-- κ·(u + v) = κ·u + κ·v -/
  smul_add : ∀ (κ : ℝ) (u v : V), κ • (u + v) = κ • u + κ • v
  /-- (κ + μ)·u = κ·u + μ·u -/
  add_smul : ∀ (κ μ : ℝ) (u : V), (κ + μ) • u = κ • u + μ • u
  /-- (κμ)·u = κ·(μ·u) -/
  mul_smul : ∀ (κ μ : ℝ) (u : V), (κ * μ) • u = κ • (μ • u)
  /-- 1·u = u -/
  one_smul : ∀ u : V, (1 : ℝ) • u = u

2. Step by step: the proof of $0\cdot u=0$

In the book: $0\cdot u=(0+0)\cdot u=0\cdot u+0\cdot u$, and adding $-(0\cdot u)$ to both sides we get $0\cdot u=0$. In Lean the same idea takes three steps. We start from the goal:

The goal
V : Type
inst✝ : VectorSpace V
u : V
⊢ 0 • u = 0

Above ⊢ is what we know ($V$ is a vector space, $u$ is a vector in it); after ⊢ is what we have to show. These do not change below, so we show only the goal line.

  1. apply eq_zero_of_add_self

    It suffices to show that $0\cdot u+0\cdot u=0\cdot u$. Why? If $x+x=x$, we add $-x$ to both sides and find $x=0$. This is the lemma eq_zero_of_add_self (see below).

    What remains to be proved
    ⊢ 0 • u + 0 • u = 0 • u
  2. rw [← VectorSpace.add_smul]

    By the axiom $(\kappa+\mu)u=\kappa u+\mu u$, read from right to left: $0\cdot u+0\cdot u=(0+0)\cdot u$. The symbol ← means “from right to left”.

    What remains to be proved
    ⊢ (0 + 0) • u = 0 • u
  3. rw [add_zero]

    In the real numbers $0+0=0$, so the two sides become identical and Lean closes the equality by itself.

    ✓ No goals: the proof is complete.
The lemma we used: if $x+x=x$, then $x=0$
theorem eq_zero_of_add_self {x : V} (h : x + x = x) : x = 0 := by
  calc x = x + 0 := (VectorSpace.add_zero x).symm
    _ = x + (x + -x) := by rw [VectorSpace.add_neg]
    _ = x + x + -x := (VectorSpace.add_assoc x x (-x)).symm
    _ = x + -x := by rw [h]
    _ = 0 := VectorSpace.add_neg x

Each line of calc is an equality, with the reason it holds next to it:

x = x + 0axiom add_zero
_ = x + (x + -x)axiom add_neg: $x+(-x)=0$
_ = x + x + -xaxiom add_assoc
_ = x + -xthe hypothesis h: $x+x=x$
_ = 0axiom add_neg

import Mathlib

/-!
# Basic Properties of a Vector Space (Chapter 1)

We define a vector space as in the book: a set "V" with addition,
a zero vector, negatives and scalar multiplication by real numbers,
satisfying eight axioms. Every property below is proved from these
axioms alone.
("λ" is a reserved word in Lean, so we call the scalars "κ" and "μ".)
-/

/-- A (linear) vector space over ℝ, with the eight axioms of the book. -/
class VectorSpace (V : Type) extends Add V, Zero V, Neg V, SMul ℝ V where
  /-- u + v = v + u -/
  add_comm : ∀ u v : V, u + v = v + u
  /-- (u + v) + w = u + (v + w) -/
  add_assoc : ∀ u v w : V, u + v + w = u + (v + w)
  /-- u + 0 = u -/
  add_zero : ∀ u : V, u + 0 = u
  /-- u + (−u) = 0 -/
  add_neg : ∀ u : V, u + -u = 0
  /-- κ·(u + v) = κ·u + κ·v -/
  smul_add : ∀ (κ : ℝ) (u v : V), κ • (u + v) = κ • u + κ • v
  /-- (κ + μ)·u = κ·u + μ·u -/
  add_smul : ∀ (κ μ : ℝ) (u : V), (κ + μ) • u = κ • u + μ • u
  /-- (κμ)·u = κ·(μ·u) -/
  mul_smul : ∀ (κ μ : ℝ) (u : V), (κ * μ) • u = κ • (μ • u)
  /-- 1·u = u -/
  one_smul : ∀ u : V, (1 : ℝ) • u = u

namespace Ch1

variable {V : Type} [VectorSpace V]

/-- (1) The zero vector is unique. -/
theorem zero_unique (z : V) (hz : ∀ u : V, u + z = u) : z = 0 := by
  calc z = z + 0 := (VectorSpace.add_zero z).symm
    _ = 0 + z := VectorSpace.add_comm z 0
    _ = 0 := hz 0

/-- (2) The negative of every vector is unique. -/
theorem neg_unique {u w : V} (h : u + w = 0) : w = -u := by
  calc w = w + 0 := (VectorSpace.add_zero w).symm
    _ = w + (u + -u) := by rw [VectorSpace.add_neg]
    _ = w + u + -u := (VectorSpace.add_assoc w u (-u)).symm
    _ = u + w + -u := by rw [VectorSpace.add_comm w u]
    _ = 0 + -u := by rw [h]
    _ = -u + 0 := VectorSpace.add_comm 0 (-u)
    _ = -u := VectorSpace.add_zero (-u)

/-- Lemma: if x + x = x, then x = 0 (add −x to both sides). -/
theorem eq_zero_of_add_self {x : V} (h : x + x = x) : x = 0 := by
  calc x = x + 0 := (VectorSpace.add_zero x).symm
    _ = x + (x + -x) := by rw [VectorSpace.add_neg]
    _ = x + x + -x := (VectorSpace.add_assoc x x (-x)).symm
    _ = x + -x := by rw [h]
    _ = 0 := VectorSpace.add_neg x

/-- (3) 0·u = 0 -/
theorem zero_smul' (u : V) : (0 : ℝ) • u = 0 := by
  apply eq_zero_of_add_self
  rw [← VectorSpace.add_smul]
  rw [add_zero]

/-- (4) κ·0 = 0 -/
theorem smul_zero' (κ : ℝ) : κ • (0 : V) = 0 := by
  apply eq_zero_of_add_self
  rw [← VectorSpace.smul_add]
  rw [VectorSpace.add_zero]

/-- (5) (−1)·u = −u -/
theorem neg_one_smul' (u : V) : (-1 : ℝ) • u = -u := by
  apply neg_unique
  calc u + (-1 : ℝ) • u = (1 : ℝ) • u + (-1 : ℝ) • u := by rw [VectorSpace.one_smul]
    _ = ((1 : ℝ) + -1) • u := (VectorSpace.add_smul 1 (-1) u).symm
    _ = (0 : ℝ) • u := by norm_num
    _ = 0 := zero_smul' u

/-- (6) If κ·u = 0, then κ = 0 or u = 0. -/
theorem eq_zero_or_eq_zero_of_smul_eq_zero {κ : ℝ} {u : V} (h : κ • u = 0) :
    κ = 0 ∨ u = 0 := by
  by_cases hκ : κ = 0
  · left
    exact hκ
  · right
    calc u = (1 : ℝ) • u := (VectorSpace.one_smul u).symm
      _ = (κ⁻¹ * κ) • u := by rw [inv_mul_cancel₀ hκ]
      _ = κ⁻¹ • (κ • u) := VectorSpace.mul_smul κ⁻¹ κ u
      _ = κ⁻¹ • (0 : V) := by rw [h]
      _ = 0 := smul_zero' κ⁻¹

end Ch1
