1. What is proved: the statement in the book and in Lean

  • The vectors $v_1,\dots,v_k$ are linearly dependent $\Leftrightarrow$ the homogeneous system $x_1v_1+\dots+x_kv_k=0$ has a nonzero solution
    theorem dependent_iff {k : ℕ} (v : Fin k → V) :
    ¬ LinearIndependent ℝ v ↔ ∃ x : Fin k → ℝ, x ≠ 0 ∧ ∑ i, x i • v i = 0
  • Consequence: if some $v_i$ is zero, the vectors are linearly dependent
    theorem dependent_of_zero {k : ℕ} (v : Fin k → V) (i : Fin k) (h : v i = 0) :
    ¬ LinearIndependent ℝ v

The vectors $v_1,\dots,v_k$ are written as a family v : Fin k → V: v i is the $i$-th vector, with $i=0,1,\dots,k-1$. A solution of the system is a family of numbers x : Fin k → ℝ, and $x_1v_1+\dots+x_kv_k$ is written ∑ i, x i • v i. x ≠ 0 means that the solution is not the zero solution.

2. Step by step: the equivalence with a nonzero solution

The system $x_1v_1+\dots+x_kv_k=0$ always has the zero solution. The vectors are linearly dependent exactly when it has another one as well. We start from the goal:

The goal
V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
k : ℕ
v : Fin k → V
⊢ ¬LinearIndependent ℝ v ↔ ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [Fintype.not_linearIndependent_iff]

    Mathlib describes linear dependence as follows: there are numbers $g_i$ with $\sum_i g_iv_i=0$ and some $g_i\neq 0$ (theorem Fintype.not_linearIndependent_iff). It remains to see that this says the same thing as a nonzero solution $x$.

    What remains to be proved
    ⊢ (∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0) ↔ ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0
  2. constructor

    An equivalence is proved in two directions: mp for $\Rightarrow$ and mpr for $\Leftarrow$.

    What remains to be proved (2 goals)part mp
    ⊢ (∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0) → ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0
    part mpr
    ⊢ (∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0) → ∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0
  3. · rintro ⟨g, hg, i, hi⟩

    Direction $\Rightarrow$: we take the numbers $g$, the relation hg and a position $i$ with $g_i\neq 0$.

    What remains to be proved
    g : Fin k → ℝ
hg : ∑ i, g i • v i = 0
i : Fin k
hi : g i ≠ 0
⊢ ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0
  4. exact ⟨g, fun h => hi (by simp [h]), hg⟩

    The solution is $x=g$. It is not the zero solution, because if $g=0$, then $g_i=0$ as well.

    ✓ This part is complete.
  5. · rintro ⟨x, hx, hsum⟩

    Direction $\Leftarrow$: we take a nonzero solution $x$ with $\sum_i x_iv_i=0$.

    What remains to be proved
    V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
k : ℕ
v : Fin k → V
x : Fin k → ℝ
hx : x ≠ 0
hsum : ∑ i, x i • v i = 0
⊢ ∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0
  6. obtain ⟨i, hi⟩ := Function.ne_iff.mp hx

    A vector $x\neq 0$ has some coordinate $x_i\neq 0$ (theorem Function.ne_iff). Lean writes x i ≠ 0 i, where 0 i is the $i$-th coordinate of the zero vector, that is, $0$.

    What remains to be proved
    i : Fin k
hi : x i ≠ 0 i
⊢ ∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0
  7. exact ⟨x, hsum, i, hi⟩

    The numbers $x$ give exactly what Mathlib asks for.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • Fintype.not_linearIndependent_iff: linear dependence $\Leftrightarrow$ there is a nontrivial linear combination equal to zero.
  • LinearIndependent.ne_zero: in a linearly independent family no vector is zero.

import Mathlib

namespace Ch1.KritirioOmogenes

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem dependent_iff {k : ℕ} (v : Fin k → V) :
    ¬ LinearIndependent ℝ v ↔ ∃ x : Fin k → ℝ, x ≠ 0 ∧ ∑ i, x i • v i = 0 := by
  rw [Fintype.not_linearIndependent_iff]
  constructor
  · rintro ⟨g, hg, i, hi⟩
    exact ⟨g, fun h => hi (by simp [h]), hg⟩
  · rintro ⟨x, hx, hsum⟩
    obtain ⟨i, hi⟩ := Function.ne_iff.mp hx
    exact ⟨x, hsum, i, hi⟩

theorem dependent_of_zero {k : ℕ} (v : Fin k → V) (i : Fin k) (h : v i = 0) :
    ¬ LinearIndependent ℝ v := by
  intro hli
  exact hli.ne_zero i h

end Ch1.KritirioOmogenes
