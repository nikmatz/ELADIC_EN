1. What is proved: the statement in the book and in Lean

  • Every vector is written as $v=\sum_i\langle v,e_i\rangle e_i$
    theorem expansion {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (v : V) :
    v = ∑ i, ⟪v, b i⟫_ℝ • b i
  • The coordinates are the inner products: if $v=\sum_i c_ie_i$, then $\langle v,e_j\rangle=c_j$
    theorem coordinate {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (c : Fin n → ℝ) (j : Fin n) :
    ⟪∑ i, c i • b i, b j⟫_ℝ = c j

The orthonormal basis $\{e_1,\dots,e_n\}$ is b : OrthonormalBasis (Fin n) ℝ V, and $e_i$ is written b i. The facts b.orthonormal.1 j, which says $\|e_j\|=1$, and b.orthonormal.2, which says $\langle e_i,e_j\rangle=0$ for $i\neq j$, are the two properties of orthonormality.

2. Step by step: the coordinate $c_j$ is $\langle v,e_j\rangle$

If $v=\sum_i c_ie_i$, we take the inner product with $e_j$ and find $\langle v,e_j\rangle=c_j$. This shows that the coordinates are the inner products. We start from the goal:

The goal
V : Type u_1
inst✝¹ : NormedAddCommGroup V
inst✝ : InnerProductSpace ℝ V
n : ℕ
b : OrthonormalBasis (Fin n) ℝ V
c : Fin n → ℝ
j : Fin n
⊢ ⟪∑ i, c i • b i, b j⟫_ℝ = c j

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [sum_inner]

    The inner product distributes over the sum: $\sum_i\langle c_ie_i,e_j\rangle$.

    What remains to be proved
    ⊢ ∑ i, ⟪c i • b i, b j⟫_ℝ = c j
  2. simp only [real_inner_smul_left]

    We pull the numbers $c_i$ out: $\sum_i c_i\langle e_i,e_j\rangle$. Here Lean names the index x.

    What remains to be proved
    ⊢ ∑ x, c x * ⟪b x, b j⟫_ℝ = c j
  3. rw [Finset.sum_eq_single j]

    Only the term $i=j$ remains, because $\langle e_i,e_j\rangle=0$ for $i\neq j$. Three goals remain: the main one, $c_j\langle e_j,e_j\rangle=c_j$, the obligation h₀ for the other terms, and the technical condition h₁.

    What remains to be proved (3 goals)
    ⊢ c j * ⟪b j, b j⟫_ℝ = c j
    part h₀
    ⊢ ∀ b_1 ∈ Finset.univ, b_1 ≠ j → c b_1 * ⟪b b_1, b j⟫_ℝ = 0
    part h₁
    ⊢ j ∉ Finset.univ → c j * ⟪b j, b j⟫_ℝ = 0
  4. · rw [real_inner_self_eq_norm_sq, b.orthonormal.1 j]

    We have $\langle e_j,e_j\rangle=\|e_j\|^2$ and $\|e_j\|=1$, because the basis is orthonormal.

    What remains to be proved
    ⊢ c j * 1 ^ 2 = c j
  5. ring

    Indeed, $c_j\cdot 1^2=c_j$.

    ✓ This part is complete.
  6. · intro i _ hij
  rw [b.orthonormal.2 hij, mul_zero]

    For $i\neq j$ we have $\langle e_i,e_j\rangle=0$, so the term is $0$.

    ✓ This part is complete.
  7. · intro hj
  exact absurd (Finset.mem_univ j) hj

    The technical condition: $j$ is one of the indices, so the assumption that it is not is a contradiction.

    ✓ No goals: the proof is complete.

Solution
