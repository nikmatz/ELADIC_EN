1. What is proved: the statement in the book and in Lean

  • All bases of the space have the same number of elements
    theorem same_card {ι κ : Type*} [Fintype ι] [Fintype κ] (b₁ : Basis ι ℝ V) (b₂ : Basis κ ℝ V) :
    Fintype.card ι = Fintype.card κ
  • This number is the dimension of the space
    theorem card_eq_dim {ι : Type*} [Fintype ι] (b : Basis ι ℝ V) :
    Fintype.card ι = finrank ℝ V

A basis indexed by a finite set ι is written b : Basis ι ℝ V, and its number of elements is Fintype.card ι. The dimension of $V$ is written finrank ℝ V. The two bases b₁ and b₂ may have different index sets ι and κ. The theorem says that the two sets have the same number of elements.

2. Where it is in Mathlib

We used the following theorems:

  • Module.finrank_eq_card_basis: the dimension equals the number of elements of any basis.

open Module

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem card_eq_dim {ι : Type*} [Fintype ι] (b : Basis ι ℝ V) :
    Fintype.card ι = finrank ℝ V :=
  (finrank_eq_card_basis b).symm

theorem same_card {ι κ : Type*} [Fintype ι] [Fintype κ] (b₁ : Basis ι ℝ V) (b₂ : Basis κ ℝ V) :
    Fintype.card ι = Fintype.card κ := by
  rw [card_eq_dim b₁, card_eq_dim b₂]

end Ch1.BasiMonadikotita
