1. What is proved: the statement in the book and in Lean

  • If $f\ge g$ on $[a,b]$, the area of the region between $y=f(x)$ and $y=g(x)$ is $E$${}=\int_a^b\bigl[f(x)-g(x)\bigr]\,dx$
    theorem area_ordered (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b))
    (hgf : ∀ x ∈ Set.Icc a b, g x ≤ f x) :
    volume (regionBetween g f (Set.Icc a b)) = ENNReal.ofReal (∫ x in a..b, (f x - g x))
  • If the curves change relative position, the area is $E$${}=\int_a^b\bigl|f(x)-g(x)\bigr|\,dx$, that is, the sum of the areas over the subintervals
    theorem area_abs (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b)) :
    volume (regionBetween (fun x => min (f x) (g x)) (fun x => max (f x) (g x)) (Set.Icc a b)) =
      ENNReal.ofReal (∫ x in a..b, |f x - g x|)

In Mathlib, the area of a plane region is its Lebesgue measure, volume. The area is a nonnegative number or $+\infty$ (type ENNReal); that is why the integral is written inside ENNReal.ofReal, which converts it into such a number. When $f\ge g$, the region is the set regionBetween g f (Set.Icc a b) of points $(x,y)$ with $x\in[a,b]$ and $g(x)\lt y\lt f(x)$. When the curves change relative position, at each $x$ the region lies between the smaller and the larger of the values $f(x)$, $g(x)$, that is, between $\min\{f(x),g(x)\}$ and $\max\{f(x),g(x)\}$. Since $\max-\min=|f-g|$, the area is $\int_a^b|f-g|\,dx$; on each subinterval where the curves do not change position, this is exactly the integral in the book. Including the boundary curves as well does not change the area.

2. Where it is in Mathlib

We used the following theorems:

  • volume_regionBetween_eq_integral: the area of the region between two graphs.
  • MeasureTheory.Measure.volume_eq_prod: area in the plane is the product of the length measures on the two axes.
  • ContinuousOn.integrableOn_Icc: a continuous function on a closed interval is integrable there.
  • ContinuousOn.inf: $\min\{f,g\}$ is continuous.
  • ContinuousOn.sup: $\max\{f,g\}$ is continuous.
  • min_le_max: $\min\{u,v\}\le\max\{u,v\}$.
  • max_sub_min_eq_abs': $\max\{u,v\}-\min\{u,v\}=|u-v|$.
  • intervalIntegral.integral_of_le: for $a\le b$, $\int_a^b$ is an integral over $(a,b]$.
  • MeasureTheory.integral_Icc_eq_integral_Ioc: the integrals over $[a,b]$ and $(a,b]$ are equal.

import Mathlib

namespace Ch17.EmvadonXwriou
open MeasureTheory

-- when f ≥ g: the area is the integral of f - g
theorem area_ordered (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b))
    (hgf : ∀ x ∈ Set.Icc a b, g x ≤ f x) :
    volume (regionBetween g f (Set.Icc a b)) = ENNReal.ofReal (∫ x in a..b, (f x - g x)) := by
  rw [Measure.volume_eq_prod, volume_regionBetween_eq_integral hg.integrableOn_Icc
    hf.integrableOn_Icc measurableSet_Icc hgf, intervalIntegral.integral_of_le hab,
    integral_Icc_eq_integral_Ioc]
  rfl

-- when the curves change relative position: the area is the integral of |f - g|
theorem area_abs (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b)) :
    volume (regionBetween (fun x => min (f x) (g x)) (fun x => max (f x) (g x)) (Set.Icc a b)) =
      ENNReal.ofReal (∫ x in a..b, |f x - g x|) := by
  rw [Measure.volume_eq_prod, volume_regionBetween_eq_integral (hf.inf hg).integrableOn_Icc
    (hf.sup hg).integrableOn_Icc measurableSet_Icc (fun x _ => min_le_max),
    intervalIntegral.integral_of_le hab, integral_Icc_eq_integral_Ioc]
  simp only [Pi.sub_apply, max_sub_min_eq_abs']

end Ch17.EmvadonXwriou
