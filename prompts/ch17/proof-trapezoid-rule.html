1. What is proved: the statement in the book and in Lean

  • With $h=\dfrac{b-a}{n}$ and $x_i=a+ih$: $T_n$${}=\dfrac{h}{2}\bigl[f(x_0)$${}+2f(x_1)+\dots+2f(x_{n-1})$${}+f(x_n)\bigr]$
    theorem trapezoid_formula (f : ℝ → ℝ) (n : ℕ) (a b : ℝ) :
    trapezoidal_integral f n a b =
      (b - a) / n / 2 *
        (f a + 2 * ∑ k ∈ Finset.range (n - 1), f (a + (k + 1) * (b - a) / n) + f b)
  • $\Bigl|T_n-\int_a^b f(x)\,dx\Bigr|\le\dfrac{(b-a)^3}{12n^2}M_2$, where $|f''(x)|\le M_2$ on $[a,b]$
    theorem trapezoid_error (f : ℝ → ℝ) (a b M : ℝ) (n : ℕ) (hn : 0 < n) (hab : a ≤ b)
    (hf : ContDiffOn ℝ 2 f (Set.Icc a b))
    (hM : ∀ x, |iteratedDerivWithin 2 f (Set.Icc a b) x| ≤ M) :
    |trapezoidal_integral f n a b - ∫ x in a..b, f x| ≤ (b - a) ^ 3 / (12 * n ^ 2) * M

Mathlib defines the trapezoid rule as trapezoidal_integral f n a b, in the form $T_n$${}=h\left[\dfrac{f(a)+f(b)}{2}+f(x_1)+\dots+f(x_{n-1})\right]$; the first theorem shows that this is the formula in the book. In the sum ∑ k ∈ Finset.range (n - 1) the index $k$ takes the values $0,1,\dots,n-2$, and the term $f\bigl(a+(k+1)\tfrac{b-a}{n}\bigr)$ is $f(x_{k+1})$. For the error we assume that $f$ has a continuous second derivative on $[a,b]$ (ContDiffOn ℝ 2 f (Set.Icc a b)). The second derivative is computed within the interval (iteratedDerivWithin 2 f (Set.Icc a b)), with one-sided derivatives at the endpoints, and $M_2$ is an upper bound for its absolute value. The hypothesis is written for every real $x$, but outside $[a,b]$ this derivative is defined to be $0$, so in effect it concerns only $[a,b]$.

2. Where it is in Mathlib

We used the following from Mathlib:

  • trapezoidal_integral: the definition of $T_n$.
  • trapezoidal_error: the definition of the error $T_n-\int_a^b f(x)\,dx$.
  • trapezoidal_error_le_of_c2: the error bound, for a function with a continuous second derivative.
  • Set.uIcc_of_le: for $a\le b$, the interval with endpoints $a$ and $b$ is $[a,b]$.

import Mathlib

namespace Ch17.KanonasTrapeziou

-- the Mathlib definition, with h = (b - a)/n, is written as in the book:
-- T_n = (h/2) (f(x₀) + 2 f(x₁) + … + 2 f(x_{n-1}) + f(xₙ))
theorem trapezoid_formula (f : ℝ → ℝ) (n : ℕ) (a b : ℝ) :
    trapezoidal_integral f n a b =
      (b - a) / n / 2 *
        (f a + 2 * ∑ k ∈ Finset.range (n - 1), f (a + (k + 1) * (b - a) / n) + f b) := by
  unfold trapezoidal_integral
  ring

-- error bound: |T_n - ∫ f| ≤ (b - a)³ M₂ / (12 n²)
theorem trapezoid_error (f : ℝ → ℝ) (a b M : ℝ) (n : ℕ) (hn : 0 < n) (hab : a ≤ b)
    (hf : ContDiffOn ℝ 2 f (Set.Icc a b))
    (hM : ∀ x, |iteratedDerivWithin 2 f (Set.Icc a b) x| ≤ M) :
    |trapezoidal_integral f n a b - ∫ x in a..b, f x| ≤ (b - a) ^ 3 / (12 * n ^ 2) * M := by
  rw [← Set.uIcc_of_le hab] at hf hM
  have h := trapezoidal_error_le_of_c2 hf hM hn
  rw [abs_of_nonneg (sub_nonneg.mpr hab)] at h
  unfold trapezoidal_error at h
  calc _ ≤ (b - a) ^ 3 * M / (12 * n ^ 2) := h
    _ = (b - a) ^ 3 / (12 * n ^ 2) * M := by ring

end Ch17.KanonasTrapeziou
