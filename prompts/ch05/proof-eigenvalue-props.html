Properties of Eigenvalues

Chapter 5 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $A\in\mathcal{M}_{n\times n}$ with eigenvalues in $\mathbb{C}$, counted with their algebraic multiplicity. (i) $\sigma(A)=\sigma(A^{T})$: the transpose has the same eigenvalues. (ii) If $A$ is triangular, its eigenvalues are the diagonal entries. (iii) If $A\mathbf{v}=\lambda\mathbf{v}$ with $\mathbf{v}\ne\mathbf{0}$, then the same $\mathbf{v}$ is an eigenvector of $A^{k}$ (with eigenvalue $\lambda^{k}$), of $cA$ (with $c\lambda$), of $A+cI$ (with $\lambda+c$) and of $p(A)$ (with $p(\lambda)$), for every $k\in\mathbb{N}^{*}$, $c\in\mathbb{R}$ and every polynomial $p$; and if moreover $A$ is invertible, of $A^{-1}$ as well, with eigenvalue $\lambda^{-1}$. That is, the eigenvalues change, the eigendirections do not. (The relations $\operatorname{tr}(A)=\sum_i\lambda_i$ and $\det(A)=\prod_i\lambda_i$ are proved separately.)

1. What is proved: the statement in the book and in Lean

  • (i) $\det(A^{T}-\lambda I)$${}=\det(A-\lambda I)$, so $A$ and $A^{T}$ have the same eigenvalues
    theorem det_transpose_shift (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (Aᵀ - μ • 1).det = (A - μ • 1).det
  • (i) $A$ and $A^{T}$ have the same characteristic polynomial, hence also the same multiplicities
    theorem charpoly_of_transpose (A : Matrix (Fin n) (Fin n) ℝ) : Aᵀ.charpoly = A.charpoly
  • (ii) For upper triangular $A$: $\det(A-\lambda I)$${}=(a_{11}-\lambda)\cdots(a_{nn}-\lambda)$
    theorem det_shift_triangular (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsUpperTriangular) (μ : ℝ) :
    (A - μ • 1).det = ∏ i, (A i i - μ)
  • (ii) Hence its eigenvalues are the diagonal entries
    theorem eigen_triangular (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsUpperTriangular) (μ : ℝ) :
    (A - μ • 1).det = 0 ↔ ∃ i, A i i = μ
  • (iii) $A^{k}\mathbf{v}$${}=\lambda^{k}\mathbf{v}$
    theorem pow_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v)
    (k : ℕ) : (A ^ k) *ᵥ v = (μ ^ k) • v
  • (iii) $(cA)\mathbf{v}$${}=(c\lambda)\mathbf{v}$
    theorem smul_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ c : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v) :
    (c • A) *ᵥ v = (c * μ) • v
  • (iii) $(A+cI)\mathbf{v}$${}=(\lambda+c)\mathbf{v}$
    theorem shift_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ c : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v) :
    (A + c • 1) *ᵥ v = (μ + c) • v
  • (iii) $p(A)\mathbf{v}$${}=p(\lambda)\mathbf{v}$ for every polynomial $p$
    theorem poly_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v)
    (p : Polynomial ℝ) : (Polynomial.aeval A p) *ᵥ v = (p.eval μ) • v
  • (iii) If $A$ is invertible, $A^{-1}\mathbf{v}$${}=\lambda^{-1}\mathbf{v}$
    theorem inv_eig (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (μ : ℝ) (v : Fin n → ℝ)
    (hv : v ≠ 0) (h : A *ᵥ v = μ • v) : A⁻¹ *ᵥ v = μ⁻¹ • v

The eigenvalue is called μ, because λ is a reserved word in Lean. “Upper triangular” is A.IsUpperTriangular: $a_{ij}=0$ whenever $i\gt j$. For a lower triangular matrix the same holds by (i), since its transpose is upper triangular. For a polynomial $p$, $p(A)$ is written Polynomial.aeval A p and $p(\lambda)$ is written p.eval μ. In (iii) the hypothesis h is $A\mathbf{v}=\lambda\mathbf{v}$; the hypothesis $\mathbf{v}\ne\mathbf{0}$ (hv) is needed only for $A^{-1}$, to show that $\lambda\ne 0$.

2. Step by step: $A^{k}\mathbf{v}$${}=\lambda^{k}\mathbf{v}$, by induction on $k$

The idea: $A^{k+1}\mathbf{v}$${}=A^{k}(A\mathbf{v})$${}=A^{k}(\lambda\mathbf{v})$${}=\lambda\,A^{k}\mathbf{v}$${}=\lambda\,\lambda^{k}\mathbf{v}$${}=\lambda^{k+1}\mathbf{v}$. We start from the goal:

The goal
n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
μ : ℝ
v : Fin n → ℝ
h : A *ᵥ v = μ • v
k : ℕ
⊢ A ^ k *ᵥ v = μ ^ k • v

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. induction k with
| zero =>

    Induction on $k$. First the case $k=0$.

    What remains to be proved
    ⊢ A ^ 0 *ᵥ v = μ ^ 0 • v
  2. rw [pow_zero, pow_zero, one_mulVec, one_smul]

    $A^{0}=I$ and $\lambda^{0}=1$, so both sides are equal to $\mathbf{v}$.

    ✓ This part is complete.
  3. | succ k ih =>

    Inductive step: we assume that $A^{k}\mathbf{v}$${}=\lambda^{k}\mathbf{v}$ (hypothesis ih) and prove it for $k+1$.

    What remains to be proved
    n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
μ : ℝ
v : Fin n → ℝ
h : A *ᵥ v = μ • v
k : ℕ
ih : A ^ k *ᵥ v = μ ^ k • v
⊢ A ^ (k + 1) *ᵥ v = μ ^ (k + 1) • v
  4. rw [pow_succ, ← mulVec_mulVec]

    $A^{k+1}\mathbf{v}$${}=(A^{k}A)\mathbf{v}$${}=A^{k}(A\mathbf{v})$. On the screen, A ^ k *ᵥ A *ᵥ v means $A^{k}(A\mathbf{v})$.

    What remains to be proved
    ⊢ A ^ k *ᵥ A *ᵥ v = μ ^ (k + 1) • v
  5. rw [h, mulVec_smul]

    We substitute $A\mathbf{v}=\lambda\mathbf{v}$ and pull the number $\lambda$ out: $A^{k}(\lambda\mathbf{v})$${}=\lambda\,A^{k}\mathbf{v}$.

    What remains to be proved
    ⊢ μ • A ^ k *ᵥ v = μ ^ (k + 1) • v
  6. rw [ih, smul_smul]

    By the induction hypothesis, $\lambda\,A^{k}\mathbf{v}$${}=\lambda\,(\lambda^{k}\mathbf{v})$${}=(\lambda\lambda^{k})\,\mathbf{v}$.

    What remains to be proved
    ⊢ (μ * μ ^ k) • v = μ ^ (k + 1) • v
  7. rw [pow_succ']

    Finally, $\lambda^{k+1}=\lambda\lambda^{k}$, and the two sides become identical.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • Matrix.det_transpose: $\det(A^{T})=\det(A)$.
  • Matrix.charpoly_transpose: $A$ and $A^{T}$ have the same characteristic polynomial.
  • Matrix.det_of_isUpperTriangular: the determinant of an upper triangular matrix is the product of its diagonal entries.
  • Matrix.mulVec_mulVec: $A(B\mathbf{v})=(AB)\mathbf{v}$.
  • Polynomial.induction_on': every polynomial is built from monomials by addition, so it suffices to check monomials and sums.

import Mathlib

namespace Ch5.IdiotitesIdiotimon
open Matrix

variable {n : ℕ}

theorem det_transpose_shift (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (Aᵀ - μ • 1).det = (A - μ • 1).det := by
  rw [← det_transpose (A - μ • 1), transpose_sub, transpose_smul, transpose_one]

theorem charpoly_of_transpose (A : Matrix (Fin n) (Fin n) ℝ) : Aᵀ.charpoly = A.charpoly :=
  charpoly_transpose A

theorem det_shift_triangular (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsUpperTriangular) (μ : ℝ) :
    (A - μ • 1).det = ∏ i, (A i i - μ) := by
  have h : (A - μ • 1).IsUpperTriangular := by
    intro i j hij
    have hne : i ≠ j := hij.ne'
    rw [Matrix.sub_apply, Matrix.smul_apply, one_apply_ne hne, smul_zero, sub_zero]
    exact hA hij
  rw [det_of_isUpperTriangular h]
  simp only [Matrix.sub_apply, Matrix.smul_apply, one_apply_eq, smul_eq_mul, mul_one]

theorem eigen_triangular (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsUpperTriangular) (μ : ℝ) :
    (A - μ • 1).det = 0 ↔ ∃ i, A i i = μ := by
  rw [det_shift_triangular A hA μ, Finset.prod_eq_zero_iff]
  simp only [Finset.mem_univ, true_and, sub_eq_zero]

theorem pow_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v)
    (k : ℕ) : (A ^ k) *ᵥ v = (μ ^ k) • v := by
  induction k with
  | zero =>
    rw [pow_zero, pow_zero, one_mulVec, one_smul]
  | succ k ih =>
    rw [pow_succ, ← mulVec_mulVec]
    rw [h, mulVec_smul]
    rw [ih, smul_smul]
    rw [pow_succ']

theorem smul_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ c : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v) :
    (c • A) *ᵥ v = (c * μ) • v := by
  rw [smul_mulVec, h, smul_smul]

theorem shift_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ c : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v) :
    (A + c • 1) *ᵥ v = (μ + c) • v := by
  rw [add_mulVec, h, smul_mulVec, one_mulVec, add_smul]

theorem poly_eig (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) (h : A *ᵥ v = μ • v)
    (p : Polynomial ℝ) : (Polynomial.aeval A p) *ᵥ v = (p.eval μ) • v := by
  induction p using Polynomial.induction_on' with
  | add p q hp hq =>
    rw [map_add, add_mulVec, hp, hq, Polynomial.eval_add, add_smul]
  | monomial k a =>
    rw [Polynomial.aeval_monomial, Polynomial.eval_monomial, Algebra.algebraMap_eq_smul_one,
      smul_mul_assoc, one_mul, smul_mulVec, pow_eig A μ v h k, smul_smul]

theorem inv_eig (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (μ : ℝ) (v : Fin n → ℝ)
    (hv : v ≠ 0) (h : A *ᵥ v = μ • v) : A⁻¹ *ᵥ v = μ⁻¹ • v := by
  have hμ : μ ≠ 0 := by
    intro h0
    rw [h0, zero_smul] at h
    exact hA (exists_mulVec_eq_zero_iff.mp ⟨v, hv, h⟩)
  have h2 : A⁻¹ *ᵥ (A *ᵥ v) = v := by
    rw [mulVec_mulVec, nonsing_inv_mul A hA.isUnit, one_mulVec]
  rw [h, mulVec_smul] at h2
  have h3 : μ⁻¹ • (μ • (A⁻¹ *ᵥ v)) = μ⁻¹ • v := by
    rw [h2]
  rw [smul_smul, inv_mul_cancel₀ hμ, one_smul] at h3
  exact h3

end Ch5.IdiotitesIdiotimon
