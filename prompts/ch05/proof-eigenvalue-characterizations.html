1. What is proved: the statement in the book and in Lean

  • (i), (ii), (iii) and (iv) are equivalent
    theorem characterizations (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) : List.TFAE [
    ∃ v : Fin n → ℝ, v ≠ 0 ∧ A *ᵥ v = μ • v,
    (A - μ • 1).det = 0,
    ¬ IsUnit (A - μ • 1),
    LinearMap.ker (A - μ • 1).mulVecLin ≠ ⊥]
  • (i)$\Leftrightarrow$(ii): $\lambda$ is an eigenvalue $\Leftrightarrow\det(A-\lambda I)=0$
    theorem i_iff_ii (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (∃ v : Fin n → ℝ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ (A - μ • 1).det = 0
  • (ii)$\Leftrightarrow$(iii): $\det(A-\lambda I)=0\Leftrightarrow$ $A-\lambda I$ is not invertible
    theorem ii_iff_iii (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (A - μ • 1).det = 0 ↔ ¬ IsUnit (A - μ • 1)
  • (i)$\Leftrightarrow$(iv): $\lambda$ is an eigenvalue $\Leftrightarrow\ker(A-\lambda I)\ne\{\mathbf{0}\}$
    theorem i_iff_iv (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (∃ v : Fin n → ℝ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ LinearMap.ker (A - μ • 1).mulVecLin ≠ ⊥
  • Auxiliary: $A\mathbf{v}$${}=\lambda\mathbf{v}\Leftrightarrow(A-\lambda I)\mathbf{v}$${}=\mathbf{0}$
    theorem eigen_eq_iff (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) :
    A *ᵥ v = μ • v ↔ (A - μ • 1) *ᵥ v = 0

The eigenvalue is called μ, because λ is a reserved word in Lean. The matrix $\lambda I$ is written μ • 1. Statement (i) says that there is a $\mathbf{v}\ne\mathbf{0}$ with $A\mathbf{v}=\lambda\mathbf{v}$. “Not invertible” is written ¬ IsUnit (A - μ • 1), and the kernel of $A-\lambda I$ is written LinearMap.ker (A - μ • 1).mulVecLin. List.TFAE (“the following are equivalent”) says that the statements in the list are pairwise equivalent; tfae_finish deduces this from the three equivalences we proved.

2. Step by step: (i)$\Leftrightarrow$(ii)

The idea: $A\mathbf{v}=\lambda\mathbf{v}$ can be written as $(A-\lambda I)\mathbf{v}=\mathbf{0}$, and a homogeneous system with a square matrix has a nonzero solution exactly when the determinant is zero. We start from the goal:

The goal
n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
μ : ℝ
⊢ (∃ v, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ (A - μ • 1).det = 0

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [← exists_mulVec_eq_zero_iff]

    We rewrite $\det(A-\lambda I)=0$ as “there is a $\mathbf{v}\ne\mathbf{0}$ with $(A-\lambda I)\mathbf{v}=\mathbf{0}$” (theorem exists_mulVec_eq_zero_iff).

    What remains to be proved
    ⊢ (∃ v, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ ∃ v, v ≠ 0 ∧ (A - μ • 1) *ᵥ v = 0
  2. constructor

    Two directions: mp for $\Rightarrow$ and mpr for $\Leftarrow$.

    What remains to be proved (2 goals)part mp
    ⊢ (∃ v, v ≠ 0 ∧ A *ᵥ v = μ • v) → ∃ v, v ≠ 0 ∧ (A - μ • 1) *ᵥ v = 0
    part mpr
    ⊢ (∃ v, v ≠ 0 ∧ (A - μ • 1) *ᵥ v = 0) → ∃ v, v ≠ 0 ∧ A *ᵥ v = μ • v
  3. · rintro ⟨v, hv, h⟩

    Direction $\Rightarrow$: we take the eigenvector $\mathbf{v}$, with $\mathbf{v}\ne\mathbf{0}$ (hypothesis hv) and $A\mathbf{v}=\lambda\mathbf{v}$ (hypothesis h).

    What remains to be proved
    v : Fin n → ℝ
hv : v ≠ 0
h : A *ᵥ v = μ • v
⊢ ∃ v, v ≠ 0 ∧ (A - μ • 1) *ᵥ v = 0
  4. rw [eigen_eq_iff] at h

    By the auxiliary lemma, h becomes $(A-\lambda I)\mathbf{v}=\mathbf{0}$.

    What remains to be proved
    h : (A - μ • 1) *ᵥ v = 0
⊢ ∃ v, v ≠ 0 ∧ (A - μ • 1) *ᵥ v = 0
  5. exact ⟨v, hv, h⟩

    The same $\mathbf{v}$ is the nonzero solution we need.

    ✓ This part is complete.
  6. · rintro ⟨v, hv, h⟩

    Direction $\Leftarrow$: we take $\mathbf{v}\ne\mathbf{0}$ with $(A-\lambda I)\mathbf{v}=\mathbf{0}$.

    What remains to be proved
    n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
μ : ℝ
v : Fin n → ℝ
hv : v ≠ 0
h : (A - μ • 1) *ᵥ v = 0
⊢ ∃ v, v ≠ 0 ∧ A *ᵥ v = μ • v
  7. rw [← eigen_eq_iff] at h

    By the auxiliary lemma, read from right to left, h becomes $A\mathbf{v}=\lambda\mathbf{v}$.

    What remains to be proved
    h : A *ᵥ v = μ • v
⊢ ∃ v, v ≠ 0 ∧ A *ᵥ v = μ • v
  8. exact ⟨v, hv, h⟩

    So $\mathbf{v}$ is an eigenvector and $\lambda$ is an eigenvalue.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • Matrix.exists_mulVec_eq_zero_iff: a nonzero solution of $M\mathbf{v}=\mathbf{0}$ exists exactly when $\det M=0$.
  • Matrix.isUnit_iff_isUnit_det: a matrix is invertible exactly when its determinant is invertible.
  • Submodule.ne_bot_iff: a subspace is not $\{\mathbf{0}\}$ exactly when it has a nonzero element.
  • Matrix.sub_mulVec: $(A-B)\mathbf{v}$${}=A\mathbf{v}-B\mathbf{v}$.

import Mathlib

namespace Ch5.XaraktirismoiIdiotimis
open Matrix

variable {n : ℕ}

theorem eigen_eq_iff (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) :
    A *ᵥ v = μ • v ↔ (A - μ • 1) *ᵥ v = 0 := by
  rw [sub_mulVec, smul_mulVec, one_mulVec, sub_eq_zero]

theorem i_iff_ii (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (∃ v : Fin n → ℝ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ (A - μ • 1).det = 0 := by
  rw [← exists_mulVec_eq_zero_iff]
  constructor
  · rintro ⟨v, hv, h⟩
    rw [eigen_eq_iff] at h
    exact ⟨v, hv, h⟩
  · rintro ⟨v, hv, h⟩
    rw [← eigen_eq_iff] at h
    exact ⟨v, hv, h⟩

theorem ii_iff_iii (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (A - μ • 1).det = 0 ↔ ¬ IsUnit (A - μ • 1) := by
  rw [isUnit_iff_isUnit_det, isUnit_iff_ne_zero, not_not]

theorem i_iff_iv (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    (∃ v : Fin n → ℝ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ LinearMap.ker (A - μ • 1).mulVecLin ≠ ⊥ := by
  rw [Submodule.ne_bot_iff]
  constructor
  · rintro ⟨v, hv, h⟩
    refine ⟨v, ?_, hv⟩
    rw [LinearMap.mem_ker, mulVecLin_apply, ← eigen_eq_iff]
    exact h
  · rintro ⟨v, hk, hv⟩
    rw [LinearMap.mem_ker, mulVecLin_apply, ← eigen_eq_iff] at hk
    exact ⟨v, hv, hk⟩

theorem characterizations (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) : List.TFAE [
    ∃ v : Fin n → ℝ, v ≠ 0 ∧ A *ᵥ v = μ • v,
    (A - μ • 1).det = 0,
    ¬ IsUnit (A - μ • 1),
    LinearMap.ker (A - μ • 1).mulVecLin ≠ ⊥] := by
  tfae_have 1 ↔ 2 := i_iff_ii A μ
  tfae_have 2 ↔ 3 := ii_iff_iii A μ
  tfae_have 1 ↔ 4 := i_iff_iv A μ
  tfae_finish

end Ch5.XaraktirismoiIdiotimis
