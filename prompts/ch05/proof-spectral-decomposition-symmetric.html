Spectral Decomposition of a Symmetric Matrix

Chapter 5 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementIf $A=A^{T}$ is a real $(n\times n)$ matrix: (i) all its eigenvalues are real, that is, there is no complex eigenvalue and hence no hidden rotation; (ii) eigenvectors corresponding to different eigenvalues are orthogonal to one another. The eigendirections of a symmetric matrix thus form an orthogonal system of axes, the principal axes of the problem. That these axes always suffice for the whole of $\mathbb{R}^n$, that is, that $A=Q\Lambda Q^{T}$ with $Q$ orthogonal, is the Spectral Theorem and is proved separately.

1. What is proved: the statement in the book and in Lean

  • (i) Every complex eigenvalue $\lambda$ of a real symmetric $A$ is real: $\operatorname{Im}\lambda=0$
    theorem real_eigenvalues (A : Matrix (Fin n) (Fin n) ℝ) (hA : Aᵀ = A) (μ : ℂ) (v : Fin n → ℂ)
    (hv : v ≠ 0) (h : toC A *ᵥ v = μ • v) : μ.im = 0
  • (ii) Eigenvectors of different eigenvalues are orthogonal: $\mathbf{v}\cdot\mathbf{w}=0$
    theorem orthogonal_eigenvectors (A : Matrix (Fin n) (Fin n) ℝ) (hA : Aᵀ = A) (μ ν : ℝ)
    (v w : Fin n → ℝ) (hv : A *ᵥ v = μ • v) (hw : A *ᵥ w = ν • w) (hμν : μ ≠ ν) :
    v ⬝ᵥ w = 0
  • Auxiliary: $A$, viewed as a complex matrix, is Hermitian
    theorem toC_hermitian (A : Matrix (Fin n) (Fin n) ℝ) (hA : Aᵀ = A) : (toC A).IsHermitian
  • Auxiliary: every eigenvalue belongs to the spectrum of the matrix
    theorem eig_mem_spectrum (M : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) (v : Fin n → ℂ) (hv : v ≠ 0)
    (h : M *ᵥ v = μ • v) : μ ∈ spectrum ℂ M

Symmetry is the hypothesis hA : Aᵀ = A. For (i) we view $A$ as a complex matrix toC A, with eigenvalue $\lambda\in\mathbb{C}$ and eigenvector $\mathbf{v}\in\mathbb{C}^n$; “real” is written μ.im = 0, that is, zero imaginary part. A complex matrix is Hermitian when $\bar{A}^{T}=A$, and a real symmetric matrix is Hermitian. The spectrum of a Hermitian matrix consists of real eigenvalues. For (ii), where the two eigenvalues are called μ and ν, symmetry gives $(A\mathbf{v})\cdot\mathbf{w}$${}=\mathbf{v}\cdot(A\mathbf{w})$, so $\mu(\mathbf{v}\cdot\mathbf{w})$${}=\nu(\mathbf{v}\cdot\mathbf{w})$, and since $\mu\ne\nu$, $\mathbf{v}\cdot\mathbf{w}=0$. The decomposition $A=Q\Lambda Q^{T}$ is on the page of the Spectral Theorem.

2. Where it is in Mathlib

We used the following theorems:

  • Matrix.IsHermitian.spectrum_eq_image_range: the spectrum of a Hermitian matrix consists of its real eigenvalues.
  • Matrix.isHermitian_iff_isSymm: for real matrices, Hermitian means symmetric.
  • Matrix.IsHermitian.map: a Hermitian matrix stays Hermitian when we view its real entries as complex numbers.
  • spectrum.mem_iff: $\lambda$ belongs to the spectrum exactly when $\lambda I-A$ is not invertible.
  • Matrix.dotProduct_mulVec: $\mathbf{v}\cdot(A\mathbf{w})$${}=(\mathbf{v}^{T}A)\cdot\mathbf{w}$.
  • Matrix.vecMul_transpose: $\mathbf{v}^{T}A^{T}$${}=(A\mathbf{v})^{T}$.

import Mathlib

namespace Ch5.FasmatikiApothesi
open Matrix

variable {n : ℕ}

-- the real matrix A, viewed as a complex matrix
def toC (A : Matrix (Fin n) (Fin n) ℝ) : Matrix (Fin n) (Fin n) ℂ := A.map Complex.ofReal

theorem toC_hermitian (A : Matrix (Fin n) (Fin n) ℝ) (hA : Aᵀ = A) : (toC A).IsHermitian := by
  have hH : A.IsHermitian := isHermitian_iff_isSymm.mpr hA
  exact hH.map Complex.ofReal (fun x => by rw [star_trivial, Complex.star_def, Complex.conj_ofReal])

theorem eig_mem_spectrum (M : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) (v : Fin n → ℂ) (hv : v ≠ 0)
    (h : M *ᵥ v = μ • v) : μ ∈ spectrum ℂ M := by
  rw [spectrum.mem_iff, Algebra.algebraMap_eq_smul_one, isUnit_iff_isUnit_det, isUnit_iff_ne_zero,
    not_not]
  apply exists_mulVec_eq_zero_iff.mp
  refine ⟨v, hv, ?_⟩
  rw [sub_mulVec, smul_mulVec, one_mulVec, h, sub_self]

theorem real_eigenvalues (A : Matrix (Fin n) (Fin n) ℝ) (hA : Aᵀ = A) (μ : ℂ) (v : Fin n → ℂ)
    (hv : v ≠ 0) (h : toC A *ᵥ v = μ • v) : μ.im = 0 := by
  have hmem := eig_mem_spectrum (toC A) μ v hv h
  rw [(toC_hermitian A hA).spectrum_eq_image_range] at hmem
  obtain ⟨r, -, rfl⟩ := hmem
  simp

theorem orthogonal_eigenvectors (A : Matrix (Fin n) (Fin n) ℝ) (hA : Aᵀ = A) (μ ν : ℝ)
    (v w : Fin n → ℝ) (hv : A *ᵥ v = μ • v) (hw : A *ᵥ w = ν • w) (hμν : μ ≠ ν) :
    v ⬝ᵥ w = 0 := by
  have h1 : (A *ᵥ v) ⬝ᵥ w = v ⬝ᵥ (A *ᵥ w) := by
    rw [← vecMul_transpose, hA, ← dotProduct_mulVec]
  rw [hv, hw, smul_dotProduct, dotProduct_smul, smul_eq_mul, smul_eq_mul] at h1
  have h2 : (μ - ν) * (v ⬝ᵥ w) = 0 := by
    rw [sub_mul, h1, sub_self]
  rcases mul_eq_zero.mp h2 with h3 | h3
  · exact absurd (sub_eq_zero.mp h3) hμν
  · exact h3

end Ch5.FasmatikiApothesi
