Linear Independence of Eigenvectors

Chapter 5 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $\lambda_1,\dots,\lambda_k$ be distinct eigenvalues of $A$. (i) If $\mathbf{v}_1,\dots,\mathbf{v}_k$ are corresponding eigenvectors, then they are linearly independent. (ii) More generally, if $\mathcal{B}_i$ is a basis of the eigenspace $E_{\lambda_i}$ for each $i$, then the union $\mathcal{B}_1\cup\dots\cup\mathcal{B}_k$ is linearly independent: eigenvectors from different eigenspaces never overlap. The fact that $n$ distinct eigenvalues imply diagonalizability is a corollary of (i) and is stated as criterion (C2) in the chapter on diagonalization.

1. What is proved: the statement in the book and in Lean

  • (i) Eigenvectors $\mathbf{v}_1,\dots,\mathbf{v}_k$ of distinct eigenvalues are linearly independent
    theorem eigenvectors_independent (A : Matrix (Fin n) (Fin n) ℝ) {k : ℕ} (μ : Fin k → ℝ)
    (hμ : Function.Injective μ) (v : Fin k → Fin n → ℝ)
    (hv : ∀ i, v i ≠ 0 ∧ A *ᵥ v i = μ i • v i) : LinearIndependent ℝ v
  • (ii) The eigenspaces $E_{\lambda_1},\dots,E_{\lambda_k}$ of distinct eigenvalues are independent
    theorem eigenspaces_independent (A : Matrix (Fin n) (Fin n) ℝ) {k : ℕ} (μ : Fin k → ℝ)
    (hμ : Function.Injective μ) :
    iSupIndep (fun i => Module.End.eigenspace (toLin' A) (μ i))

The eigenvalues are a family μ : Fin k → ℝ, and “distinct” is Function.Injective μ, that is, $\lambda_i\ne\lambda_j$ for $i\ne j$. The eigenspace $E_\lambda$ is written Module.End.eigenspace (toLin' A) μ, where toLin' A is the map $\mathbf{x}\mapsto A\mathbf{x}$. Mathlib states (ii) with iSupIndep: each eigenspace meets the sum of the others only in $\mathbf{0}$. This is equivalent to the union $\mathcal{B}_1\cup\dots\cup\mathcal{B}_k$ of the bases being linearly independent: a linear combination of elements of the union is a sum with one term from each eigenspace, and by independence it vanishes only when every term vanishes.

2. Where it is in Mathlib

We used the following theorems:

  • Module.End.eigenvectors_linearIndependent': eigenvectors of distinct eigenvalues are linearly independent.
  • Module.End.eigenspaces_iSupIndep: the eigenspaces of an operator are independent.
  • Module.End.hasEigenvector_iff: an eigenvector means $\mathbf{v}\in E_\lambda$ and $\mathbf{v}\ne\mathbf{0}$.
  • iSupIndep.comp: independence is preserved for every subfamily.

import Mathlib

namespace Ch5.AnexartisiaIdiodianysmaton
open Matrix

variable {n : ℕ}

theorem eigenvectors_independent (A : Matrix (Fin n) (Fin n) ℝ) {k : ℕ} (μ : Fin k → ℝ)
    (hμ : Function.Injective μ) (v : Fin k → Fin n → ℝ)
    (hv : ∀ i, v i ≠ 0 ∧ A *ᵥ v i = μ i • v i) : LinearIndependent ℝ v := by
  apply Module.End.eigenvectors_linearIndependent' (toLin' A) μ hμ v
  intro i
  rw [Module.End.hasEigenvector_iff, Module.End.mem_eigenspace_iff, toLin'_apply]
  exact ⟨(hv i).2, (hv i).1⟩

theorem eigenspaces_independent (A : Matrix (Fin n) (Fin n) ℝ) {k : ℕ} (μ : Fin k → ℝ)
    (hμ : Function.Injective μ) :
    iSupIndep (fun i => Module.End.eigenspace (toLin' A) (μ i)) :=
  (Module.End.eigenspaces_iSupIndep (toLin' A)).comp hμ

end Ch5.AnexartisiaIdiodianysmaton
