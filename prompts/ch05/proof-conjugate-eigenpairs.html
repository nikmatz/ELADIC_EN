1. What is proved: the statement in the book and in Lean

  • If $A\mathbf{v}=\lambda\mathbf{v}$ with $\mathbf{v}\ne\mathbf{0}$, then $\bar{\mathbf{v}}\ne\mathbf{0}$ and $A\bar{\mathbf{v}}$${}=\bar{\lambda}\,\bar{\mathbf{v}}$
    theorem conj_eigenpair (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℂ) (v : Fin n → ℂ)
    (hv : v ≠ 0) (h : toC A *ᵥ v = μ • v) :
    star v ≠ 0 ∧ toC A *ᵥ star v = star μ • star v
  • Auxiliary: for real $A$ we have $\overline{A\mathbf{v}}$${}=A\bar{\mathbf{v}}$
    theorem star_toC_mulVec (A : Matrix (Fin n) (Fin n) ℝ) (v : Fin n → ℂ) :
    star (toC A *ᵥ v) = toC A *ᵥ star v
  • Special case: if $\lambda$ is real, then $\bar{\mathbf{v}}$ is also an eigenvector for the same $\lambda$
    theorem real_eigenvalue (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℂ) (v : Fin n → ℂ)
    (hμ : star μ = μ) (h : toC A *ᵥ v = μ • v) : toC A *ᵥ star v = μ • star v

The eigenvalue is called μ, because λ is a reserved word in Lean. The real matrix $A$, viewed as a complex matrix, is toC A: the same entries, regarded as complex numbers. The conjugate $\bar{z}$ of a complex number is written star z, and for a vector, star v takes the conjugate of every coordinate. The statement is a conjunction ∧: first that $\bar{\mathbf{v}}$ is not zero, so that it really is an eigenvector, and then the equation.

2. Step by step: $A\bar{\mathbf{v}}$${}=\bar{\lambda}\,\bar{\mathbf{v}}$

The idea: we take conjugates of both sides of $A\mathbf{v}=\lambda\mathbf{v}$. Since $A$ has real entries, $\bar{A}=A$, so $\overline{A\mathbf{v}}$${}=A\bar{\mathbf{v}}$ (auxiliary lemma star_toC_mulVec). We start from the goal:

The goal
n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
μ : ℂ
v : Fin n → ℂ
hv : v ≠ 0
h : toC A *ᵥ v = μ • v
⊢ star v ≠ 0 ∧ toC A *ᵥ star v = star μ • star v

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. constructor

    Two goals: that $\bar{\mathbf{v}}\ne\mathbf{0}$ and that $A\bar{\mathbf{v}}$${}=\bar{\lambda}\,\bar{\mathbf{v}}$.

    What remains to be proved (2 goals)part left
    ⊢ star v ≠ 0
    part right
    ⊢ toC A *ᵥ star v = star μ • star v
  2. · rw [star_ne_zero]

    A vector and its conjugate are either both zero or both nonzero (theorem star_ne_zero).

    What remains to be proved
    ⊢ v ≠ 0
  3. exact hv

    So it suffices that $\mathbf{v}\ne\mathbf{0}$, which is the hypothesis hv.

    ✓ This part is complete.
  4. · rw [← star_toC_mulVec]

    Second goal: we write $A\bar{\mathbf{v}}$${}=\overline{A\mathbf{v}}$, using the auxiliary lemma from right to left.

    What remains to be proved
    n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
μ : ℂ
v : Fin n → ℂ
hv : v ≠ 0
h : toC A *ᵥ v = μ • v
⊢ star (toC A *ᵥ v) = star μ • star v
  5. rw [h]

    We replace $A\mathbf{v}$ by $\lambda\mathbf{v}$ (hypothesis h).

    What remains to be proved
    ⊢ star (μ • v) = star μ • star v
  6. rw [star_smul]

    The conjugate of $\lambda\mathbf{v}$ is $\bar{\lambda}\,\bar{\mathbf{v}}$ (theorem star_smul), and the two sides become identical.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • star_ne_zero: $\bar{\mathbf{v}}\ne\mathbf{0}\Leftrightarrow\mathbf{v}\ne\mathbf{0}$.
  • star_smul: $\overline{\lambda\mathbf{v}}$${}=\bar{\lambda}\,\bar{\mathbf{v}}$.
  • RingHom.map_mulVec: a ring homomorphism, here conjugation, passes inside the matrix-vector product.
  • Complex.star_def: star on the complex numbers is conjugation.

import Mathlib

namespace Ch5.SyzygeisIdiotimes
open Matrix

variable {n : ℕ}

-- the real matrix A, viewed as a complex matrix
def toC (A : Matrix (Fin n) (Fin n) ℝ) : Matrix (Fin n) (Fin n) ℂ := A.map Complex.ofReal

theorem star_toC_mulVec (A : Matrix (Fin n) (Fin n) ℝ) (v : Fin n → ℂ) :
    star (toC A *ᵥ v) = toC A *ᵥ star v := by
  have hA : (toC A).map (starRingEnd ℂ) = toC A := by
    ext i j
    simp [toC]
  funext i
  rw [Pi.star_apply, Complex.star_def, RingHom.map_mulVec, hA]
  rfl

theorem conj_eigenpair (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℂ) (v : Fin n → ℂ)
    (hv : v ≠ 0) (h : toC A *ᵥ v = μ • v) :
    star v ≠ 0 ∧ toC A *ᵥ star v = star μ • star v := by
  constructor
  · rw [star_ne_zero]
    exact hv
  · rw [← star_toC_mulVec]
    rw [h]
    rw [star_smul]

theorem real_eigenvalue (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℂ) (v : Fin n → ℂ)
    (hμ : star μ = μ) (h : toC A *ᵥ v = μ • v) : toC A *ᵥ star v = μ • star v := by
  rw [← star_toC_mulVec, h, star_smul, hμ]

end Ch5.SyzygeisIdiotimes
