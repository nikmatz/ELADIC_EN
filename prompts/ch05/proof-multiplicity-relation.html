Relation Between the Multiplicities

Chapter 5 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor every eigenvalue $\lambda$ we have $1\le m_g(\lambda)\le m_a(\lambda)$: the geometric multiplicity (the dimension of the eigenspace $E_\lambda$) never exceeds the algebraic one (the multiplicity of $\lambda$ as a root of the characteristic polynomial). The eigenvalue is called semisimple when $m_g(\lambda)=m_a(\lambda)$ and defective when $m_g(\lambda)$ is strictly less than $m_a(\lambda)$.

1. What is proved: the statement in the book and in Lean

  • $m_g(\lambda)\le m_a(\lambda)$
    theorem geom_le_alg (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    Module.finrank ℝ (Module.End.eigenspace (toLin' A) μ) ≤ A.charpoly.rootMultiplicity μ
  • $1\le m_g(\lambda)$, when $\lambda$ is an eigenvalue
    theorem one_le_geom (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) (hv : v ≠ 0)
    (h : A *ᵥ v = μ • v) : 1 ≤ Module.finrank ℝ (Module.End.eigenspace (toLin' A) μ)

The geometric multiplicity $m_g(\lambda)=\dim E_\lambda$ is Module.finrank ℝ (Module.End.eigenspace (toLin' A) μ), where toLin' A is the map $\mathbf{x}\mapsto A\mathbf{x}$. The algebraic multiplicity $m_a(\lambda)$ is the multiplicity of $\lambda$ as a root of the characteristic polynomial, A.charpoly.rootMultiplicity μ. Mathlib defines the characteristic polynomial as $\det(tI-A)$, which differs from $\det(A-tI)$ only by the factor $(-1)^n$, so it has the same roots with the same multiplicities. The terms “semisimple” and “defective” are definitions and need no proof.

2. Where it is in Mathlib

We used the following theorems:

  • LinearMap.finrank_eigenspace_le: the dimension of $E_\lambda$ does not exceed the multiplicity of $\lambda$ as a root of the characteristic polynomial.
  • Matrix.charpoly_toLin': the matrix $A$ and the map $\mathbf{x}\mapsto A\mathbf{x}$ have the same characteristic polynomial.
  • Submodule.one_le_finrank_iff: a subspace has dimension at least $1$ exactly when it is not $\{\mathbf{0}\}$.
  • Module.End.mem_eigenspace_iff: $\mathbf{v}\in E_\lambda\Leftrightarrow A\mathbf{v}$${}=\lambda\mathbf{v}$.

import Mathlib

namespace Ch5.SxesiPollaplotiton
open Matrix

variable {n : ℕ}

theorem geom_le_alg (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) :
    Module.finrank ℝ (Module.End.eigenspace (toLin' A) μ) ≤ A.charpoly.rootMultiplicity μ := by
  rw [← charpoly_toLin' A]
  exact LinearMap.finrank_eigenspace_le (toLin' A) μ

theorem one_le_geom (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℝ) (v : Fin n → ℝ) (hv : v ≠ 0)
    (h : A *ᵥ v = μ • v) : 1 ≤ Module.finrank ℝ (Module.End.eigenspace (toLin' A) μ) := by
  rw [Submodule.one_le_finrank_iff, Submodule.ne_bot_iff]
  refine ⟨v, ?_, hv⟩
  rw [Module.End.mem_eigenspace_iff, toLin'_apply]
  exact h

end Ch5.SxesiPollaplotiton
