1. What is proved: the statement in the book and in Lean

  • If $f$ is differentiable at $x_0$, then it is continuous at $x_0$
    theorem continuous_of_hasDeriv (f : ℝ → ℝ) (x₀ f' : ℝ) (hf : HasDerivAt f f' x₀) :
    ContinuousAt f x₀
  • Application: if $f$ and $g$ are differentiable at $x_0$, then $f+g$ is continuous at $x_0$
    theorem sum_continuous (f g : ℝ → ℝ) (x₀ f' g' : ℝ) (hf : HasDerivAt f f' x₀)
    (hg : HasDerivAt g g' x₀) : ContinuousAt (fun x => f x + g x) x₀
  • The converse does not hold: $|x|$ is continuous at $0$ but not differentiable there
    theorem abs_counterexample :
    ContinuousAt (fun x : ℝ => |x|) 0 ∧ ¬ DifferentiableAt ℝ (fun x : ℝ => |x|) 0

HasDerivAt f f' x₀ means that $f$ has derivative $f'$ at $x_0$, and ContinuousAt f x₀ that $f$ is continuous at $x_0$. Mathlib writes limits with Tendsto: Tendsto g (𝓝[≠] x₀) (𝓝 L) means that $g(x)\to L$ as $x\to x_0$ with $x\neq x_0$. The slope $\dfrac{f(x)-f(x_0)}{x-x_0}$ is written slope f x₀ x. The proof is the one in the book: $f(x)-f(x_0)$${}=\dfrac{f(x)-f(x_0)}{x-x_0}\,(x-x_0)\to f'\cdot 0$${}=0$.

2. Step by step: differentiable $\Rightarrow$ continuous

The idea: we write the difference $f(x)-f(x_0)$ as the product of the slope and $x-x_0$; the slope tends to $f'$ and the second factor to $0$. We start from the goal:

The goal
f : ℝ → ℝ
x₀ f' : ℝ
hf : HasDerivAt f f' x₀
⊢ ContinuousAt f x₀

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [hasDerivAt_iff_tendsto_slope] at hf

    We write the derivative as a limit: the slope slope f x₀ x tends to $f'$ as $x\to x_0$ with $x\neq x_0$.

    What remains to be proved
    hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
⊢ ContinuousAt f x₀
  2. have h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0) := by

    Intermediate claim h1: $x-x_0\to 0$ as $x\to x_0$ with $x\neq x_0$.

    What remains to be proved
    ⊢ Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0)
  3. have h : Tendsto (fun x => x - x₀) (𝓝 x₀) (𝓝 (x₀ - x₀)) :=
  (continuous_id.sub continuous_const).tendsto x₀
rw [sub_self] at h
exact h.mono_left nhdsWithin_le_nhds

    The map $x\mapsto x-x_0$ is continuous, so it tends to $x_0-x_0=0$; the same holds when we keep only the $x\neq x_0$.

    ✓ This part is complete.
  4. have h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 (f' * 0)) := hf.mul h1

    Limit of a product (h2): the slope times $(x-x_0)$ tends to $f'\cdot 0$.

    What remains to be proved
    f : ℝ → ℝ
x₀ f' : ℝ
hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0)
h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 (f' * 0))
⊢ ContinuousAt f x₀
  5. rw [mul_zero] at h2

    We simplify: $f'\cdot 0=0$.

    What remains to be proved
    h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 0)
⊢ ContinuousAt f x₀
  6. have h3 : Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0) := by

    Intermediate claim h3: $f(x)-f(x_0)\to 0$.

    What remains to be proved
    ⊢ Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0)
  7. apply h2.congr'

    It suffices that the two functions are equal for $x$ near $x_0$ with $x\neq x_0$; then they have the same limit, the $0$ of h2.

    What remains to be proved
    ⊢ (fun x => slope f x₀ x * (x - x₀)) =ᶠ[𝓝[≠] x₀] fun x => f x - f x₀
  8. filter_upwards [self_mem_nhdsWithin] with x hx

    We take $x\neq x_0$ ({x₀}ᶜ is the set of all $x\neq x_0$).

    What remains to be proved
    x : ℝ
hx : x ∈ {x₀}ᶜ
⊢ slope f x₀ x * (x - x₀) = f x - f x₀
  9. rw [slope_def_field, div_mul_cancel₀ _ (sub_ne_zero.mpr (Set.mem_compl_singleton_iff.mp hx))]

    Since $x-x_0\neq 0$: $\dfrac{f(x)-f(x_0)}{x-x_0}\cdot(x-x_0)$${}=f(x)-f(x_0)$.

    ✓ This part is complete.
  10. rw [continuousAt_iff_punctured_nhds]

    Continuity at $x_0$ means $f(x)\to f(x_0)$ as $x\to x_0$ with $x\neq x_0$.

    What remains to be proved
    f : ℝ → ℝ
x₀ f' : ℝ
hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0)
h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 0)
h3 : Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0)
⊢ Tendsto f (𝓝[≠] x₀) (𝓝 (f x₀))
  11. have h4 := h3.add_const (f x₀)

    We add the constant $f(x_0)$ to the limit in h3: $f(x)-f(x_0)+f(x_0)\to 0+f(x_0)$.

    What remains to be proved
    h4 : Tendsto (fun x => f x - f x₀ + f x₀) (𝓝[≠] x₀) (𝓝 (0 + f x₀))
⊢ Tendsto f (𝓝[≠] x₀) (𝓝 (f x₀))
  12. simpa using h4

    We simplify: $f(x)-f(x_0)+f(x_0)=f(x)$ and $0+f(x_0)=f(x_0)$, which is exactly the goal.

    ✓ No goals: the proof is complete.

Solution
theorem sum_continuous (f g : ℝ → ℝ) (x₀ f' g' : ℝ) (hf : HasDerivAt f f' x₀)

4. In Mathlib

We used the following theorems:

  • hasDerivAt_iff_tendsto_slope: the derivative as the limit of the slope $\dfrac{f(x)-f(x_0)}{x-x_0}$.
  • Filter.Tendsto.mul: the limit of a product.
  • Filter.Tendsto.congr': functions that are equal near the point have the same limit.
  • Filter.Tendsto.add_const: the limit of a sum with a constant.
  • continuousAt_iff_punctured_nhds: continuity at $x_0$ means $f(x)\to f(x_0)$ as $x\to x_0$ with $x\neq x_0$.
  • slope_def_field: the formula for the slope, $\dfrac{f(x)-f(x_0)}{x-x_0}$.
  • div_mul_cancel₀: $\dfrac{a}{b}\cdot b=a$ when $b\neq 0$.
  • HasDerivAt.add: the sum rule.
  • not_differentiableAt_abs_zero: $|x|$ is not differentiable at $0$.

import Mathlib

namespace Ch10.ParagogisimotitaSynexeia
open Filter Topology

theorem continuous_of_hasDeriv (f : ℝ → ℝ) (x₀ f' : ℝ) (hf : HasDerivAt f f' x₀) :
    ContinuousAt f x₀ := by
  rw [hasDerivAt_iff_tendsto_slope] at hf
  have h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0) := by
    have h : Tendsto (fun x => x - x₀) (𝓝 x₀) (𝓝 (x₀ - x₀)) :=
      (continuous_id.sub continuous_const).tendsto x₀
    rw [sub_self] at h
    exact h.mono_left nhdsWithin_le_nhds
  have h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 (f' * 0)) := hf.mul h1
  rw [mul_zero] at h2
  have h3 : Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0) := by
    apply h2.congr'
    filter_upwards [self_mem_nhdsWithin] with x hx
    rw [slope_def_field, div_mul_cancel₀ _ (sub_ne_zero.mpr (Set.mem_compl_singleton_iff.mp hx))]
  rw [continuousAt_iff_punctured_nhds]
  have h4 := h3.add_const (f x₀)
  simpa using h4

theorem sum_continuous (f g : ℝ → ℝ) (x₀ f' g' : ℝ) (hf : HasDerivAt f f' x₀)
    (hg : HasDerivAt g g' x₀) : ContinuousAt (fun x => f x + g x) x₀ :=
  continuous_of_hasDeriv _ x₀ (f' + g') (hf.add hg)

theorem abs_counterexample :
    ContinuousAt (fun x : ℝ => |x|) 0 ∧ ¬ DifferentiableAt ℝ (fun x : ℝ => |x|) 0 :=
  ⟨continuous_abs.continuousAt, not_differentiableAt_abs_zero⟩

end Ch10.ParagogisimotitaSynexeia
