1. What is proved: the statement in the book and in Lean

  • If $f$ is continuous on $[a,b]$, differentiable on $(a,b)$ and $f(a)=f(b)$, there exists $c\in(a,b)$ with $f'(c)=0$

    (hfab : f a = f b) (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) :
    ∃ c ∈ Set.Ioo a b, f' c = 0
  • Auxiliary: if $f(a)=f(b)$, every $x\in[a,b]$ that does not belong to $(a,b)$ gives $f(x)=f(a)$
    theorem endpoint_value (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hfab : f a = f b) (x : ℝ)
    (hx : x ∈ Set.Icc a b) (hxi : x ∉ Set.Ioo a b) : f x = f a
  • Application: if $f(a)=f(b)=0$, then $f'$ has a root in $(a,b)$
    theorem between_roots (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b) (hfc : ContinuousOn f (Set.Icc a b))
    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) (ha : f a = 0) (hb : f b = 0) :
    ∃ c ∈ Set.Ioo a b, f' c = 0

Continuity on $[a,b]$ is written ContinuousOn f (Set.Icc a b). For differentiability on $(a,b)$ we give a function f' for the derivative: ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x. IsMaxOn f (Set.Icc a b) M means that $f$ attains at $M$ its maximum value on $[a,b]$; similarly IsMinOn for the minimum. The proof follows the usual pattern: by Weierstrass' theorem we find a maximum and a minimum. If one of the two is an interior point, we apply Fermat's theorem; otherwise $f$ is constant and its derivative is $0$.

2. Step by step: Rolle's theorem

The idea: if the maximum or the minimum lies inside $(a,b)$, the derivative vanishes there; otherwise $f$ is constant. We start from the goal:

4. In Mathlib

We used the following theorems:

  • IsCompact.exists_isMaxOn: a continuous function on a compact, nonempty set attains a maximum value.
  • IsCompact.exists_isMinOn: the same for the minimum value.
  • isCompact_Icc: $[a,b]$ is compact.
  • IsMaxOn.isLocalMax: a maximum on a set that contains an interval around the point is a local maximum.
  • IsMinOn.isLocalMin: the same for the minimum.
  • IsLocalMax.hasDerivAt_eq_zero: Fermat's theorem for a local maximum.
  • IsLocalMin.hasDerivAt_eq_zero: Fermat's theorem for a local minimum.
  • Set.Icc_sdiff_Ioo_same: $[a,b]\setminus(a,b)=\{a,b\}$ when $a\le b$.
  • hasDerivAt_const: a constant function has derivative $0$.
  • HasDerivAt.congr_of_eventuallyEq: functions that are equal near the point have the same derivative.
  • HasDerivAt.unique: the derivative is unique.

theorem endpoint_value (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hfab : f a = f b) (x : ℝ)
    (hx : x ∈ Set.Icc a b) (hxi : x ∉ Set.Ioo a b) : f x = f a := by
  have h : x ∈ ({a, b} : Set ℝ) := by
    rw [← Set.Icc_sdiff_Ioo_same hab]
    exact ⟨hx, hxi⟩
  rcases h with h | h
  · rw [h]
  · rw [Set.mem_singleton_iff] at h
    rw [h, hfab]

theorem rolle (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b) (hfc : ContinuousOn f (Set.Icc a b))
    (hfab : f a = f b) (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) :
    ∃ c ∈ Set.Ioo a b, f' c = 0 := by
  obtain ⟨M, hM, hMax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab.le) hfc
  obtain ⟨m, hm, hMin⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab.le) hfc
  by_cases hMi : M ∈ Set.Ioo a b
  · have hloc : IsLocalMax f M := hMax.isLocalMax (Icc_mem_nhds hMi.1 hMi.2)
    exact ⟨M, hMi, hloc.hasDerivAt_eq_zero (hff' M hMi)⟩
  by_cases hmi : m ∈ Set.Ioo a b
  · have hloc : IsLocalMin f m := hMin.isLocalMin (Icc_mem_nhds hmi.1 hmi.2)
    exact ⟨m, hmi, hloc.hasDerivAt_eq_zero (hff' m hmi)⟩
  have hfM : f M = f a := endpoint_value f a b hab.le hfab M hM hMi
  have hfm : f m = f a := endpoint_value f a b hab.le hfab m hm hmi
  have hconst : ∀ x ∈ Set.Ioo a b, f x = f a := by
    intro x hx
    have h1 : f x ≤ f M := isMaxOn_iff.mp hMax x (Set.Ioo_subset_Icc_self hx)
    have h2 : f m ≤ f x := isMinOn_iff.mp hMin x (Set.Ioo_subset_Icc_self hx)
    linarith
  have hc : (a + b) / 2 ∈ Set.Ioo a b := ⟨by linarith, by linarith⟩
  have hd : HasDerivAt f 0 ((a + b) / 2) := by
    apply (hasDerivAt_const ((a + b) / 2) (f a)).congr_of_eventuallyEq
    filter_upwards [Ioo_mem_nhds hc.1 hc.2] with x hx
    exact hconst x hx
  exact ⟨(a + b) / 2, hc, (hff' _ hc).unique hd⟩

theorem between_roots (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b) (hfc : ContinuousOn f (Set.Icc a b))
    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) (ha : f a = 0) (hb : f b = 0) :
    ∃ c ∈ Set.Ioo a b, f' c = 0 :=
  rolle f f' a b hab hfc (by rw [ha, hb]) hff'
