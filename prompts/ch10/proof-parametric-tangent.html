Slope of the Tangent Line to a Parametric Curve

Chapter 10 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor a smooth parametric curve $x=x(t)$, $y=y(t)$ with $x'(t)\ne 0$: $\dfrac{dy}{dx}=\dfrac{y'(t)}{x'(t)}$. The tangent line is horizontal if $y'(t)=0$ (and $x'(t)\ne 0$), and vertical if $x'(t)=0$ (and $y'(t)\ne 0$). Second derivative: $\dfrac{d^2 y}{dx^2}=\dfrac{\frac{d}{dt}\!\left(\frac{dy}{dx}\right)}{x'(t)}$.

  • If $x'(t_0)\neq 0$, the slope of the tangent line is $\dfrac{dy}{dx}$${}=\dfrac{y'(t_0)}{x'(t_0)}$

  • With $x'(t_0)\neq 0$, the tangent line is horizontal exactly when $y'(t_0)=0$

  • If $x'(t_0)=0$ and $y'(t_0)\neq 0$, the tangent line is vertical: $\dfrac{dx}{dy}=0$
    theorem vertical_tangent (x y G : ℝ → ℝ) (t₀ x' y' G' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hG : HasDerivAt G G' (y t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, x t = G (y t)) (hy0 : y' ≠ 0) (hx0 : x' = 0) : G' = 0
  • Second derivative: $\dfrac{d^2y}{dx^2}$${}=\dfrac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{x'(t_0)}$
    theorem second_derivative (x F' : ℝ → ℝ) (t₀ x' F'' d : ℝ) (hx : HasDerivAt x x' t₀)
    (hF' : HasDerivAt F' F'' (x t₀)) (hd : HasDerivAt (fun t => F' (x t)) d t₀)
    (hx0 : x' ≠ 0) : F'' = d / x'

The derivatives are written HasDerivAt x x' t₀ and HasDerivAt y y' t₀. Near $t_0$ the curve is the graph $y=F(x)$ of a function $F$ with derivative $F'$ at $x(t_0)$: this is what the hypothesis hcurve says, $y(t)=F(x(t))$ for $t$ near $t_0$ (for a smooth curve with $x'(t_0)\neq 0$ it always holds, by the inverse function theorem). The slope of the tangent line is $F'$, that is, $\dfrac{dy}{dx}$. For the vertical tangent line the curve is written the other way around, as $x=G(y)$, and a vertical tangent line means $\dfrac{dx}{dy}=G'=0$. In the second derivative, F' is $\dfrac{dy}{dx}$ as a function of $x$, d is the derivative of $t\mapsto F'(x(t))$ at $t_0$, and F'' is $\dfrac{d^2y}{dx^2}$: the formula follows from the slope formula, applied to $\dfrac{dy}{dx}$. F ∘ x is the composition $t\mapsto F(x(t))$.

2. Step by step: the slope $\dfrac{dy}{dx}$

The idea: by the chain rule, $y=F(x(t))$ has derivative $F'\cdot x'(t_0)$; so $y'(t_0)=F'\,x'(t_0)$, and we divide by $x'(t_0)\neq 0$. We start from the goal:

The goal
x y F : ℝ → ℝ
t₀ x' y' F' : ℝ
hx : HasDerivAt x x' t₀
hy : HasDerivAt y y' t₀
hF : HasDerivAt F F' (x t₀)
hcurve : ∀ᶠ (t : ℝ) in 𝓝 t₀, y t = F (x t)
hx0 : x' ≠ 0
⊢ F' = y' / x'

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have h1 : HasDerivAt (F ∘ x) (F' * x') t₀ := hF.comp t₀ hx

    Chain rule: $t\mapsto F(x(t))$ has derivative $F'\cdot x'$ at $t_0$.

    What remains to be proved
    h1 : HasDerivAt (F ∘ x) (F' * x') t₀
⊢ F' = y' / x'
  2. have h2 : HasDerivAt y (F' * x') t₀ := h1.congr_of_eventuallyEq hcurve

    Near $t_0$ we have $y(t)=F(x(t))$, so $y$ also has derivative $F'\cdot x'$ at $t_0$.

    What remains to be proved
    h2 : HasDerivAt y (F' * x') t₀
⊢ F' = y' / x'
  3. have h3 : y' = F' * x' := hy.unique h2

    The derivative is unique, so $y'=F'\cdot x'$.

    What remains to be proved
    h3 : y' = F' * x'
⊢ F' = y' / x'
  4. rw [h3, mul_div_cancel_right₀ _ hx0]

    Therefore $\dfrac{y'}{x'}$${}=\dfrac{F'\,x'}{x'}$${}=F'$, since $x'\neq 0$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • HasDerivAt.comp: the chain rule.
  • HasDerivAt.congr_of_eventuallyEq: functions that are equal near the point have the same derivative.
  • HasDerivAt.unique: the derivative is unique.
  • mul_div_cancel_right₀: $\dfrac{ab}{b}=a$ when $b\neq 0$.
  • div_eq_zero_iff: $\dfrac{a}{b}=0$ exactly when $a=0$ or $b=0$.
  • zero_div: $\dfrac{0}{b}=0$.
  • Filter.Eventually.of_forall: whatever holds for every $t$ also holds near $t_0$.

import Mathlib

namespace Ch10.Parametriki
open Filter Topology

theorem slope_parametric (x y F : ℝ → ℝ) (t₀ x' y' F' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hF : HasDerivAt F F' (x t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, y t = F (x t)) (hx0 : x' ≠ 0) : F' = y' / x' := by
  have h1 : HasDerivAt (F ∘ x) (F' * x') t₀ := hF.comp t₀ hx
  have h2 : HasDerivAt y (F' * x') t₀ := h1.congr_of_eventuallyEq hcurve
  have h3 : y' = F' * x' := hy.unique h2
  rw [h3, mul_div_cancel_right₀ _ hx0]

theorem horizontal_iff (x' y' : ℝ) (hx0 : x' ≠ 0) : y' / x' = 0 ↔ y' = 0 := by
  rw [div_eq_zero_iff, or_iff_left hx0]

-- vertical tangent line: the curve is written x = G(y) and dx/dy = 0
theorem vertical_tangent (x y G : ℝ → ℝ) (t₀ x' y' G' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hG : HasDerivAt G G' (y t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, x t = G (y t)) (hy0 : y' ≠ 0) (hx0 : x' = 0) : G' = 0 := by
  rw [slope_parametric y x G t₀ y' x' G' hy hx hG hcurve hy0, hx0, zero_div]

-- second derivative: F' is dy/dx as a function of x, and F'' is d²y/dx²
theorem second_derivative (x F' : ℝ → ℝ) (t₀ x' F'' d : ℝ) (hx : HasDerivAt x x' t₀)
    (hF' : HasDerivAt F' F'' (x t₀)) (hd : HasDerivAt (fun t => F' (x t)) d t₀)
    (hx0 : x' ≠ 0) : F'' = d / x' :=
  slope_parametric x (fun t => F' (x t)) F' t₀ x' d F'' hx hd hF'
    (Eventually.of_forall fun _ => rfl) hx0

end Ch10.Parametriki
