Slope of the Tangent Line to a Parametric Curve

Proof with the help of a Large Language Model (AI)

StatementFor a smooth parametric curve $x=x(t)$, $y=y(t)$ with $x'(t)\ne 0$: $\dfrac{dy}{dx}=\dfrac{y'(t)}{x'(t)}$. The tangent line is horizontal if $y'(t)=0$ (and $x'(t)\ne 0$), and vertical if $x'(t)=0$ (and $y'(t)\ne 0$). Second derivative: $\dfrac{d^2 y}{dx^2}=\dfrac{\frac{d}{dt}\!\left(\frac{dy}{dx}\right)}{x'(t)}$.
