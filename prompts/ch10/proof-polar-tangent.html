Slope of the Tangent Line to a Polar Curve

Chapter 10 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor a polar curve $r=f(\theta)$ (with $r'=dr/d\theta$): $\dfrac{dy}{dx}=\dfrac{r'\sin\theta+r\cos\theta}{r'\cos\theta-r\sin\theta}$. The tangent line is horizontal if $r'\sin\theta+r\cos\theta=0$ and $r'\cos\theta-r\sin\theta\ne 0$, and vertical if $r'\cos\theta-r\sin\theta=0$ and $r'\sin\theta+r\cos\theta\ne 0$. When both vanish (the form $0/0$, for instance at the cusp of the cardioid) the test is inconclusive and a limit or a higher-order expansion is needed.

In Cartesian coordinates the curve $r=r(\theta)$ is written as $x(\theta)=r(\theta)\cos\theta$, $y(\theta)=r(\theta)\sin\theta$, that is, it is a parametric curve with parameter $\theta$. As with parametric curves, we assume that near $\theta_0$ the curve is the graph $y=F(x)$ (hypothesis hcurve) and show that the slope $F'$ is $\dfrac{y'(\theta_0)}{x'(\theta_0)}$. For the vertical tangent line the curve is written as $x=G(y)$, and we show that $\dfrac{dx}{dy}=G'=0$. Here $r'$ is the derivative $\dfrac{dr}{d\theta}$ at $\theta_0$. When both expressions vanish, neither criterion applies, as the book also says.

2. Step by step: the slope $\dfrac{dy}{dx}$

The idea: the polar curve is parametric, with $x(\theta)=r\cos\theta$ and $y(\theta)=r\sin\theta$, so $\dfrac{dy}{dx}$${}=\dfrac{y'(\theta_0)}{x'(\theta_0)}$. We start from the goal:

The goal
r F : ℝ → ℝ
θ₀ r' F' : ℝ
hr : HasDerivAt r r' θ₀
hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀)
hcurve : ∀ᶠ (t : ℝ) in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t)
hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hx := x_deriv r θ₀ r' hr

    The function $x(\theta)=r(\theta)\cos\theta$ has derivative $r'\cos\theta_0-r(\theta_0)\sin\theta_0$ (auxiliary lemma x_deriv).

    What remains to be proved
    hx : HasDerivAt (fun t => r t * Real.cos t) (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  2. have hy := y_deriv r θ₀ r' hr

    The function $y(\theta)=r(\theta)\sin\theta$ has derivative $r'\sin\theta_0+r(\theta_0)\cos\theta_0$ (auxiliary lemma y_deriv).

    What remains to be proved
    hy : HasDerivAt (fun t => r t * Real.sin t) (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  3. have h1 := hF.comp θ₀ hx

    Chain rule: $\theta\mapsto F(x(\theta))$ has derivative $F'\cdot x'(\theta_0)$.

    What remains to be proved
    h1 : HasDerivAt (F ∘ fun t => r t * Real.cos t) (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  4. have h2 : HasDerivAt (fun t => r t * Real.sin t)
    (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀ := h1.congr_of_eventuallyEq hcurve

    Near $\theta_0$ we have $y(\theta)=F(x(\theta))$, so $y$ also has derivative $F'\cdot x'(\theta_0)$.

    What remains to be proved
    h2 : HasDerivAt (fun t => r t * Real.sin t) (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  5. have h3 := hy.unique h2

    The derivative is unique: $y'(\theta_0)=F'\cdot x'(\theta_0)$.

    What remains to be proved
    h3 : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ = F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  6. rw [h3, mul_div_cancel_right₀ _ hden]

    Therefore $F'$${}=\dfrac{y'(\theta_0)}{x'(\theta_0)}$, since the denominator is not $0$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • HasDerivAt.mul: the product rule.
  • Real.hasDerivAt_sin: $(\sin\theta)'=\cos\theta$.
  • Real.hasDerivAt_cos: $(\cos\theta)'=-\sin\theta$.
  • HasDerivAt.comp: the chain rule.
  • HasDerivAt.congr_of_eventuallyEq: functions that are equal near the point have the same derivative.
  • HasDerivAt.unique: the derivative is unique.
  • mul_div_cancel_right₀: $\dfrac{ab}{b}=a$ when $b\neq 0$.
  • HasDerivAt.comp_of_eq: the chain rule, with the point given as an equality.
  • mul_eq_zero: $ab=0$ exactly when $a=0$ or $b=0$.

open Filter Topology

theorem x_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.cos t) (r' * Real.cos θ - r θ * Real.sin θ) θ := by
  have h := hr.mul (Real.hasDerivAt_cos θ)
  rw [show r' * Real.cos θ - r θ * Real.sin θ = r' * Real.cos θ + r θ * -Real.sin θ by ring]
  exact h

theorem y_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.sin t) (r' * Real.sin θ + r θ * Real.cos θ) θ :=
  hr.mul (Real.hasDerivAt_sin θ)

theorem polar_slope (r F : ℝ → ℝ) (θ₀ r' F' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t))
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0) :
    F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀) := by
  have hx := x_deriv r θ₀ r' hr
  have hy := y_deriv r θ₀ r' hr
  have h1 := hF.comp θ₀ hx
  have h2 : HasDerivAt (fun t => r t * Real.sin t)
      (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀ := h1.congr_of_eventuallyEq hcurve
  have h3 := hy.unique h2
  rw [h3, mul_div_cancel_right₀ _ hden]

-- horizontal tangent line
theorem polar_horizontal (r F : ℝ → ℝ) (θ₀ r' F' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t))
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0)
    (hnum : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ = 0) : F' = 0 := by
  rw [polar_slope r F θ₀ r' F' hr hF hcurve hden, hnum, zero_div]

-- vertical tangent line: the curve is written x = G(y) and dx/dy = 0
theorem polar_vertical (r G : ℝ → ℝ) (θ₀ r' G' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hG : HasDerivAt G G' (r θ₀ * Real.sin θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.cos t = G (r t * Real.sin t))
    (hnum : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ ≠ 0)
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ = 0) : G' = 0 := by
  have hx := x_deriv r θ₀ r' hr
  have hy := y_deriv r θ₀ r' hr
  have h1 := hG.comp_of_eq θ₀ hy rfl
  have h2 : HasDerivAt (fun t => r t * Real.cos t)
      (G' * (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀)) θ₀ := h1.congr_of_eventuallyEq hcurve
  have h3 := hx.unique h2
  rw [hden] at h3
  exact (mul_eq_zero.mp h3.symm).resolve_right hnum
