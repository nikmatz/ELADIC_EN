1. What is proved: the statement in the book and in Lean

  • If $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$, there exists $c\in(a,b)$ with $f'(c)=\dfrac{f(b)-f(a)}{b-a}$
    theorem mean_value (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b) (hfc : ContinuousOn f (Set.Icc a b))
    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) :
    ∃ c ∈ Set.Ioo a b, f' c = (f b - f a) / (b - a)
  • Corollary: if in addition $f(a)=f(b)$, there exists $c\in(a,b)$ with $f'(c)=0$
    theorem rolle_from_mvt (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hfc : ContinuousOn f (Set.Icc a b)) (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hfab : f a = f b) : ∃ c ∈ Set.Ioo a b, f' c = 0

Continuity on $[a,b]$ is written ContinuousOn f (Set.Icc a b). For differentiability on $(a,b)$ we give a function f' for the derivative: ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x. The proof applies Rolle's theorem to an auxiliary function, $g(x)=f(x)-k(x-a)$, where $k$ is the slope of the chord. In Mathlib, Rolle's theorem is exists_hasDerivAt_eq_zero. In the code, $g$ is written directly as fun x => f x - k * (x - a).

2. Step by step: the mean value theorem

The idea: $g(x)=f(x)-k(x-a)$ takes the same value at the endpoints, so by Rolle's theorem $g'=f'-k$ vanishes somewhere in $(a,b)$. We start from the goal:

The goal
f f' : ℝ → ℝ
a b : ℝ
hab : a < b
hfc : ContinuousOn f (Set.Icc a b)
hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x
⊢ ∃ c ∈ Set.Ioo a b, f' c = (f b - f a) / (b - a)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. set k := (f b - f a) / (b - a) with hk

    We call $k=\dfrac{f(b)-f(a)}{b-a}$ the slope of the chord. We look for $c\in(a,b)$ with $f'(c)=k$.

    What remains to be proved

hk : k = (f b - f a) / (b - a)
⊢ ∃ c ∈ Set.Ioo a b, f' c = k
  2. have hcont : ContinuousOn (fun x => f x - k * (x - a)) (Set.Icc a b) := by
  exact hfc.sub (continuousOn_const.mul (continuousOn_id.sub continuousOn_const))

    The function $g(x)=f(x)-k(x-a)$ is continuous on $[a,b]$, as a difference of continuous functions (hcont).

    ✓ This part is complete.

4. In Mathlib

We used the following theorems:

  • exists_hasDerivAt_eq_zero: Rolle's theorem.
  • ContinuousOn.sub: the difference of continuous functions is continuous.
  • ContinuousOn.mul: the product of continuous functions is continuous.
  • HasDerivAt.sub: the difference rule.
  • HasDerivAt.const_mul: the rule for $c\,f(x)$.
  • HasDerivAt.sub_const: $f(x)-a$ has the same derivative as $f$.
  • hasDerivAt_id: the derivative of $x\mapsto x$ is $1$.
  • div_mul_cancel₀: $\dfrac{a}{b}\cdot b=a$ when $b\neq 0$.

theorem mean_value (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b) (hfc : ContinuousOn f (Set.Icc a b))
    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) :
    ∃ c ∈ Set.Ioo a b, f' c = (f b - f a) / (b - a) := by
  set k := (f b - f a) / (b - a) with hk
  have hcont : ContinuousOn (fun x => f x - k * (x - a)) (Set.Icc a b) := by
    exact hfc.sub (continuousOn_const.mul (continuousOn_id.sub continuousOn_const))
  have hderiv : ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => f x - k * (x - a)) (f' x - k) x := by
    intro x hx
    have h := ((hasDerivAt_id x).sub_const a).const_mul k
    rw [mul_one] at h
    exact (hff' x hx).sub h
  have hends : f a - k * (a - a) = f b - k * (b - a) := by
    rw [sub_self, mul_zero, sub_zero, hk, div_mul_cancel₀ _ (sub_ne_zero.mpr hab.ne')]
    ring
  obtain ⟨c, hc, hc0⟩ := exists_hasDerivAt_eq_zero hab hcont hends hderiv
  exact ⟨c, hc, by linarith⟩

theorem rolle_from_mvt (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hfc : ContinuousOn f (Set.Icc a b)) (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hfab : f a = f b) : ∃ c ∈ Set.Ioo a b, f' c = 0 := by
  obtain ⟨c, hc, h⟩ := mean_value f f' a b hab hfc hff'
  rw [hfab, sub_self, zero_div] at h
  exact ⟨c, hc, h⟩
