1. What is proved: the statement in the book and in Lean

  • If $f$ has a local maximum at $x_0$ and is differentiable there, then $f'(x_0)=0$
    theorem fermat_max (f : ℝ → ℝ) (x₀ f' : ℝ) (hmax : IsLocalMax f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0
  • The same for a local minimum
    theorem fermat_min (f : ℝ → ℝ) (x₀ f' : ℝ) (hmin : IsLocalMin f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0
  • The same for every local extremum, with the Mathlib theorem
    theorem fermat_mathlib (f : ℝ → ℝ) (x₀ f' : ℝ) (hext : IsLocalExtr f x₀)
    (hf : HasDerivAt f f' x₀) : f' = 0

“$f$ has a local maximum at $x_0$” is written IsLocalMax f x₀, a local minimum IsLocalMin f x₀, and a local extremum IsLocalExtr f x₀. All three mean that the inequality holds on an open interval around $x_0$, so $x_0$ is an interior point, as the book requires. HasDerivAt f f' x₀ means that $f$ has derivative $f'$ at $x_0$. ∀ᶠ x in 𝓝[>] x₀, P x means that the property $P(x)$ holds for every $x\gt x_0$ close enough to $x_0$. The proof is the one in the book: the slope $\dfrac{f(x)-f(x_0)}{x-x_0}$ is $\le 0$ to the right of $x_0$ and $\ge 0$ to the left, so its limit $f'$ is both $\le 0$ and $\ge 0$.

2. Step by step: local maximum

The idea: to the right of $x_0$ the slope is $\le 0$ and to the left it is $\ge 0$, so its limit $f'$ is $0$. We start from the goal:

The goal
f : ℝ → ℝ
x₀ f' : ℝ
hmax : IsLocalMax f x₀
hf : HasDerivAt f f' x₀
⊢ f' = 0

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [hasDerivAt_iff_tendsto_slope] at hf

    We write the derivative as a limit: the slope slope f x₀ x tends to $f'$ as $x\to x_0$ with $x\neq x_0$.

    What remains to be proved
    hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
⊢ f' = 0
  2. have hR : f' ≤ 0 := by

    First half, hR: $f'\le 0$.

    What remains to be proved
    ⊢ f' ≤ 0
  3. have h1 : Tendsto (slope f x₀) (𝓝[>] x₀) (𝓝 f') := hf.mono_left (nhdsGT_le_nhdsNE x₀)
have hm : ∀ᶠ x in 𝓝[>] x₀, f x ≤ f x₀ := nhdsWithin_le_nhds hmax

    The slope also tends to $f'$ as $x\to x_0^+$ (h1; 𝓝[>] x₀ means $x\to x_0$ with $x\gt x_0$). Since $f$ has a local maximum at $x_0$, we have $f(x)\le f(x_0)$ for $x$ near $x_0$ (hm).

    What remains to be proved
    h1 : Tendsto (slope f x₀) (𝓝[>] x₀) (𝓝 f')
hm : ∀ᶠ (x : ℝ) in 𝓝[>] x₀, f x ≤ f x₀
⊢ f' ≤ 0
  4. apply le_of_tendsto h1

    If a quantity tends to $f'$ and is $\le 0$ for $x\gt x_0$ near $x_0$, then $f'\le 0$. It remains to show that the slope is $\le 0$ there.

    What remains to be proved
    ⊢ ∀ᶠ (c : ℝ) in 𝓝[>] x₀, slope f x₀ c ≤ 0
  5. filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx

    We take $x\gt x_0$ near $x_0$, with $f(x)\le f(x_0)$.

    What remains to be proved
    x : ℝ
hfx : f x ≤ f x₀
hx : x ∈ Set.Ioi x₀
⊢ slope f x₀ x ≤ 0
  6. rw [slope_def_field]

    We write the slope as a fraction.

    What remains to be proved
    ⊢ (f x - f x₀) / (x - x₀) ≤ 0
  7. exact div_nonpos_of_nonpos_of_nonneg (sub_nonpos.mpr hfx) (sub_nonneg.mpr (le_of_lt hx))

    The numerator $f(x)-f(x_0)$ is $\le 0$ and the denominator $x-x_0$ is positive, so the fraction is $\le 0$.

    ✓ This part is complete.
  8. have hL : 0 ≤ f' := by

    Second half, hL: $0\le f'$.

    What remains to be proved
    f : ℝ → ℝ
x₀ f' : ℝ
hmax : IsLocalMax f x₀
hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
hR : f' ≤ 0
⊢ 0 ≤ f'
  9. have h2 : Tendsto (slope f x₀) (𝓝[<] x₀) (𝓝 f') := hf.mono_left (nhdsLT_le_nhdsNE x₀)
have hm : ∀ᶠ x in 𝓝[<] x₀, f x ≤ f x₀ := nhdsWithin_le_nhds hmax

    Now $x\to x_0^-$ (h2; 𝓝[<] x₀ means $x\to x_0$ with $x\lt x_0$), again with $f(x)\le f(x_0)$.

    What remains to be proved
    h2 : Tendsto (slope f x₀) (𝓝[<] x₀) (𝓝 f')
hm : ∀ᶠ (x : ℝ) in 𝓝[<] x₀, f x ≤ f x₀
⊢ 0 ≤ f'
  10. apply ge_of_tendsto h2

    If a quantity tends to $f'$ and is $\ge 0$ for $x\lt x_0$ near $x_0$, then $f'\ge 0$.

    What remains to be proved
    ⊢ ∀ᶠ (c : ℝ) in 𝓝[<] x₀, 0 ≤ slope f x₀ c
  11. filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx

    We take $x\lt x_0$ near $x_0$, with $f(x)\le f(x_0)$.

    What remains to be proved
    x : ℝ
hfx : f x ≤ f x₀
hx : x ∈ Set.Iio x₀
⊢ 0 ≤ slope f x₀ x
  12. rw [slope_def_field]

    We write the slope as a fraction.

    What remains to be proved
    ⊢ 0 ≤ (f x - f x₀) / (x - x₀)
  13. exact div_nonneg_of_nonpos (sub_nonpos.mpr hfx) (sub_nonpos.mpr (le_of_lt hx))

    The numerator is $\le 0$ and the denominator $x-x_0$ is negative, so the fraction is $\ge 0$.

    ✓ This part is complete.
  14. linarith

    From $f'\le 0$ and $0\le f'$ we get $f'=0$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • hasDerivAt_iff_tendsto_slope: the derivative as the limit of the slope $\dfrac{f(x)-f(x_0)}{x-x_0}$.
  • nhdsGT_le_nhdsNE: if $x\to x_0$ with $x\gt x_0$, then also $x\to x_0$ with $x\neq x_0$.
  • nhdsLT_le_nhdsNE: the same for $x\lt x_0$.
  • le_of_tendsto: if $g(x)\to L$ and $g(x)\le c$ near the point, then $L\le c$.
  • ge_of_tendsto: the same with $\ge$ in place of $\le$.
  • div_nonpos_of_nonpos_of_nonneg: from $a\le 0$ and $b\ge 0$ we get $\dfrac{a}{b}\le 0$.
  • div_nonneg_of_nonpos: from $a\le 0$ and $b\le 0$ we get $\dfrac{a}{b}\ge 0$.
  • IsLocalMin.neg: a local minimum of $f$ is a local maximum of $-f$.
  • IsLocalExtr.hasDerivAt_eq_zero: Fermat's theorem in Mathlib.

import Mathlib

namespace Ch10.Fermat
open Filter Topology

theorem fermat_max (f : ℝ → ℝ) (x₀ f' : ℝ) (hmax : IsLocalMax f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0 := by
  rw [hasDerivAt_iff_tendsto_slope] at hf
  have hR : f' ≤ 0 := by
    have h1 : Tendsto (slope f x₀) (𝓝[>] x₀) (𝓝 f') := hf.mono_left (nhdsGT_le_nhdsNE x₀)
    have hm : ∀ᶠ x in 𝓝[>] x₀, f x ≤ f x₀ := nhdsWithin_le_nhds hmax
    apply le_of_tendsto h1
    filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx
    rw [slope_def_field]
    exact div_nonpos_of_nonpos_of_nonneg (sub_nonpos.mpr hfx) (sub_nonneg.mpr (le_of_lt hx))
  have hL : 0 ≤ f' := by
    have h2 : Tendsto (slope f x₀) (𝓝[<] x₀) (𝓝 f') := hf.mono_left (nhdsLT_le_nhdsNE x₀)
    have hm : ∀ᶠ x in 𝓝[<] x₀, f x ≤ f x₀ := nhdsWithin_le_nhds hmax
    apply ge_of_tendsto h2
    filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx
    rw [slope_def_field]
    exact div_nonneg_of_nonpos (sub_nonpos.mpr hfx) (sub_nonpos.mpr (le_of_lt hx))
  linarith

theorem fermat_min (f : ℝ → ℝ) (x₀ f' : ℝ) (hmin : IsLocalMin f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0 := by
  have h := fermat_max (fun x => -f x) x₀ (-f') hmin.neg hf.neg
  linarith

theorem fermat_mathlib (f : ℝ → ℝ) (x₀ f' : ℝ) (hext : IsLocalExtr f x₀)
    (hf : HasDerivAt f f' x₀) : f' = 0 :=
  hext.hasDerivAt_eq_zero hf

end Ch10.Fermat
