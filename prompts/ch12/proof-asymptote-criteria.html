Criteria for Asymptotes

Chapter 12 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor a rational function $f(x)=\dfrac{P(x)}{Q(x)}$ (with $P,Q$ having no common factor): (i) a vertical asymptote $x=x_0$ at every root $x_0$ of $Q$; (ii) a horizontal asymptote if $\deg P\le\deg Q$ — namely $y=0$ when $\deg P<\deg Q$, or $y$ equal to the ratio of the leading coefficients when $\deg P=\deg Q$; (iii) an oblique asymptote $y=\alpha x+\beta$ if and only if $\deg P=\deg Q+1$, where $\alpha x+\beta$ is the quotient of the division $P/Q$. More generally (not only for rational functions), $y=\alpha x+\beta$ is an oblique asymptote of $f$ at $\pm\infty$ if and only if the finite limits $\alpha=\lim_{x\to\pm\infty}\dfrac{f(x)}{x}\ne 0$ and $\beta=\lim_{x\to\pm\infty}\bigl(f(x)-\alpha x\bigr)$ exist. If $\alpha=0$ and $\beta$ exists, the asymptote is horizontal.

1. What is proved: the statement in the book and in Lean

  • (i) If $q(x_0)=0$, $p(x_0)\neq 0$ and $q(x)\neq 0$ near $x_0$, then $\left|\dfrac{p(x)}{q(x)}\right|\to+\infty$ as $x\to x_0$: vertical asymptote $x=x_0$
    theorem vertical_asymptote (p q : ℝ → ℝ) (x₀ : ℝ) (hp : ContinuousAt p x₀)
    (hq : ContinuousAt q x₀) (hq0 : q x₀ = 0) (hp0 : p x₀ ≠ 0)
    (hqne : ∀ᶠ x in 𝓝[≠] x₀, q x ≠ 0) :
    Tendsto (fun x => |p x / q x|) (𝓝[≠] x₀) atTop
  • (ii) If $\deg P\lt\deg Q$, then $\dfrac{P(x)}{Q(x)}\to 0$: horizontal asymptote $y=0$
    theorem horizontal_zero (P Q : ℝ[X]) (hdeg : P.degree < Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 0)
  • (ii) If $\deg P=\deg Q$, then $\dfrac{P(x)}{Q(x)}$ tends to the ratio of the leading coefficients
    theorem horizontal_ratio (P Q : ℝ[X]) (hdeg : P.degree = Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 (P.leadingCoeff / Q.leadingCoeff))
  • (iii) If $S$ is the quotient of the division $P:Q$, then $\dfrac{P(x)}{Q(x)}-S(x)\to 0$; when $\deg P=\deg Q+1$, $S(x)=\alpha x+\beta$ is the oblique asymptote
    theorem minus_quotient (P Q : ℝ[X]) (hQ : Q ≠ 0) :
    Tendsto (fun x => P.eval x / Q.eval x - (P / Q).eval x) atTop (𝓝 0)
  • General criterion: $y=\alpha x+\beta$ is an asymptote at $+\infty$ exactly when $\dfrac{f(x)}{x}\to\alpha$ and $f(x)-\alpha x\to\beta$
    theorem oblique_iff (f : ℝ → ℝ) (α β : ℝ) :
    Tendsto (fun x => f x - (α * x + β)) atTop (𝓝 0) ↔
      Tendsto (fun x => f x / x) atTop (𝓝 α) ∧ Tendsto (fun x => f x - α * x) atTop (𝓝 β)

A limit is written with Tendsto: Tendsto F atTop (𝓝 L) means $F(x)\to L$ as $x\to+\infty$. 𝓝[≠] x₀ means $x\to x_0$ with $x\neq x_0$, and atTop in the place of the limit means $+\infty$. Polynomials are elements of ℝ[X]: P.eval x is the value $P(x)$, P.degree the degree and P.leadingCoeff the leading coefficient. P / Q is the quotient and P % Q the remainder of the division. For a rational function with no common factor, at every root $x_0$ of $Q$ we have $P(x_0)\neq 0$, and $Q$ has no other roots near $x_0$; so (i) applies. The phrase “asymptote $y=\alpha x+\beta$” means $f(x)-(\alpha x+\beta)\to 0$, and for $\alpha=0$ the asymptote is horizontal. Parts (ii) and (iii) are stated for $x\to+\infty$; the case $x\to-\infty$ is symmetric and is not written out separately here, nor is the “only if” direction of (iii).

2. Where it is in Mathlib

We used the following theorems:

  • Polynomial.div_tendsto_atTop_zero_of_degree_lt: $\dfrac{P(x)}{Q(x)}\to 0$ when $\deg P\lt\deg Q$.
  • Polynomial.div_tendsto_atTop_leadingCoeff_div_of_degree_eq: the limit when $\deg P=\deg Q$.
  • Polynomial.degree_mod_lt: the remainder has smaller degree than the divisor.
  • EuclideanDomain.div_add_mod: the division identity $P=Q\,S+R$.
  • Polynomial.finite_setOfPred_isRoot: a nonzero polynomial has finitely many roots.
  • Filter.Tendsto.pos_mul_atTop: if $F\to C\gt 0$ and $G\to+\infty$, then $F\,G\to+\infty$.
  • tendsto_inv_nhdsGT_zero: $\dfrac{1}{t}\to+\infty$ as $t\to 0^+$.
  • Filter.Tendsto.div_atTop: if $F\to L$ and $G\to+\infty$, then $\dfrac{F}{G}\to 0$.

import Mathlib

namespace Ch12.Asymptotes
open Filter Topology Polynomial

-- (i) vertical asymptote: at the root x₀ of the denominator, with numerator ≠ 0, |p/q| → +∞
theorem vertical_asymptote (p q : ℝ → ℝ) (x₀ : ℝ) (hp : ContinuousAt p x₀)
    (hq : ContinuousAt q x₀) (hq0 : q x₀ = 0) (hp0 : p x₀ ≠ 0)
    (hqne : ∀ᶠ x in 𝓝[≠] x₀, q x ≠ 0) :
    Tendsto (fun x => |p x / q x|) (𝓝[≠] x₀) atTop := by
  have h1 : Tendsto (fun x => |p x|) (𝓝[≠] x₀) (𝓝 |p x₀|) :=
    (hp.tendsto.abs).mono_left nhdsWithin_le_nhds
  have h2 : Tendsto (fun x => |q x|) (𝓝[≠] x₀) (𝓝[>] 0) := by
    apply tendsto_nhdsWithin_iff.mpr
    constructor
    · have h := (hq.tendsto.abs).mono_left (nhdsWithin_le_nhds (s := {x₀}ᶜ))
      rwa [hq0, abs_zero] at h
    · filter_upwards [hqne] with x hx
      exact abs_pos.mpr hx
  have h3 := h1.pos_mul_atTop (abs_pos.mpr hp0) (tendsto_inv_nhdsGT_zero.comp h2)
  refine h3.congr (fun x => ?_)
  simp [div_eq_mul_inv]

-- (ii) horizontal asymptote y = 0 when deg P < deg Q
theorem horizontal_zero (P Q : ℝ[X]) (hdeg : P.degree < Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 0) :=
  Polynomial.div_tendsto_atTop_zero_of_degree_lt hdeg

-- (ii) when deg P = deg Q, the asymptote is the ratio of the leading coefficients
theorem horizontal_ratio (P Q : ℝ[X]) (hdeg : P.degree = Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 (P.leadingCoeff / Q.leadingCoeff)) :=
  Polynomial.div_tendsto_atTop_leadingCoeff_div_of_degree_eq hdeg

-- (iii) the quotient S of the division P / Q: the difference P/Q - S tends to 0
theorem minus_quotient (P Q : ℝ[X]) (hQ : Q ≠ 0) :
    Tendsto (fun x => P.eval x / Q.eval x - (P / Q).eval x) atTop (𝓝 0) := by
  have hR : Tendsto (fun x => (P % Q).eval x / Q.eval x) atTop (𝓝 0) :=
    Polynomial.div_tendsto_atTop_zero_of_degree_lt (Polynomial.degree_mod_lt P hQ)
  refine hR.congr' ?_
  have hfin : {x | Q.IsRoot x}.Finite := Polynomial.finite_setOfPred_isRoot hQ
  filter_upwards [Filter.atTop_le_cofinite hfin.compl_mem_cofinite] with x hx
  have hx' : Q.eval x ≠ 0 := hx
  have he : P.eval x = Q.eval x * (P / Q).eval x + (P % Q).eval x := by
    rw [← Polynomial.eval_mul, ← Polynomial.eval_add, EuclideanDomain.div_add_mod]
  rw [he, add_div, mul_div_cancel_left₀ _ hx']
  ring

-- general criterion: y = αx + β is an asymptote at +∞ exactly when f(x)/x → α and f(x) - αx → β
theorem oblique_iff (f : ℝ → ℝ) (α β : ℝ) :
    Tendsto (fun x => f x - (α * x + β)) atTop (𝓝 0) ↔
      Tendsto (fun x => f x / x) atTop (𝓝 α) ∧ Tendsto (fun x => f x - α * x) atTop (𝓝 β) := by
  constructor
  · intro h
    have h2 : Tendsto (fun x => f x - α * x) atTop (𝓝 β) := by
      have h' := h.add_const β
      rw [zero_add] at h'
      refine h'.congr (fun x => ?_)
      ring
    refine ⟨?_, h2⟩
    have h3 : Tendsto (fun x => (f x - α * x) / x) atTop (𝓝 0) := h2.div_atTop tendsto_id
    have h4 := h3.add_const α
    rw [zero_add] at h4
    refine h4.congr' ?_
    filter_upwards [eventually_ne_atTop 0] with x hx
    rw [sub_div, mul_div_assoc, div_self hx, mul_one, sub_add_cancel]
  · rintro ⟨_, h2⟩
    have h' := h2.sub_const β
    rw [sub_self] at h'
    refine h'.congr (fun x => ?_)
    ring

end Ch12.Asymptotes
