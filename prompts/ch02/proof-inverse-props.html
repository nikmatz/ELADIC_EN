Properties of the Inverse Matrix

Chapter 2 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $A,B\in\mathcal{M}_{n\times n}$ be invertible and $\lambda\ne 0$: $(A^{-1})^{-1}=A$; $(AB)^{-1}=B^{-1}A^{-1}$; $(A^{T})^{-1}=(A^{-1})^{T}$; $\det(A^{-1})=\dfrac{1}{\det(A)}$; $(\lambda A)^{-1}=\dfrac{1}{\lambda}A^{-1}$; if $A$ is diagonal with $a_{ii}\ne 0$, then $A^{-1}$ is diagonal with entries $\dfrac{1}{a_{ii}}$.

$A$ is invertible when $\det A\neq 0$, and this is the hypothesis hA : A.det ≠ 0. hA.isUnit writes $\det A\neq 0$ in the form required by the theorems of Mathlib. The inverse is written A⁻¹ and the transpose Aᵀ. The formulas $(A^{T})^{-1}=(A^{-1})^{T}$ and $\det(A^{-1})=\frac{1}{\det(A)}$ hold in Lean without any hypothesis: when $\det A=0$, Mathlib defines $A^{-1}=0$, and the two sides coincide.

2. Step by step: $(AB)^{-1}=B^{-1}A^{-1}$

As in the book, all the properties follow from the uniqueness of the inverse: to show that a matrix is the inverse of $M$, it suffices to show that the product of $M$ with it gives $I$. We start from the goal:

The goal
n : ℕ
A B : Matrix (Fin n) (Fin n) ℝ
hA : A.det ≠ 0
hB : B.det ≠ 0
⊢ (A * B)⁻¹ = B⁻¹ * A⁻¹

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. apply inv_eq_right_inv

    It suffices to show that $(AB)(B^{-1}A^{-1})=I$: then $B^{-1}A^{-1}$ is the inverse of $AB$ (theorem Matrix.inv_eq_right_inv).

    What remains to be proved
    ⊢ A * B * (B⁻¹ * A⁻¹) = 1
  2. rw [Matrix.mul_assoc]

    Associativity: $(AB)(B^{-1}A^{-1})$${}=A\,\big(B\,(B^{-1}A^{-1})\big)$.

    What remains to be proved
    ⊢ A * (B * (B⁻¹ * A⁻¹)) = 1
  3. rw [← Matrix.mul_assoc B]

    Associativity again, inside the parentheses: $B\,(B^{-1}A^{-1})$${}=(BB^{-1})\,A^{-1}$.

    What remains to be proved
    ⊢ A * (B * B⁻¹ * A⁻¹) = 1
  4. rw [mul_nonsing_inv B hB.isUnit]

    Since $\det B\neq 0$, we have $BB^{-1}=I$.

    What remains to be proved
    ⊢ A * (1 * A⁻¹) = 1
  5. rw [Matrix.one_mul]

    We have $IA^{-1}=A^{-1}$.

    What remains to be proved
    ⊢ A * A⁻¹ = 1
  6. exact mul_nonsing_inv A hA.isUnit

    Since $\det A\neq 0$, we have $AA^{-1}=I$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • Matrix.inv_eq_right_inv: if $AB=I$, then $A^{-1}=B$.
  • Matrix.mul_nonsing_inv: $AA^{-1}=I$ when $\det A\neq 0$.
  • Matrix.nonsing_inv_mul: $A^{-1}A=I$ when $\det A\neq 0$.
  • Matrix.transpose_nonsing_inv: $(A^{-1})^{T}=(A^{T})^{-1}$.
  • Matrix.det_nonsing_inv: the determinant of $A^{-1}$.

import Mathlib

namespace Ch2.IdiotitesAntistrofou
open Matrix

variable {n : ℕ}

theorem inv_of_inv (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) : A⁻¹⁻¹ = A := by
  apply inv_eq_right_inv
  exact nonsing_inv_mul A hA.isUnit

theorem inv_of_mul (A B : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (hB : B.det ≠ 0) :
    (A * B)⁻¹ = B⁻¹ * A⁻¹ := by
  apply inv_eq_right_inv
  rw [Matrix.mul_assoc]
  rw [← Matrix.mul_assoc B]
  rw [mul_nonsing_inv B hB.isUnit]
  rw [Matrix.one_mul]
  exact mul_nonsing_inv A hA.isUnit

theorem inv_of_transpose (A : Matrix (Fin n) (Fin n) ℝ) : Aᵀ⁻¹ = A⁻¹ᵀ :=
  (transpose_nonsing_inv A).symm

theorem det_of_inv (A : Matrix (Fin n) (Fin n) ℝ) : A⁻¹.det = 1 / A.det := by
  rw [det_nonsing_inv, Ring.inverse_eq_inv, one_div]

theorem inv_of_smul (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (c : ℝ) (hc : c ≠ 0) :
    (c • A)⁻¹ = (1 / c) • A⁻¹ := by
  apply inv_eq_right_inv
  rw [Matrix.smul_mul, Matrix.mul_smul, smul_smul, one_div, mul_inv_cancel₀ hc, one_smul,
    mul_nonsing_inv A hA.isUnit]

theorem inv_of_diagonal (d : Fin n → ℝ) (h : ∀ i, d i ≠ 0) :
    (diagonal d)⁻¹ = diagonal (fun i => 1 / d i) := by
  apply inv_eq_right_inv
  rw [diagonal_mul_diagonal, ← diagonal_one]
  congr 1
  funext i
  rw [mul_one_div_cancel (h i)]

end Ch2.IdiotitesAntistrofou
