Rank–Nullity Theorem for Matrices

Chapter 2 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor $A\in\mathcal{M}_{m\times n}(\mathbb{R})$ with $\operatorname{rank}(A)=r$: $\dim\mathcal{R}(A)=\dim\mathcal{C}(A)=r$, $\dim\mathcal{N}(A)=n-r$, $\dim\mathcal{N}(A^{T})=m-r$, and therefore $\operatorname{rank}(A)+\dim\mathcal{N}(A)=n$ and $\operatorname{rank}(A)+\dim\mathcal{N}(A^{T})=m$. Moreover $\mathcal{C}(A)\perp\mathcal{N}(A^{T})$ in $\mathbb{R}^m$ and $\mathcal{R}(A)\perp\mathcal{N}(A)$ in $\mathbb{R}^n$.

1. What is proved: the statement in the book and in Lean

  • $\dim\mathcal{R}(A)$${}=\dim\mathcal{C}(A)$${}=r$: $A^{T}$ has the same rank as $A$

  • $\operatorname{rank}(A)+\dim\mathcal{N}(A)$${}=n$, hence $\dim\mathcal{N}(A)=n-r$
    theorem rank_nullity (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n
  • $\operatorname{rank}(A)+\dim\mathcal{N}(A^{T})$${}=m$, hence $\dim\mathcal{N}(A^{T})=m-r$
    theorem rank_nullity_transpose (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker Aᵀ.mulVecLin) = m
  • $\mathcal{C}(A)\perp\mathcal{N}(A^{T})$ in $\mathbb{R}^m$

    (hw : Aᵀ *ᵥ w = 0) : (A *ᵥ v) ⬝ᵥ w = 0
  • $\mathcal{R}(A)\perp\mathcal{N}(A)$ in $\mathbb{R}^n$
    theorem row_perp_null (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hv : A *ᵥ v = 0) : (Aᵀ *ᵥ w) ⬝ᵥ v = 0

The rank is written A.rank, and in Mathlib it is the dimension of the column space. The row space of $A$ is the column space of $A^{T}$, so the equality $\dim\mathcal{R}(A)$${}=\dim\mathcal{C}(A)$ is Aᵀ.rank = A.rank. The null space $\mathcal{N}(A)$ is the kernel of the map $x\mapsto Ax$, namely LinearMap.ker A.mulVecLin, and its dimension is written with finrank ℝ. For orthogonality: every vector of $\mathcal{C}(A)$ has the form $Av$, every vector of $\mathcal{R}(A)$ the form $A^{T}w$, and the inner product is written ⬝ᵥ.

2. Where it is in Mathlib

We used the following theorems:

  • Matrix.rank_transpose: $\operatorname{rank}(A^{T})$${}=\operatorname{rank}(A)$.
  • Matrix.finrank_range_mulVecLin: the rank is the dimension of the image of $x\mapsto Ax$.
  • LinearMap.finrank_range_add_finrank_ker: the rank–nullity theorem.
  • Matrix.dotProduct_mulVec: $v\cdot(Aw)=(v^{T}A)\cdot w$.
  • Matrix.mulVec_transpose: $A^{T}x=x^{T}A$.

import Mathlib

namespace Ch2.TaksiMidenoxoros
open Matrix Module

variable {m n : ℕ}

theorem row_rank_eq_col_rank (A : Matrix (Fin m) (Fin n) ℝ) : Aᵀ.rank = A.rank :=
  rank_transpose A

theorem rank_nullity (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
  rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]

theorem rank_nullity_transpose (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker Aᵀ.mulVecLin) = m := by
  rw [← rank_transpose A, ← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker,
    finrank_fin_fun]

theorem col_perp_null_transpose (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hw : Aᵀ *ᵥ w = 0) : (A *ᵥ v) ⬝ᵥ w = 0 := by
  rw [dotProduct_comm, dotProduct_mulVec, ← mulVec_transpose, hw, zero_dotProduct]

theorem row_perp_null (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hv : A *ᵥ v = 0) : (Aᵀ *ᵥ w) ⬝ᵥ v = 0 := by
  rw [mulVec_transpose, ← dotProduct_mulVec, hv, dotProduct_zero]

end Ch2.TaksiMidenoxoros
