The Characteristic Polynomial

Statement$\lambda\in\mathbb{C}$ is an eigenvalue of $A$ if and only if $\det(A-\lambda I)=0$. The polynomial $p(\lambda)=\det(A-\lambda I)$ is the characteristic polynomial, of degree $n$ in $\lambda$. For $A\in\mathcal{M}_{n\times n}(\mathbb{R})$ the complex eigenvalues occur in conjugate pairs.

1. What is proved: the statement in the book and in Lean

  • $\lambda$ is an eigenvalue of $A$ $\Leftrightarrow\det(A-\lambda I)=0$
    theorem eigen_iff_det (A : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) :
    (∃ v : Fin n → ℂ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔
      (A - μ • (1 : Matrix (Fin n) (Fin n) ℂ)).det = 0
  • Equivalently: $\lambda$ is a root of the characteristic polynomial
    theorem eigen_iff_root (A : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) :
    (∃ v : Fin n → ℂ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ A.charpoly.IsRoot μ
  • The characteristic polynomial of Mathlib differs from $\det(A-\lambda I)$ only by the factor $(-1)^n$
    theorem charpoly_eval (A : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) :
    A.charpoly.eval μ = (-1) ^ n * (A - μ • (1 : Matrix (Fin n) (Fin n) ℂ)).det
  • The characteristic polynomial has degree $n$
    theorem degree (A : Matrix (Fin n) (Fin n) ℂ) : A.charpoly.natDegree = n
  • For real $A$: if $\lambda$ is an eigenvalue, then so is $\overline{\lambda}$
    theorem conj_root (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℂ)
    (h : (A.map (algebraMap ℝ ℂ)).charpoly.IsRoot μ) :
    (A.map (algebraMap ℝ ℂ)).charpoly.IsRoot (starRingEnd ℂ μ)

The matrix is A : Matrix (Fin n) (Fin n) ℂ, so that complex eigenvalues are allowed. “$\lambda$ is an eigenvalue” is written as: there is $v\neq 0$ with $Av=\lambda v$, that is, A *ᵥ v = μ • v, where *ᵥ is the matrix-vector product. In the code the eigenvalue is called μ, because λ is a reserved word in Lean. Mathlib defines the characteristic polynomial A.charpoly as $\det(tI-A)$, which has the same roots as the book’s $\det(A-tI)$. For the real matrix, A.map (algebraMap ℝ ℂ) is the same matrix with its entries viewed as complex numbers, and starRingEnd ℂ μ is the conjugate $\overline{\mu}$.

2. Where it is in Mathlib

We used the following theorems:

  • Matrix.charpoly: the definition of the characteristic polynomial, $\det(tI-A)$.
  • Matrix.exists_mulVec_eq_zero_iff: $Mv=0$ has a solution $v\neq 0$ exactly when $\det M=0$.
  • Matrix.eval_charpoly: the value of the characteristic polynomial at a point, as a determinant.
  • Matrix.charpoly_natDegree_eq_dim: its degree is $n$.
  • Matrix.charpoly_map: a real matrix has a characteristic polynomial with real coefficients.

import Mathlib

namespace Ch2.XaraktiristikoPolyonymo
open Matrix Polynomial

variable {n : ℕ}

theorem eigen_iff_det (A : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) :
    (∃ v : Fin n → ℂ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔
      (A - μ • (1 : Matrix (Fin n) (Fin n) ℂ)).det = 0 := by
  rw [← exists_mulVec_eq_zero_iff]
  refine exists_congr fun v => and_congr_right fun _ => ?_
  rw [sub_mulVec, smul_mulVec, one_mulVec, sub_eq_zero]

theorem charpoly_eval (A : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) :
    A.charpoly.eval μ = (-1) ^ n * (A - μ • (1 : Matrix (Fin n) (Fin n) ℂ)).det := by
  have h : Matrix.scalar (Fin n) μ - A = -(A - μ • (1 : Matrix (Fin n) (Fin n) ℂ)) := by
    rw [neg_sub, scalar_apply, smul_one_eq_diagonal]
  rw [eval_charpoly, h, det_neg, Fintype.card_fin]

theorem eigen_iff_root (A : Matrix (Fin n) (Fin n) ℂ) (μ : ℂ) :
    (∃ v : Fin n → ℂ, v ≠ 0 ∧ A *ᵥ v = μ • v) ↔ A.charpoly.IsRoot μ := by
  rw [eigen_iff_det, IsRoot.def, charpoly_eval]
  constructor
  · intro h
    rw [h, mul_zero]
  · intro h
    exact (mul_eq_zero.mp h).resolve_left (pow_ne_zero _ (by norm_num))

theorem degree (A : Matrix (Fin n) (Fin n) ℂ) : A.charpoly.natDegree = n := by
  rw [charpoly_natDegree_eq_dim, Fintype.card_fin]

theorem conj_root (A : Matrix (Fin n) (Fin n) ℝ) (μ : ℂ)
    (h : (A.map (algebraMap ℝ ℂ)).charpoly.IsRoot μ) :
    (A.map (algebraMap ℝ ℂ)).charpoly.IsRoot (starRingEnd ℂ μ) := by
  rw [charpoly_map, IsRoot.def, eval_map_algebraMap] at h ⊢
  rw [← Complex.conjAe_coe, aeval_algHom_apply, h, map_zero]

end Ch2.XaraktiristikoPolyonymo
