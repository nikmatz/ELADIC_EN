The dimensions are general: A is $m\times n$, B is $n\times p$ and C is $p\times q$, so that the products are defined. The entry $(MN)_{ij}$ is written (M * N) i j, and $\sum_k$ is written ∑ k. The identity matrix is 1 and the transpose is Aᵀ. The distributive properties and the properties of $I$ we take ready-made from Mathlib.

2. Step by step: $(AB)C=A(BC)$

The associative property requires handling double sums. The idea: in position $(i,l)$ both sides give $\sum_j\sum_k a_{ij}b_{jk}c_{kl}$. We start from the goal:

The goal
m n p q : ℕ
A : Matrix (Fin m) (Fin n) ℝ
B : Matrix (Fin n) (Fin p) ℝ
C : Matrix (Fin p) (Fin q) ℝ
⊢ A * B * C = A * (B * C)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. ext i l

    We compare the entries in position $(i,l)$.

    What remains to be proved
    i : Fin m
l : Fin q
⊢ (A * B * C) i l = (A * (B * C)) i l
  2. simp only [Matrix.mul_apply]

    The definition of the product: $(MN)_{ij}=\sum_k m_{ik}n_{kj}$. On the left we get $\sum_k\big(\sum_j a_{ij}b_{jk}\big)c_{kl}$ and on the right $\sum_j a_{ij}\sum_k b_{jk}c_{kl}$. Lean gives its own names to the summation indices.

    What remains to be proved
    ⊢ ∑ j, (∑ j_1, A i j_1 * B j_1 j) * C j l = ∑ j, A i j * ∑ j_1, B j j_1 * C j_1 l
  3. simp only [Finset.sum_mul, Finset.mul_sum]

    We move the factors inside the sums (distributive property). Left: $\sum_k\sum_j a_{ij}b_{jk}c_{kl}$. Right: $\sum_j\sum_k a_{ij}(b_{jk}c_{kl})$.

    What remains to be proved
    ⊢ ∑ x, ∑ i_1, A i i_1 * B i_1 x * C x l = ∑ x, ∑ i_1, A i x * (B x i_1 * C i_1 l)
  4. rw [Finset.sum_comm]

    We interchange the order of the two sums on the left-hand side (theorem Finset.sum_comm). Now both sides sum first over $j$ and then over $k$.

    What remains to be proved
    ⊢ ∑ y, ∑ x, A i y * B y x * C x l = ∑ x, ∑ i_1, A i x * (B x i_1 * C i_1 l)
  5. refine Finset.sum_congr rfl (fun j _ => Finset.sum_congr rfl (fun k _ => ?_))

    It suffices that the terms are equal one by one, for every $j$ and $k$ (theorem Finset.sum_congr).

    What remains to be proved
    j : Fin n
x✝¹ : j ∈ Finset.univ
k : Fin p
x✝ : k ∈ Finset.univ
⊢ A i j * B j k * C k l = A i j * (B j k * C k l)
  6. ring

    What remains is the associative property of the real numbers.

    ✓ No goals: the proof is complete.

import Mathlib

namespace Ch2.GinomenoPinakon
open Matrix

variable {m n p q : ℕ}

theorem mul_associates (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ)
    (C : Matrix (Fin p) (Fin q) ℝ) : (A * B) * C = A * (B * C) := by
  ext i l
  simp only [Matrix.mul_apply]
  simp only [Finset.sum_mul, Finset.mul_sum]
  rw [Finset.sum_comm]
  refine Finset.sum_congr rfl (fun j _ => Finset.sum_congr rfl (fun k _ => ?_))
  ring

theorem mul_distrib_left (A : Matrix (Fin m) (Fin n) ℝ) (B C : Matrix (Fin n) (Fin p) ℝ) :
    A * (B + C) = A * B + A * C :=
  Matrix.mul_add A B C

theorem mul_distrib_right (A B : Matrix (Fin m) (Fin n) ℝ) (C : Matrix (Fin n) (Fin p) ℝ) :
    (A + B) * C = A * C + B * C :=
  Matrix.add_mul A B C

theorem smul_mul_left (c : ℝ) (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :
    c • (A * B) = (c • A) * B :=
  (Matrix.smul_mul c A B).symm

theorem smul_mul_right (c : ℝ) (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :
    c • (A * B) = A * (c • B) :=
  (Matrix.mul_smul A c B).symm

theorem mul_identity (A : Matrix (Fin m) (Fin n) ℝ) :
    A * (1 : Matrix (Fin n) (Fin n) ℝ) = A ∧ (1 : Matrix (Fin m) (Fin m) ℝ) * A = A :=
  ⟨Matrix.mul_one A, Matrix.one_mul A⟩

theorem transpose_of_mul (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :
    (A * B)ᵀ = Bᵀ * Aᵀ := by
  ext i j
  rw [Matrix.transpose_apply, Matrix.mul_apply, Matrix.mul_apply]
  refine Finset.sum_congr rfl (fun k _ => ?_)
  rw [Matrix.transpose_apply, Matrix.transpose_apply, mul_comm]

end Ch2.GinomenoPinakon
