1. What is proved: the statement in the book and in Lean

  • (i)$\Leftrightarrow$(ii): $A$ is invertible $\Leftrightarrow\det(A)\ne 0$
    theorem unit_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : IsUnit A ↔ A.det ≠ 0
  • (iii)$\Leftrightarrow$(ii): $\operatorname{rank}(A)$${}=n\Leftrightarrow\det(A)\ne 0$
    theorem rank_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : A.rank = n ↔ A.det ≠ 0
  • (iv)$\Leftrightarrow$(ii): the columns are linearly independent $\Leftrightarrow\det(A)\ne 0$
    theorem cols_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : LinearIndependent ℝ A.col ↔ A.det ≠ 0
  • The same for the rows
    theorem rows_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : LinearIndependent ℝ A.row ↔ A.det ≠ 0

We show that each condition is equivalent to (ii), $\det(A)\ne 0$, so all of them are equivalent to one another. The rank is written A.rank, the columns A.col and the rows A.row. For the rank we use the rank–nullity theorem: if $\operatorname{rank}(A)=n$, the null space is $\{0\}$, so $Ax=0$ has no nonzero solution and $\det(A)\neq 0$.

2. Where it is in Mathlib

We used the following theorems:

  • Matrix.isUnit_iff_isUnit_det: a matrix is invertible exactly when its determinant is invertible.
  • Matrix.rank_of_isUnit: an invertible $n\times n$ matrix has rank $n$.
  • Matrix.exists_mulVec_eq_zero_iff: $Ax=0$ has a nonzero solution exactly when $\det A=0$.
  • LinearMap.finrank_range_add_finrank_ker: the rank–nullity theorem.
  • Matrix.linearIndependent_col_iff: the columns are independent exactly when the matrix is nonsingular.
  • Matrix.linearIndependent_row_iff: the rows are independent exactly when the matrix is nonsingular.
  • Matrix.nonsingular_iff_det_ne_zero: nonsingular matrix $\Leftrightarrow$ determinant $\neq 0$.

import Mathlib

namespace Ch2.KritiriaAntistrepsimotitas
open Matrix Module

variable {n : ℕ}

theorem unit_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : IsUnit A ↔ A.det ≠ 0 := by
  rw [isUnit_iff_isUnit_det, isUnit_iff_ne_zero]

theorem rank_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : A.rank = n ↔ A.det ≠ 0 := by
  constructor
  · intro h hdet
    obtain ⟨x, hx, hAx⟩ := exists_mulVec_eq_zero_iff.mpr hdet
    have hrn : A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
      rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]
    have hk : LinearMap.ker A.mulVecLin = ⊥ := by
      rw [← Submodule.finrank_eq_zero]
      omega
    have hmem : x ∈ LinearMap.ker A.mulVecLin := LinearMap.mem_ker.mpr hAx
    rw [hk, Submodule.mem_bot] at hmem
    exact hx hmem
  · intro h
    have := A.rank_of_isUnit ((unit_iff_det A).mpr h)
    simpa using this

theorem cols_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : LinearIndependent ℝ A.col ↔ A.det ≠ 0 :=
  linearIndependent_col_iff.trans nonsingular_iff_det_ne_zero

theorem rows_iff_det (A : Matrix (Fin n) (Fin n) ℝ) : LinearIndependent ℝ A.row ↔ A.det ≠ 0 :=
  linearIndependent_row_iff.trans nonsingular_iff_det_ne_zero

end Ch2.KritiriaAntistrepsimotitas
