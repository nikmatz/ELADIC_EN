Integration by Partial Fraction Decomposition

Chapter 16 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementEvery proper rational function $\dfrac{P(x)}{Q(x)}$ (with $\deg P<\deg Q$) decomposes uniquely into a sum of simple fractions: to every linear factor $(x-a)^k$ of $Q$ correspond the terms $\dfrac{A_1}{x-a}+\cdots+\dfrac{A_k}{(x-a)^k}$; to every irreducible quadratic factor $(x^2+px+q)^m$ (with $p^2-4q<0$) correspond the terms $\dfrac{B_1x+\Gamma_1}{x^2+px+q}+\cdots+\dfrac{B_mx+\Gamma_m}{(x^2+px+q)^m}$. Integration then yields logarithms and powers (linear terms) or logarithms and arctangents (irreducible quadratic terms).

1. What is proved: the statement in the book and in Lean

  • Existence: for monic polynomials $g_i$ that are pairwise coprime, and exponents $n_i$, every polynomial $P$ can be written as $P$${}=q\prod_i g_i^{n_i}+\sum_i\sum_{j\lt n_i} r_{ij}\,g_i^{\,j}\prod_{k\neq i}g_k^{n_k}$, with $\deg r_{ij}\lt\deg g_i$
    theorem decomposition (P : ℝ[X]) {ι : Type*} [DecidableEq ι] (s : Finset ι) (g : ι → ℝ[X])
    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))
    (n : ι → ℕ) :
    ∃ (q : ℝ[X]) (r : (i : ι) → Fin (n i) → ℝ[X]),
      (∀ i ∈ s, ∀ j, (r i j).degree < (g i).degree) ∧
      P = q * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k
  • Uniqueness: two such representations have the same $q$ and the same $r_{ij}$
    theorem uniqueness {ι : Type*} [DecidableEq ι] (s : Finset ι) (g : ι → ℝ[X])
    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))
    (n : ι → ℕ) (q₁ q₂ : ℝ[X]) (r₁ r₂ : (i : ι) → Fin (n i) → ℝ[X])
    (hr₁ : ∀ i ∈ s, ∀ j, (r₁ i j).degree < (g i).degree)
    (hr₂ : ∀ i ∈ s, ∀ j, (r₂ i j).degree < (g i).degree)
    (h : q₁ * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r₁ i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k =
      q₂ * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r₂ i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k) :
    q₁ = q₂ ∧ ∀ i ∈ s, r₁ i = r₂ i
  • Example: $\dfrac{1}{x^2-1}$${}=\dfrac{1/2}{x-1}-\dfrac{1/2}{x+1}$
    theorem example_decomposition (x : ℝ) (h1 : x ≠ 1) (h2 : x ≠ -1) :
    1 / (x ^ 2 - 1) = 1 / 2 / (x - 1) - 1 / 2 / (x + 1)
  • and $\int\dfrac{dx}{x^2-1}$${}=\dfrac{1}{2}\ln|x-1|-\dfrac{1}{2}\ln|x+1|+C$
    theorem example_integral (x : ℝ) (h1 : x ≠ 1) (h2 : x ≠ -1) :
    HasDerivAt (fun x => 1 / 2 * Real.log |x - 1| - 1 / 2 * Real.log |x + 1|)
      (1 / (x ^ 2 - 1)) x

Mathlib states the partial fraction decomposition for polynomials (ℝ[X]), without divisions. If we divide both sides by $Q=\prod_i g_i^{n_i}$, we obtain $\dfrac{P}{Q}$${}=q+\sum_i\sum_{j}\dfrac{r_{ij}}{g_i^{\,n_i-j}}$, which is the form in the book, with denominators $g_i,g_i^2,\dots,g_i^{n_i}$. For a linear factor $g_i=x-a$ the numerators $r_{ij}$ have degree $0$, that is, they are constants; for an irreducible quadratic factor they have degree at most $1$, that is, they are of the form $Bx+\Gamma$. When $\deg P\lt\deg Q$, the polynomial $q$ is $0$. Uniqueness is the word “uniquely” in the book. The example shows the decomposition and the integration for a specific function. In Mathlib the logarithm Real.log is also defined for negative numbers, as $\ln|t|$, so the absolute value disappears at once (Real.log_abs).

2. Where it is in Mathlib

We used the following theorems:

  • Polynomial.eq_quo_mul_prod_pow_add_sum_rem_mul_prod_pow: the existence of the partial fraction decomposition.
  • Polynomial.quo_mul_prod_pow_add_sum_rem_mul_prod_pow_unique: the uniqueness of the decomposition.
  • Real.log_abs: $\ln|t|=\ln t$ in Mathlib.
  • HasDerivAt.log: the derivative of $\ln f(x)$.
  • HasDerivAt.const_mul: the rule for $c\,f(x)$.
  • HasDerivAt.sub: the difference rule.

open Polynomial

-- existence: P = q · ∏ gᵢ^nᵢ + Σᵢ Σⱼ rᵢⱼ · gᵢ^j · ∏ (k ≠ i) gₖ^nₖ, with deg rᵢⱼ < deg gᵢ
theorem decomposition (P : ℝ[X]) {ι : Type*} [DecidableEq ι] (s : Finset ι) (g : ι → ℝ[X])
    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))
    (n : ι → ℕ) :
    ∃ (q : ℝ[X]) (r : (i : ι) → Fin (n i) → ℝ[X]),
      (∀ i ∈ s, ∀ j, (r i j).degree < (g i).degree) ∧
      P = q * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k :=
  eq_quo_mul_prod_pow_add_sum_rem_mul_prod_pow P hg hcop n

-- uniqueness: two such decompositions have the same q and the same rᵢⱼ
theorem uniqueness {ι : Type*} [DecidableEq ι] (s : Finset ι) (g : ι → ℝ[X])
    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))
    (n : ι → ℕ) (q₁ q₂ : ℝ[X]) (r₁ r₂ : (i : ι) → Fin (n i) → ℝ[X])
    (hr₁ : ∀ i ∈ s, ∀ j, (r₁ i j).degree < (g i).degree)
    (hr₂ : ∀ i ∈ s, ∀ j, (r₂ i j).degree < (g i).degree)
    (h : q₁ * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r₁ i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k =
      q₂ * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r₂ i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k) :
    q₁ = q₂ ∧ ∀ i ∈ s, r₁ i = r₂ i :=
  quo_mul_prod_pow_add_sum_rem_mul_prod_pow_unique hg hcop hr₁ hr₂ h

-- example: 1/(x² - 1) = (1/2)/(x - 1) - (1/2)/(x + 1)
theorem example_decomposition (x : ℝ) (h1 : x ≠ 1) (h2 : x ≠ -1) :
    1 / (x ^ 2 - 1) = 1 / 2 / (x - 1) - 1 / 2 / (x + 1) := by
  have h1' : x - 1 ≠ 0 := sub_ne_zero.mpr h1
  have h2' : x + 1 ≠ 0 := fun h => h2 (by linarith)
  have h3 : x ^ 2 - 1 ≠ 0 := by
    rw [show x ^ 2 - 1 = (x - 1) * (x + 1) by ring]
    exact mul_ne_zero h1' h2'
  field_simp
  ring

-- and the integral: ∫ dx/(x² - 1) = (1/2) ln|x - 1| - (1/2) ln|x + 1| + C
theorem example_integral (x : ℝ) (h1 : x ≠ 1) (h2 : x ≠ -1) :
    HasDerivAt (fun x => 1 / 2 * Real.log |x - 1| - 1 / 2 * Real.log |x + 1|)
      (1 / (x ^ 2 - 1)) x := by
  simp only [Real.log_abs]
  have ha : HasDerivAt (fun x => Real.log (x - 1)) (1 / (x - 1)) x :=
    ((hasDerivAt_id' x).sub_const 1).log (sub_ne_zero.mpr h1)
  have hb : HasDerivAt (fun x => Real.log (x + 1)) (1 / (x + 1)) x :=
    ((hasDerivAt_id' x).add_const 1).log (fun h => h2 (by linarith))
  have h : HasDerivAt (fun x => 1 / 2 * Real.log (x - 1) - 1 / 2 * Real.log (x + 1))
      (1 / 2 * (1 / (x - 1)) - 1 / 2 * (1 / (x + 1))) x :=
    (ha.const_mul (1 / 2)).sub (hb.const_mul (1 / 2))
  convert h using 1
  rw [example_decomposition x h1 h2]
  ring

end Ch16.MerikaKlasmata
