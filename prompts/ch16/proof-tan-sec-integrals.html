1. What is proved: the statement in the book and in Lean

  • $\int\sec^2x\,dx=\tan x+C$
    theorem int_sec_sq (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt Real.tan (1 / Real.cos x ^ 2) x
  • $\int\sec x\tan x\,dx=\sec x+C$
    theorem int_sec_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => 1 / Real.cos x) (1 / Real.cos x * Real.tan x) x
  • $\int\sec x\,dx$${}=\ln|\sec x+\tan x|+C$
    theorem int_sec (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x + Real.tan x|) (1 / Real.cos x) x
  • $\int\tan x\,dx=\ln|\sec x|+C$
    theorem int_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x|) (Real.tan x) x

Each formula is written as “the right-hand side has the integrand as its derivative”, at every $x$ with $\cos x\neq 0$. The function $\sec x$ is written $\dfrac{1}{\cos x}$. The guidelines for $\int\tan^m x\sec^n x\,dx$ say which substitution to make; they are not theorems, which is why they are not stated here. In Mathlib the logarithm Real.log is also defined for negative numbers, as $\ln|t|$, so the absolute value disappears at once (Real.log_abs).

2. Step by step: $\int\sec x\,dx$

The idea: we differentiate $\ln(\sec x+\tan x)$ and find $\dfrac{\sec x\tan x+\sec^2x}{\sec x+\tan x}$${}=\sec x$. We start from the goal:

The goal
x : ℝ
hc : Real.cos x ≠ 0
⊢ HasDerivAt (fun x => Real.log |1 / Real.cos x + Real.tan x|) (1 / Real.cos x) x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- in Mathlib, ln|t| = ln t
simp only [Real.log_abs]

    In Mathlib $\ln|t|=\ln t$ (Real.log_abs), so the absolute value disappears.

    What remains to be proved
    ⊢ HasDerivAt (fun x => Real.log (1 / Real.cos x + Real.tan x)) (1 / Real.cos x) x
  2. -- when cos x ≠ 0, sin x ≠ -1
have hs : 1 + Real.sin x ≠ 0 := by

    Claim hs: $1+\sin x\neq 0$.

    What remains to be proved
    ⊢ 1 + Real.sin x ≠ 0
  3. intro h
have h1 : Real.sin x = -1 := by linarith
have h2 := Real.sin_sq_add_cos_sq x
rw [h1] at h2
have h3 : Real.cos x ^ 2 = 0 := by linarith
exact hc (pow_eq_zero_iff two_ne_zero |>.mp h3)

    If $1+\sin x=0$, then $\sin x=-1$, and from $\sin^2x+\cos^2x=1$ we would have $\cos^2x=0$, hence $\cos x=0$, which contradicts the hypothesis.

    ✓ This part is complete.
  4. -- sec x + tan x = (1 + sin x)/cos x ≠ 0
have hne : 1 / Real.cos x + Real.tan x ≠ 0 := by
  rw [Real.tan_eq_sin_div_cos, ← add_div]
  exact div_ne_zero hs hc

    Therefore $\sec x+\tan x$${}=\dfrac{1+\sin x}{\cos x}\neq 0$.

    ✓ This part is complete.
  5. -- (sec x + tan x)' = sec x tan x + sec² x
have h1 : HasDerivAt (fun x => 1 / Real.cos x + Real.tan x)
    (1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) x :=
  (int_sec_tan x hc).add (int_sec_sq x hc)

    $\sec x+\tan x$ has derivative $\sec x\tan x+\sec^2x$, by the two previous formulas.

    What remains to be proved
    x : ℝ
hc : Real.cos x ≠ 0
hs : 1 + Real.sin x ≠ 0
hne : 1 / Real.cos x + Real.tan x ≠ 0
h1 : HasDerivAt (fun x => 1 / Real.cos x + Real.tan x) (1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) x
⊢ HasDerivAt (fun x => Real.log (1 / Real.cos x + Real.tan x)) (1 / Real.cos x) x
  6. -- logarithm rule
have h2 := h1.log hne

    Logarithm rule (HasDerivAt.log): $\ln(\sec x+\tan x)$ has derivative $\dfrac{\sec x\tan x+\sec^2x}{\sec x+\tan x}$.

    What remains to be proved
    h2 : HasDerivAt (fun y => Real.log (1 / Real.cos y + Real.tan y))
  ((1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) / (1 / Real.cos x + Real.tan x)) x
⊢ HasDerivAt (fun x => Real.log (1 / Real.cos x + Real.tan x)) (1 / Real.cos x) x
  7. convert h2 using 1

    The function is already the right one; it remains to show that the two derivatives are equal.

    What remains to be proved
    ⊢ 1 / Real.cos x = (1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) / (1 / Real.cos x + Real.tan x)
  8. rw [Real.tan_eq_sin_div_cos]

    We write $\tan x=\dfrac{\sin x}{\cos x}$.

    What remains to be proved
    ⊢ 1 / Real.cos x =
  (1 / Real.cos x * (Real.sin x / Real.cos x) + 1 / Real.cos x ^ 2) / (1 / Real.cos x + Real.sin x / Real.cos x)
  9. field_simp
ring

    We clear the denominators (field_simp) and check the remaining equality with ring.

    ✓ No goals: the proof is complete.

Solution
theorem int_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x|) (Real.tan x) x := by
  simp only [Real.log_abs]
  have h := (int_sec_tan x hc).log (one_div_ne_zero hc)
  convert h using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp

4. In Mathlib

We used the following theorems:

  • Real.hasDerivAt_tan: the derivative of $\tan x$.
  • Real.hasDerivAt_cos: the derivative of $\cos x$.
  • HasDerivAt.fun_div: the quotient rule.
  • Real.log_abs: $\ln|t|=\ln t$ in Mathlib.
  • Real.sin_sq_add_cos_sq: $\sin^2x+\cos^2x=1$.
  • Real.tan_eq_sin_div_cos: $\tan x=\dfrac{\sin x}{\cos x}$.
  • HasDerivAt.add: the sum rule.
  • HasDerivAt.log: the derivative of $\ln f(x)$.

import Mathlib

namespace Ch16.TanSec

-- we write sec x = 1/cos x

-- ∫ sec² x dx = tan x + C
theorem int_sec_sq (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt Real.tan (1 / Real.cos x ^ 2) x :=
  Real.hasDerivAt_tan hc

-- ∫ sec x tan x dx = sec x + C
theorem int_sec_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => 1 / Real.cos x) (1 / Real.cos x * Real.tan x) x := by
  have h := (hasDerivAt_const x (1 : ℝ)).fun_div (Real.hasDerivAt_cos x) hc
  convert h using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp
  ring

-- ∫ sec x dx = ln|sec x + tan x| + C
theorem int_sec (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x + Real.tan x|) (1 / Real.cos x) x := by
  -- in Mathlib, ln|t| = ln t
  simp only [Real.log_abs]
  -- when cos x ≠ 0, sin x ≠ -1
  have hs : 1 + Real.sin x ≠ 0 := by
    intro h
    have h1 : Real.sin x = -1 := by linarith
    have h2 := Real.sin_sq_add_cos_sq x
    rw [h1] at h2
    have h3 : Real.cos x ^ 2 = 0 := by linarith
    exact hc (pow_eq_zero_iff two_ne_zero |>.mp h3)
  -- sec x + tan x = (1 + sin x)/cos x ≠ 0
  have hne : 1 / Real.cos x + Real.tan x ≠ 0 := by
    rw [Real.tan_eq_sin_div_cos, ← add_div]
    exact div_ne_zero hs hc
  -- (sec x + tan x)' = sec x tan x + sec² x
  have h1 : HasDerivAt (fun x => 1 / Real.cos x + Real.tan x)
      (1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) x :=
    (int_sec_tan x hc).add (int_sec_sq x hc)
  -- logarithm rule
  have h2 := h1.log hne
  convert h2 using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp
  ring

theorem int_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x|) (Real.tan x) x := by
  simp only [Real.log_abs]
  have h := (int_sec_tan x hc).log (one_div_ne_zero hc)
  convert h using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp

end Ch16.TanSec
