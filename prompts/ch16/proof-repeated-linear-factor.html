Repeated Linear Factor

StatementIf the denominator contains the factor $(x-a)^k$ with $k\ge 2$, the partial fraction decomposition includes $k$ terms: $\dfrac{A_1}{x-a}+\dfrac{A_2}{(x-a)^2}+\dots+\dfrac{A_k}{(x-a)^k}$, with $\int\dfrac{A_1}{x-a}dx=A_1\ln|x-a|+C$ and $\int\dfrac{A_j}{(x-a)^j}dx=-\dfrac{A_j}{(j-1)(x-a)^{j-1}}+C$ for $j\ge 2$.

1. What is proved: the statement in the book and in Lean

  • $\int\dfrac{A}{x-a}\,dx=A\ln|x-a|+C$
    theorem int_first (A a x : ℝ) (hx : x ≠ a) :
    HasDerivAt (fun x => A * Real.log |x - a|) (A / (x - a)) x
  • $\int\dfrac{A}{(x-a)^j}\,dx$${}=-\dfrac{A}{(j-1)(x-a)^{j-1}}+C$ for $j\ge 2$, written with $j=m+2$
    theorem int_power (A a x : ℝ) (m : ℕ) (hx : x ≠ a) :
    HasDerivAt (fun x => -A / ((m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  • Example: $\int\dfrac{3}{(x-1)^2}\,dx$${}=-\dfrac{3}{x-1}+C$
    theorem int_example (x : ℝ) (hx : x ≠ 1) :
    HasDerivAt (fun x => -3 / (x - 1)) (3 / (x - 1) ^ 2) x

Each formula is written as “the right-hand side has the integrand as its derivative”, at every $x\neq a$. To avoid the hypothesis $j\ge 2$, we write $j=m+2$ with $m=0,1,2,\dots$; then $j-1=m+1$. The decomposition $\dfrac{A_1}{x-a}+\dots+\dfrac{A_k}{(x-a)^k}$ is the linear-factor case of the partial fraction decomposition; here we check the integrals of its terms. In Mathlib the logarithm Real.log is also defined for negative numbers, as $\ln|t|$, so the absolute value disappears at once (Real.log_abs).

2. Step by step: $\int\dfrac{A}{(x-a)^{m+2}}\,dx$

The idea: we differentiate $-\dfrac{A}{(m+1)(x-a)^{m+1}}$ with the quotient rule. We start from the goal:

The goal
A a x : ℝ
m : ℕ
hx : x ≠ a
⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hxa : x - a ≠ 0 := sub_ne_zero.mpr hx

    Since $x\neq a$, we have $x-a\neq 0$.

    What remains to be proved
    hxa : x - a ≠ 0
⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  2. -- ((x - a)^(m+1))' = (m + 1)(x - a)^m
have h1 : HasDerivAt (fun x => (x - a) ^ (m + 1)) ((m + 1) * (x - a) ^ m) x := by
  simpa using ((hasDerivAt_id' x).sub_const a).fun_pow (m + 1)

    $(x-a)^{m+1}$ has derivative $(m+1)(x-a)^m$ (power rule). ↑m is the natural number $m$ viewed as a real number.

    ✓ This part is complete.
  3. -- ((m + 1)(x - a)^(m+1))' = (m + 1)(m + 1)(x - a)^m
have h2 := h1.const_mul ((m : ℝ) + 1)

    We multiply by the constant $m+1$.

    What remains to be proved
    A a x : ℝ
m : ℕ
hx : x ≠ a
hxa : x - a ≠ 0
h1 : HasDerivAt (fun x => (x - a) ^ (m + 1)) ((↑m + 1) * (x - a) ^ m) x
h2 : HasDerivAt (fun y => (↑m + 1) * (y - a) ^ (m + 1)) ((↑m + 1) * ((↑m + 1) * (x - a) ^ m)) x
⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  4. -- the denominator does not vanish
have hden : ((m : ℝ) + 1) * (x - a) ^ (m + 1) ≠ 0 :=
  mul_ne_zero (by positivity) (pow_ne_zero _ hxa)

    The denominator $(m+1)(x-a)^{m+1}$ does not vanish.

    What remains to be proved
    hden : (↑m + 1) * (x - a) ^ (m + 1) ≠ 0
⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  5. -- quotient rule
have h3 := (hasDerivAt_const x (-A)).fun_div h2 hden

    Quotient rule for $\dfrac{-A}{(m+1)(x-a)^{m+1}}$ (HasDerivAt.fun_div).

    What remains to be proved
    h3 : HasDerivAt (fun y => -A / ((↑m + 1) * (y - a) ^ (m + 1)))
  ((0 * ((↑m + 1) * (x - a) ^ (m + 1)) - -A * ((↑m + 1) * ((↑m + 1) * (x - a) ^ m))) /
    ((↑m + 1) * (x - a) ^ (m + 1)) ^ 2)
  x
⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  6. convert h3 using 1

    The function is already the right one; it remains to show that the two derivatives are equal.

    What remains to be proved
    ⊢ A / (x - a) ^ (m + 2) =
  (0 * ((↑m + 1) * (x - a) ^ (m + 1)) - -A * ((↑m + 1) * ((↑m + 1) * (x - a) ^ m))) / ((↑m + 1) * (x - a) ^ (m + 1)) ^ 2
  7. field_simp

    We clear the denominators (field_simp).

    What remains to be proved
    ⊢ A * (↑m + 1) * ((x - a) ^ (m + 1)) ^ 2 = (x - a) ^ (m + 2) * (0 * (x - a) ^ (m + 1) - -(A * (↑m + 1) * (x - a) ^ m))
  8. ring

    What remains is a polynomial identity, which ring checks.

    ✓ No goals: the proof is complete.

3. Try it yourself: $\int\dfrac{3}{(x-1)^2}\,dx$

theorem int_example (x : ℝ) (hx : x ≠ 1) :
    HasDerivAt (fun x => -3 / (x - 1)) (3 / (x - 1) ^ 2) x := by

  simp only [Nat.cast_zero, zero_add, one_mul, pow_one] at h
  exact h

4. In Mathlib

We used the following theorems:

  • Real.log_abs: $\ln|t|=\ln t$ in Mathlib.
  • HasDerivAt.log: the derivative of $\ln f(x)$.
  • HasDerivAt.sub_const: $f(x)-c$ has the same derivative as $f$.
  • HasDerivAt.fun_pow: the derivative of $f(x)^n$.
  • HasDerivAt.const_mul: the rule for $c\,f(x)$.
  • hasDerivAt_const: the derivative of a constant is $0$.
  • HasDerivAt.fun_div: the quotient rule.

import Mathlib

namespace Ch16.EpanalambanomenosParagontas

-- the term A/(x - a): ∫ A/(x - a) dx = A ln|x - a| + C
theorem int_first (A a x : ℝ) (hx : x ≠ a) :
    HasDerivAt (fun x => A * Real.log |x - a|) (A / (x - a)) x := by
  simp only [Real.log_abs]
  have h : HasDerivAt (fun x => Real.log (x - a)) (1 / (x - a)) x :=
    ((hasDerivAt_id' x).sub_const a).log (sub_ne_zero.mpr hx)
  convert h.const_mul A using 1
  ring

-- the terms A/(x - a)^j with j ≥ 2, written as j = m + 2:
-- ∫ A/(x - a)^(m+2) dx = -A/((m + 1)(x - a)^(m+1)) + C
theorem int_power (A a x : ℝ) (m : ℕ) (hx : x ≠ a) :
    HasDerivAt (fun x => -A / ((m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x := by
  have hxa : x - a ≠ 0 := sub_ne_zero.mpr hx
  -- ((x - a)^(m+1))' = (m + 1)(x - a)^m
  have h1 : HasDerivAt (fun x => (x - a) ^ (m + 1)) ((m + 1) * (x - a) ^ m) x := by
    simpa using ((hasDerivAt_id' x).sub_const a).fun_pow (m + 1)
  -- ((m + 1)(x - a)^(m+1))' = (m + 1)(m + 1)(x - a)^m
  have h2 := h1.const_mul ((m : ℝ) + 1)
  -- the denominator does not vanish
  have hden : ((m : ℝ) + 1) * (x - a) ^ (m + 1) ≠ 0 :=
    mul_ne_zero (by positivity) (pow_ne_zero _ hxa)
  -- quotient rule
  have h3 := (hasDerivAt_const x (-A)).fun_div h2 hden
  convert h3 using 1
  field_simp
  ring

theorem int_example (x : ℝ) (hx : x ≠ 1) :
    HasDerivAt (fun x => -3 / (x - 1)) (3 / (x - 1) ^ 2) x := by
  have h := int_power 3 1 x 0 hx
  simp only [Nat.cast_zero, zero_add, one_mul, pow_one] at h
  exact h

end Ch16.EpanalambanomenosParagontas
