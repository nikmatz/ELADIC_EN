Irreducible Quadratic Factor (Completing the Square)

Chapter 16 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $x^2+bx+c$ be irreducible ($b^2-4c<0$). Completing the square gives $x^2+bx+c=\left(x+\tfrac{b}{2}\right)^2+k^2$, with $k=\sqrt{c-\tfrac{b^2}{4}}>0$, and $\int\dfrac{Ax+B}{x^2+bx+c}dx$ splits into a logarithmic part (whose numerator is the derivative $2x+b$) and an arctangent.

1. What is proved: the statement in the book and in Lean

  • If $b^2-4c\lt 0$ and $k=\sqrt{c-\tfrac{b^2}{4}}$, then $\int\dfrac{Ax+B}{x^2+bx+c}\,dx$${}=\dfrac{A}{2}\ln(x^2+bx+c)$ $+\,\dfrac{B-\tfrac{Ab}{2}}{k}\arctan\dfrac{x+\tfrac{b}{2}}{k}+C$
    theorem quadratic_factor (A B b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c) +
        (B - A * b / 2) / Real.sqrt (c - b ^ 2 / 4) *
          Real.arctan ((x + b / 2) / Real.sqrt (c - b ^ 2 / 4)))
      ((A * x + B) / (x ^ 2 + b * x + c)) x
  • Application: when the numerator is a multiple of $2x+b$, only the logarithmic part remains: $\int\dfrac{Ax+\tfrac{Ab}{2}}{x^2+bx+c}\,dx$${}=\dfrac{A}{2}\ln(x^2+bx+c)+C$
    theorem log_part (A b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c))
      ((A * x + A * b / 2) / (x ^ 2 + b * x + c)) x

The indefinite integral $\int f(x)\,dx=F(x)+C$ means that $F$ is an antiderivative of $f$, that is, $F$ has derivative $f$: this is written HasDerivAt F (f x) x. The proposition in the book describes how the integral is decomposed; here we state the formula that the decomposition leads to and check that the derivative of the right-hand side is $\dfrac{Ax+B}{x^2+bx+c}$. Since $x^2+bx+c\gt 0$ for every $x$, the logarithm needs no absolute value. The square root is written Real.sqrt, and in Lean's goal states it appears as √.

2. Step by step: logarithm and arctangent

The idea: $\dfrac{Ax+B}{x^2+bx+c}$${}=\dfrac{A}{2}\cdot\dfrac{2x+b}{x^2+bx+c}+\dfrac{B-\tfrac{Ab}{2}}{(x+\tfrac{b}{2})^2+k^2}$. We differentiate the two parts of the formula and check that the sum of the derivatives is the function being integrated. We start from the goal:

4. In Mathlib

We used the following theorems:

  • Real.sqrt_pos: $\sqrt{t}\gt 0$ exactly when $t\gt 0$.
  • Real.sq_sqrt: $(\sqrt{t})^2=t$ for $t\ge 0$.
  • hasDerivAt_pow: the derivative of $x^n$.
  • HasDerivAt.log: the derivative of $\ln f(x)$.
  • HasDerivAt.arctan: the derivative of $\arctan f(x)$.
  • HasDerivAt.div_const: the derivative of $\dfrac{f(x)}{c}$.
  • HasDerivAt.const_mul: the rule for $c\,f(x)$.
  • HasDerivAt.add: the sum rule.

theorem quadratic_factor (A B b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c) +
        (B - A * b / 2) / Real.sqrt (c - b ^ 2 / 4) *
          Real.arctan ((x + b / 2) / Real.sqrt (c - b ^ 2 / 4)))
      ((A * x + B) / (x ^ 2 + b * x + c)) x := by
  -- k = √(c - b²/4) > 0
  set k := Real.sqrt (c - b ^ 2 / 4) with hk_def
  have hk : 0 < k := Real.sqrt_pos.mpr (by linarith)
  have hk0 : k ≠ 0 := hk.ne'
  have hk2 : k ^ 2 = c - b ^ 2 / 4 := Real.sq_sqrt (by linarith)
  -- completing the square: x² + bx + c = (x + b/2)² + k²
  have hsq : x ^ 2 + b * x + c = (x + b / 2) ^ 2 + k ^ 2 := by
    rw [hk2]
    ring
  have hpos : 0 < x ^ 2 + b * x + c := by
    rw [hsq]
    positivity
  -- logarithmic part: (ln(x² + bx + c))' = (2x + b)/(x² + bx + c)
  have h1 : HasDerivAt (fun x => x ^ 2 + b * x + c) (2 * x + b) x := by
    simpa using ((hasDerivAt_pow 2 x).add ((hasDerivAt_id' x).const_mul b)).add_const c
  have h2 := h1.log hpos.ne'
  -- arctangent: (arctan((x + b/2)/k))' = 1/(1 + ((x + b/2)/k)²) · 1/k
  have h3 : HasDerivAt (fun x => (x + b / 2) / k) (1 / k) x :=
    ((hasDerivAt_id' x).add_const (b / 2)).div_const k
  have h4 := h3.arctan
  -- we combine the two parts
  have h5 : HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c) +
      (B - A * b / 2) / k * Real.arctan ((x + b / 2) / k))
      (A / 2 * ((2 * x + b) / (x ^ 2 + b * x + c)) +
        (B - A * b / 2) / k * (1 / (1 + ((x + b / 2) / k) ^ 2) * (1 / k))) x :=
    (h2.const_mul (A / 2)).add (h4.const_mul ((B - A * b / 2) / k))
  convert h5 using 1
  -- an algebraic identity remains
  have h6 : 1 + ((x + b / 2) / k) ^ 2 = ((x + b / 2) ^ 2 + k ^ 2) / k ^ 2 := by
    field_simp
    ring
  have hq : (x + b / 2) ^ 2 + k ^ 2 ≠ 0 := by
    rw [← hsq]
    exact hpos.ne'
  rw [h6, hsq]
  field_simp
  ring

theorem log_part (A b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c))
      ((A * x + A * b / 2) / (x ^ 2 + b * x + c)) x := by
  have h := quadratic_factor A (A * b / 2) b c hdisc x
  simp only [sub_self, zero_div, zero_mul, add_zero] at h
  exact h

end Ch16.AnagwgosTetragwnikos
