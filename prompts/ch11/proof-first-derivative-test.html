1. What is proved: the statement in the book and in Lean

  • If $f'\gt 0$ on $(a,x_0)$ and $f'\lt 0$ on $(x_0,b)$, then $f$ has a local maximum at $x_0$
    theorem first_derivative_test_max (f f' : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hc : ContinuousOn f (Set.Icc a b)) (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hpos : ∀ x ∈ Set.Ioo a x₀, 0 < f' x) (hneg : ∀ x ∈ Set.Ioo x₀ b, f' x < 0) :
    IsLocalMax f x₀
  • If $f'\lt 0$ on $(a,x_0)$ and $f'\gt 0$ on $(x_0,b)$, then $f$ has a local minimum at $x_0$
    theorem first_derivative_test_min (f f' : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hc : ContinuousOn f (Set.Icc a b)) (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hneg : ∀ x ∈ Set.Ioo a x₀, f' x < 0) (hpos : ∀ x ∈ Set.Ioo x₀ b, 0 < f' x) :
    IsLocalMin f x₀

Continuity on $[a,b]$ is written ContinuousOn f (Set.Icc a b). For differentiability on $(a,b)$ we supply a function f' for the derivative: ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x. The sign change “from $+$ to $-$” is written as two hypotheses: $f'(x)\gt 0$ for $x\in(a,x_0)$ (hpos) and $f'(x)\lt 0$ for $x\in(x_0,b)$ (hneg). The book's condition $f'(x_0)=0$ is not needed as a hypothesis, because it follows from Fermat's theorem. IsLocalMax f x₀ means that $f(x)\le f(x_0)$ for every $x$ sufficiently close to $x_0$. The proof uses the mean value theorem (exists_hasDerivAt_eq_slope) on the intervals $[x,x_0]$ and $[x_0,x]$.

2. Step by step: local maximum

The idea: for $x\lt x_0$ the mean value theorem gives $f(x_0)-f(x)=f'(c)(x_0-x)\gt 0$, and for $x\gt x_0$ it gives $f(x)-f(x_0)=f'(c)(x-x_0)\lt 0$. We start from the goal:

The goal
f f' : ℝ → ℝ
a b x₀ : ℝ
hx₀ : x₀ ∈ Set.Ioo a b
hc : ContinuousOn f (Set.Icc a b)
hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x
hpos : ∀ x ∈ Set.Ioo a x₀, 0 < f' x
hneg : ∀ x ∈ Set.Ioo x₀ b, f' x < 0
⊢ IsLocalMax f x₀

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

    A local maximum means $f(x)\le f(x_0)$ for every $x$ near $x_0$. It suffices to show this for every $x\in(a,b)$, which is an interval around $x_0$.

hx : x ∈ Set.Ioo a b
⊢ f x ≤ f x₀

    Three cases: $x\lt x_0$, $x=x_0$, or $x\gt x_0$.

    If $x\lt x_0$: the mean value theorem on $[x,x_0]$. There exists $c\in(x,x_0)$ with $f'(c)=\dfrac{f(x_0)-f(x)}{x_0-x}$.

Hint

Apply the theorem to $-f$, whose derivative $-f'$ changes sign from $+$ to $-$: have h := first_derivative_test_max (fun x => -f x) (fun x => -f' x) a b x₀ hx₀ hc.neg (fun x hx => (hd x hx).neg) (fun x hx => neg_pos.mpr (hneg x hx)) (fun x hx => neg_lt_zero.mpr (hpos x hx)). Solution
theorem first_derivative_test_min (f f' : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hc : ContinuousOn f (Set.Icc a b)) (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hneg : ∀ x ∈ Set.Ioo a x₀, f' x < 0) (hpos : ∀ x ∈ Set.Ioo x₀ b, 0 < f' x) :
    IsLocalMin f x₀ := by
  have h := first_derivative_test_max (fun x => -f x) (fun x => -f' x) a b x₀ hx₀ hc.neg
    (fun x hx => (hd x hx).neg) (fun x hx => neg_pos.mpr (hneg x hx))
    (fun x hx => neg_lt_zero.mpr (hpos x hx))
  simpa using h.neg

4. In Mathlib

We used the following theorems:

  • exists_hasDerivAt_eq_slope: the mean value theorem.
  • lt_div_iff₀: for $c\gt 0$: $a\lt\dfrac{b}{c}$ exactly when $ac\lt b$.
  • div_lt_iff₀: for $c\gt 0$: $\dfrac{b}{c}\lt a$ exactly when $b\lt ac$.
  • Ioo_mem_nhds: $(a,b)$ is a neighborhood of each of its points.
  • Set.Icc_subset_Icc: a closed interval inside a larger one.
  • IsLocalMax.neg: a local maximum of $f$ is a local minimum of $-f$.

theorem first_derivative_test_max (f f' : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hc : ContinuousOn f (Set.Icc a b)) (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hpos : ∀ x ∈ Set.Ioo a x₀, 0 < f' x) (hneg : ∀ x ∈ Set.Ioo x₀ b, f' x < 0) :
    IsLocalMax f x₀ := by
  filter_upwards [Ioo_mem_nhds hx₀.1 hx₀.2] with x hx
  rcases lt_trichotomy x x₀ with hlt | heq | hgt
  · obtain ⟨c, hc', hfc⟩ := exists_hasDerivAt_eq_slope f f' hlt
      (hc.mono (Set.Icc_subset_Icc hx.1.le hx₀.2.le))
      (fun y hy => hd y ⟨hx.1.trans hy.1, hy.2.trans hx₀.2⟩)
    have h1 : 0 < f' c := hpos c ⟨hx.1.trans hc'.1, hc'.2⟩
    rw [hfc, lt_div_iff₀ (sub_pos.mpr hlt)] at h1
    linarith
  · rw [heq]
  · obtain ⟨c, hc', hfc⟩ := exists_hasDerivAt_eq_slope f f' hgt
      (hc.mono (Set.Icc_subset_Icc hx₀.1.le hx.2.le))
      (fun y hy => hd y ⟨hx₀.1.trans hy.1, hy.2.trans hx.2⟩)
    have h1 : f' c < 0 := hneg c ⟨hc'.1, hc'.2.trans hx.2⟩
    rw [hfc, div_lt_iff₀ (sub_pos.mpr hgt)] at h1
    linarith

theorem first_derivative_test_min (f f' : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hc : ContinuousOn f (Set.Icc a b)) (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hneg : ∀ x ∈ Set.Ioo a x₀, f' x < 0) (hpos : ∀ x ∈ Set.Ioo x₀ b, 0 < f' x) :
    IsLocalMin f x₀ := by
  have h := first_derivative_test_max (fun x => -f x) (fun x => -f' x) a b x₀ hx₀ hc.neg
    (fun x hx => (hd x hx).neg) (fun x hx => neg_pos.mpr (hneg x hx))
    (fun x hx => neg_lt_zero.mpr (hpos x hx))
  simpa using h.neg

end Ch11.KritirioProtisParagogou
