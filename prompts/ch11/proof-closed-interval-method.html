The Closed Interval Method

1. What is proved: the statement in the book and in Lean

  • If $f$ is continuous on $[a,b]$, it attains a maximum value at a point $M$ that is an endpoint or a critical point (where $f'(M)=0$ or $f'(M)$ does not exist)
    theorem max_at_critical_or_endpoint (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ M ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f x ≤ f M) ∧
      (M = a ∨ M = b ∨ ∀ f', HasDerivAt f f' M → f' = 0)
  • The same for the minimum value
    theorem min_at_critical_or_endpoint (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ m ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f m ≤ f x) ∧
      (m = a ∨ m = b ∨ ∀ f', HasDerivAt f f' m → f' = 0)
  • Application: if $f'$ vanishes nowhere, the maximum occurs at an endpoint
    theorem max_at_endpoint (f f' : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hd : ∀ x, HasDerivAt f (f' x) x)
    (hne : ∀ x, f' x ≠ 0) :
    ∃ M ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f x ≤ f M) ∧ (M = a ∨ M = b)

Continuity on $[a,b]$ is written ContinuousOn f (Set.Icc a b). “$M$ is a critical point” is written ∀ f', HasDerivAt f f' M → f' = 0: if the derivative at $M$ exists, it is $0$. In this way the same statement also covers the points where $f'$ does not exist. Since $f(x)\le f(M)$ for every $x\in[a,b]$, the value $f(M)$ is the largest of the values at the endpoints and at the critical points, that is, the global maximum; similarly for the minimum. IsMaxOn f (Set.Icc a b) M means that $f$ attains at $M$ its maximum value on $[a,b]$.

2. Step by step: the maximum

The idea: Weierstrass' theorem gives the maximum point $M$; if it is not an endpoint, it is an interior point, and Fermat's theorem gives $f'(M)=0$. We start from the goal:

The goal
f : ℝ → ℝ
a b : ℝ
hab : a ≤ b
hf : ContinuousOn f (Set.Icc a b)
⊢ ∃ M ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f x ≤ f M) ∧ (M = a ∨ M = b ∨ ∀ (f' : ℝ), HasDerivAt f f' M → f' = 0)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. obtain ⟨M, hM, hmax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab) hf

    Weierstrass' theorem: $f$ attains a maximum value at some $M\in[a,b]$ (hmax).

    What remains to be proved
    M : ℝ
hM : M ∈ Set.Icc a b
hmax : IsMaxOn f (Set.Icc a b) M
⊢ ∃ M ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f x ≤ f M) ∧ (M = a ∨ M = b ∨ ∀ (f' : ℝ), HasDerivAt f f' M → f' = 0)
  2. refine ⟨M, hM, fun x hx => isMaxOn_iff.mp hmax x hx, ?_⟩

    We choose this $M$. The inequality $f(x)\le f(M)$ for every $x\in[a,b]$ follows from hmax. It remains to show that $M$ is an endpoint or a critical point.

    What remains to be proved
    ⊢ M = a ∨ M = b ∨ ∀ (f' : ℝ), HasDerivAt f f' M → f' = 0
  3. by_cases ha : M = a

    Two cases: $M=a$ or not.

    We take the derivative $f'$ of $f$ at $M$ (hf').

    What remains to be proved

⊢ f' = 0

    Since $a\le M\le b$, $M\neq a$ and $M\neq b$, the point $M$ is an interior point: $M\in(a,b)$.

    hMi : M ∈ Set.Ioo a b
⊢ f' = 0

    Therefore $M$ is a local maximum, because $[a,b]$ contains an interval around $M$.

    Fermat's theorem: $f'=0$.

Hint

Take the point given by the theorem: obtain ⟨M, hM, hmax, h⟩ := max_at_critical_or_endpoint f a b hab hf, and then rcases h with h | h | h. In the first two cases write exact ⟨M, hM, hmax, Or.inl h⟩ and exact ⟨M, hM, hmax, Or.inr h⟩. In the third, h (f' M) (hd M) gives $f'(M)=0$, which contradicts hne M: exact absurd (h (f' M) (hd M)) (hne M).

Solution
theorem max_at_endpoint (f f' : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hd : ∀ x, HasDerivAt f (f' x) x)
    (hne : ∀ x, f' x ≠ 0) :
    ∃ M ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f x ≤ f M) ∧ (M = a ∨ M = b) := by
  obtain ⟨M, hM, hmax, h⟩ := max_at_critical_or_endpoint f a b hab hf
  rcases h with h | h | h
  · exact ⟨M, hM, hmax, Or.inl h⟩
  · exact ⟨M, hM, hmax, Or.inr h⟩
  · exact absurd (h (f' M) (hd M)) (hne M)

4. In Mathlib

We used the following theorems:

  • IsCompact.exists_isMaxOn: a continuous function on a compact, nonempty set attains a maximum value.
  • IsCompact.exists_isMinOn: the same for the minimum value.
  • isCompact_Icc: $[a,b]$ is compact.
  • IsMaxOn.isLocalMax: a maximum on a set that contains an interval around the point is a local maximum.
  • IsMinOn.isLocalMin: the same for the minimum.
  • IsLocalMax.hasDerivAt_eq_zero: Fermat's theorem for a local maximum.
  • IsLocalMin.hasDerivAt_eq_zero: Fermat's theorem for a local minimum.

theorem max_at_critical_or_endpoint (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ M ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f x ≤ f M) ∧
      (M = a ∨ M = b ∨ ∀ f', HasDerivAt f f' M → f' = 0) := by
  obtain ⟨M, hM, hmax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab) hf
  refine ⟨M, hM, fun x hx => isMaxOn_iff.mp hmax x hx, ?_⟩
  by_cases ha : M = a
  · exact Or.inl ha
  by_cases hb : M = b
  · exact Or.inr (Or.inl hb)
  refine Or.inr (Or.inr ?_)
  intro f' hf'
  have hMi : M ∈ Set.Ioo a b := ⟨lt_of_le_of_ne hM.1 (Ne.symm ha), lt_of_le_of_ne hM.2 hb⟩
  have hloc : IsLocalMax f M := hmax.isLocalMax (Icc_mem_nhds hMi.1 hMi.2)
  exact hloc.hasDerivAt_eq_zero hf'

theorem min_at_critical_or_endpoint (f : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ m ∈ Set.Icc a b, (∀ x ∈ Set.Icc a b, f m ≤ f x) ∧
      (m = a ∨ m = b ∨ ∀ f', HasDerivAt f f' m → f' = 0) := by
  obtain ⟨m, hm, hmin⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab) hf
  refine ⟨m, hm, fun x hx => isMinOn_iff.mp hmin x hx, ?_⟩
  by_cases ha : m = a
  · exact Or.inl ha
  by_cases hb : m = b
  · exact Or.inr (Or.inl hb)
  refine Or.inr (Or.inr ?_)
  intro f' hf'
  have hmi : m ∈ Set.Ioo a b := ⟨lt_of_le_of_ne hm.1 (Ne.symm ha), lt_of_le_of_ne hm.2 hb⟩
