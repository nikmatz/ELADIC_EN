Second Derivative Test for Extrema

1. What is proved: the statement in the book and in Lean

  • If $f'(x_0)=0$ and $f''(x_0)\gt 0$, then $f$ has a local minimum at $x_0$
    theorem second_deriv_min (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hpos : 0 < deriv (deriv f) x₀) : IsLocalMin f x₀
  • If $f'(x_0)=0$ and $f''(x_0)\lt 0$, then $f$ has a local maximum at $x_0$
    theorem second_deriv_max (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hneg : deriv (deriv f) x₀ < 0) : IsLocalMax f x₀
  • When $f''(x_0)=0$ there may be an extremum: $x^4$ has $f'(0)=f''(0)=0$ and a minimum at $0$
    theorem quartic : deriv (fun x : ℝ => x ^ 4) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 4)) 0 = 0 ∧
    IsLocalMin (fun x : ℝ => x ^ 4) 0
  • But there may also be none: $x^3$ has $f'(0)=f''(0)=0$ and no extremum at $0$
    theorem cubic : deriv (fun x : ℝ => x ^ 3) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 3)) 0 = 0 ∧
    ¬ IsLocalExtr (fun x : ℝ => x ^ 3) 0

The derivative is written deriv f x₀ and the second derivative deriv (deriv f) x₀. The Mathlib theorem requires less than the book: only the continuity of $f$ at $x_0$ (ContinuousAt f x₀), not the continuity of $f''$ on a neighborhood. The functions $x^4$ and $x^3$ show why the test is inconclusive when $f''(x_0)=0$: they have the same values $f'(0)=f''(0)=0$, but the first has a minimum and the second has no extremum. IsLocalExtr means “local extremum”.

2. Where it is in Mathlib

We used the following theorems:

  • isLocalMin_of_deriv_deriv_pos: the second derivative test for a minimum.
  • isLocalMax_of_deriv_deriv_neg: the second derivative test for a maximum.
  • deriv_pow_field: the derivative of $x^n$ is $n\,x^{n-1}$.
  • deriv_const_mul: the derivative of $c\,f(x)$ is $c\,f'(x)$.
  • Metric.eventually_nhds_iff: a property holds near $x_0$ exactly when it holds on an interval $(x_0-\varepsilon,x_0+\varepsilon)$.

theorem second_deriv_min (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hpos : 0 < deriv (deriv f) x₀) : IsLocalMin f x₀ :=
  isLocalMin_of_deriv_deriv_pos hpos hd hc

theorem second_deriv_max (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hneg : deriv (deriv f) x₀ < 0) : IsLocalMax f x₀ :=
  isLocalMax_of_deriv_deriv_neg hneg hd hc

-- when f''(x₀) = 0 the test is inconclusive: x⁴ has a minimum at 0, x³ has no extremum
theorem quartic : deriv (fun x : ℝ => x ^ 4) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 4)) 0 = 0 ∧
    IsLocalMin (fun x : ℝ => x ^ 4) 0 := by
  have h1 : deriv (fun x : ℝ => x ^ 4) = fun x => 4 * x ^ 3 := by
    funext x
    rw [deriv_pow_field]
    norm_num
  refine ⟨by rw [h1]; norm_num, ?_, ?_⟩
  · rw [h1, deriv_const_mul _ (differentiableAt_pow 3), deriv_pow_field]
    norm_num
  · exact Filter.Eventually.of_forall fun x => by
      show (0 : ℝ) ^ 4 ≤ x ^ 4
      rw [zero_pow (by norm_num)]
      positivity

theorem cubic : deriv (fun x : ℝ => x ^ 3) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 3)) 0 = 0 ∧
    ¬ IsLocalExtr (fun x : ℝ => x ^ 3) 0 := by
  have h1 : deriv (fun x : ℝ => x ^ 3) = fun x => 3 * x ^ 2 := by
    funext x
    rw [deriv_pow_field]
    norm_num
  refine ⟨by rw [h1]; norm_num, ?_, ?_⟩
  · rw [h1, deriv_const_mul _ (differentiableAt_pow 2), deriv_pow_field]
    norm_num
  · have hpt : ∀ ε : ℝ, 0 < ε → dist (ε / 2) 0 < ε ∧ dist (-(ε / 2)) 0 < ε := by
      intro ε hε
      rw [Real.dist_eq, Real.dist_eq, sub_zero, sub_zero, abs_neg, abs_of_pos (half_pos hε)]
      constructor <;> linarith
    rintro (h | h)
    · obtain ⟨ε, hε, hball⟩ := Metric.eventually_nhds_iff.mp h
      have h2 : (0 : ℝ) ^ 3 ≤ (-(ε / 2)) ^ 3 := hball (hpt ε hε).2
      have h3 : 0 < (ε / 2) ^ 3 := pow_pos (half_pos hε) 3
      linarith
    · obtain ⟨ε, hε, hball⟩ := Metric.eventually_nhds_iff.mp h
      have h2 : (ε / 2) ^ 3 ≤ (0 : ℝ) ^ 3 := hball (hpt ε hε).1
      have h3 : 0 < (ε / 2) ^ 3 := pow_pos (half_pos hε) 3
      linarith
