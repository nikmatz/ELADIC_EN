Taylor Polynomial

Chapter 11 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementIf $f$ is $n$ times differentiable at $x_0$: $T_n(x)=\sum_{k=0}^{n}\dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k$ (Maclaurin for $x_0=0$). If moreover $f^{(n+1)}$ exists on an interval containing $x_0$ and $x$, the Lagrange remainder is $R_n(x)=f(x)-T_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ for some $\xi$ between $x_0$ and $x$.

In Mathlib the Taylor polynomial is taylorWithinEval f n s x₀ x, where the derivatives are computed within a set $s$: iteratedDerivWithin k f s x₀ is the $k$-th derivative $f^{(k)}(x_0)$. For the remainder, $s$ is the closed interval with endpoints $x_0$ and $x$ (Set.uIcc x₀ x) and $\xi$ lies in the open one (Set.uIoo x₀ x), whichever of $x_0$, $x$ is smaller. The hypothesis ContDiffOn ℝ n f means that $f$ has $n$ continuous derivatives on the interval, and hf' that the $n$-th derivative is differentiable in the interior, so that $f^{(n+1)}$ exists. The factorial $k!$ is written k !.

2. Where it is in Mathlib

We used the following theorems:

  • taylor_within_apply: the Taylor polynomial as a sum.
  • taylorWithinEval_self: the value of the Taylor polynomial at $x_0$.
  • taylor_mean_remainder_lagrange: the Lagrange remainder.

import Mathlib

namespace Ch11.PolyonymoTaylor
open scoped Nat

-- the Taylor polynomial in Mathlib: T_n(x) = Σ f^(k)(x₀)/k! · (x - x₀)^k
theorem taylor_formula (f : ℝ → ℝ) (n : ℕ) (s : Set ℝ) (x₀ x : ℝ) :
    taylorWithinEval f n s x₀ x =
      ∑ k ∈ Finset.range (n + 1), iteratedDerivWithin k f s x₀ / k ! * (x - x₀) ^ k := by
  rw [taylor_within_apply]
  refine Finset.sum_congr rfl (fun k _ => ?_)
  rw [smul_eq_mul]
  ring

theorem taylor_at_center (f : ℝ → ℝ) (n : ℕ) (s : Set ℝ) (x₀ : ℝ) :
    taylorWithinEval f n s x₀ x₀ = f x₀ :=
  taylorWithinEval_self f n s x₀

-- Lagrange remainder: R_n(x) = f^(n+1)(ξ)/(n+1)! · (x - x₀)^(n+1), with ξ between x₀ and x
theorem lagrange_remainder (f : ℝ → ℝ) (n : ℕ) (x₀ x : ℝ) (hx : x₀ ≠ x)
    (hf : ContDiffOn ℝ n f (Set.uIcc x₀ x))
    (hf' : DifferentiableOn ℝ (iteratedDerivWithin n f (Set.uIcc x₀ x)) (Set.uIoo x₀ x)) :
    ∃ ξ ∈ Set.uIoo x₀ x, f x - taylorWithinEval f n (Set.uIcc x₀ x) x₀ x =
      iteratedDerivWithin (n + 1) f (Set.uIcc x₀ x) ξ * (x - x₀) ^ (n + 1) / (n + 1)! :=
  taylor_mean_remainder_lagrange hx hf hf'

end Ch11.PolyonymoTaylor
