1. What is proved: the statement in the book and in Lean

  • If $f$ has a local minimum at an interior point $x_0$ and is differentiable there, then $f'(x_0)=0$
    theorem fermat_min (f : ℝ → ℝ) (x₀ f' : ℝ) (hmin : IsLocalMin f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0
  • The same for a local maximum
    theorem fermat_max (f : ℝ → ℝ) (x₀ f' : ℝ) (hmax : IsLocalMax f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0
  • The same for every local extremum, with the Mathlib theorem
    theorem fermat_extr (f : ℝ → ℝ) (x₀ f' : ℝ) (hext : IsLocalExtr f x₀)
    (hf : HasDerivAt f f' x₀) : f' = 0
  • The function $f(x)=x^3$ has $f'(0)=0$
    theorem cube_critical : HasDerivAt (fun x : ℝ => x ^ 3) 0 0
  • But $x^3$ does not have a local extremum at $0$: not all critical points are extrema
    theorem cube_not_extr : ¬ IsLocalExtr (fun x : ℝ => x ^ 3) 0

“$f$ has a local minimum at $x_0$” is written IsLocalMin f x₀, a local maximum IsLocalMax f x₀, and a local extremum IsLocalExtr f x₀. All three mean that the inequality holds on an open interval around $x_0$, so $x_0$ is an interior point. ∀ᶠ x in 𝓝[>] x₀, P x means that the property $P(x)$ holds for every $x\gt x_0$ close enough to $x_0$. The proof: the slope $\dfrac{f(x)-f(x_0)}{x-x_0}$ is $\ge 0$ to the right of $x_0$ and $\le 0$ to the left, so its limit $f'$ is both $\ge 0$ and $\le 0$. For $x^3$: $0$ is not an extremum, because on every interval around $0$ the function $x^3$ takes both positive and negative values.

2. Step by step: local minimum

The idea: to the right of $x_0$ the slope is $\ge 0$ and to the left it is $\le 0$, so its limit $f'$ is $0$. We start from the goal:

The goal
f : ℝ → ℝ
x₀ f' : ℝ
hmin : IsLocalMin f x₀
hf : HasDerivAt f f' x₀
⊢ f' = 0

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [hasDerivAt_iff_tendsto_slope] at hf

    We write the derivative as a limit: the slope slope f x₀ x tends to $f'$ as $x\to x_0$ with $x\neq x_0$.

    What remains to be proved
    hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
⊢ f' = 0
  2. have hR : 0 ≤ f' := by

    First half, hR: $0\le f'$.

    What remains to be proved
    ⊢ 0 ≤ f'
  3. have h1 : Tendsto (slope f x₀) (𝓝[>] x₀) (𝓝 f') := hf.mono_left (nhdsGT_le_nhdsNE x₀)
have hm : ∀ᶠ x in 𝓝[>] x₀, f x₀ ≤ f x := nhdsWithin_le_nhds hmin

    The slope also tends to $f'$ as $x\to x_0^+$ (h1; 𝓝[>] x₀ means $x\to x_0$ with $x\gt x_0$). Since $f$ has a local minimum at $x_0$, we have $f(x_0)\le f(x)$ for $x$ near $x_0$ (hm).

    What remains to be proved
    h1 : Tendsto (slope f x₀) (𝓝[>] x₀) (𝓝 f')
hm : ∀ᶠ (x : ℝ) in 𝓝[>] x₀, f x₀ ≤ f x
⊢ 0 ≤ f'
  4. apply ge_of_tendsto h1

    If a quantity tends to $f'$ and is $\ge 0$ for $x\gt x_0$ near $x_0$, then $f'\ge 0$. It remains to show that the slope is $\ge 0$ there.

    What remains to be proved
    ⊢ ∀ᶠ (c : ℝ) in 𝓝[>] x₀, 0 ≤ slope f x₀ c
  5. filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx

    We take $x\gt x_0$ near $x_0$, with $f(x_0)\le f(x)$.

    What remains to be proved
    x : ℝ
hfx : f x₀ ≤ f x
hx : x ∈ Set.Ioi x₀
⊢ 0 ≤ slope f x₀ x
  6. rw [slope_def_field]

    We write the slope as a fraction.

    What remains to be proved
    ⊢ 0 ≤ (f x - f x₀) / (x - x₀)
  7. exact div_nonneg (sub_nonneg.mpr hfx) (sub_nonneg.mpr (le_of_lt hx))

    The numerator $f(x)-f(x_0)$ is $\ge 0$ and the denominator $x-x_0$ is positive, so the fraction is $\ge 0$.

    ✓ This part is complete.
  8. have hL : f' ≤ 0 := by

    Second half, hL: $f'\le 0$.

    What remains to be proved
    f : ℝ → ℝ
x₀ f' : ℝ
hmin : IsLocalMin f x₀
hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
hR : 0 ≤ f'
⊢ f' ≤ 0
  9. have h2 : Tendsto (slope f x₀) (𝓝[<] x₀) (𝓝 f') := hf.mono_left (nhdsLT_le_nhdsNE x₀)
have hm : ∀ᶠ x in 𝓝[<] x₀, f x₀ ≤ f x := nhdsWithin_le_nhds hmin

    Now $x\to x_0^-$ (h2; 𝓝[<] x₀ means $x\to x_0$ with $x\lt x_0$), again with $f(x_0)\le f(x)$.

    What remains to be proved
    h2 : Tendsto (slope f x₀) (𝓝[<] x₀) (𝓝 f')
hm : ∀ᶠ (x : ℝ) in 𝓝[<] x₀, f x₀ ≤ f x
⊢ f' ≤ 0
  10. apply le_of_tendsto h2

    If a quantity tends to $f'$ and is $\le 0$ for $x\lt x_0$ near $x_0$, then $f'\le 0$.

    What remains to be proved
    ⊢ ∀ᶠ (c : ℝ) in 𝓝[<] x₀, slope f x₀ c ≤ 0
  11. filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx

    We take $x\lt x_0$ near $x_0$, with $f(x_0)\le f(x)$.

    What remains to be proved
    x : ℝ
hfx : f x₀ ≤ f x
hx : x ∈ Set.Iio x₀
⊢ slope f x₀ x ≤ 0
  12. rw [slope_def_field]

    We write the slope as a fraction.

    What remains to be proved
    ⊢ (f x - f x₀) / (x - x₀) ≤ 0
  13. exact div_nonpos_of_nonneg_of_nonpos (sub_nonneg.mpr hfx) (sub_nonpos.mpr (le_of_lt hx))

    The numerator is $\ge 0$ and the denominator $x-x_0$ is negative, so the fraction is $\le 0$.

    ✓ This part is complete.
  14. linarith

    From $0\le f'$ and $f'\le 0$ we get $f'=0$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • hasDerivAt_iff_tendsto_slope: the derivative as the limit of the slope $\dfrac{f(x)-f(x_0)}{x-x_0}$.
  • nhdsGT_le_nhdsNE: if $x\to x_0$ with $x\gt x_0$, then also $x\to x_0$ with $x\neq x_0$.
  • nhdsLT_le_nhdsNE: the same for $x\lt x_0$.
  • ge_of_tendsto: if $g(x)\to L$ and $g(x)\ge c$ near the point, then $L\ge c$.
  • le_of_tendsto: the same with $\le$ in place of $\ge$.
  • div_nonneg: from $a\ge 0$ and $b\ge 0$ we get $\dfrac{a}{b}\ge 0$.
  • div_nonpos_of_nonneg_of_nonpos: from $a\ge 0$ and $b\le 0$ we get $\dfrac{a}{b}\le 0$.
  • IsLocalMax.neg: a local maximum of $f$ is a local minimum of $-f$.
  • IsLocalExtr.hasDerivAt_eq_zero: Fermat's theorem in Mathlib.
  • hasDerivAt_pow: the derivative of $x^n$.
  • Metric.eventually_nhds_iff: a property holds near $x_0$ exactly when it holds on an interval $(x_0-\varepsilon,x_0+\varepsilon)$.

import Mathlib

namespace Ch11.Fermat
open Filter Topology

theorem fermat_min (f : ℝ → ℝ) (x₀ f' : ℝ) (hmin : IsLocalMin f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0 := by
  rw [hasDerivAt_iff_tendsto_slope] at hf
  have hR : 0 ≤ f' := by
    have h1 : Tendsto (slope f x₀) (𝓝[>] x₀) (𝓝 f') := hf.mono_left (nhdsGT_le_nhdsNE x₀)
    have hm : ∀ᶠ x in 𝓝[>] x₀, f x₀ ≤ f x := nhdsWithin_le_nhds hmin
    apply ge_of_tendsto h1
    filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx
    rw [slope_def_field]
    exact div_nonneg (sub_nonneg.mpr hfx) (sub_nonneg.mpr (le_of_lt hx))
  have hL : f' ≤ 0 := by
    have h2 : Tendsto (slope f x₀) (𝓝[<] x₀) (𝓝 f') := hf.mono_left (nhdsLT_le_nhdsNE x₀)
    have hm : ∀ᶠ x in 𝓝[<] x₀, f x₀ ≤ f x := nhdsWithin_le_nhds hmin
    apply le_of_tendsto h2
    filter_upwards [hm, self_mem_nhdsWithin] with x hfx hx
    rw [slope_def_field]
    exact div_nonpos_of_nonneg_of_nonpos (sub_nonneg.mpr hfx) (sub_nonpos.mpr (le_of_lt hx))
  linarith

theorem fermat_max (f : ℝ → ℝ) (x₀ f' : ℝ) (hmax : IsLocalMax f x₀) (hf : HasDerivAt f f' x₀) :
    f' = 0 := by
  have h := fermat_min (fun x => -f x) x₀ (-f') hmax.neg hf.neg
  linarith

theorem fermat_extr (f : ℝ → ℝ) (x₀ f' : ℝ) (hext : IsLocalExtr f x₀)
    (hf : HasDerivAt f f' x₀) : f' = 0 :=
  hext.hasDerivAt_eq_zero hf

-- a critical point that is not an extremum: f(x) = x³ at 0
theorem cube_critical : HasDerivAt (fun x : ℝ => x ^ 3) 0 0 := by
  simpa using hasDerivAt_pow 3 (0 : ℝ)

theorem cube_not_extr : ¬ IsLocalExtr (fun x : ℝ => x ^ 3) 0 := by
  have hpt : ∀ ε : ℝ, 0 < ε → dist (ε / 2) 0 < ε ∧ dist (-(ε / 2)) 0 < ε := by
    intro ε hε
    rw [Real.dist_eq, Real.dist_eq, sub_zero, sub_zero, abs_neg, abs_of_pos (half_pos hε)]
    constructor <;> linarith
  rintro (h | h)
  · obtain ⟨ε, hε, hball⟩ := Metric.eventually_nhds_iff.mp h
    have h1 : (0 : ℝ) ^ 3 ≤ (-(ε / 2)) ^ 3 := hball (hpt ε hε).2
    have h2 : 0 < (ε / 2) ^ 3 := pow_pos (half_pos hε) 3
    linarith
  · obtain ⟨ε, hε, hball⟩ := Metric.eventually_nhds_iff.mp h
    have h1 : (ε / 2) ^ 3 ≤ (0 : ℝ) ^ 3 := hball (hpt ε hε).1
    have h2 : 0 < (ε / 2) ^ 3 := pow_pos (half_pos hε) 3
    linarith

end Ch11.Fermat
