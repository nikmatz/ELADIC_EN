“Strictly increasing on $(a,b)$” is written StrictMonoOn f (Set.Ioo a b), and “strictly decreasing” StrictAntiOn f (Set.Ioo a b). For the sign change we use theorems from Mathlib, where the derivative is written deriv f x and the weak inequalities $\ge 0$ and $\le 0$ suffice. Continuity at $x_0$ is written ContinuousAt f x₀, and the book's condition $f'(x_0)=0$ is not needed as a hypothesis.

2. Step by step: strictly increasing

The idea: for $x\lt y$ the mean value theorem gives $f(y)-f(x)=f'(c)(y-x)\gt 0$. We start from the goal:

The goal
f f' : ℝ → ℝ
a b : ℝ
hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x
hpos : ∀ x ∈ Set.Ioo a b, 0 < f' x
⊢ StrictMonoOn f (Set.Ioo a b)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. intro x hx y hy hxy

    Strictly increasing on $(a,b)$ means: for $x\lt y$ in $(a,b)$ we have $f(x)\lt f(y)$. We take such $x$ and $y$.

    What remains to be proved
    x : ℝ
hx : x ∈ Set.Ioo a b
y : ℝ
hy : y ∈ Set.Ioo a b
hxy : x < y
⊢ f x < f y
  2. have hcont : ContinuousOn f (Set.Icc x y) := by

    Claim hcont: $f$ is continuous on $[x,y]$.

    What remains to be proved
    ⊢ ContinuousOn f (Set.Icc x y)
  3. intro z hz
exact (hd z ⟨hx.1.trans_le hz.1, hz.2.trans_lt hy.2⟩).continuousAt.continuousWithinAt

    $f$ has a derivative at every point of $[x,y]$, which lies inside $(a,b)$, so it is continuous there.

    ✓ This part is complete.
  4. obtain ⟨c, hc, hfc⟩ := exists_hasDerivAt_eq_slope f f' hxy hcont
  (fun z hz => hd z ⟨hx.1.trans hz.1, hz.2.trans hy.2⟩)

    The mean value theorem on $[x,y]$: there exists $c\in(x,y)$ with $f'(c)=\dfrac{f(y)-f(x)}{y-x}$.

    What remains to be proved
    f f' : ℝ → ℝ
a b : ℝ
hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x
hpos : ∀ x ∈ Set.Ioo a b, 0 < f' x
x : ℝ
hx : x ∈ Set.Ioo a b
y : ℝ
hy : y ∈ Set.Ioo a b
hxy : x < y
hcont : ContinuousOn f (Set.Icc x y)
c : ℝ
hc : c ∈ Set.Ioo x y
hfc : f' c = (f y - f x) / (y - x)
⊢ f x < f y
  5. have h1 : 0 < f' c := hpos c ⟨hx.1.trans hc.1, hc.2.trans hy.2⟩

    Since $c\in(a,b)$, we have $f'(c)\gt 0$.

    What remains to be proved
    h1 : 0 < f' c
⊢ f x < f y
  6. rw [hfc, lt_div_iff₀ (sub_pos.mpr hxy)] at h1

    We multiply by the positive denominator $y-x$: $f(y)-f(x)\gt 0$.

    What remains to be proved
    h1 : 0 * (y - x) < f y - f x
⊢ f x < f y
  7. linarith

    Therefore, $f(x)\lt f(y)$.

    ✓ No goals: the proof is complete.

3. Try it yourself: strictly decreasing

Hint

The function $-f$ has derivative $-f'\gt 0$: have h := strict_mono_of_deriv_pos (fun x => -f x) (fun x => -f' x) a b (fun x hx => (hd x hx).neg) (fun x hx => neg_pos.mpr (hneg x hx)). Then intro x hx y hy hxy and exact neg_lt_neg_iff.mp (h hx hy hxy), because $-f(x)\lt -f(y)$ means $f(y)\lt f(x)$.

Solution
theorem strict_anti_of_deriv_neg (f f' : ℝ → ℝ) (a b : ℝ)
    (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) (hneg : ∀ x ∈ Set.Ioo a b, f' x < 0) :
    StrictAntiOn f (Set.Ioo a b) := by
  have h := strict_mono_of_deriv_pos (fun x => -f x) (fun x => -f' x) a b
    (fun x hx => (hd x hx).neg) (fun x hx => neg_pos.mpr (hneg x hx))
  intro x hx y hy hxy
  exact neg_lt_neg_iff.mp (h hx hy hxy)

4. In Mathlib

We used the following theorems:

  • exists_hasDerivAt_eq_slope: the mean value theorem.
  • lt_div_iff₀: for $c\gt 0$: $a\lt\dfrac{b}{c}$ exactly when $ac\lt b$.
  • HasDerivAt.continuousAt: a differentiable function is continuous.
  • neg_lt_neg_iff: $-a\lt -b$ exactly when $b\lt a$.
  • isLocalMax_of_deriv_Ioo: the first derivative test for a maximum in Mathlib.
  • isLocalMin_of_deriv_Ioo: the same for a minimum.

theorem strict_mono_of_deriv_pos (f f' : ℝ → ℝ) (a b : ℝ)
    (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) (hpos : ∀ x ∈ Set.Ioo a b, 0 < f' x) :
    StrictMonoOn f (Set.Ioo a b) := by
  intro x hx y hy hxy
  have hcont : ContinuousOn f (Set.Icc x y) := by
    intro z hz
    exact (hd z ⟨hx.1.trans_le hz.1, hz.2.trans_lt hy.2⟩).continuousAt.continuousWithinAt
  obtain ⟨c, hc, hfc⟩ := exists_hasDerivAt_eq_slope f f' hxy hcont
    (fun z hz => hd z ⟨hx.1.trans hz.1, hz.2.trans hy.2⟩)
  have h1 : 0 < f' c := hpos c ⟨hx.1.trans hc.1, hc.2.trans hy.2⟩
  rw [hfc, lt_div_iff₀ (sub_pos.mpr hxy)] at h1
  linarith

theorem strict_anti_of_deriv_neg (f f' : ℝ → ℝ) (a b : ℝ)
    (hd : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) (hneg : ∀ x ∈ Set.Ioo a b, f' x < 0) :
    StrictAntiOn f (Set.Ioo a b) := by
  have h := strict_mono_of_deriv_pos (fun x => -f x) (fun x => -f' x) a b
    (fun x hx => (hd x hx).neg) (fun x hx => neg_pos.mpr (hneg x hx))
  intro x hx y hy hxy
  exact neg_lt_neg_iff.mp (h hx hy hxy)
