1. What is proved: the statement in the book and in Lean

  • $T:\mathbb{R}^n\to\mathbb{R}^m$ is one-to-one if and only if $\ker T=\{\mathbf{0}\}$
    theorem injective_iff_ker (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    Function.Injective T ↔ LinearMap.ker T = ⊥
  • Consequence: if $T$ is one-to-one and $T(\mathbf{x})=\mathbf{0}$, then $\mathbf{x}=\mathbf{0}$
    theorem zero_of_injective (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) (h : Function.Injective T)
    (x : Fin n → ℝ) (hx : T x = 0) : x = 0
  • The same equivalence, as it is stated in Mathlib
    theorem mathlib_version (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    LinearMap.ker T = ⊥ ↔ Function.Injective T

The linear transformation $T:\mathbb{R}^n\to\mathbb{R}^m$ is written T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ). “One-to-one” is Function.Injective T: $T(\mathbf{x})=T(\mathbf{y})$ implies $\mathbf{x}=\mathbf{y}$. The kernel $\ker T$${}=\{\mathbf{x}: T(\mathbf{x})$${}=\mathbf{0}\}$ is written LinearMap.ker T (in the goals it appears as T.ker), and the zero subspace $\{\mathbf{0}\}$ is written ⊥. The ⇑T in the goals is simply $T$ viewed as a function.

2. Step by step: one-to-one $\Leftrightarrow\ker T$${}=\{\mathbf{0}\}$

The idea: if $T$ is one-to-one, the only vector with image $\mathbf{0}$ is $\mathbf{0}$, since already $T(\mathbf{0})=\mathbf{0}$. Conversely, if $T(\mathbf{x})=T(\mathbf{y})$, then $T(\mathbf{x}-\mathbf{y})$${}=\mathbf{0}$, so $\mathbf{x}-\mathbf{y}\in\ker T$${}=\{\mathbf{0}\}$. We start from the goal:

The goal
m n : ℕ
T : (Fin n → ℝ) →ₗ[ℝ] Fin m → ℝ
⊢ Function.Injective ⇑T ↔ T.ker = ⊥

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. constructor

    Two directions: mp for $\Rightarrow$ and mpr for $\Leftarrow$.

    What remains to be proved (2 goals)part mp
    ⊢ Function.Injective ⇑T → T.ker = ⊥
    part mpr
    ⊢ T.ker = ⊥ → Function.Injective ⇑T
  2. · intro h

    Direction $\Rightarrow$: we assume that $T$ is one-to-one (hypothesis h).

    What remains to be proved
    h : Function.Injective ⇑T
⊢ T.ker = ⊥
  3. rw [eq_bot_iff]

    $\{\mathbf{0}\}$ is the smallest subspace, so a subspace is equal to it exactly when it is contained in it. The symbol ≤ between subspaces means $\subseteq$.

    What remains to be proved
    ⊢ T.ker ≤ ⊥
  4. intro x hx

    We take a vector $\mathbf{x}$ in the kernel (hypothesis hx) and will show that $\mathbf{x}\in\{\mathbf{0}\}$.

    What remains to be proved
    x : Fin n → ℝ
hx : x ∈ T.ker
⊢ x ∈ ⊥
  5. rw [LinearMap.mem_ker] at hx

    $\mathbf{x}\in\ker T$ means $T(\mathbf{x})=\mathbf{0}$.

    What remains to be proved
    hx : T x = 0
⊢ x ∈ ⊥
  6. rw [Submodule.mem_bot]

    $\mathbf{x}\in\{\mathbf{0}\}$ means $\mathbf{x}=\mathbf{0}$.

    What remains to be proved
    ⊢ x = 0
  7. apply h

    Since $T$ is one-to-one, to show $\mathbf{x}=\mathbf{0}$ it suffices to show $T(\mathbf{x})=T(\mathbf{0})$.

    What remains to be proved
    ⊢ T x = T 0
  8. rw [hx, map_zero]

    This holds, because $T(\mathbf{x})=\mathbf{0}$ and $T(\mathbf{0})=\mathbf{0}$ (theorem map_zero).

    ✓ This part is complete.
  9. · intro h x y hxy

    Direction $\Leftarrow$: we assume $\ker T=\{\mathbf{0}\}$ and take $\mathbf{x},\mathbf{y}$ with $T(\mathbf{x})=T(\mathbf{y})$ (hypothesis hxy). We will show that $\mathbf{x}=\mathbf{y}$.

    What remains to be proved
    m n : ℕ
T : (Fin n → ℝ) →ₗ[ℝ] Fin m → ℝ
h : T.ker = ⊥
x y : Fin n → ℝ
hxy : T x = T y
⊢ x = y
  10. have hsub : x - y ∈ LinearMap.ker T := by

    Intermediate claim: $\mathbf{x}-\mathbf{y}$ belongs to the kernel.

    What remains to be proved
    ⊢ x - y ∈ T.ker
  11. rw [LinearMap.mem_ker, map_sub, hxy, sub_self]

    $T(\mathbf{x}-\mathbf{y})$${}=T(\mathbf{x})-T(\mathbf{y})$${}=T(\mathbf{y})-T(\mathbf{y})$${}=\mathbf{0}$.

    ✓ This part is complete.
  12. rw [h, Submodule.mem_bot, sub_eq_zero] at hsub

    Since the kernel is $\{\mathbf{0}\}$, we have $\mathbf{x}-\mathbf{y}=\mathbf{0}$, that is, $\mathbf{x}=\mathbf{y}$.

    What remains to be proved
    m n : ℕ
T : (Fin n → ℝ) →ₗ[ℝ] Fin m → ℝ
h : T.ker = ⊥
x y : Fin n → ℝ
hxy : T x = T y
hsub : x = y
⊢ x = y
  13. exact hsub

    This is what we wanted.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • LinearMap.mem_ker: $\mathbf{x}\in\ker T\Leftrightarrow T(\mathbf{x})$${}=\mathbf{0}$.
  • Submodule.mem_bot: $\mathbf{x}\in\{\mathbf{0}\}\Leftrightarrow\mathbf{x}$${}=\mathbf{0}$.
  • eq_bot_iff: a subspace is $\{\mathbf{0}\}$ exactly when it is contained in it.
  • map_zero: $T(\mathbf{0})=\mathbf{0}$.
  • map_sub: $T(\mathbf{x}-\mathbf{y})$${}=T(\mathbf{x})-T(\mathbf{y})$.
  • LinearMap.ker_eq_bot: the same equivalence in Mathlib.

namespace Ch4.EnaProsEnaPyrinas

variable {m n : ℕ}

theorem injective_iff_ker (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    Function.Injective T ↔ LinearMap.ker T = ⊥ := by
  constructor
  · intro h
    rw [eq_bot_iff]
    intro x hx
    rw [LinearMap.mem_ker] at hx
    rw [Submodule.mem_bot]
    apply h
    rw [hx, map_zero]
  · intro h x y hxy
    have hsub : x - y ∈ LinearMap.ker T := by
      rw [LinearMap.mem_ker, map_sub, hxy, sub_self]
    rw [h, Submodule.mem_bot, sub_eq_zero] at hsub
    exact hsub

theorem zero_of_injective (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) (h : Function.Injective T)
    (x : Fin n → ℝ) (hx : T x = 0) : x = 0 := by
  apply h
  rw [hx, map_zero]

theorem mathlib_version (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    LinearMap.ker T = ⊥ ↔ Function.Injective T :=
  LinearMap.ker_eq_bot

end Ch4.EnaProsEnaPyrinas
