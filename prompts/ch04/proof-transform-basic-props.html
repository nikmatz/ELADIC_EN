1. What is proved: the statement in the book and in Lean

  • $T(\mathbf{0})=\mathbf{0}$
    theorem image_zero (T : V →ₗ[ℝ] W) : T 0 = 0
  • $T(-\mathbf{u})=-T(\mathbf{u})$
    theorem image_neg (T : V →ₗ[ℝ] W) (u : V) : T (-u) = -T u
  • $T(c_1\mathbf{u}_1+\dots+c_k\mathbf{u}_k)$${}=c_1T(\mathbf{u}_1)+\dots+c_kT(\mathbf{u}_k)$
    theorem image_lincomb (T : V →ₗ[ℝ] W) (k : ℕ) (c : Fin k → ℝ) (u : Fin k → V) :
    T (∑ i, c i • u i) = ∑ i, c i • T (u i)

Here $V,W$ are arbitrary real vector spaces, and $T$ is written T : V →ₗ[ℝ] W. The linear combination $c_1\mathbf{u}_1+\dots+c_k\mathbf{u}_k$ is written ∑ i, c i • u i, where the coefficients c and the vectors u have indices $i=0,\dots,k-1$. The lines inst✝ : … in the goals are the hypotheses that $V,W$ are vector spaces.

2. Step by step: $T(\mathbf{0})=\mathbf{0}$

The idea: $T(\mathbf{0})$${}=T(\mathbf{0}+\mathbf{0})$${}=T(\mathbf{0})+T(\mathbf{0})$, and we cancel $T(\mathbf{0})$ from both sides. We start from the goal:

The goal
V : Type u_1
W : Type u_2
inst✝³ : AddCommGroup V
inst✝² : Module ℝ V
inst✝¹ : AddCommGroup W
inst✝ : Module ℝ W
T : V →ₗ[ℝ] W
⊢ T 0 = 0

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have h : T 0 + T 0 = T 0 + 0 := by

    Intermediate claim: $T(\mathbf{0})+T(\mathbf{0})$${}=T(\mathbf{0})+\mathbf{0}$.

    What remains to be proved
    ⊢ T 0 + T 0 = T 0 + 0
  2. rw [← map_add]

    By linearity, $T(\mathbf{0})+T(\mathbf{0})$${}=T(\mathbf{0}+\mathbf{0})$ (theorem map_add, read from right to left).

    What remains to be proved
    ⊢ T (0 + 0) = T 0 + 0
  3. rw [add_zero, add_zero]

    Since $\mathbf{0}+\mathbf{0}=\mathbf{0}$ and $T(\mathbf{0})+\mathbf{0}$${}=T(\mathbf{0})$, the two sides become identical.

    ✓ This part is complete.
  4. rw [add_right_inj] at h

    We cancel $T(\mathbf{0})$ on the left: $a+b=a+c$ implies $b=c$. Hypothesis h becomes $T(\mathbf{0})=\mathbf{0}$.

    What remains to be proved
    V : Type u_1
W : Type u_2
inst✝³ : AddCommGroup V
inst✝² : Module ℝ V
inst✝¹ : AddCommGroup W
inst✝ : Module ℝ W
T : V →ₗ[ℝ] W
h : T 0 = 0
⊢ T 0 = 0
  5. exact h

    This is what we wanted.

    ✓ No goals: the proof is complete.

4. In Mathlib

The same properties are ready-made in Mathlib, for every linear map:

  • map_zero: $T(\mathbf{0})=\mathbf{0}$.
  • map_neg: $T(-\mathbf{u})=-T(\mathbf{u})$.
  • map_add: $T(\mathbf{u}+\mathbf{v})$${}=T(\mathbf{u})+T(\mathbf{v})$.
  • map_smul: $T(c\,\mathbf{u})=c\,T(\mathbf{u})$.
  • map_sum: the image of a sum is the sum of the images.

import Mathlib

namespace Ch4.VasikesIdiotites

variable {V W : Type*} [AddCommGroup V] [Module ℝ V] [AddCommGroup W] [Module ℝ W]

theorem image_zero (T : V →ₗ[ℝ] W) : T 0 = 0 := by
  have h : T 0 + T 0 = T 0 + 0 := by
    rw [← map_add]
    rw [add_zero, add_zero]
  rw [add_right_inj] at h
  exact h

theorem image_neg (T : V →ₗ[ℝ] W) (u : V) : T (-u) = -T u := by
  rw [← neg_one_smul ℝ u, map_smul, neg_one_smul]

theorem image_lincomb (T : V →ₗ[ℝ] W) (k : ℕ) (c : Fin k → ℝ) (u : Fin k → V) :
    T (∑ i, c i • u i) = ∑ i, c i • T (u i) := by
  rw [map_sum]
  simp only [map_smul]

end Ch4.VasikesIdiotites
