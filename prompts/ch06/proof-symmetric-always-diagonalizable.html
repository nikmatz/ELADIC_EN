Symmetric Matrices: Always Orthogonally Diagonalizable

Chapter 6 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementThe key step of the Spectral Theorem: in a real symmetric matrix $A=A^{T}$ no eigenvalue is defective, that is, $m_g(\lambda)=m_a(\lambda)$ for every eigenvalue $\lambda$. From this, together with the orthogonality of eigenvectors of different eigenvalues, the orthogonal diagonalization $A=Q\Lambda Q^{T}$ follows. Caution: the claim $m_g=m_a$ may not be used as a step in a proof of diagonalizability itself, since it is precisely what is to be shown; the proof goes through the complex inner-product structure or through induction on the dimension.

1. What is proved: the statement in the book and in Lean

  • $m_g(\lambda)=m_a(\lambda)$ for every $\lambda$, in a real symmetric $A$: no eigenvalue is defective
    theorem geom_eq_alg (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) (μ : ℝ) :
    finrank ℝ (End.eigenspace (toEuclideanLin A) μ) = A.charpoly.rootMultiplicity μ
  • The same equality for a symmetric operator on an inner product space
    theorem geom_eq_alg_operator {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    [FiniteDimensional ℝ E] (T : E →ₗ[ℝ] E) (hT : T.IsSymmetric) {m : ℕ}
    (hm : finrank ℝ E = m) (μ : ℝ) :
    finrank ℝ (End.eigenspace T μ) = T.charpoly.rootMultiplicity μ
  • The orthogonal diagonalization $A=Q\Lambda Q^{T}$ with $Q^{T}Q=I$
    theorem orthogonal_diagonalization (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) :
    ∃ Q : Matrix (Fin n) (Fin n) ℝ, Qᵀ * Q = 1 ∧ A = Q * diagonal hA.eigenvalues * Qᵀ
  • Auxiliary: $A$ and the map $\mathbf{x}\mapsto A\mathbf{x}$ of $\mathbb{R}^n$ have the same characteristic polynomial
    theorem charpoly_euclidean (A : Matrix (Fin n) (Fin n) ℝ) :
    (toEuclideanLin A).charpoly = A.charpoly

The symmetric matrix is given by the hypothesis hA : A.IsHermitian: for real matrices, Hermitian means exactly $A^{T}=A$. The geometric multiplicity $m_g(\lambda)$ is the dimension of the eigenspace End.eigenspace (toEuclideanLin A) μ, where toEuclideanLin A is the map $\mathbf{x}\mapsto A\mathbf{x}$ of $\mathbb{R}^n$ with the usual inner product. The algebraic multiplicity $m_a(\lambda)$ is A.charpoly.rootMultiplicity μ. The proof counts: both multiplicities are equal to the number of indices $i$ with $\lambda_i=\lambda$. For $m_g$, Mathlib relies on an orthonormal basis of eigenvectors, which it has constructed beforehand without using $m_g=m_a$. For $m_a$, it relies on the fact that the roots of the characteristic polynomial are $\lambda_1,\dots,\lambda_n$.

2. Where it is in Mathlib

We used the following theorems:

  • LinearMap.IsSymmetric.card_filter_eigenvalues_eq: the dimension of the eigenspace of $\lambda$ is the number of $i$ with $\lambda_i=\lambda$.
  • LinearMap.IsSymmetric.roots_charpoly_eq_eigenvalues: the roots of the characteristic polynomial are $\lambda_1,\dots,\lambda_n$.
  • Polynomial.count_roots: the multiplicity of a root is the number of times it appears in the multiset of roots.
  • Matrix.isSymmetric_toEuclideanLin_iff: $A$ is symmetric exactly when $\mathbf{x}\mapsto A\mathbf{x}$ is a symmetric operator.
  • Matrix.IsHermitian.spectral_theorem: the spectral theorem for Hermitian matrices.

open Matrix Module

-- the general form: a symmetric operator on an inner product space
theorem geom_eq_alg_operator {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    [FiniteDimensional ℝ E] (T : E →ₗ[ℝ] E) (hT : T.IsSymmetric) {m : ℕ}
    (hm : finrank ℝ E = m) (μ : ℝ) :
    finrank ℝ (End.eigenspace T μ) = T.charpoly.rootMultiplicity μ := by
  rw [← Polynomial.count_roots, hT.roots_charpoly_eq_eigenvalues hm, Multiset.count_map,
    ← hT.card_filter_eigenvalues_eq hm μ, Finset.card_def, Finset.filter_val]
  congr 1
  apply Multiset.filter_congr
  intro i _
  rw [Function.comp_apply, eq_comm]

variable {n : ℕ}

theorem charpoly_euclidean (A : Matrix (Fin n) (Fin n) ℝ) :
    (toEuclideanLin A).charpoly = A.charpoly := by
  rw [toEuclideanLin_eq_toLin_orthonormal, charpoly_toLin]

theorem geom_eq_alg (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) (μ : ℝ) :
    finrank ℝ (End.eigenspace (toEuclideanLin A) μ) = A.charpoly.rootMultiplicity μ := by
  rw [← charpoly_euclidean A]
  exact geom_eq_alg_operator _ (isSymmetric_toEuclideanLin_iff.mpr hA) finrank_euclideanSpace μ

theorem orthogonal_diagonalization (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) :
    ∃ Q : Matrix (Fin n) (Fin n) ℝ, Qᵀ * Q = 1 ∧ A = Q * diagonal hA.eigenvalues * Qᵀ := by
  refine ⟨hA.eigenvectorUnitary, ?_, ?_⟩
  · rw [← conjTranspose_eq_transpose_of_trivial, ← star_eq_conjTranspose]
    exact Unitary.coe_star_mul_self hA.eigenvectorUnitary
  · conv_lhs => rw [hA.spectral_theorem]
    rw [Unitary.conjStarAlgAut_apply, star_eq_conjTranspose,
      conjTranspose_eq_transpose_of_trivial, RCLike.ofReal_real_eq_id, Function.id_comp]

end Ch6.SymmetrikosDiagonopoiisimos
