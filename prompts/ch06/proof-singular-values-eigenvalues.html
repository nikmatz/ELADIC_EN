Singular Values from the Eigenvalues of AᵀA

StatementThe singular values of $A$ ($m\times n$) are $\sigma_i=\sqrt{\lambda_i(A^{T}A)}$ for $i=1,\dots,\min(m,n)$, with the eigenvalues of $A^{T}A$ in decreasing order. If $r=\operatorname{rank}(A)$, then $\sigma_1,\dots,\sigma_r\gt 0$ and $\sigma_{r+1}=\dots=\sigma_{\min(m,n)}=0$.

1. What is proved: the statement in the book and in Lean

  • $\sigma_i=\sqrt{\lambda_i(A^{T}A)}$
    theorem singular_sqrt (T : E →ₗ[ℝ] F) {n : ℕ} (hn : finrank ℝ E = n) (i : Fin n) :
    T.singularValues i = √(T.isSymmetric_adjoint_comp_self.eigenvalues hn i)
  • Equivalently, $\sigma_i^{2}=\lambda_i(A^{T}A)$
    theorem singular_sq (T : E →ₗ[ℝ] F) {n : ℕ} (hn : finrank ℝ E = n) (i : Fin n) :
    T.singularValues i ^ 2 = T.isSymmetric_adjoint_comp_self.eigenvalues hn i
  • The singular values are in decreasing order: $\sigma_1\ge\sigma_2\ge\cdots$
    theorem antitone_singular (T : E →ₗ[ℝ] F) : Antitone T.singularValues
  • $\sigma_i\gt 0$ exactly for the first $r=\operatorname{rank}(A)$ positions
    theorem singular_pos_iff (T : E →ₗ[ℝ] F) (i : ℕ) :
    0 < T.singularValues i ↔ i < finrank ℝ (range T)
  • $\sigma_i=0$ for all positions after the first $r$
    theorem singular_zero_iff (T : E →ₗ[ℝ] F) (i : ℕ) :
    T.singularValues i = 0 ↔ finrank ℝ (range T) ≤ i

Mathlib states the theorem for a linear map $T:E\to F$ between finite-dimensional inner product spaces; an $m\times n$ matrix $A$ gives the map $T(\mathbf{x})=A\mathbf{x}$ from $\mathbb{R}^n$ to $\mathbb{R}^m$. $A^{T}A$ corresponds to adjoint T ∘ₗ T, which is symmetric, and its eigenvalues in decreasing order are T.isSymmetric_adjoint_comp_self.eigenvalues hn i. The singular values are the sequence T.singularValues, indexed from $0$: T.singularValues 0 is $\sigma_1$. After position $n=\dim E$ the sequence is zero. The rank $r$ is the dimension of the image, finrank ℝ (range T), so $\sigma_i\gt 0$ exactly for positions $0,\dots,r-1$, that is, for $\sigma_1,\dots,\sigma_r$.

2. Where it is in Mathlib

We used the following theorems:

  • LinearMap.singularValues: the singular values of a linear map.
  • LinearMap.singularValues_fin: each singular value is the square root of an eigenvalue of $T^{*}T$.
  • LinearMap.sq_singularValues_fin: the square of each singular value is an eigenvalue of $T^{*}T$.
  • LinearMap.singularValues_antitone: the singular values are decreasing.
  • LinearMap.singularValues_pos_iff_lt_finrank_range: $\sigma_i\gt 0$ exactly for the positions before the rank.
  • LinearMap.singularValues_eq_zero_iff_le_finrank_range: $\sigma_i=0$ exactly for the positions from the rank onward.
