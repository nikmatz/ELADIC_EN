Non-trivial Solutions of a Homogeneous System

Chapter 3 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor a homogeneous system $Ax=0$ with $A$ of size $m\times n$: if $\operatorname{rank}(A)\lt n$ there are infinitely many non-trivial solutions; if $\operatorname{rank}(A)=n$ (full column rank, which requires $m\ge n$) the only solution is the trivial one. In particular, if $A$ is square this is equivalent to $\det(A)\ne 0$.

  • If $\operatorname{rank}(A)\lt n$, there is a nonzero solution

  • If $\operatorname{rank}(A)\lt n$, there are infinitely many solutions

  • If $\operatorname{rank}(A)=n$, the only solution is the zero solution

    (hx : A *ᵥ x = 0) : x = 0
  • Full column rank requires $m\ge n$
    theorem full_rank_needs (A : Matrix (Fin m) (Fin n) ℝ) (h : A.rank = n) : n ≤ m
  • For square $A$: only the zero solution $\Leftrightarrow\det(A)\ne 0$
    theorem square_iff (A : Matrix (Fin n) (Fin n) ℝ) :
    (∀ x, A *ᵥ x = 0 → x = 0) ↔ A.det ≠ 0

The rank is written A.rank, and the null space $\mathcal{N}(A)=\{x: Ax=0\}$ is written LinearMap.ker A.mulVecLin. The subspace $\{0\}$ is ⊥. “Infinitely many solutions” is written {x | A *ᵥ x = 0}.Infinite: the multiples $cx$ of a nonzero solution are all different from one another. The inequality $m\ge n$ holds because the rank does not exceed the number of rows.

2. Step by step: if $\operatorname{rank}(A)\lt n$, there is a nonzero solution

The idea: by the rank–nullity theorem, $\dim\mathcal{N}(A)$${}=n-\operatorname{rank}(A)\gt 0$, so the null space contains a nonzero vector. We start from the goal:

The goal
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
h : A.rank < n
⊢ ∃ x, x ≠ 0 ∧ A *ᵥ x = 0

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. have hrn : A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
  rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]

    Rank–nullity theorem: $\operatorname{rank}(A)+\dim\mathcal{N}(A)$${}=n$ (hypothesis hrn).

    What remains to be proved
    hrn : A.rank + finrank ℝ ↥A.mulVecLin.ker = n
⊢ ∃ x, x ≠ 0 ∧ A *ᵥ x = 0
  2. have hk : LinearMap.ker A.mulVecLin ≠ ⊥ := by

    We will show that the null space is not $\{0\}$.

    What remains to be proved
    ⊢ A.mulVecLin.ker ≠ ⊥
  3. intro hbot

    We assume the opposite, $\mathcal{N}(A)=\{0\}$, and will reach a contradiction (False).

    What remains to be proved
    hbot : A.mulVecLin.ker = ⊥
⊢ False
  4. rw [hbot, finrank_bot] at hrn

    Then $\dim\mathcal{N}(A)=0$, so $\operatorname{rank}(A)=n$.

    What remains to be proved
    hrn : A.rank + 0 = n
⊢ False
  5. omega

    This contradicts the hypothesis $\operatorname{rank}(A)\lt n$. The contradiction is found by omega.

    ✓ This part is complete.
  6. obtain ⟨x, hx, hne⟩ := Submodule.exists_mem_ne_zero_of_ne_bot hk

    A subspace different from $\{0\}$ contains a nonzero vector $x$.

    What remains to be proved
    m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
h : A.rank < n
hrn : A.rank + finrank ℝ ↥A.mulVecLin.ker = n
hk : A.mulVecLin.ker ≠ ⊥
x : Fin n → ℝ
hx : x ∈ A.mulVecLin.ker
hne : x ≠ 0
⊢ ∃ x, x ≠ 0 ∧ A *ᵥ x = 0
  7. exact ⟨x, hne, LinearMap.mem_ker.mp hx⟩

    This $x$ is the nonzero solution, because $x\in\mathcal{N}(A)$ means $Ax=0$.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • LinearMap.finrank_range_add_finrank_ker: the rank–nullity theorem.
  • Submodule.exists_mem_ne_zero_of_ne_bot: a subspace different from $\{0\}$ has a nonzero element.
  • Matrix.exists_mulVec_eq_zero_iff: for square $A$, there is a nonzero solution exactly when $\det A=0$.
  • Matrix.rank_le_card_height: the rank does not exceed the number of rows.

import Mathlib

namespace Ch3.OmogenesSystima
open Matrix Module

variable {m n : ℕ}

theorem nonzero_of_rank_lt (A : Matrix (Fin m) (Fin n) ℝ) (h : A.rank < n) :
    ∃ x : Fin n → ℝ, x ≠ 0 ∧ A *ᵥ x = 0 := by
  have hrn : A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
    rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]
  have hk : LinearMap.ker A.mulVecLin ≠ ⊥ := by
    intro hbot
    rw [hbot, finrank_bot] at hrn
    omega
  obtain ⟨x, hx, hne⟩ := Submodule.exists_mem_ne_zero_of_ne_bot hk
  exact ⟨x, hne, LinearMap.mem_ker.mp hx⟩

theorem multiples (A : Matrix (Fin m) (Fin n) ℝ) (x : Fin n → ℝ) (hx : A *ᵥ x = 0) (c : ℝ) :
    A *ᵥ (c • x) = 0 := by
  rw [mulVec_smul, hx, smul_zero]

theorem infinitely_many (A : Matrix (Fin m) (Fin n) ℝ) (h : A.rank < n) :
    {x : Fin n → ℝ | A *ᵥ x = 0}.Infinite := by
  obtain ⟨x, hx0, hx⟩ := nonzero_of_rank_lt A h
  exact Set.infinite_of_injective_forall_mem (smul_left_injective ℝ hx0)
    (fun c => multiples A x hx c)

theorem zero_of_rank_eq (A : Matrix (Fin m) (Fin n) ℝ) (h : A.rank = n) (x : Fin n → ℝ)
    (hx : A *ᵥ x = 0) : x = 0 := by
  have hrn : A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
    rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]
  have hk : LinearMap.ker A.mulVecLin = ⊥ := by
    rw [← Submodule.finrank_eq_zero]
    omega
  have hmem : x ∈ LinearMap.ker A.mulVecLin := LinearMap.mem_ker.mpr hx
  rw [hk, Submodule.mem_bot] at hmem
  exact hmem

theorem full_rank_needs (A : Matrix (Fin m) (Fin n) ℝ) (h : A.rank = n) : n ≤ m := by
  have hr : A.rank ≤ m := by simpa using A.rank_le_card_height
  omega

theorem square_iff (A : Matrix (Fin n) (Fin n) ℝ) :
    (∀ x, A *ᵥ x = 0 → x = 0) ↔ A.det ≠ 0 := by
  rw [← not_iff_not, not_not, ← exists_mulVec_eq_zero_iff]
  push Not
  constructor
  · rintro ⟨x, h1, h2⟩
    exact ⟨x, h2, h1⟩
  · rintro ⟨x, h1, h2⟩
    exact ⟨x, h2, h1⟩

end Ch3.OmogenesSystima
