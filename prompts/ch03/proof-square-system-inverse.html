1. What is proved: the statement in the book and in Lean

  • $\det(A)\ne 0\Leftrightarrow\operatorname{rank}(A)$${}=n$
    theorem det_iff_rank (A : Matrix (Fin n) (Fin n) ℝ) : A.det ≠ 0 ↔ A.rank = n
  • If $\det(A)\ne 0$: $\mathbf{x}$ is a solution $\Leftrightarrow\mathbf{x}$${}=A^{-1}\mathbf{b}$, so the solution exists and is unique
    theorem unique_solution (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (b x : Fin n → ℝ) :
    A *ᵥ x = b ↔ x = A⁻¹ *ᵥ b

The inverse is written A⁻¹, and $A^{-1}\mathbf{b}$ is written A⁻¹ *ᵥ b. The term hA.isUnit states the hypothesis $\det A\neq 0$ in the form required by the Mathlib theorems. The equivalence with the rank is proved using the rank–nullity theorem.

2. Step by step: the unique solution is $\mathbf{x}=A^{-1}\mathbf{b}$

We show that $\mathbf{x}$ is a solution exactly when $\mathbf{x}=A^{-1}\mathbf{b}$. This says at the same time that a solution exists and that it is unique. We start from the goal:

The goal
n : ℕ
A : Matrix (Fin n) (Fin n) ℝ
hA : A.det ≠ 0
b x : Fin n → ℝ
⊢ A *ᵥ x = b ↔ x = A⁻¹ *ᵥ b

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

    Direction $\Rightarrow$: $\mathbf{x}$ is a solution.

⊢ x = A⁻¹ *ᵥ b

    We replace $\mathbf{b}$ with $A\mathbf{x}$.

    What remains to be proved
    ⊢ x = A⁻¹ *ᵥ A *ᵥ x
  4. rw [mulVec_mulVec]

    $A^{-1}(A\mathbf{x})$${}=(A^{-1}A)\,\mathbf{x}$.

    What remains to be proved
    ⊢ x = (A⁻¹ * A) *ᵥ x
  5. rw [nonsing_inv_mul A hA.isUnit]

    $A^{-1}A=I$, because $\det A\neq 0$.

    What remains to be proved
    ⊢ x = 1 *ᵥ x
  6. rw [one_mulVec]

    $I\mathbf{x}=\mathbf{x}$.

    ✓ This part is complete.

    Direction $\Leftarrow$: $\mathbf{x}$ is $A^{-1}\mathbf{b}$.

    What remains to be proved

    What remains to be proved

4. In Mathlib

We used the following theorems:

  • Matrix.mulVec_mulVec: $A(B\mathbf{x})=(AB)\,\mathbf{x}$.
  • Matrix.nonsing_inv_mul: $A^{-1}A=I$ when $\det A\neq 0$.
  • Matrix.mul_nonsing_inv: $AA^{-1}=I$ when $\det A\neq 0$.
  • Matrix.rank_of_isUnit: an invertible $n\times n$ matrix has rank $n$.

import Mathlib

namespace Ch3.TetragonikoSystima
open Matrix Module

variable {n : ℕ}

theorem det_iff_rank (A : Matrix (Fin n) (Fin n) ℝ) : A.det ≠ 0 ↔ A.rank = n := by
  constructor
  · intro h
    have := A.rank_of_isUnit ((isUnit_iff_isUnit_det A).mpr h.isUnit)
    simpa using this
  · intro h hdet
    obtain ⟨x, hx, hAx⟩ := exists_mulVec_eq_zero_iff.mpr hdet
    have hrn : A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
      rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]
    have hk : LinearMap.ker A.mulVecLin = ⊥ := by
      rw [← Submodule.finrank_eq_zero]
      omega
    have hmem : x ∈ LinearMap.ker A.mulVecLin := LinearMap.mem_ker.mpr hAx
    rw [hk, Submodule.mem_bot] at hmem
    exact hx hmem

theorem unique_solution (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (b x : Fin n → ℝ) :
    A *ᵥ x = b ↔ x = A⁻¹ *ᵥ b := by
  constructor
  · intro h
    rw [← h]
    rw [mulVec_mulVec]
    rw [nonsing_inv_mul A hA.isUnit]
    rw [one_mulVec]
  · intro h
    rw [h]
    rw [mulVec_mulVec]
    rw [mul_nonsing_inv A hA.isUnit]
    rw [one_mulVec]

theorem solves (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (b : Fin n → ℝ) :
    A *ᵥ (A⁻¹ *ᵥ b) = b := by
  rw [mulVec_mulVec, mul_nonsing_inv A hA.isUnit, one_mulVec]

end Ch3.TetragonikoSystima
