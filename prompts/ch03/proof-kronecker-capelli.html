Kronecker–Capelli Theorem

Chapter 3 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementKronecker–Capelli Theorem: the system $Ax=b$, with $\tilde{A}=[A\mid b]$ the augmented matrix, is consistent $\Leftrightarrow\operatorname{rank}(A)=\operatorname{rank}(\tilde{A})$. In that case: if $\operatorname{rank}(A)=n$ there is a unique solution; if $\operatorname{rank}(A)\lt n$ there are infinitely many solutions with $n-\operatorname{rank}(A)$ free parameters.

1. What is proved: the statement in the book and in Lean

  • $Ax=b$ is consistent $\Leftrightarrow\operatorname{rank}(A)$${}=\operatorname{rank}(\tilde{A})$
    theorem compatible_iff (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    (∃ x, A *ᵥ x = b) ↔ A.rank = (augmented A b).rank
  • If $\operatorname{rank}(A)=n$, the solution is unique
    theorem unique_of_rank (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (h : A.rank = n)
    (x y : Fin n → ℝ) (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : x = y
  • The solutions of the homogeneous system form a space of dimension $n-\operatorname{rank}(A)$: this is the number of free parameters
    theorem dim_solutions (A : Matrix (Fin m) (Fin n) ℝ) :
    finrank ℝ (LinearMap.ker A.mulVecLin) = n - A.rank

The augmented matrix $\tilde{A}=[A\mid b]$ is defined in the code as augmented A b, an $m\times(n+1)$ matrix whose last column is $b$. The columns of a matrix are written A.col, and the space they span, the column space $\mathcal{C}(A)$, is written span ℝ (Set.range A.col). For the case $\operatorname{rank}(A)\lt n$: every solution is a particular solution plus a solution of the homogeneous system, and the solutions of the homogeneous system form a space of dimension $n-\operatorname{rank}(A)$.

2. Step by step: consistent $\Leftrightarrow\operatorname{rank}(A)$${}=\operatorname{rank}(\tilde{A})$

The idea: the rank is the dimension of the column space. The matrix $\tilde{A}$ has one extra column, $b$, and the rank stays the same exactly when $b$ already belongs to the column space of $A$. We start from the goal:

The goal
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
⊢ (∃ x, A *ᵥ x = b) ↔ A.rank = (augmented A b).rank

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [solvable_iff_mem]

    The system has a solution exactly when $b$ is a linear combination of the columns of $A$, that is, $b\in\mathcal{C}(A)$ (lemma solvable_iff_mem, the exercise below).

    What remains to be proved
    ⊢ b ∈ span ℝ (Set.range A.col) ↔ A.rank = (augmented A b).rank
  2. rw [← finrank_span_range_col, ← finrank_span_range_col]

    The rank of a matrix is the dimension of the space spanned by its columns.

    What remains to be proved
    ⊢ b ∈ span ℝ (Set.range A.col) ↔
  finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (Set.range (augmented A b).col))
  3. rw [cols_augmented]

    The columns of $\tilde{A}$ are the columns of $A$ together with $b$ (lemma cols_augmented).

    What remains to be proved
    ⊢ b ∈ span ℝ (Set.range A.col) ↔ finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (insert b (Set.range A.col)))

    Then adding $b$ does not change the spanned space, and hence not its dimension either.

    $\mathcal{C}(A)$ is contained in the space spanned by the columns of $A$ together with $b$.

4. In Mathlib

We used the following theorems:

  • Matrix.finrank_span_range_col: the rank is the dimension of the column space.
  • Matrix.range_mulVecLin: the image of $\mathbf{x}\mapsto A\mathbf{x}$ is the column space.
  • Submodule.span_insert_eq_span: adding a vector that already lies in the span does not change the spanned space.
  • Submodule.eq_of_le_of_finrank_eq: a subspace inside another one of the same dimension is equal to it.
  • LinearMap.finrank_range_add_finrank_ker: the rank–nullity theorem.

import Mathlib

namespace Ch3.KroneckerCapelli
open Matrix Module Submodule

variable {m n : ℕ}

/-- The augmented matrix [A | b]: the columns of A, followed by b as the last column. -/
def augmented (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) : Matrix (Fin m) (Fin (n + 1)) ℝ :=
  Matrix.of fun i => Fin.snoc (A i) (b i)

theorem cols_augmented (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    Set.range (augmented A b).col = insert b (Set.range A.col) := by
  ext v
  simp only [Set.mem_range, Set.mem_insert_iff]
  constructor
  · rintro ⟨j, rfl⟩
    induction j using Fin.lastCases with
    | last => left; funext i; simp [augmented]
    | cast k => right; exact ⟨k, by funext i; simp [augmented]⟩
  · rintro (rfl | ⟨k, rfl⟩)
    · exact ⟨Fin.last n, by funext i; simp [augmented]⟩
    · exact ⟨k.castSucc, by funext i; simp [augmented]⟩

theorem solvable_iff_mem (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    (∃ x, A *ᵥ x = b) ↔ b ∈ span ℝ (Set.range A.col) := by
  rw [← range_mulVecLin, LinearMap.mem_range]
  rfl

theorem compatible_iff (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    (∃ x, A *ᵥ x = b) ↔ A.rank = (augmented A b).rank := by
  rw [solvable_iff_mem]
  rw [← finrank_span_range_col, ← finrank_span_range_col]
  rw [cols_augmented]
  constructor
  · intro hb
    rw [span_insert_eq_span hb]
  · intro h
    have hle : span ℝ (Set.range A.col) ≤ span ℝ (insert b (Set.range A.col)) :=
      span_mono (Set.subset_insert b _)
    have heq := eq_of_le_of_finrank_eq hle h
    rw [heq]
    exact subset_span (Set.mem_insert b _)

theorem dim_solutions (A : Matrix (Fin m) (Fin n) ℝ) :
    finrank ℝ (LinearMap.ker A.mulVecLin) = n - A.rank := by
  have h := LinearMap.finrank_range_add_finrank_ker A.mulVecLin
  rw [finrank_range_mulVecLin, finrank_fin_fun] at h
  omega

theorem unique_of_rank (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (h : A.rank = n)
    (x y : Fin n → ℝ) (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : x = y := by
  have hk : LinearMap.ker A.mulVecLin = ⊥ := by
    rw [← Submodule.finrank_eq_zero, dim_solutions, h, Nat.sub_self]
  have hmem : x - y ∈ LinearMap.ker A.mulVecLin := by
    rw [LinearMap.mem_ker, mulVecLin_apply, mulVec_sub, hx, hy, sub_self]
  rw [hk, Submodule.mem_bot] at hmem
  exact sub_eq_zero.mp hmem

end Ch3.KroneckerCapelli
