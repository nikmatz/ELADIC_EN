The Vandermonde Matrix and Interpolation

Chapter 3 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementFor $n+1$ points $(x_0,y_0),\dots,(x_n,y_n)$ with pairwise distinct abscissas ($x_i\ne x_j$ for $i\ne j$), the unique polynomial $p(x)=a_0+a_1 x+\dots+a_n x^n$ of degree $\le n$ that interpolates them satisfies $V a=y$ with $V_{ij}=x_i^{\,j}$ (the Vandermonde matrix). Since the $x_i$ are distinct, $\det(V)\ne 0$ and the solution is unique.

1. What is proved: the statement in the book and in Lean

  • $V_{ij}=x_i^{\,j}$, with indices starting from $0$
    theorem entry (x : Fin (n + 1) → ℝ) (i j : Fin (n + 1)) : vandermonde x i j = x i ^ (j : ℕ)
  • The $i$th equation of $Va=y$ is $p(x_i)$${}=a_0+a_1x_i+\dots+a_nx_i^n$${}=y_i$
    theorem system_row (x a : Fin (n + 1) → ℝ) (i : Fin (n + 1)) :
    (vandermonde x *ᵥ a) i = ∑ j, a j * x i ^ (j : ℕ)
  • If the $x_i$ are distinct, then $\det(V)\ne 0$
    theorem det_ne_zero (x : Fin (n + 1) → ℝ) (hx : Function.Injective x) :
    (vandermonde x).det ≠ 0
  • Hence $Va=y$ has a unique solution: the coefficients of the interpolating polynomial
    theorem unique_coeffs (x : Fin (n + 1) → ℝ) (hx : Function.Injective x) (y : Fin (n + 1) → ℝ) :
    ∃! a : Fin (n + 1) → ℝ, vandermonde x *ᵥ a = y

The $n+1$ points have abscissas x : Fin (n + 1) → ℝ and ordinates y. “Pairwise distinct” is written Function.Injective x: if $x_i=x_j$, then $i=j$. The Vandermonde matrix is vandermonde x, and the coefficients $a_0,\dots,a_n$ of the polynomial are a. The symbol ∃! means “there exists exactly one”.

2. Where it is in Mathlib

We used the following theorems:

  • Matrix.vandermonde: the Vandermonde matrix.
  • Matrix.det_vandermonde_ne_zero_iff: $\det(V)\neq 0$ exactly when the $x_i$ are distinct.
  • Lagrange.interpolate: the Lagrange interpolating polynomial, ready-made in Mathlib.

import Mathlib

namespace Ch3.Vandermonde
open Matrix

variable {n : ℕ}

theorem entry (x : Fin (n + 1) → ℝ) (i j : Fin (n + 1)) : vandermonde x i j = x i ^ (j : ℕ) :=
  vandermonde_apply x i j

theorem system_row (x a : Fin (n + 1) → ℝ) (i : Fin (n + 1)) :
    (vandermonde x *ᵥ a) i = ∑ j, a j * x i ^ (j : ℕ) := by
  simp only [mulVec, dotProduct, vandermonde_apply]
  exact Finset.sum_congr rfl (fun j _ => mul_comm _ _)

theorem det_ne_zero (x : Fin (n + 1) → ℝ) (hx : Function.Injective x) :
    (vandermonde x).det ≠ 0 :=
  det_vandermonde_ne_zero_iff.mpr hx

theorem unique_coeffs (x : Fin (n + 1) → ℝ) (hx : Function.Injective x) (y : Fin (n + 1) → ℝ) :
    ∃! a : Fin (n + 1) → ℝ, vandermonde x *ᵥ a = y := by
  have hV := det_ne_zero x hx
  refine ExistsUnique.intro ((vandermonde x)⁻¹ *ᵥ y) ?_ ?_
  · rw [mulVec_mulVec, mul_nonsing_inv _ hV.isUnit, one_mulVec]
  · intro a ha
    rw [← ha, mulVec_mulVec, nonsing_inv_mul _ hV.isUnit, one_mulVec]

end Ch3.Vandermonde
