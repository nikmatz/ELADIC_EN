1. What is proved: the statement in the book and in Lean

  • If $\det(A)\neq0$, then $\mathbf{x}$ is a solution of $A\mathbf{x}=\mathbf{b}$ exactly when $x_i=\dfrac{\det(A_i)}{\det(A)}$ for every $i$
    theorem cramer_solution (A : Matrix (Fin n) (Fin n) ℝ) (b : Fin n → ℝ) (hA : A.det ≠ 0)
    (x : Fin n → ℝ) : A *ᵥ x = b ↔ ∀ i, x i = (A.updateCol i b).det / A.det

The matrix $A_i$, that is, $A$ with its $i$th column replaced by $\mathbf{b}$, is written A.updateCol i b. The equivalence says that a vector $\mathbf{x}$ is a solution exactly when each of its coordinates is given by the formula, so it contains both the existence and the uniqueness of the solution. The proof uses the vector with coordinates $\det(A_1),\dots,\det(A_n)$, which in Mathlib is called cramer A b, and the relation $A\cdot\big(\det A_1,\dots,\det A_n\big)$${}=\det(A)\,\mathbf{b}$.

2. Where it is in Mathlib

We used the following theorems:

  • Matrix.cramer: the vector with coordinates $\det(A_i)$.
  • Matrix.cramer_apply: its $i$th coordinate is $\det(A_i)$.
  • Matrix.mulVec_cramer: $A\cdot\mathrm{cramer}(A,\mathbf{b})$${}=\det(A)\,\mathbf{b}$.
  • Matrix.exists_mulVec_eq_zero_iff: $A\mathbf{x}=\mathbf{0}$ has a nonzero solution exactly when $\det A=0$.

import Mathlib

namespace Ch3.Cramer
open Matrix

variable {n : ℕ}

theorem cramer_solution (A : Matrix (Fin n) (Fin n) ℝ) (b : Fin n → ℝ) (hA : A.det ≠ 0)
    (x : Fin n → ℝ) : A *ᵥ x = b ↔ ∀ i, x i = (A.updateCol i b).det / A.det := by
  have key : A *ᵥ (A.det⁻¹ • cramer A b) = b := by
    rw [mulVec_smul, mulVec_cramer, smul_smul, inv_mul_cancel₀ hA, one_smul]
  have hx₀ : A.det⁻¹ • cramer A b = fun i => (A.updateCol i b).det / A.det := by
    funext i
    rw [Pi.smul_apply, cramer_apply, smul_eq_mul, div_eq_inv_mul]
  rw [hx₀] at key
  constructor
  · intro h i
    have h2 : A *ᵥ (x - fun i => (A.updateCol i b).det / A.det) = 0 := by
      rw [mulVec_sub, h, key, sub_self]
    have h3 : (x - fun i => (A.updateCol i b).det / A.det) = 0 := by
      by_contra hne
      exact hA (exists_mulVec_eq_zero_iff.mp ⟨_, hne, h2⟩)
    rw [sub_eq_zero] at h3
    rw [h3]
  · intro h
    have hx : x = fun i => (A.updateCol i b).det / A.det := funext h
    rw [hx, key]

end Ch3.Cramer
