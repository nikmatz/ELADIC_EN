1. What is proved: the statement in the book and in Lean

  • Every solution can be written as $\mathbf{x}$${}=\mathbf{x}_p+\mathbf{x}_h$ with $A\mathbf{x}_h=\mathbf{0}$, and conversely
    theorem general_solution (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (xp : Fin n → ℝ)
    (hp : A *ᵥ xp = b) (x : Fin n → ℝ) :
    A *ᵥ x = b ↔ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh
  • The difference of two solutions is a solution of the homogeneous system
    theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (x - y) = 0

The matrix is $m\times n$ (Matrix (Fin m) (Fin n) ℝ), and $A\mathbf{x}$ is written A *ᵥ x. The particular solution $\mathbf{x}_p$ is called xp, and the hypothesis hp says that $A\mathbf{x}_p=\mathbf{b}$. The system is consistent precisely because this particular solution exists.

2. Step by step: every solution is $\mathbf{x}_p+\mathbf{x}_h$

We prove something slightly stronger: $\mathbf{x}$ is a solution exactly when it can be written as $\mathbf{x}_p+\mathbf{x}_h$ with $\mathbf{x}_h$ a solution of the homogeneous system. We start from the goal:

The goal
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
xp : Fin n → ℝ
hp : A *ᵥ xp = b
x : Fin n → ℝ
⊢ A *ᵥ x = b ↔ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. constructor

    Two directions: mp for $\Rightarrow$ and mpr for $\Leftarrow$.

    What remains to be proved (2 goals)part mp
    ⊢ A *ᵥ x = b → ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh
    part mpr
    ⊢ (∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh) → A *ᵥ x = b
  2. · intro hx

    Direction $\Rightarrow$: we assume that $\mathbf{x}$ is a solution (hypothesis hx).

    What remains to be proved
    hx : A *ᵥ x = b
⊢ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh
  3. refine ⟨x - xp, ?_, ?_⟩

    We take $\mathbf{x}_h$${}=\mathbf{x}-\mathbf{x}_p$. Two goals remain: that $\mathbf{x}_h$ solves the homogeneous system and that $\mathbf{x}$${}=\mathbf{x}_p+\mathbf{x}_h$.

    What remains to be proved (2 goals)part mp.refine_1
    ⊢ A *ᵥ (x - xp) = 0
    part mp.refine_2
    ⊢ x = xp + (x - xp)
  4. · rw [mulVec_sub, hx, hp, sub_self]

    $A(\mathbf{x}-\mathbf{x}_p)$${}=A\mathbf{x}-A\mathbf{x}_p$${}=\mathbf{b}-\mathbf{b}$${}=\mathbf{0}$.

    ✓ This part is complete.
  5. · abel

    $\mathbf{x}_p+(\mathbf{x}-\mathbf{x}_p)$${}=\mathbf{x}$. These addition manipulations are done by abel.

    ✓ This part is complete.
  6. · rintro ⟨xh, hh, rfl⟩

    Direction $\Leftarrow$: we have $\mathbf{x}$${}=\mathbf{x}_p+\mathbf{x}_h$ with $A\mathbf{x}_h=\mathbf{0}$. The rfl replaces $\mathbf{x}$ with $\mathbf{x}_p+\mathbf{x}_h$.

    What remains to be proved
    m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
xp : Fin n → ℝ
hp : A *ᵥ xp = b
xh : Fin n → ℝ
hh : A *ᵥ xh = 0
⊢ A *ᵥ (xp + xh) = b
  7. rw [mulVec_add, hp, hh, add_zero]

    $A(\mathbf{x}_p+\mathbf{x}_h)$${}=A\mathbf{x}_p+A\mathbf{x}_h$${}=\mathbf{b}+\mathbf{0}$${}=\mathbf{b}$.

    ✓ No goals: the proof is complete.

namespace Ch3.DomiLyseon
open Matrix

variable {m n : ℕ}

theorem general_solution (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (xp : Fin n → ℝ)
    (hp : A *ᵥ xp = b) (x : Fin n → ℝ) :
    A *ᵥ x = b ↔ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh := by
  constructor
  · intro hx
    refine ⟨x - xp, ?_, ?_⟩
    · rw [mulVec_sub, hx, hp, sub_self]
    · abel
  · rintro ⟨xh, hh, rfl⟩
    rw [mulVec_add, hp, hh, add_zero]

theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (x - y) = 0 := by
  rw [mulVec_sub, hx, hy, sub_self]

end Ch3.DomiLyseon
