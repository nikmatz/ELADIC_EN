1. What is proved: the statement in the book and in Lean

  • The systems $A\mathbf{x}=\mathbf{b}$ and $(EA)\mathbf{x}=E\mathbf{b}$ have the same solutions when $\det E\neq 0$
    theorem same_solutions (E : Matrix (Fin m) (Fin m) ℝ) (hE : E.det ≠ 0)
    (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x : Fin n → ℝ) :
    A *ᵥ x = b ↔ (E * A) *ᵥ x = E *ᵥ b
  • (i) The matrix that interchanges two rows is invertible
    theorem swap_invertible (i j : Fin m) (h : i ≠ j) :
    ((Equiv.swap i j).permMatrix ℝ).det ≠ 0
  • (ii) The matrix that multiplies a row by $c\neq 0$ is invertible
    theorem scale_invertible (i : Fin m) (c : ℝ) (hc : c ≠ 0) :
    (diagonal (Function.update (fun _ => (1 : ℝ)) i c)).det ≠ 0
  • (iii) The matrix that adds a multiple of one row to another is invertible
    theorem add_row_invertible (i j : Fin m) (h : i ≠ j) (c : ℝ) :
    (transvection i j c).det ≠ 0

The three elementary matrices in Mathlib: (i) the permutation matrix (Equiv.swap i j).permMatrix ℝ, which interchanges rows $i$ and $j$; (ii) the diagonal matrix with $c$ in position $i$ and $1$ in the others; (iii) transvection i j c, which adds $c$ times row $j$ to row $i$. Multiplying on the left by these matrices performs the corresponding operation on the rows of the augmented matrix. Their determinants are $-1$, $c$ and $1$, so they are invertible, and the first theorem shows that the solutions do not change.

2. Step by step: multiplying by an invertible matrix does not change the solutions

Every elementary row operation is carried out by multiplying on the left by an elementary matrix $E$, which is invertible. So it suffices to show that $A\mathbf{x}=\mathbf{b}$ and $(EA)\mathbf{x}=E\mathbf{b}$ have the same solutions for every $E$ with $\det E\neq 0$. We start from the goal:

The goal
m n : ℕ
E : Matrix (Fin m) (Fin m) ℝ
hE : E.det ≠ 0
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
x : Fin n → ℝ
⊢ A *ᵥ x = b ↔ (E * A) *ᵥ x = E *ᵥ b

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. rw [← mulVec_mulVec]

    We write $(EA)\mathbf{x}=E(A\mathbf{x})$ (theorem mulVec_mulVec).

    What remains to be proved
    ⊢ A *ᵥ x = b ↔ E *ᵥ A *ᵥ x = E *ᵥ b
  2. constructor

    Two directions: mp for $\Rightarrow$ and mpr for $\Leftarrow$.

    What remains to be proved (2 goals)part mp

    part mpr
    ⊢ E *ᵥ A *ᵥ x = E *ᵥ b → A *ᵥ x = b

    Direction $\Rightarrow$: we assume that $A\mathbf{x}=\mathbf{b}$.

    What remains to be proved
    h : A *ᵥ x = b
⊢ E *ᵥ A *ᵥ x = E *ᵥ b

    Then $E(A\mathbf{x})=E\mathbf{b}$, simply by substitution.

    ✓ This part is complete.

    Direction $\Leftarrow$: we assume that $E(A\mathbf{x})=E\mathbf{b}$.

    What remains to be proved

    We multiply both sides by $E^{-1}$.

    What remains to be proved
    h2 : E⁻¹ *ᵥ E *ᵥ A *ᵥ x = E⁻¹ *ᵥ E *ᵥ b
⊢ A *ᵥ x = b
  7. rw [mulVec_mulVec (A *ᵥ x) E⁻¹ E, mulVec_mulVec b E⁻¹ E, nonsing_inv_mul E hE.isUnit,
  one_mulVec, one_mulVec] at h2

    Since $\det E\neq 0$, we have $E^{-1}E=I$, so $E^{-1}(E\mathbf{v})=\mathbf{v}$. Hypothesis h2 becomes $A\mathbf{x}=\mathbf{b}$.

    What remains to be proved
    h2 : A *ᵥ x = b
⊢ A *ᵥ x = b
  8. exact h2

    This is what we wanted.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • Matrix.mulVec_mulVec: $E(A\mathbf{x})=(EA)\mathbf{x}$.
  • Matrix.nonsing_inv_mul: $E^{-1}E=I$ when $\det E\neq 0$.
  • Matrix.det_permutation: the determinant of a permutation matrix is the sign of the permutation.
  • Matrix.det_diagonal: the determinant of a diagonal matrix.
  • Matrix.det_transvection_of_ne: the matrix that adds a multiple of a row has determinant $1$.

import Mathlib

namespace Ch3.StoixeiodeisMetasximatismoi
open Matrix

variable {m n : ℕ}

theorem same_solutions (E : Matrix (Fin m) (Fin m) ℝ) (hE : E.det ≠ 0)
    (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x : Fin n → ℝ) :
    A *ᵥ x = b ↔ (E * A) *ᵥ x = E *ᵥ b := by
  rw [← mulVec_mulVec]
  constructor
  · intro h
    rw [h]
  · intro h
    have h2 : E⁻¹ *ᵥ (E *ᵥ (A *ᵥ x)) = E⁻¹ *ᵥ (E *ᵥ b) := by rw [h]
    rw [mulVec_mulVec (A *ᵥ x) E⁻¹ E, mulVec_mulVec b E⁻¹ E, nonsing_inv_mul E hE.isUnit,
      one_mulVec, one_mulVec] at h2
    exact h2

theorem swap_invertible (i j : Fin m) (h : i ≠ j) :
    ((Equiv.swap i j).permMatrix ℝ).det ≠ 0 := by
  rw [det_permutation, Equiv.Perm.sign_swap h]
  norm_num

theorem scale_invertible (i : Fin m) (c : ℝ) (hc : c ≠ 0) :
    (diagonal (Function.update (fun _ => (1 : ℝ)) i c)).det ≠ 0 := by
  rw [det_diagonal, Finset.prod_update_of_mem (Finset.mem_univ i)]
  simpa using hc

theorem add_row_invertible (i j : Fin m) (h : i ≠ j) (c : ℝ) :
    (transvection i j c).det ≠ 0 := by
  rw [det_transvection_of_ne i j h c]
  exact one_ne_zero

end Ch3.StoixeiodeisMetasximatismoi
