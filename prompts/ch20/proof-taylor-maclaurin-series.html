Taylor and Maclaurin Series

Chapter 20 · Explanation by a Large Language Model and a proof checked by computer (Lean)

StatementLet $f$ have derivatives of every order on an open interval containing $x_0$. The equality $f(x)=\sum_{n=0}^{\infty}\dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ holds if and only if $\lim_{n\to\infty}R_n(x)=0$, where $R_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ (the Lagrange remainder, with $\xi$ between $x_0$ and $x$). For $x_0=0$ we obtain the Maclaurin series.

1. What is proved: the statement in the book and in Lean

  • The Taylor polynomial $T_n(x)$${}=\sum_{k=0}^{n}\dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k$ is the partial sum of the Taylor series
    theorem taylor_partial_sum (f : ℝ → ℝ) (n : ℕ) (s : Set ℝ) (x₀ x : ℝ) :
    taylorWithinEval f n s x₀ x =
      ∑ k ∈ Finset.range (n + 1), iteratedDerivWithin k f s x₀ / k ! * (x - x₀) ^ k
  • $f(x)$${}=\sum_{n=0}^{\infty}\dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ if and only if $R_n(x)=f(x)-T_n(x)\to 0$
    theorem taylor_series_iff (f : ℝ → ℝ) (s : Set ℝ) (x₀ x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
  • For $x_0=0$: the Maclaurin series
    theorem maclaurin_iff (f : ℝ → ℝ) (s : Set ℝ) (x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s 0 x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s 0 x) atTop (𝓝 0)
  • Lagrange remainder: $R_n(x)$${}=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ for some $\xi$ between $x_0$ and $x$
    theorem lagrange_remainder (f : ℝ → ℝ) (n : ℕ) (x₀ x : ℝ) (hx : x₀ ≠ x)
    (hf : ContDiffOn ℝ n f (Set.uIcc x₀ x))
    (hf' : DifferentiableOn ℝ (iteratedDerivWithin n f (Set.uIcc x₀ x)) (Set.uIoo x₀ x)) :
    ∃ ξ ∈ Set.uIoo x₀ x, f x - taylorWithinEval f n (Set.uIcc x₀ x) x₀ x =
      iteratedDerivWithin (n + 1) f (Set.uIcc x₀ x) ξ * (x - x₀) ^ (n + 1) / (n + 1)!
  • At the center $x_0$ the Taylor series always converges to $f(x_0)$
    theorem taylor_at_center (f : ℝ → ℝ) (s : Set ℝ) (x₀ : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x₀) atTop (𝓝 (f x₀))

In Mathlib the Taylor polynomial is taylorWithinEval f n s x₀ x, where the derivatives are computed within a set $s$, as in Chapter 11. The equality $f(x)$${}=\sum_{n=0}^{\infty}\dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ means that the partial sums $T_n(x)$ tend to $f(x)$. The equivalence with $R_n(x)\to 0$ is a matter of limits and holds with no hypotheses on $f$; the differentiability hypotheses are needed for the coefficients to make sense and for the Lagrange form of the remainder, which is given as in Chapter 11. The Maclaurin series is the special case $x_0=0$.

2. Step by step: $T_n(x)\to f(x)$ $\Leftrightarrow$ $R_n(x)\to 0$

The idea: $R_n(x)=f(x)-T_n(x)$, so the limit laws suffice. We start from the goal:

The goal
f : ℝ → ℝ
s : Set ℝ
x₀ x : ℝ
⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) ↔
    Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

4. In Mathlib

We used the following theorems:

  • taylor_within_apply: the Taylor polynomial as a sum.
  • tendsto_const_nhds: a constant sequence converges.
  • Filter.Tendsto.sub: the limit of a difference.
  • taylor_mean_remainder_lagrange: the Lagrange remainder.
  • taylorWithinEval_self: the value of the Taylor polynomial at $x_0$ is $f(x_0)$.

import Mathlib

namespace Ch20.SeiraTaylor
open Filter Topology
open scoped Nat

-- T_n(x) = Σ from k = 0 to n of f^(k)(x₀)/k! · (x - x₀)^k, with derivatives within the set s
theorem taylor_partial_sum (f : ℝ → ℝ) (n : ℕ) (s : Set ℝ) (x₀ x : ℝ) :
    taylorWithinEval f n s x₀ x =
      ∑ k ∈ Finset.range (n + 1), iteratedDerivWithin k f s x₀ / k ! * (x - x₀) ^ k := by
  rw [taylor_within_apply]
  refine Finset.sum_congr rfl (fun k _ => ?_)
  rw [smul_eq_mul]
  ring

-- the Taylor series has sum f(x) if and only if R_n(x) = f(x) - T_n(x) → 0
theorem taylor_series_iff (f : ℝ → ℝ) (s : Set ℝ) (x₀ x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0) := by
  constructor
  · -- (⇒) if T_n(x) → f(x), then f(x) - T_n(x) → f(x) - f(x) = 0
    intro h
    have h1 := (tendsto_const_nhds (x := f x)).sub h
    rw [sub_self] at h1
    exact h1
  · -- (⇐) if R_n(x) → 0, then T_n(x) = f(x) - R_n(x) → f(x) - 0 = f(x)
    intro h
    have h1 := (tendsto_const_nhds (x := f x)).sub h
    rw [sub_zero] at h1
    have h2 : (fun n => f x - (f x - taylorWithinEval f n s x₀ x)) =
        fun n => taylorWithinEval f n s x₀ x := by
      funext n
      ring
    rw [h2] at h1
    exact h1

-- for x₀ = 0: the Maclaurin series
theorem maclaurin_iff (f : ℝ → ℝ) (s : Set ℝ) (x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s 0 x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s 0 x) atTop (𝓝 0) :=
  taylor_series_iff f s 0 x

-- Lagrange remainder: R_n(x) = f^(n+1)(ξ)/(n+1)! · (x - x₀)^(n+1), with ξ between x₀ and x
theorem lagrange_remainder (f : ℝ → ℝ) (n : ℕ) (x₀ x : ℝ) (hx : x₀ ≠ x)
    (hf : ContDiffOn ℝ n f (Set.uIcc x₀ x))
    (hf' : DifferentiableOn ℝ (iteratedDerivWithin n f (Set.uIcc x₀ x)) (Set.uIoo x₀ x)) :
    ∃ ξ ∈ Set.uIoo x₀ x, f x - taylorWithinEval f n (Set.uIcc x₀ x) x₀ x =
      iteratedDerivWithin (n + 1) f (Set.uIcc x₀ x) ξ * (x - x₀) ^ (n + 1) / (n + 1)! :=
  taylor_mean_remainder_lagrange hx hf hf'

-- at the center x₀ the Taylor series always converges to f(x₀)
theorem taylor_at_center (f : ℝ → ℝ) (s : Set ℝ) (x₀ : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x₀) atTop (𝓝 (f x₀)) := by
  simp only [taylorWithinEval_self]
  exact tendsto_const_nhds

end Ch20.SeiraTaylor
