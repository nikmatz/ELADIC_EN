1. What is proved: the statement in the book and in Lean

  • Part A: if $f$ is continuous on $[a,b]$, then $G(x)=\int_a^x f(t)\,dt$ has derivative $f(x)$ at every $x\in(a,b)$
    theorem ftc_part_A (f : ℝ → ℝ) (a b : ℝ) (hf : ContinuousOn f (Set.Icc a b))
    (x : ℝ) (hx : x ∈ Set.Ioo a b) :
    HasDerivAt (fun u => ∫ t in a..u, f t) (f x) x
  • Part B (Newton–Leibniz): if $F$ is continuous on $[a,b]$ with $F'=f$ on $(a,b)$ and $f$ is continuous on $[a,b]$, then $\int_a^b f(x)\,dx=F(b)-F(a)$
    theorem ftc_part_B (f F : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hF : ContinuousOn F (Set.Icc a b))
    (hFf : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hf : ContinuousOn f (Set.Icc a b)) :
    ∫ x in a..b, f x = F b - F a

The function $G$ is written fun u => ∫ t in a..u, f t, and the derivative is expressed with HasDerivAt. In Part A we give the derivative at the interior points of $[a,b]$; at the endpoints $a$ and $b$ the derivative in the book is one-sided. In Part B we require $F'(x)=f(x)$ only on the open interval $(a,b)$, together with the continuity of $F$ on $[a,b]$. This hypothesis is weaker than $F'=f$ on all of $[a,b]$, so the result also holds under the hypotheses of the book. Both parts are available ready-made in Mathlib.

2. Where it is in Mathlib

We used the following theorems:

  • intervalIntegral.integral_hasDerivAt_right: the derivative of $\int_a^x f(t)\,dt$ (Part A).
  • intervalIntegral.integral_eq_sub_of_hasDerivAt_of_le: the Newton–Leibniz formula (Part B).
  • ContinuousOn.intervalIntegrable_of_Icc: a continuous function on $[a,b]$ is integrable.
  • ContinuousOn.stronglyMeasurableAtFilter: a technical measurability condition, which holds for continuous functions.
  • ContinuousOn.continuousAt: $f$ is continuous at every interior point of $[a,b]$.

import Mathlib

namespace Ch15.ThemeliodesThewrima
open MeasureTheory

-- Part A: G(x) = ∫ f(t) dt from a to x has derivative f(x) at every x ∈ (a, b)
theorem ftc_part_A (f : ℝ → ℝ) (a b : ℝ) (hf : ContinuousOn f (Set.Icc a b))
    (x : ℝ) (hx : x ∈ Set.Ioo a b) :
    HasDerivAt (fun u => ∫ t in a..u, f t) (f x) x := by
  have hint : IntervalIntegrable f volume a x :=
    (hf.mono (Set.Icc_subset_Icc le_rfl hx.2.le)).intervalIntegrable_of_Icc hx.1.le
  have hmeas : StronglyMeasurableAtFilter f (nhds x) volume :=
    (hf.mono Set.Ioo_subset_Icc_self).stronglyMeasurableAtFilter isOpen_Ioo x hx
  exact intervalIntegral.integral_hasDerivAt_right hint hmeas
    (hf.continuousAt (Icc_mem_nhds hx.1 hx.2))

-- Part B (Newton–Leibniz): if F' = f, then the integral of f from a to b is F(b) - F(a)
theorem ftc_part_B (f F : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hF : ContinuousOn F (Set.Icc a b))
    (hFf : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hf : ContinuousOn f (Set.Icc a b)) :
    ∫ x in a..b, f x = F b - F a :=
  intervalIntegral.integral_eq_sub_of_hasDerivAt_of_le hab hF hFf (hf.intervalIntegrable_of_Icc hab)

end Ch15.ThemeliodesThewrima
