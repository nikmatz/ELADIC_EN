1. What is proved: the statement in the book and in Lean

  • If $g$ has a continuous derivative on $[a,b]$ and $f$ is continuous, then $\int_a^b f\bigl(g(x)\bigr)g'(x)\,dx$${}=\int_{g(a)}^{g(b)}f(u)\,du$
    theorem subst_definite (f g g' : ℝ → ℝ) (a b : ℝ) (hf : Continuous f)
    (hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x) (hg' : ContinuousOn g' (Set.uIcc a b)) :
    ∫ x in a..b, f (g x) * g' x = ∫ u in g a..g b, f u
  • Application: $\int_a^b f(x+c)\,dx$${}=\int_{a+c}^{b+c}f(u)\,du$
    theorem shift (f : ℝ → ℝ) (a b c : ℝ) (hf : Continuous f) :
    ∫ x in a..b, f (x + c) = ∫ u in a + c..b + c, f u

For simplicity we take $f$ continuous on all of $\mathbb{R}$, whereas the book requires continuity only on the range of $g$. “$g$ has a continuous derivative on $[a,b]$” is written as two hypotheses: ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x and ContinuousOn g' (Set.uIcc a b). Set.uIcc a b is the interval with endpoints $a$ and $b$. The proof is the one in the book: if $F$ is an antiderivative of $f$, then $F\bigl(g(x)\bigr)$ is an antiderivative of $f\bigl(g(x)\bigr)g'(x)$.

2. Step by step: changing the limits

The idea: with $F(u)=\int_{g(a)}^{u}f(t)\,dt$, the function $F\bigl(g(x)\bigr)$ is an antiderivative of $f\bigl(g(x)\bigr)g'(x)$, and the fundamental theorem gives the result. We start from the goal:

The goal
f g g' : ℝ → ℝ
a b : ℝ
hf : Continuous f
hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x
hg' : ContinuousOn g' (Set.uIcc a b)
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- F(u) = ∫ f(t) dt from g(a) to u has derivative f(u)
have hF : ∀ u, HasDerivAt (fun u => ∫ t in g a..u, f t) (f u) u :=
  fun u => (hf.integral_hasStrictDerivAt (g a) u).hasDerivAt

    Fundamental theorem: $F(u)=\int_{g(a)}^{u}f(t)\,dt$ has derivative $f(u)$ at every $u$.

    What remains to be proved
    hF : ∀ (u : ℝ), HasDerivAt (fun u => ∫ (t : ℝ) in g a..u, f t) (f u) u
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u
  2. -- chain rule: (F(g(x)))' = f(g(x)) g'(x)
have hcomp : ∀ x ∈ Set.uIcc a b,
    HasDerivAt (fun x => ∫ t in g a..g x, f t) (f (g x) * g' x) x :=
  fun x hx => (hF (g x)).comp x (hg x hx)

    Chain rule: $F\bigl(g(x)\bigr)$ has derivative $f\bigl(g(x)\bigr)\,g'(x)$ at every $x$ of the interval.

    What remains to be proved
    hcomp : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => ∫ (t : ℝ) in g a..g x, f t) (f (g x) * g' x) x
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u
  3. -- f(g(x)) g'(x) is continuous, hence integrable
have hgc : ContinuousOn g (Set.uIcc a b) := fun x hx => (hg x hx).continuousAt.continuousWithinAt
have hint : IntervalIntegrable (fun x => f (g x) * g' x) volume a b :=
  ((hf.comp_continuousOn hgc).mul hg').intervalIntegrable

    $g$ is differentiable, hence continuous, and $f\bigl(g(x)\bigr)g'(x)$ is continuous, hence integrable.

    What remains to be proved
    hgc : ContinuousOn g (Set.uIcc a b)
hint : IntervalIntegrable (fun x => f (g x) * g' x) volume a b
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u
  4. -- fundamental theorem: the integral is F(g(b)) - F(g(a))
rw [intervalIntegral.integral_eq_sub_of_hasDerivAt hcomp hint]

    Fundamental theorem for $F\bigl(g(x)\bigr)$: the integral equals $F\bigl(g(b)\bigr)-F\bigl(g(a)\bigr)$.

    What remains to be proved
    ⊢ (∫ (t : ℝ) in g a..g b, f t) - ∫ (t : ℝ) in g a..g a, f t = ∫ (u : ℝ) in g a..g b, f u
  5. -- F(g(a)) = 0, because the limits are equal
rw [intervalIntegral.integral_same, sub_zero]

    $F\bigl(g(a)\bigr)$${}=\int_{g(a)}^{g(a)}f(t)\,dt$ is $0$, because the limits are equal, and what remains is $F\bigl(g(b)\bigr)$${}=\int_{g(a)}^{g(b)}f(u)\,du$.

    ✓ No goals: the proof is complete.

Hint

Apply the rule with $g(x)=x+c$ and $g'(x)=1$: have h := subst_definite f (fun x => x + c) (fun _ => 1) a b hf (fun x _ => (hasDerivAt_id' x).add_const c) continuousOn_const. In h the integrand has the factor $1$; remove it with simp only [mul_one] at h and finish with exact h.

Solution
theorem shift (f : ℝ → ℝ) (a b c : ℝ) (hf : Continuous f) :
    ∫ x in a..b, f (x + c) = ∫ u in a + c..b + c, f u := by
  have h := subst_definite f (fun x => x + c) (fun _ => 1) a b hf
    (fun x _ => (hasDerivAt_id' x).add_const c) continuousOn_const
  simp only [mul_one] at h
  exact h

4. In Mathlib

We used the following theorems:

  • Continuous.integral_hasStrictDerivAt: the fundamental theorem: $\int_{g(a)}^u f(t)\,dt$ has derivative $f(u)$.
  • HasDerivAt.comp: the chain rule.
  • HasDerivAt.continuousAt: a differentiable function is continuous.
  • Continuous.comp_continuousOn: the composition of continuous functions is continuous.
  • ContinuousOn.mul: the product of continuous functions is continuous.
  • ContinuousOn.intervalIntegrable: a continuous function on a closed interval is integrable.
  • intervalIntegral.integral_eq_sub_of_hasDerivAt: the fundamental theorem of calculus.
  • intervalIntegral.integral_same: $\int_a^a f=0$.

open MeasureTheory

theorem subst_definite (f g g' : ℝ → ℝ) (a b : ℝ) (hf : Continuous f)
    (hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x) (hg' : ContinuousOn g' (Set.uIcc a b)) :
    ∫ x in a..b, f (g x) * g' x = ∫ u in g a..g b, f u := by
  -- F(u) = ∫ f(t) dt from g(a) to u has derivative f(u)
  have hF : ∀ u, HasDerivAt (fun u => ∫ t in g a..u, f t) (f u) u :=
    fun u => (hf.integral_hasStrictDerivAt (g a) u).hasDerivAt
  -- chain rule: (F(g(x)))' = f(g(x)) g'(x)
  have hcomp : ∀ x ∈ Set.uIcc a b,
      HasDerivAt (fun x => ∫ t in g a..g x, f t) (f (g x) * g' x) x :=
    fun x hx => (hF (g x)).comp x (hg x hx)
  -- f(g(x)) g'(x) is continuous, hence integrable
  have hgc : ContinuousOn g (Set.uIcc a b) := fun x hx => (hg x hx).continuousAt.continuousWithinAt
  have hint : IntervalIntegrable (fun x => f (g x) * g' x) volume a b :=
    ((hf.comp_continuousOn hgc).mul hg').intervalIntegrable
  -- fundamental theorem: the integral is F(g(b)) - F(g(a))
  rw [intervalIntegral.integral_eq_sub_of_hasDerivAt hcomp hint]
  -- F(g(a)) = 0, because the limits are equal
  rw [intervalIntegral.integral_same, sub_zero]

theorem shift (f : ℝ → ℝ) (a b c : ℝ) (hf : Continuous f) :
    ∫ x in a..b, f (x + c) = ∫ u in a + c..b + c, f u := by
  have h := subst_definite f (fun x => x + c) (fun _ => 1) a b hf
    (fun x _ => (hasDerivAt_id' x).add_const c) continuousOn_const
  simp only [mul_one] at h
  exact h

end Ch15.AntikatastasiOrismeno
