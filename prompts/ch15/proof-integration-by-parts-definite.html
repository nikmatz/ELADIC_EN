1. What is proved: the statement in the book and in Lean

  • If $u,v$ have continuous derivatives on $[a,b]$, then $\int_a^b u(x)v'(x)\,dx$${}=\bigl[u(x)v(x)\bigr]_a^b-\int_a^b u'(x)v(x)\,dx$
    theorem parts_definite (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b)) :
    ∫ x in a..b, u x * v' x = (u b * v b - u a * v a) - ∫ x in a..b, u' x * v x
  • Application: if $u(a)v(a)=u(b)v(b)=0$, then $\int_a^b u v'\,dx$${}=-\int_a^b u' v\,dx$
    theorem parts_zero_boundary (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b))
    (ha : u a * v a = 0) (hb : u b * v b = 0) :
    ∫ x in a..b, u x * v' x = -∫ x in a..b, u' x * v x

“$u$ has derivative $u'$ on $[a,b]$” is written ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x, and the continuity of the derivative is written ContinuousOn u' (Set.uIcc a b). Set.uIcc a b is the interval with endpoints $a$ and $b$, whichever of the two is smaller; for $a\le b$ it is $[a,b]$. The expression $\bigl[u(x)v(x)\bigr]_a^b$ is written u b * v b - u a * v a. Mathlib has the theorem ready-made (intervalIntegral.integral_mul_deriv_eq_deriv_mul); here we prove it from the fundamental theorem, as in the book.

2. Step by step: integration by parts

The idea: we integrate the product rule $(uv)'=u'v+uv'$ from $a$ to $b$ and use the fundamental theorem. We start from the goal:

The goal
u v u' v' : ℝ → ℝ
a b : ℝ
hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x
hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x
hu' : ContinuousOn u' (Set.uIcc a b)
hv' : ContinuousOn v' (Set.uIcc a b)
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- product rule: (u v)' = u' v + u v'
have hd : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => u x * v x) (u' x * v x + u x * v' x) x :=
  fun x hx => (hu x hx).mul (hv x hx)

    Product rule: $uv$ has derivative $u'v+uv'$ at every point of the interval.

    What remains to be proved
    hd : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => u x * v x) (u' x * v x + u x * v' x) x
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  2. -- u, v are continuous, so u' v and u v' are integrable
have huc : ContinuousOn u (Set.uIcc a b) := fun x hx => (hu x hx).continuousAt.continuousWithinAt
have hvc : ContinuousOn v (Set.uIcc a b) := fun x hx => (hv x hx).continuousAt.continuousWithinAt

    $u$ and $v$ are differentiable, hence continuous.

    What remains to be proved
    huc : ContinuousOn u (Set.uIcc a b)
hvc : ContinuousOn v (Set.uIcc a b)
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  3. have h1 : IntervalIntegrable (fun x => u' x * v x) volume a b := (hu'.mul hvc).intervalIntegrable
have h2 : IntervalIntegrable (fun x => u x * v' x) volume a b := (huc.mul hv').intervalIntegrable

    $u'v$ and $uv'$ are continuous, as products of continuous functions, hence integrable.

    What remains to be proved
    h1 : IntervalIntegrable (fun x => u' x * v x) volume a b
h2 : IntervalIntegrable (fun x => u x * v' x) volume a b
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  4. -- fundamental theorem for u v
have hftc := intervalIntegral.integral_eq_sub_of_hasDerivAt hd (h1.add h2)

    Fundamental theorem (intervalIntegral.integral_eq_sub_of_hasDerivAt): $\int_a^b (u'v+uv')\,dx$${}=u(b)v(b)-u(a)v(a)$.

    What remains to be proved
    hftc : ∫ (y : ℝ) in a..b, u' y * v y + u y * v' y = u b * v b - u a * v a
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  5. -- the integral of the sum splits into two integrals
rw [intervalIntegral.integral_add h1 h2] at hftc

    The integral of the sum splits into two integrals (intervalIntegral.integral_add).

    What remains to be proved
    hftc : (∫ (x : ℝ) in a..b, u' x * v x) + ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  6. linarith

    We move $\int_a^b u'v\,dx$ to the other side; linarith does this.

    ✓ No goals: the proof is complete.

4. In Mathlib

We used the following theorems:

  • HasDerivAt.mul: the product rule.
  • HasDerivAt.continuousAt: a differentiable function is continuous.
  • ContinuousOn.mul: the product of continuous functions is continuous.
  • ContinuousOn.intervalIntegrable: a continuous function on a closed interval is integrable.
  • intervalIntegral.integral_eq_sub_of_hasDerivAt: the fundamental theorem of calculus.
  • intervalIntegral.integral_add: the integral of a sum.

theorem parts_definite (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b)) :
    ∫ x in a..b, u x * v' x = (u b * v b - u a * v a) - ∫ x in a..b, u' x * v x := by
  -- product rule: (u v)' = u' v + u v'
  have hd : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => u x * v x) (u' x * v x + u x * v' x) x :=
    fun x hx => (hu x hx).mul (hv x hx)
  -- u, v are continuous, so u' v and u v' are integrable
  have huc : ContinuousOn u (Set.uIcc a b) := fun x hx => (hu x hx).continuousAt.continuousWithinAt
  have hvc : ContinuousOn v (Set.uIcc a b) := fun x hx => (hv x hx).continuousAt.continuousWithinAt
  have h1 : IntervalIntegrable (fun x => u' x * v x) volume a b := (hu'.mul hvc).intervalIntegrable
  have h2 : IntervalIntegrable (fun x => u x * v' x) volume a b := (huc.mul hv').intervalIntegrable
  -- fundamental theorem for u v
  have hftc := intervalIntegral.integral_eq_sub_of_hasDerivAt hd (h1.add h2)
  -- the integral of the sum splits into two integrals
  rw [intervalIntegral.integral_add h1 h2] at hftc
  linarith

    (ha : u a * v a = 0) (hb : u b * v b = 0) :
    ∫ x in a..b, u x * v' x = -∫ x in a..b, u' x * v x := by
