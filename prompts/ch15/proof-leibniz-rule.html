1. What is proved: the statement in the book and in Lean

  • If $f$ is continuous and $a(x),b(x)$ are differentiable, then $H(x)=\int_{a(x)}^{b(x)}f(t)\,dt$ has derivative $H'(x)$${}=f\bigl(b(x)\bigr)b'(x)-f\bigl(a(x)\bigr)a'(x)$
    theorem leibniz (f a b a' b' : ℝ → ℝ) (hf : Continuous f)
    (ha : ∀ x, HasDerivAt a (a' x) x) (hb : ∀ x, HasDerivAt b (b' x) x) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x
  • Application: $\dfrac{d}{dx}\int_0^{x^2}f(t)\,dt$${}=f(x^2)\cdot 2x$
    theorem leibniz_square (f : ℝ → ℝ) (hf : Continuous f) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in (0 : ℝ)..x ^ 2, f t) (f (x ^ 2) * (2 * x)) x

For simplicity we take $f$ continuous on all of $\mathbb{R}$, that is $I=\mathbb{R}$, and $a,b$ differentiable at every point. The integral with variable limits is written ∫ t in a x..b x, f t. The proof is the one in the book: with $F(u)=\int_0^u f(t)\,dt$ we have $H(x)$${}=F\bigl(b(x)\bigr)-F\bigl(a(x)\bigr)$, and the chain rule gives the derivative.

2. Step by step: the Leibniz rule

The idea: we write $H$ as the difference of two integrals with fixed lower limit $0$ and differentiate each one with the fundamental theorem and the chain rule. We start from the goal:

The goal
f a b a' b' : ℝ → ℝ
hf : Continuous f
ha : ∀ (x : ℝ), HasDerivAt a (a' x) x
hb : ∀ (x : ℝ), HasDerivAt b (b' x) x
x : ℝ
⊢ HasDerivAt (fun x => ∫ (t : ℝ) in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x

Above ⊢ is what we know; after ⊢ is what we have to show. After each step we show only what changed.

  1. -- F(u) = ∫ f(t) dt from 0 to u has derivative f(u) (fundamental theorem)
have hF : ∀ u, HasDerivAt (fun u => ∫ t in (0 : ℝ)..u, f t) (f u) u :=
  fun u => (hf.integral_hasStrictDerivAt 0 u).hasDerivAt

    Fundamental theorem (Continuous.integral_hasStrictDerivAt): $F(u)=\int_0^u f(t)\,dt$ has derivative $f(u)$ at every $u$.

    What remains to be proved
    hF : ∀ (u : ℝ), HasDerivAt (fun u => ∫ (t : ℝ) in 0..u, f t) (f u) u
⊢ HasDerivAt (fun x => ∫ (t : ℝ) in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x
  2. -- H(x) = F(b(x)) - F(a(x))
have hH : (fun x => ∫ t in a x..b x, f t) =
    fun x => (∫ t in (0 : ℝ)..b x, f t) - ∫ t in (0 : ℝ)..a x, f t := by

    Claim hH: $H(x)$${}=F\bigl(b(x)\bigr)-F\bigl(a(x)\bigr)$, that is, the two functions are equal.

    What remains to be proved
    ⊢ (fun x => ∫ (t : ℝ) in a x..b x, f t) = fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t
  3. funext y

    Two functions are equal when they take the same value at every point $y$ (funext).

    What remains to be proved
    y : ℝ
⊢ ∫ (t : ℝ) in a y..b y, f t = (∫ (t : ℝ) in 0..b y, f t) - ∫ (t : ℝ) in 0..a y, f t
  4. rw [intervalIntegral.integral_interval_sub_left (hf.intervalIntegrable (μ := volume) 0 (b y))
  (hf.intervalIntegrable (μ := volume) 0 (a y))]

    By the additivity of the integral, $\int_0^{b(y)}f-\int_0^{a(y)}f$${}=\int_{a(y)}^{b(y)}f$ (intervalIntegral.integral_interval_sub_left). $f$ is continuous, hence integrable on every interval.

    ✓ This part is complete.
  5. rw [hH]

    We replace $H$ with the difference $F\bigl(b(x)\bigr)-F\bigl(a(x)\bigr)$.

    What remains to be proved
    f a b a' b' : ℝ → ℝ
hf : Continuous f
ha : ∀ (x : ℝ), HasDerivAt a (a' x) x
hb : ∀ (x : ℝ), HasDerivAt b (b' x) x
x : ℝ
hF : ∀ (u : ℝ), HasDerivAt (fun u => ∫ (t : ℝ) in 0..u, f t) (f u) u
hH : (fun x => ∫ (t : ℝ) in a x..b x, f t) = fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t
⊢ HasDerivAt (fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t) (f (b x) * b' x - f (a x) * a' x) x
  6. -- chain rule for each of the two integrals
have h1 := (hF (b x)).comp x (hb x)

    Chain rule: $F\bigl(b(x)\bigr)$ has derivative $f\bigl(b(x)\bigr)\,b'(x)$. Composition is written with the symbol ∘.

    What remains to be proved
    h1 : HasDerivAt ((fun u => ∫ (t : ℝ) in 0..u, f t) ∘ b) (f (b x) * b' x) x
⊢ HasDerivAt (fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t) (f (b x) * b' x - f (a x) * a' x) x
  7. have h2 := (hF (a x)).comp x (ha x)

    Similarly, $F\bigl(a(x)\bigr)$ has derivative $f\bigl(a(x)\bigr)\,a'(x)$.

    What remains to be proved
    h2 : HasDerivAt ((fun u => ∫ (t : ℝ) in 0..u, f t) ∘ a) (f (a x) * a' x) x
⊢ HasDerivAt (fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t) (f (b x) * b' x - f (a x) * a' x) x
  8. exact h1.sub h2

    Difference rule: we subtract the two derivatives.

    ✓ No goals: the proof is complete.

Solution
theorem leibniz_square (f : ℝ → ℝ) (hf : Continuous f) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in (0 : ℝ)..x ^ 2, f t) (f (x ^ 2) * (2 * x)) x := by
  have h := leibniz f (fun _ => 0) (fun x => x ^ 2) (fun _ => 0) (fun x => 2 * x) hf
    (fun x => hasDerivAt_const x 0) (fun x => by simpa using hasDerivAt_pow 2 x) x
  simp only [mul_zero, sub_zero] at h
  exact h

4. In Mathlib

We used the following theorems:

  • Continuous.integral_hasStrictDerivAt: the fundamental theorem: $\int_0^u f(t)\,dt$ has derivative $f(u)$.
  • intervalIntegral.integral_interval_sub_left: $\int_0^{b}f-\int_0^{a}f=\int_a^b f$.
  • Continuous.intervalIntegrable: a continuous function is integrable on every interval.
  • HasDerivAt.comp: the chain rule.
  • HasDerivAt.sub: the difference rule.

import Mathlib

namespace Ch15.KanonasLeibniz
open MeasureTheory

theorem leibniz (f a b a' b' : ℝ → ℝ) (hf : Continuous f)
    (ha : ∀ x, HasDerivAt a (a' x) x) (hb : ∀ x, HasDerivAt b (b' x) x) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x := by
  -- F(u) = ∫ f(t) dt from 0 to u has derivative f(u) (fundamental theorem)
  have hF : ∀ u, HasDerivAt (fun u => ∫ t in (0 : ℝ)..u, f t) (f u) u :=
    fun u => (hf.integral_hasStrictDerivAt 0 u).hasDerivAt
  -- H(x) = F(b(x)) - F(a(x))
  have hH : (fun x => ∫ t in a x..b x, f t) =
      fun x => (∫ t in (0 : ℝ)..b x, f t) - ∫ t in (0 : ℝ)..a x, f t := by
    funext y
    rw [intervalIntegral.integral_interval_sub_left (hf.intervalIntegrable (μ := volume) 0 (b y))
      (hf.intervalIntegrable (μ := volume) 0 (a y))]
  rw [hH]
  -- chain rule for each of the two integrals
  have h1 := (hF (b x)).comp x (hb x)
  have h2 := (hF (a x)).comp x (ha x)
  exact h1.sub h2

theorem leibniz_square (f : ℝ → ℝ) (hf : Continuous f) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in (0 : ℝ)..x ^ 2, f t) (f (x ^ 2) * (2 * x)) x := by
  have h := leibniz f (fun _ => 0) (fun x => x ^ 2) (fun _ => 0) (fun x => 2 * x) hf
    (fun x => hasDerivAt_const x 0) (fun x => by simpa using hasDerivAt_pow 2 x) x
  simp only [mul_zero, sub_zero] at h
  exact h

end Ch15.KanonasLeibniz
