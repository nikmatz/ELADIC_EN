The Indefinite Integral

Chapter 13 · The Indefinite Integral

How to use them. The exercises are arranged by type of integral and, within each group, in increasing order of difficulty: BASIC INTERMEDIATE ADVANCED.

You need only the tools of Chapters 0–13: the table of basic integrals, linearity, the linear substitution $\displaystyle\int f(ax+b)\,dx$, the logarithmic rule $\displaystyle\int \frac{f'(x)}{f(x)}\,dx$ and simple $u$-substitution. In several cases an algebraic or trigonometric simplification before integrating makes every technique unnecessary.

In every indefinite integral the constant $+C$ is understood. The result of every exercise is always checked by differentiating: if the derivative of your antiderivative gives the integrand, the solution is correct. You do not need an answer key.

A. Basic formulas and linearity

Split the integral into separate terms and read the table of derivatives backwards.

13E.1 BASIC

Evaluate $\displaystyle\int \left(6x^{5}-8x^{3}+5\right)dx$.

13E.2 BASIC

Evaluate $\displaystyle\int \left(2\sec^{2}x+\frac{5}{1+x^{2}}-3e^{x}\right)dx$.

13E.3 INTERMEDIATE

Evaluate $\displaystyle\int 2^{x}\,3^{x}\,dx$.

Hint: first write the product as a power of a single base and then apply the table formula for $a^{x}$.

B. Powers, roots and fractions

Convert every root and every fraction into a power $x^{n}$ and then apply the power rule.

13E.4 BASIC

Evaluate $\displaystyle\int \left(\frac{5}{x^{3}}+4\sqrt[3]{x}\right)dx$, for $x>0$.

13E.5 INTERMEDIATE

Evaluate $\displaystyle\int \frac{x^{3}-2\sqrt{x}+1}{x^{2}}\,dx$, for $x>0$.

Hint: split the fraction into three terms and subtract the exponents; watch the half-integer exponent of the middle term.

13E.6 INTERMEDIATE

Evaluate $\displaystyle\int \frac{x^{4}+2x^{2}+1}{x^{2}+1}\,dx$.

Hint: the numerator is a perfect square; simplifying makes every integration technique unnecessary.

C. Exponential and logarithmic

Direct formulas from the table, combined with the linear substitution $ax+b$ where needed.

13E.7 BASIC

Evaluate $\displaystyle\int \left(3e^{x}-e^{-2x}\right)dx$.

13E.8 INTERMEDIATE

Evaluate $\displaystyle\int \frac{1+\ln x}{x}\,dx$, for $x>0$.

Hint: set $u=\ln x$ and notice which factor is $du$.

13E.9 ADVANCED

Evaluate $\displaystyle\int \frac{dx}{e^{x}+e^{-x}}$.

Hint: multiply numerator and denominator by $e^{x}$ and then set $u=e^{x}$; you will recognize a formula from the basic table.

D. Trigonometric

Before integrating, check whether some trigonometric identity reduces the integrand to a term of the table.

13E.10 BASIC

Evaluate $\displaystyle\int \left(3\sin x-\frac{2}{\cos^{2}x}\right)dx$.

13E.11 INTERMEDIATE

Evaluate $\displaystyle\int \left(\sin x+\cos x\right)^{2}dx$.

Hint: expand the square and use the fundamental identity together with the double-angle identity.

13E.12 ADVANCED

Evaluate $\displaystyle\int \frac{\cos 2x}{\cos x-\sin x}\,dx$, on an interval where $\cos x\neq\sin x$.

Hint: write $\cos 2x$ as a difference of squares and simplify the fraction.

E. Simple substitution

Look inside the integral for the pair “function – its derivative” and take $u$ to be the inner function.

13E.13 BASIC

Evaluate $\displaystyle\int x^{2}e^{-x^{3}}\,dx$.

13E.14 INTERMEDIATE

Evaluate $\displaystyle\int \frac{dx}{x\sqrt{\ln x}}$, for $x>1$.

Hint: with $u=\ln x$ the integral reduces to a simple power rule with a negative half-integer exponent.

13E.15 ADVANCED

Evaluate $\displaystyle\int \frac{dx}{1+\sqrt{x+1}}$, for $x>-1$.

Hint: set $u=\sqrt{x+1}$, so that $x=u^{2}-1$ and $dx=2u\,du$; then carry out the division $\dfrac{u}{1+u}$, writing it as $1-\dfrac{1}{1+u}$.

F. Antiderivative with an initial condition

First the general antiderivative with its constant, then the initial condition, which determines that constant.

13E.16 BASIC

Find the function $f$ for which $f'(x)=6x^{2}-4\sin x$ and $f(0)=3$.

13E.17 INTERMEDIATE

Solve the initial value problem $y'=\dfrac{x}{\sqrt{x^{2}+9}}$ with $y(0)=5$.

Hint: the substitution $u=x^{2}+9$ gives the general solution; the initial condition is applied at the end.

13E.18 ADVANCED

Find the function $f$ for which $f''(x)=4e^{2x}$, $f'(0)=1$ and $f(0)=0$.

Hint: two successive integrations with two different constants are required; each condition determines one of them.

G. Engineering applications (motion, rates)

The rate of change is given and the quantity itself is asked for: integrate, then determine the constant from the initial state.

13E.19 BASIC

A disk rotates with angular acceleration $\alpha(t)=6t$ (in $\mathrm{rad/s^{2}}$), with initial angular velocity $\omega(0)=2$ $\mathrm{rad/s}$ and initial angle $\theta(0)=0$ $\mathrm{rad}$. Find the functions $\omega(t)$ and $\theta(t)$.

13E.20 BASIC

A particle moves along a straight line with velocity $v(t)=\sqrt{t+4}$ (in $\mathrm{m/s}$) and starts from the position $s(0)=0$ $\mathrm{m}$. Find the position function $s(t)$ and the position at time $t=5$ $\mathrm{s}$.

Hint: apply the linear-substitution formula to the root.

13E.21 INTERMEDIATE

A body of mass $m$ moves under a periodic force, so that $m\,v'(t)=F_{0}\sin(\omega t)$, with $F_{0}$, $\omega$ positive constants and $v(0)=0$. Find the velocity function $v(t)$ and the maximum value of its magnitude.

Hint: the constants $m$, $F_{0}$, $\omega$ are treated as numbers when integrating with respect to $t$.

H. Mixed / composite

The method is not given here: first identify the structure of the integrand, then evaluate.

13E.22 INTERMEDIATE

Evaluate $\displaystyle\int \frac{x+1}{x^{2}+1}\,dx$.

Hint: split into two integrals; one is handled by the logarithmic rule and the other is a table formula.

13E.23 INTERMEDIATE

Evaluate $\displaystyle\int \frac{x^{2}}{x^{2}+1}\,dx$.

Hint: add and subtract $1$ in the numerator, so that an integer part plus a familiar fraction appears.

13E.24 ADVANCED

Evaluate $\displaystyle\int \frac{dx}{1+\cos x}$, on an interval where $\cos x\neq-1$.

Hint: multiply numerator and denominator by $1-\cos x$ and use the fundamental trigonometric identity; two table integrals will appear.
