Why +C?
Any two functions F(x) differing by a constant have the same derivative.
The constant is fixed by an initial condition.

The Indefinite Integral (Antiderivative)

The function F(x) is an antiderivative of f(x) if F′(x) = f(x).

∫ f(x) dx = F(x) + C   (C ∈ ℝ an arbitrary constant)

The orange curve is f(x) and the blue curves are its antiderivatives F(x)+C for various values of C. Notice that they have the same slope (tangent line) everywhere.

Basic integrals:
∫xⁿdx = xⁿ⁺¹/(n+1)+C  ·  ∫eˣdx = eˣ+C  ·  ∫sin x dx = −cos x+C
∫cos x dx = sin x+C  ·  ∫(1/x)dx = ln|x|+C
