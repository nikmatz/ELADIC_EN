Chapter 7: Stochastic processes - Convergence to a stationary distribution

Learning objective: A Markov chain is a stochastic process in which the next state depends only on the current state. The transition matrix P contains the transition probabilities. If the chain is regular (some power of P has all entries positive), the probability distribution converges to a unique stationary distribution, independently of the initial one.
The second component is set automatically so that the sum is 1. Try x₀=(1,0) and x₀=(0,1): the stationary distribution is the same.

Markov Chains

A Markov chain is a random process in which the next state depends only on the current one.

Transition matrix in column form: Pᵢⱼ = P(j→i), that is P = [[p₁₁, p₂₁], [p₁₂, p₂₂]] — each column sums to 1. Distribution: π(n+1) = P·π(n)

In the long run the distribution converges to the stationary distribution π* with P·π* = π*. This is an eigenvector with eigenvalue λ=1.
