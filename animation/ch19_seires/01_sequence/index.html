Convergence of a Sequence

A sequence {aₙ} converges to L if: for every ε>0 there is an N such that n>N ⟹ |aₙ−L|<ε.

lim[n→∞] aₙ = L  ·  If it does not converge: it diverges (→±∞ or oscillates)

Key facts: (1/n)→0, (rⁿ)→0 if |r|<1, (1+1/n)ⁿ→e. Squeeze theorem: aₙ≤bₙ≤cₙ and aₙ,cₙ→L ⟹ bₙ→L.
