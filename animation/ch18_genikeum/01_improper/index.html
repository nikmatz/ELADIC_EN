Improper Integrals

An integral is improper when a limit is infinite, ∫ₐ^∞ f dx, or when there is a singular point, ∫ₐᵇ f dx with f→∞.

∫ₐ^∞f dx = lim[t→∞] ∫ₐᵗf dx  ·  Converges if the limit is finite, diverges if it is ±∞

Key case: ∫₁^∞ x⁻ᵖdx converges ⟺ p>1. Comparison test: if |f|≤g and ∫g converges, then ∫f converges.
