The Limit of a Function - the ε-δ Definition

Chapter 9: Limits - Approaching a value

Learning objective: The limit lim(x→a) f(x) = L means: for every ε>0 there is a δ>0 such that if 0<|x−a|<δ then |f(x)−L|<ε. Geometrically: the whole graph above the punctured neighborhood 0<|x−a|<δ stays inside the rectangle formed by the horizontal band of width 2ε around L and the vertical band of width 2δ around a. The value f(a) plays no role whatsoever.
ε-δ Definition: ∀ε>0 ∃δ>0: 0<|x−a|<δ ⟹ |f(x)−L|<ε

The ε-δ Definition of the Limit

lim[x→a] f(x) = L means: for every ε>0 there is a δ>0 such that 0<|x−a|<δ ⟹ |f(x)−L|<ε.

ε: how close we want f(x) to be to L  ·  δ: how close x must be to a

The ε-δ definition shows that we can make f(x) AS CLOSE AS WE LIKE to L, provided x is close enough to a. The value f(a) is irrelevant!
