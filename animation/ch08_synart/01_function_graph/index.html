The Graph of a Function

Chapter 8: Functions - Visual representation

Learning objective: Every function f(x) can be drawn as a graph in the xy-plane. The domain consists of the admissible values of x, and the range of the resulting values of y. Asymptotes are lines that the graph approaches but never touches.
f(x) = x²
Domain: ℝ
Range: [0, +∞)

Functions & Their Graphs

A function f: A→B assigns to each x∈A a unique f(x)∈B.

Basic functions: polynomial, trigonometric, exponential, logarithmic.

Transformations: f(x)+c (vertical shift), f(x+c) (horizontal shift), a·f(x) (y-scaling), f(a·x) (x-scaling), −f(x) (reflection in the x-axis).
