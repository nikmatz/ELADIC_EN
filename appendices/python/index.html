Introduction: Why Python for Mathematical Computations?

Python is today the most widely used programming language in the scientific community. Unlike specialized tools such as MATLAB or Mathematica, Python is free and open source, and it has one of the richest ecosystems of libraries for scientific computing.

For this course we use four specialized libraries:

  • NumPy (Numerical Python) — the foundation of every scientific computation: fast $n$-dimensional arrays, linear algebra operations, mathematical functions.
  • SciPy (Scientific Python) — higher-level algorithms: numerical integration, initial value problems for ODEs, special functions, optimization.
  • SymPy (Symbolic Python) — symbolic computation comparable to Maxima: exact derivatives, integrals, limits, Taylor series, solutions of equations.
  • Matplotlib — a professional plotting library: 2D/3D plots, direction fields, contour curves, application plots.

What can I do with Python that I cannot do with Maxima?

  • Process large matrices (thousands of rows) at high speed.
  • Automate repetitive computations with loops.
  • Produce publication-quality plots ready for print.
  • Combine symbolic (SymPy) and numerical (NumPy/SciPy) computations in the same program.
  • Solve real engineering problems: structural analysis, fluid dynamics, signal processing.

For a deeper study of Python in mathematics and scientific computing, see the relevant references in the book.

Linear Algebra with NumPy

Statement: Let $A = \begin{pmatrix}2&1&-1\\3&2&1\\1&-1&2\end{pmatrix}$. Use NumPy to: (a) solve the linear system $A\mathbf{x} = \mathbf{b}$ for $\mathbf{b} = (8,11,-3)^T$ and check the answer, (b) find the determinant and the inverse matrix, (c) compute the eigenvalues and eigenvectors of a $2\times2$ matrix $B$.

Python
import numpy as np

A = np.array([[2., 1., -1.],
 [3., 2., 1.],
 [1., -1., 2.]])
b = np.array([8., 11., -3.])

# Solving Ax = b
x = np.linalg.solve(A, b)
print("Solution:", x) # [2. 3. -1.]

# Check
print("Check:", A @ x) # [8. 11. -3.]

# Determinant
print("det(A):", np.linalg.det(A)) # 10.0

# Inverse
Ainv = np.linalg.inv(A)
print("A*A^-1 =\n", A @ Ainv) # I

# Eigenvalues and eigenvectors
B = np.array([[4., 1.], [2., 3.]])
vals, vecs = np.linalg.eig(B)
print("Eigenvalues:", vals) # [5. 2.]
print("Eigenvectors:\n", vecs)

# Check: B*v = lambda*v
for i in range(len(vals)):
 lam, v = vals[i], vecs[:,i]
 print(f"B*v{i} - {lam}*v{i} =", B@v - lam*v) # ~[0,0]

Numerical Integration

Statement: Use the quad function of SciPy to evaluate numerically the integrals: (a) $\int_0^1 x^2\,dx$, (b) $\int_0^{\pi} \sin x\,dx$, (c) $\int_1^{\infty} e^{-x}\,dx$. Compare the numerical results with the analytical values.

Python
import numpy as np
from scipy.integrate import quad, dblquad

# Simple integral: int_0^pi sin(x)dx = 2
val, err = quad(np.sin, 0, np.pi)
print(f"integral = {val:.6f}, error = {err:.2e}") # 2.000000

# Gaussian: int_0^inf exp(-x^2)dx = sqrt(pi)/2
val, err = quad(lambda x: np.exp(-x**2), 0, np.inf)
print(f"Gaussian = {val:.6f}") # 0.886227 = sqrt(pi)/2

# An integral with no closed form
val, err = quad(lambda x: np.sin(x)/x, 0.001, 10)
print(f"Si(10) ≈ {val:.4f}")

# Double integral: int_0^1 int_0^1 x*y dydx = 1/4
val, err = dblquad(lambda y, x: x*y, 0, 1, 0, 1)
print(f"Double integral = {val:.4f}") # 0.25

Initial Value Problem for an ODE

Statement: Solve numerically the initial value problem $y' = -y + \sin t$, $y(0)=1$ on the interval $[0,10]$ using the solve_ivp function of SciPy. Plot the solution and compare it with the analytical one, $y(t) = e^{-t} + \frac{1}{2}(\sin t - \cos t) + \frac{1}{2}e^{-t}$.

Python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

# Example 1: y' = -y, y(0)=1 => y=e^-t
def f(t, y):
 return [-y[0]]

sol = solve_ivp(f, [0, 5], [1.0], dense_output=True)
t = np.linspace(0, 5, 200)
y_numerical = sol.sol(t)[0]
y_exact = np.exp(-t)

plt.plot(t, y_numerical, 'b-', label='Numerical solution')
plt.plot(t, y_exact, 'r--', label='Exact: $e^{-t}$')
plt.xlabel('t'); plt.ylabel('y(t)')
plt.legend(); plt.grid(True); plt.show()

# Example 2: a 2x2 system (harmonic oscillator)
# y'' + omega^2*y = 0 => [y', v'] = [v, -omega^2*y]
omega = 2.0
def harmonic(t, Y):
 y, v = Y
 return [v, -omega**2 * y]

sol2 = solve_ivp(harmonic, [0, 10], [1.0, 0.0],
 dense_output=True, max_step=0.1)
t2 = np.linspace(0, 10, 500)
Y2 = sol2.sol(t2)
plt.plot(t2, Y2[0], label='y(t) position')

SymPy — Derivative, Integral, Limit

Statement: Use SymPy to carry out symbolic computations: (a) compute derivatives of $f(x) = x^3 e^{-x} \sin x$, (b) find the integral $\int \frac{1}{1+x^2}\,dx$, (c) compute the limit $\lim_{x\to 0} \frac{\sin x}{x}$, (d) expand in a Taylor series about $x=0$ up to order 8.

Python
from sympy import symbols, diff, integrate, limit, solve
from sympy import sin, cos, exp, ln, pi, oo, simplify, series

x, t, n = symbols('x t n')

# Derivative
f = x**2 * sin(x)
fp = diff(f, x)
print("f'(x) =", fp) # 2*x*sin(x) + x^2*cos(x)

# Second derivative
fpp = diff(f, x, 2)
print("f''(x) =", fpp)

# Integral
g = x * exp(x)
print(integrate(g, x)) # (x-1)*exp(x)
print(integrate(g, (x, 0, 1))) # 1

# Limit
print(limit(sin(x)/x, x, 0)) # 1
print(limit((1+1/n)**n, n, oo)) # E = 2.718...

# Solving an equation
sols = solve(x**2 - 5*x + 6, x)
print("Roots:", sols) # [2, 3]

# Taylor (Maclaurin) series
print(series(sin(x), x, 0, 8))
# x - x^3/6 + x^5/120 - x^7/5040 + O(x^8)

SymPy — Linear Algebra and ODEs

Statement: Use SymPy to: (a) define a symbolic matrix $A$ and compute its determinant, inverse and eigenvalues, (b) compute the characteristic polynomial, (c) solve symbolically the linear ODE $y'' - 3y' + 2y = 0$.

Python
from sympy import Matrix, symbols, dsolve, Function, Eq, diff

x_s = symbols('x')

# Symbolic matrix
A = Matrix([[3, 1], [0, 2]])
print("det =", A.det()) # 6
print("inv =\n", A.inv())
print("eigenvals =", A.eigenvals()) # {2: 1, 3: 1}
print("eigenvects =\n", A.eigenvects())

# Characteristic polynomial
lam = symbols('lambda')
print("charpoly =", A.charpoly(lam)) # lambda^2 - 5*lambda + 6

# Symbolic solution of the ODE
y = Function('y')
ode = Eq(y(x_s).diff(x_s, 2) - 3*y(x_s).diff(x_s) + 2*y(x_s), 0)
sol = dsolve(ode, y(x_s))
print("Solution:", sol)
# y(x) = C1*exp(x) + C2*exp(2*x)

A Complete Linear Algebra Analysis

Statement: Let $P$ be the stochastic matrix of a Markov chain. Use NumPy to: (a) compute the eigenvalues and verify that the largest one is $\lambda=1$, (b) find the stationary distribution $\boldsymbol{\pi}$ as an eigenvector, (c) carry out many iterations, up to $P^{100}$, and confirm the convergence.

Python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import null_space

# The Markov matrix
P = np.array([[0.7, 0.1, 0.2],
 [0.2, 0.8, 0.1],
 [0.1, 0.1, 0.7]])

# Stationary distribution (column-stochastic): P*pi = pi => (P - I)*pi = 0
A = P - np.eye(3)
ker = null_space(A)
pi = ker[:,0] / ker[:,0].sum() # Normalization
print("Stationary distribution:", np.round(pi, 4))

# Evolution of the distribution
x0 = np.array([1., 0., 0.])
states = [x0]
for _ in range(50):
 x0 = P @ x0
 states.append(x0)
states = np.array(states)

plt.plot(states[:,0], label='State 1'); 
plt.plot(states[:,1], label='State 2')
plt.plot(states[:,2], label='State 3')
plt.axhline(pi[0], linestyle='--', color='blue')
plt.xlabel('Steps k'); plt.ylabel('Probability')
plt.title('Convergence of the Markov Chain')
plt.legend(); plt.grid(True); plt.show()

Symbolic + Numerical Computation

Statement: Show how SymPy and NumPy work together: (a) define a function $f(x)$ symbolically and find its derivative and integral analytically, (b) convert the symbolic results into numerical functions with lambdify, (c) draw the plot while also printing the formula in LaTeX.

Python
import numpy as np
import matplotlib.pyplot as plt
from sympy import symbols, sin, diff, integrate, lambdify, latex

x = symbols('x')

# Symbolic f and its derivatives
f_sym = sin(x**2)
fp_sym = diff(f_sym, x) # 2*x*cos(x^2)
fpp_sym = diff(f_sym, x, 2)

print("f'(x) =", fp_sym)
print("f''(x) =", fpp_sym)
print("LaTeX:", latex(fp_sym)) # 2 x \cos{\left(x^{2} \right)}

# Indefinite integral (no closed form -> Fresnel)
# Use numerical integration instead
from scipy.integrate import quad
F = lambda t: np.sin(t**2)
x_vals = np.linspace(0, 4, 200)
F_vals = [quad(F, 0, xi)[0] for xi in x_vals]

# Convert to numerical form for plotting
f_num = lambdify(x, f_sym, 'numpy')
fp_num = lambdify(x, fp_sym, 'numpy')

plt.figure(figsize=(10, 4))
plt.subplot(1,2,1)
plt.plot(x_vals, f_num(x_vals), 'b-', label=r'$\sin(x^2)$')
plt.plot(x_vals, fp_num(x_vals), 'r-', label=r"$f'(x)$")
plt.legend(); plt.grid(True); plt.title('Function and Derivative')

plt.subplot(1,2,2)
plt.plot(x_vals, F_vals, 'g-', label=r'$\int_0^x\sin(t^2)dt$')
plt.legend(); plt.grid(True); plt.title('Fresnel Integral')
plt.tight_layout(); plt.show()

Root-Finding and Minimization

Python
from scipy.optimize import fsolve, brentq, minimize
import numpy as np

# -- Root-finding: f(x) = cos(x) - x
f = lambda x: np.cos(x) - x
root = brentq(f, 0, 1)
print(f"Root (Brent): x = {root:.6f}")   # ~ 0.739085

# -- System of equations: x^2 + y^2 = 1, x - y = 0
def system(vars):
    x, y = vars
    return [x**2 + y**2 - 1, x - y]

sol = fsolve(system, [0.5, 0.5])
print(f"System: x={sol[0]:.4f}, y={sol[1]:.4f}")  # ~ 0.7071

# -- Minimization: f(x,y) = (x-1)^2 + (y-2)^2
def objective(v):
    return (v[0]-1)**2 + (v[1]-2)**2

result = minimize(objective, [0, 0], method='BFGS')
print(f"Minimum: x={result.x[0]:.4f}, y={result.x[1]:.4f}")  # -> (1, 2)
print(f"f_min = {result.fun:.6f}")

Constrained Optimization — An Engineering Example

Python
from scipy.optimize import minimize
import numpy as np

# Cost minimization: f = 2*x + 3*y
# Constraints: x + y >= 4,  x >= 1, y >= 1
def cost(v):
    return 2*v[0] + 3*v[1]

constraints = [
    {'type': 'ineq', 'fun': lambda v: v[0] + v[1] - 4},  # x+y >= 4
]
bounds = [(1, None), (1, None)]   # x>=1, y>=1

res = minimize(cost, [2, 2], method='SLSQP',
               constraints=constraints, bounds=bounds)
print(f"Optimum: x={res.x[0]:.3f}, y={res.x[1]:.3f}")
print(f"Minimum cost: {res.fun:.3f}")
