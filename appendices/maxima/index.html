Introduction: What Is Maxima?

Maxima is a Computer Algebra System (CAS): software that carries out mathematical operations symbolically, that is, exactly as a person would with pencil and paper, without truncating decimals.

Whereas a scientific computing environment (for example Python/NumPy or MATLAB) works numerically — it computes $\sqrt{2}\approx 1.41421\ldots$ — Maxima returns exactly sqrt(2), factors polynomials, integrates functions analytically and solves equations in closed form. This makes it particularly useful for:

  • Checking computations done by hand — you catch mistakes before the exam.
  • Exploring mathematical concepts — for example, how does the solution of an ODE change if the initial condition changes?
  • Computing limits, derivatives and integrals that are time-consuming by hand.
  • Geometric visualization with built-in 2D/3D plots.

History: Maxima descends from Macsyma, the first CAS, developed at MIT in the 1960s. Today it is distributed as free software (GNU GPL) and is one of the most complete free alternatives to commercial systems such as Mathematica or Maple.

For a deeper study and an extensive presentation of the Maxima commands, see the relevant references in the book.

💡 Maxima vs Python/NumPy — When to use which?

  • Use Maxima when: you want an exact analytical answer, you need to check a theoretical result, or you are working with parameters (for example, integrate $\int x^n\,dx$ for general $n$).
  • Use Python/NumPy when: you need a numerical result for a large matrix, you want to produce high-quality plots, or the function has no closed form.
  • Ideally: use the two of them together!

Getting Started with Maxima

Maxima is a free computer algebra system (CAS — Computer Algebra System), available for Windows, macOS and Linux. It was developed at MIT as "Macsyma" in the 1960s and is distributed today as open-source software. Its graphical front end, wxMaxima, offers a friendly interface with results displayed in mathematical notation.

Installation

  1. Go to https://wxmaxima-developers.github.io/wxmaxima/
  2. Download the installer for your operating system.
  3. Install it — Maxima itself is included automatically.

Basic Syntax Rules

  • Every command ends with a semicolon ; or a dollar sign $ (no printed output).
  • Comments: /* text */
  • Assignment: a : 5 (with a colon)
  • Function definition: f(x) := x^2 + 1
  • The symbol % refers to the last result.
  • float(…) converts to a decimal number.
  • Execution: Shift+Enter in wxMaxima.

First Commands in Maxima

Statement: Open Maxima or wxMaxima and run the following basic commands: (a) arithmetic operations and numerical constants ($\pi$, $e$), (b) computing factors, roots and powers, (c) defining a variable and a function. Notice the difference between symbolic and numerical evaluation.

Maxima
/* Arithmetic operations */
2 + 3; /* 5 */
sqrt(2); /* sqrt(2) -- symbolic */
float(sqrt(2)); /* 1.41421356... */

/* Function definition */
f(x) := x^2 - 3*x + 2;
f(3); /* 2 */
f(a+1); /* (a+1)^2 - 3*(a+1) + 2 */

/* Note: Maxima keeps results exact */
1/3 + 1/6; /* 1/2 */

Algebraic Operations — Examples

Statement: Use Maxima for algebraic operations: (a) simplify algebraic expressions with expand and factor, (b) solve equations and inequalities with solve, (c) factor polynomials. Compare the results with computations done by hand.

Maxima
/* Factorization */
factor(x^3 - 3*x^2 + 3*x - 1); /* (x-1)^3 */

/* Trigonometric simplification */
trigsimp(sin(x)^2 + cos(x)^2); /* 1 */

/* Solving an equation */
solve(x^2 - 5*x + 6 = 0, x); /* [x=2, x=3] */

/* Substitution */
f(x) := x^3 - 2*x;
ev(f(x), x = sqrt(2)); /* 0 */

Basic Matrix Operations

Statement: Use Maxima for matrix operations: (a) define a matrix with matrix, (b) multiply matrices with the . operator, (c) compute the determinant with determinant and the inverse with invert. Verify that $A \cdot A^{-1} = I$.

Maxima
/* Defining matrices */
A: matrix([2, 1], [5, 3]);
B: matrix([3, -1], [-5, 2]);

/* Multiplication */
A . B; /* matrix([1,0],[0,1]) -- they are inverses! */

/* Determinant */
determinant(A); /* 1 */

/* Inverse */
invert(A); /* matrix([3,-1],[-5,2]) */

/* Check: A * A^(-1) = I */
A . invert(A); /* ident(2) */

/* Transpose */
C: matrix([1,2,3],[4,5,6]);
transpose(C); /* matrix([1,4],[2,5],[3,6]) */

A $3\times3$ Linear System with Maxima

Statement: Use Maxima to solve the $3\times3$ linear system: define the coefficient matrix $A$ and the right-hand-side vector $\mathbf{b}$, and find the solution $\mathbf{x} = A^{-1}\mathbf{b}$ using linsolve. Check the result by computing $A \cdot \mathbf{x}$.

Maxima
load("linearalgebra");

/* System: 2x+y-z=8, 3x+2y+z=11, x-y+2z=-3 */
A: matrix([2, 1, -1], [3, 2, 1], [1, -1, 2]);
b: matrix([8], [11], [-3]);

/* Method 1: linsolve */
linsolve([2*x+y-z=8, 3*x+2*y+z=11, x-y+2*z=-3], [x,y,z]);
/* [x=2, y=3, z=-1] */

/* Method 2: inverse matrix (valid only if det(A) # 0) */
determinant(A); /* 10 */
invert(A) . b; /* matrix([2],[3],[-1]) */

/* Analysis: echelon form of the augmented matrix [A|b] */
echelon(addcol(A, b));

/* Kernel (homogeneous system) */
nullspace(A); /* span() -- only the zero solution, since det(A) # 0 */

Eigenvalues and Eigenvectors

Statement: Let $A = \begin{pmatrix}4&1\\2&3\end{pmatrix}$. Use Maxima to: (a) compute the characteristic polynomial with charpoly, (b) find the eigenvalues with eigenvalues, (c) compute the eigenvectors with eigenvectors. Interpret the results.

Maxima
A: matrix([4, 1], [2, 3]);

/* Characteristic polynomial */
expand(charpoly(A, lambda)); /* lambda^2 - 7*lambda + 10 */

/* Eigenvalues */
eigenvalues(A); /* [[5, 2], [1, 1]] => l1=5 (mult. 1), l2=2 (mult. 1) */

/* Eigenvectors */
eigenvectors(A);
/* For l=5: v=[1,1]; for l=2: v=[1,-2] (equivalently [-1,2]) */

/* Check: A*v = l*v */
v1: matrix([-1], [2]);
A . v1; /* 2 * v1 */

Derivative, Limit and Taylor Series

Statement: Use Maxima for symbolic differential calculus: (a) compute derivatives of various orders of $f(x) = x^3 e^{-x}$ with diff, (b) find limits with limit, including limits at infinity, (c) expand in a Taylor series about $x_0 = 0$ with taylor.

Maxima
/* Derivative */
f(x) := x^2 * sin(x);
diff(f(x), x); /* 2*x*sin(x) + x^2*cos(x) */

/* Chain rule */
g(x) := exp(x^2 + 1);
diff(g(x), x); /* 2*x*exp(x^2+1) */

/* Second derivative */
diff(f(x), x, 2);

/* Limits */
limit(sin(x)/x, x, 0); /* 1 */
limit((1+1/n)^n, n, inf); /* %e */
limit(exp(-x), x, inf); /* 0 */

/* L'Hopital's rule */
limit((exp(x)-1)/x, x, 0); /* 1 */

/* Taylor about x=0, order 5 */
taylor(sin(x), x, 0, 5);
/* x - x^3/6 + x^5/120 + ... */

/* Numerical root */
find_root(x^3 - 2, x, 1, 2); /* 1.259921... */

Indefinite and Definite Integrals

Statement: Use Maxima to compute integrals: (a) indefinite integrals of composite functions with integrate, (b) definite integrals over an interval, (c) integrals involving trigonometric and exponential functions. Check the results by differentiating.

Maxima
/* Indefinite integral */
integrate(x^2, x); /* x^3/3 */
integrate(sin(x)*exp(x), x); /* exp(x)*(sin(x)-cos(x))/2 */
integrate(1/(x^2-1), x); /* log(x-1)/2 - log(x+1)/2 */

/* Definite integral */
integrate(x^2, x, 0, 1); /* 1/3 */
integrate(sin(x), x, 0, %pi); /* 2 */

/* Improper integral */
integrate(exp(-x^2), x, 0, inf); /* sqrt(%pi)/2 */

/* Numerical integration (when there is no closed form) */
romberg(exp(-x^2), x, 0, 1); /* 0.7468241... */

Differential Equations — Separable and Second-Order

Statement: Use Maxima to solve differential equations: (a) a separable first-order ODE with ode2, (b) a linear second-order ODE with constant coefficients, (c) an initial value problem with ic1 and ic2. Plot the solution with plot2d.

Maxima
/* First-order ODE: dy/dx = -y */
depends(y, x);
ode1: diff(y,x) + y = 0;
sol1: ode2(ode1, y, x); /* y = %c * exp(-x) */

/* With the initial condition y(0)=2 */
ic1(sol1, x=0, y=2); /* y = 2*exp(-x) */

/* Second-order ODE: y'' - 3y' + 2y = 0 */
ode2_eq: diff(y,x,2) - 3*diff(y,x) + 2*y = 0;
sol2: ode2(ode2_eq, y, x);
/* y = %k1*exp(x) + %k2*exp(2*x) */

/* With the initial conditions y(0)=1, y'(0)=0 */
ic2(sol2, x=0, y=1, diff(y,x)=0);
/* y = 2*exp(x) - exp(2*x) */

/* Bernoulli ODE: y' + y/x = y^2 */
ode_bern: diff(y,x) + y/x = y^2;
ode2(ode_bern, y, x);

Series and Sequences

Statement: Use Maxima to work with sequences and series: (a) define a sequence and compute its first terms, (b) study the convergence of a geometric series with sum, (c) evaluate infinite sums (inf) — for example $\sum_{n=1}^{\infty} \frac{1}{n^2}$. Interpret the results.

Maxima
/* Numerical series */
ev(sum(1/k^2, k, 1, inf), simpsum); /* %pi^2/6 -- without simpsum it stays unevaluated */
sum(1/k, k, 1, 10); /* 7381/2520 */

/* Taylor series of sin(x) about 0 */
taylor(sin(x), x, 0, 7);
/* x - x^3/6 + x^5/120 - x^7/5040 */

/* Series for exp(x) */
taylor(exp(x), x, 0, 5);
/* 1 + x + x^2/2 + x^3/6 + x^4/24 + x^5/120 */

/* Radius of convergence by the ratio test */
f(n) := 1/n!;
float(limit(f(n+1)/f(n), n, inf)); /* 0 => radius = +inf */

/* Power series */
powerseries(atan(x), x, 0);

Diagonalizing a Matrix

Maxima
/* Define the matrix */
A : matrix([4, 1], [2, 3]);

/* Eigenvalues and eigenvectors */
[vals, vecs] : eigenvectors(A);
print("Eigenvalues:", vals);
print("Eigenvectors:", vecs);

/* Eigenvector matrix P */
P : transpose(matrix(vecs[1][1], vecs[2][1]));

/* Check: A = P * D * P^(-1) */
D : matrix([vals[1][1], 0], [0, vals[1][2]]);
print("Check A = P*D*P^-1:", ratsimp(P . D . invert(P) - A));

The Matrix Exponential and the Jordan Normal Form

Maxima
/* Matrix exponential e^(At) */
load("diag");
A : matrix([0, 1], [-1, 0]);   /* harmonic oscillator */
eAt : matrixexp(A * t);
print("e^(At) =", eAt);
/* the result comes out in complex exponential form;
   it is equivalent to matrix([cos(t), sin(t)], [-sin(t), cos(t)]) */

/* Jordan normal form (for a non-diagonalizable matrix) */
B : matrix([3, 1], [0, 3]);    /* double eigenvalue */
JB : jordan(B);
print("Jordan(B) =", dispJordan(JB));

Complex Numbers

Statement: Use Maxima to work with complex numbers: (a) define complex numbers and carry out arithmetic operations, (b) find the modulus, the conjugate and the argument, (c) express a complex number in polar form $r e^{i\theta}$ and apply De Moivre's formula. Verify that $e^{i\pi} + 1 = 0$.

Maxima
/* Definition: %i is the imaginary unit i */
z1: 3 + 4*%i;
z2: 1 - 2*%i;

/* Basic operations */
rectform(z1 * z2); /* 11 - 2*%i */
rectform(z1 / z2); /* -1 + 2*%i */
rectform(z1^2); /* -7 + 24*%i */

/* Modulus and argument */
abs(z1); /* 5 */
float(carg(z1)); /* 0.9272952... = arctan(4/3) */

/* Polar form */
polarform(z1); /* 5 * exp(%i*arctan(4/3)) */

/* De Moivre's theorem */
z: cos(%pi/6) + %i*sin(%pi/6);
rectform(z^6); /* -1 = exp(%i*%pi) */

Plotting with Maxima

Statement: Use the plotting commands of Maxima: (a) plot a single function with plot2d — for example $f(x) = x \sin x$ on $[0, 4\pi]$, (b) draw several curves in the same figure with different colors, (c) draw a three-dimensional surface $f(x,y)$ with plot3d.

Maxima
/* Simple plot */
plot2d(sin(x), [x, -%pi, %pi]);

/* Two functions together */
plot2d([sin(x), cos(x)], [x, 0, 2*%pi],
 [legend, "sin(x)", "cos(x)"],
 [xlabel, "x"], [ylabel, "y"]);

/* Function and its derivative */
f(x) := x^3 - 3*x;
plot2d([f(x), diff(f(x),x)], [x,-2,2],
 [legend, "f(x)", "f'(x)"],
 [color, blue, red]);

/* Three-dimensional plot */
plot3d(sin(x)*cos(y), [x, 0, 2*%pi], [y, 0, 2*%pi]);

/* Numerical solution and plot of an ODE */
depends(y, x);
sol: ode2(diff(y,x) + y = sin(x), y, x);
sol_part: ic1(sol, x=0, y=0);
plot2d(rhs(sol_part), [x, 0, 4*%pi]);

Root-Finding and Numerical Integration

Maxima
/* Root-finding for f(x)=cos(x)-x on [0,1] */
f(x) := cos(x) - x;
r : find_root(f, x, 0, 1);
print("Root:", float(r));    /* ~ 0.7391 */

/* Newton's method: f(x)=x^3-2, x0=1 */
load("newton1");
g(x) := x^3 - 2;
x_newton : newton(g(x), x, 1, 1e-10);
print("Newton:", float(x_newton));  /* ~ 1.2599 */

/* Numerical integration: int_0^1 exp(-x^2) dx */
h(x) := exp(-x^2);
I : romberg(h(x), x, 0, 1);
print("Integral:", float(I));    /* ~ 0.7468 */

Numerical Solution of ODE Systems — Runge-Kutta

Maxima
/* Solve y'=-2*y, y(0)=1 with RK4, step h=0.1 */
sol_rk : rk([-2*y], [y], [1], [t, 0, 2, 0.1]);

/* sol_rk: a list of [t, y(t)] pairs */
/* Print the first 5 points */
for i:1 thru 5 do
  print("t=", sol_rk[i][1], " y=", sol_rk[i][2]);

/* Exact solution for comparison */
y_exact(t) := exp(-2*t);
print("Error at t=0.5:",
  abs(sol_rk[6][2] - y_exact(0.5)));
