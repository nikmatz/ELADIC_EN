    Finding Local Extrema

    A point x₀ is critical if f ′(x₀) = 0 or f ′(x₀) does not exist.

    First Derivative Test: if f ′ changes sign at x₀, then x₀ is an extremum.
    f ′: + → − ⟹ local maximum · f ′: − → + ⟹ local minimum
    Second Derivative Test: if f ′(x₀) = 0, then:
    f ″(x₀) > 0 ⟹ local minimum  ·  f ″(x₀) < 0 ⟹ local maximum
    f ″(x₀) = 0 ⟹ inconclusive (check with the first derivative or higher-order derivatives)

    Move the slider to see how f(x), f ′(x) and f ″(x) change at each point. At the critical points the tangent line is horizontal (f ′= 0).
