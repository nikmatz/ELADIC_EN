Gaussian Elimination — Row Echelon Reduction (REF)

The augmented matrix [A|b] is brought to row echelon form by three permitted row operations:

Ri ↔ Rj  ·  Ri ← λ·Ri (λ≠0)  ·  Ri ← Ri + λ·Rj

Color coding: ■ blue = pivot row · ■ orange = row being changed · ■ green = new zero.

Kronecker–Capelli theorem: the system Ax=b is consistent ⟺ rank(A) = rank([A|b])
