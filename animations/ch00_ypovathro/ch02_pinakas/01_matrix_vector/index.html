Linear Transformation — $A\mathbf{x}$

Chapter 2 · Matrix Algebra · Elements of LA & Calculus

What does this animation show?

Drag the vector $\mathbf{x}$ (orange) and see how the matrix $A$ transforms it into $A\mathbf{x}$ (green). Change the entries of the matrix with the sliders.

The unit square is shown in gray and its image under $A$ in green; the arrows $A\mathbf{e}_1$ (purple) and $A\mathbf{e}_2$ (pink) are exactly the columns of $A$. This is how a matrix is read geometrically.

Matrix × Vector Multiplication

The product Ax (A: m×n, x: n×1) gives a new vector y = Ax (m×1).

yᵢ = Σⱼ Aᵢⱼ·xⱼ  ·  Geometrically: a linear transformation of x

Each column of A shows where the corresponding basis vector goes. Move x to see how Ax changes.
