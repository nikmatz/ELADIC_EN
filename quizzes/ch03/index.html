10 questions on Gaussian elimination, echelon form, the Rouché–Capelli theorem, Cramer's rule and LU factorization.

Question 1 / 10

When is a linear system $Ax=b$ consistent?

✓ Answer: b) When $\mathrm{rank}(A)=\mathrm{rank}(A|b)$
Rouché–Capelli theorem: the system is consistent if and only if $\mathrm{rank}(A)=\mathrm{rank}(A|b)$.
Question 2 / 10

A homogeneous system $Ax=0$ always has the solution $x=0$.

✓ Answer: Correct
The zero vector $x=0$ is always a solution of every homogeneous system.
Question 3 / 10

If $Ax=b$ with $\mathrm{rank}(A)=\mathrm{rank}(A|b)=r<n$ ($n$: number of unknowns), then the system:

✓ Answer: c) has $\infty$ many solutions with $n-r$ free parameters
If rank = r < n, then there are $n-r$ free unknowns, hence infinitely many solutions.
Question 4 / 10

Which operation is NOT allowed in Gaussian elimination?

✓ Answer: d) Multiplying a row by 0
Multiplying a row by 0 destroys information and is not an elementary row operation.
Question 5 / 10

In the row echelon form of a matrix, each row has its pivot to the right of the pivot of the previous row.

✓ Answer: Correct
This is precisely the definition of the row echelon form.
Question 6 / 10

Cramer's rule applies only if:

✓ Answer: c) $\det(A)\neq0$ (square matrix)
Cramer's rule requires a square matrix with $\det(A)\neq 0$.
Question 7 / 10

In the LU factorization $A=LU$, the matrix $L$ is:

✓ Answer: b) lower triangular with 1s on the diagonal
$L$: lower triangular with 1s on the diagonal. $U$: upper triangular.
Question 8 / 10

A $3\times4$ system cannot have a unique solution.

✓ Answer: Correct
With 3 equations and 4 unknowns, rank ≤ 3 < 4, so there is at least $4-3=1$ free unknown.
Question 9 / 10

If the system $Ax=b$ has a unique solution, how many solutions does $Ax=0$ have?

✓ Answer: b) Only $x=0$
If $Ax=b$ has a unique solution, then $\det A\neq 0$, so $Ax=0$ has only $x=0$.
Question 10 / 10

After Gaussian elimination, the matrix $\begin{pmatrix}1&2&|&3\\0&0&|&5\end{pmatrix}$ means that the system:

✓ Answer: c) has no solution
The second row gives $0=5$, a contradiction. The system is inconsistent (it has no solution).
