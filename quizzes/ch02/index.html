10 questions on operations, the determinant, the inverse, rank and special forms of matrices.

Question 1 / 10

If $A$ is $2\times3$ and $B$ is $3\times4$, then $AB$ has dimensions:

✓ Answer: a) $2\times4$
$(2\times3)(3\times4)$: the inner dimensions (3,3) agree, so the product is defined and has dimensions $2\times4$.
Question 2 / 10

Matrix multiplication is commutative (i.e. $AB=BA$ always).

✓ Answer: Incorrect
In general $AB\neq BA$. For example, if $A=\begin{pmatrix}1&1\\0&0\end{pmatrix}$ and $B=\begin{pmatrix}0&1\\0&1\end{pmatrix}$, then $AB\neq BA$.
Question 3 / 10

If $\det(A)=0$, then the matrix $A$:

✓ Answer: b) is NOT invertible
$A$ is invertible $\Leftrightarrow$ $\det(A)\neq 0$. If $\det(A)=0$, then $A$ is non-invertible (singular).
Question 4 / 10

Which statement about the determinant is true?

✓ Answer: b) $\det(AB)=\det A\cdot\det B$
$\det(AB)=\det A\cdot\det B$ (multiplicativity). The others are false.
Question 5 / 10

For every matrix $A$: $\det(A^T)=\det(A)$.

✓ Answer: Correct
A basic property: the determinant is unchanged by transposition. $\det(A^T)=\det(A)$.
Question 6 / 10

The rank of a $3\times3$ matrix with $\det=0$ can be:

✓ Answer: c) 0, 1 or 2
$\det=0$ means $\mathrm{rank}<3$, so $\mathrm{rank}\in\{0,1,2\}$.
Question 7 / 10

If $A^{-1}$ exists, which statement is true?

✓ Answer: b) $AA^{-1}=I$
By definition: $AA^{-1}=A^{-1}A=I$.
Question 8 / 10

Every symmetric matrix has real eigenvalues.

✓ Answer: Correct
Spectral theorem: every real symmetric matrix has real eigenvalues.
Question 9 / 10

At most how many nonzero entries does an $n\times n$ diagonal matrix have?

✓ Answer: c) $n$
In a diagonal matrix only the $n$ diagonal entries can be nonzero.
Question 10 / 10

If $A=A^T$, then $A$ is called:

✓ Answer: c) symmetric
$A=A^T$ is the definition of a symmetric matrix. (Orthogonal: $A^TA=I$; skew-symmetric: $A=-A^T$.)
